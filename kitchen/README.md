# 밥 짓는 집 (가칭) — 링크로 들어오는 온라인 부엌

누구나 링크 하나로 들어와(로그인 없음) 귀여운 요리사가 되어 일거리를 하고, 3분마다 다 같이 "잘 먹겠습니다" 하는 곳.
**아직 공개 전이에요.** 공개(주소 배포)는 회장님 결재 뒤에 해요. 지금은 검색에 안 나오게 막아 두었어요 (`index.html` 의 noindex, `_headers`).

## 쉬운 설명 (1분)
- **왜:** 온라인 절처럼 "혼자인데 함께"인 곳. 사업 연결은 문패 하나(누르면 쏠 인스타그램)뿐, 광고·판매 없음.
- **어떻게:** 입장 화면에서 "이 안에서 불릴 이름"(음식 별명이 미리 채워짐, 🎲로 다시 뽑기)만 적고 [들어가기]. [일거리]에서 나물 다듬기·불 지피기·고추 따기 같은 일을 고르고 화면을 톡톡. 2분이 되면 주인 쏠이 "밥 됐어요~~~" 하고 불러요. [밥 먹으러 가기]를 누른 사람은 큰 상에 앉고, 30초 뒤 상에 앉은 사람과 식구들만 다 같이 "잘 먹겠습니다" + 오늘의 한 그릇 카드(요리 이름만). 다 먹으면 [일거리로 돌아가기].
- 매일 저녁 7시(한국 시간) 30분은 "다 같이 저녁 짓는 시간": 쏠이 부엌 가운데에서 한 줄씩 글 방송 (`live.js`).
- **회장님이 할 일:** 공개할 때 Cloudflare 로그인 한 번 (아래 "공개할 때").

## 쓰는 법 · 미리 보기 주소
- 기본: `index.html` (한옥)
- 다른 장소: `?place=tuscany` · `?place=paris`
- 밤으로 보기: `?hour=21` (장소 현지 시각 대신)
- 밥 부르기 직전부터: `?at=118` (솥 한 바퀴 118초 지점부터)
- 저녁 짓는 시간 미리 보기: `?live=1` (인스타 라이브 버튼까지: `?live=1&insta=1`)
- 이 컴퓨터에서만 서버 시험: `?server=ws://localhost:8787` (localhost 에서 열 때만 됨)

## 솥 한 바퀴 (3분, 모든 사람 같은 때 — 서버 없이 시계로 계산)
0:00 요리·일거리 → 2:00 쏠 "밥 됐어요~~~" + [밥 먹으러 가기] → 2:30 상에 앉은 사람 + 연출 캐릭터만 "잘 먹겠습니다", 카드 → 2:56 다 먹음, [일거리로 돌아가기] → 3:00 다음 솥.
상이 꽉 차면 앞쪽에 상을 하나 더 펴요 (최대 4상).

## 캐릭터
- **손님:** 진짜 사람만. 서버가 없으면 나 혼자 (가짜 손님 없음).
- **연출 캐릭터 (사람 수에 안 셈, 이름표 = 역할):** 모든 장소에 주인 **쏠**(임시 모습 — 디자인 시안 확정 뒤 바꿈) + 한옥 종갓집 할머니·막내 며느리 / 토스카나 논나·농부 아저씨(창밖) / 파리 파티시에·빵집 견습생. 미엘(고양이)은 모든 장소.

## 바꾸는 곳
- 별명: `names.js` 목록만 / 카드: `cards/장소.js` (화면에는 요리 이름만 나옴. line·tip·inBook 은 보이지 않음)
- 손님 옷: `places.js` 의 `guest` (한옥 파스텔 한복 + 짧은 앞치마 · 토스카나 린넨 + 밀짚모자 · 파리 흰 제빵복 + 모자). 장소를 바꾸면 옷도 바뀜
- 저녁 방송 글·인스타 라이브 날짜: `live.js` (`instaLive.dates` 에 'YYYY-MM-DD' 넣으면 그날 버튼이 뜸)
- 문패 글자: `places.js` 의 `plate` (한옥 "SOLL BUEOK / 쏠키친 · 쏠의 부엌", 나머지 "SOLL KITCHEN · 쏠키친")
- 일거리 자리: `places.js` 의 `jobs` (자리 위치·동작·소리)
- 한마디 금지 낱말: `notes-rules.js`

## 밥상 한마디
- 쓰기 창 "오늘 어떤 하루였어요?" (100자, 하루 3개). "이름 없이 나누기"가 기본으로 켜져 있음.
- 60일까지 보이고 그 뒤 서버에서 지워짐. 하루 개수 확인용 해시는 다음 날 지움 (이름·기기 정보 없이).
- 내가 올린 글은 이 기기에 "내리기 열쇠"가 저장돼 언제든 [내리기]. 남의 글에는 [토닥 n] · [한 줄 답하기](50자) · [신고](3번이면 숨김, 답도 같음).
- 서버가 없으면 쓰기만 막고 "첫 한마디를 남겨 주세요" 안내. 가짜 예시 글은 넣지 않음.

## 공개할 때 (결재 뒤, 순서)
1. 화면 올리기: Cloudflare Pages 새 프로젝트, 출력 폴더 `kitchen` (빌드 없음). `worker/` 는 올라가도 비밀 값이 없지만, 따로 두려면 Pages 대신 이 폴더만 복사해 올림.
2. 서버 올리기 (회장님 로그인 필요): `cd kitchen/worker && npx wrangler login && npx wrangler deploy` → 나온 주소를 `config.js` 의 `SERVER` 에 `wss://…` 로 넣고, `wrangler.toml` 의 `ALLOWED_ORIGIN` 을 화면 주소로.
3. noindex 두 곳 지우기 (`index.html` 의 robots 줄, `_headers`).
- 무료 한도: Cloudflare 무료 Durable Object(SQLite) 사용. 하루 요청 6만 건(`DAILY_LIMIT`)이 넘으면 그날은 모두 구경 모드. 같은 Cloudflare 계정의 다른 Worker 와 한도를 같이 써요.
