부모님께: 사진 읽기 켜는 법

공부 루틴은 계획·타이머·복습 카드는 무료예요. 틀린 문제를 찍으면 원인과 풀이를 알려 주는 사진 읽기만 Claude AI를 써서, 쓰는 집마다 각자 결제합니다.

걸리는 시간약 10분
사진 1장 정리약 100원
한 달 (하루 3장)약 1만 원

1달러 1,400원으로 계산한 대략값이에요. 미리 충전한 만큼만 쓰이고, 다 쓰면 멈춥니다.

준비물

  • 부모님 이메일 (Claude API 계정은 만 18세 이상만 만들 수 있어요)
  • 해외 결제가 되는 카드 (Visa·Mastercard 등)
  • 아이 아이패드·휴대폰 (공부 루틴이 홈 화면에 있는 것)

  1. 가입하기

    platform.claude.com 에 들어가 이메일이나 Google 계정으로 가입합니다.

    화면이 영어일 수 있어요. 메뉴 이름은 조금 다를 수 있습니다.

  2. 충전하기

    • 왼쪽 메뉴(휴대폰은 ☰)의 Billing에서 카드를 등록하고 5달러쯤 충전합니다.
    • 자동 충전(Auto reload)은 끄세요. 그러면 충전한 돈 이상은 나가지 않아요.

  3. 키 만들기

    • API Keys → Create Key를 누르고 이름을 공부루틴으로 정합니다.
    • sk-ant-로 시작하는 긴 글자가 나오면 복사합니다. 이 화면을 닫으면 다시 볼 수 없어요.

  4. 아이 기기에 넣기

    • 아이 기기에서 공부 루틴 → 오른쪽 위 톱니바퀴(설정) → AI 연결에 붙여 넣고 저장.
    • 아이패드와 휴대폰을 같이 쓰면 두 기기에 각각 넣어 주세요.

키는 비밀번호처럼 다뤄 주세요. 키가 있으면 누구나 그 계정으로 AI를 쓸 수 있어요. 카톡으로 보내기보다 아이 기기에 직접 넣어 주세요. 새어 나갔다면 API Keys에서 그 키를 지우고 새로 만들면 됩니다.

자주 묻는 것

다른 집 사용료가 우리에게 나오나요?
아니요. 각 기기에 넣은 키의 계정으로만 나갑니다. 키는 그 기기에만 저장되고 다른 기기로 넘어가지 않아요.

얼마나 썼는지 볼 수 있나요?
platform.claude.com의 Usage나 Billing에서 볼 수 있어요.

안 넣으면요?
계획, 타이머, 복습 카드는 그대로 쓸 수 있어요. 틀린 문제 사진도 저장은 되고, 원인 분석과 풀이만 빠집니다.
