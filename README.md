# 공부 루틴

군포고 1학년 학생용 아이패드 공부 앱(1단계)입니다. 설치나 서버가 필요 없는 정적 웹앱이고, 기록은 아이패드 브라우저 안(IndexedDB)에 저장됩니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 오늘 | 아침 10분 목록(오늘 다시 볼 진도와 다시 풀 오답), 방과 후 블록 체크리스트 |
| 진도 기록 | 매일 수업에서 나간 범위를 입력합니다. 1·3·7·14·30일 후에 복습 목록에 자동으로 다시 나옵니다. |
| 수학 | 오답 사진 등록(2·7·14·30일 후 재출제, 틀리면 처음부터), "꼬임 유형" 통계, 조건 해석 훈련(하루 3문제), 쎈 공통수학2 진도표 |
| 시험 모드 | 시험 날짜와 범위를 입력하면 D-21부터 방과 후 블록이 시험 대비용으로 바뀝니다. |
| 설정 | 과목 편집, 백업 파일 내보내기/불러오기 |

시험 범위가 미리 나오지 않기 때문에 **매일 진도를 기록하는 것**이 핵심입니다. 이렇게 쌓인 기록이 복습 일정이 되고, 시험 범위가 공지되면 그대로 시험 범위 자료가 됩니다.

## 아이패드에서 쓰는 법

1. 이 저장소에서 GitHub Pages를 켭니다. Settings → Pages → Branch를 이 브랜치(또는 main)의 `/ (root)`로 지정하세요.
2. 아이패드 Safari로 주소를 열고, 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 일주일에 한 번 **설정 → 백업 파일 받기**를 합니다. Safari 기록을 지우면 데이터도 지워지기 때문입니다.

로컬에서 확인할 때: `python3 -m http.server` 실행 후 `http://localhost:8000`을 엽니다.

## 수학 프로그램 (쎈 사용, 현재 70점대 중반 → 목표 85점 이상)

1. **개념**: 매일 백지 설명 5~15분. 공식이나 정의를 설명하지 못하면 다음 단계로 넘어가지 않습니다.
2. **유형 (쎈 A → B)**: B단계 **오답 0개**가 될 때까지 반복합니다. 틀린 문제는 사진을 찍어 앱에 등록합니다.
3. **조건 해석 훈련**: 하루 3문제. 풀지 말고 조건 수, 숨은 조건, 단원만 적습니다. 꼬인 문제에서 놓치는 부분은 대부분 조건이기 때문입니다.
4. **실전**: 시험 3주 전부터 쎈 C 선별, 군포고 기출, 변형 문제를 시간을 재고 풉니다. 틀린 문제에는 "어디서 꼬였나"를 한 줄로 남깁니다.
