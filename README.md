# 공부 루틴

군포고 1학년 학생용 **개인 맞춤형 학습 관리** 웹앱입니다. 아이패드에서 씁니다.

공부 시간을 기록하는 플래너가 아니라, 과목별 현재 상태와 실제 공부 속도를 바탕으로 **오늘 무엇을 어떻게 공부할지 정하고**, 계획이 틀어지면 **다음 계획을 자동으로 고치는** 구조입니다.
(진단 → 계획 → 실행 → 기록 → 분석 → 재계획)

설치나 서버가 필요 없는 정적 웹앱입니다. 기록은 각 기기 브라우저(IndexedDB)에 먼저 저장되고, Google로 로그인하면 **아이패드, 아이 휴대폰, 부모님 휴대폰이 같은 기록을 봅니다** (Firebase, 무료). 설정 방법은 [FIREBASE_SETUP.md](FIREBASE_SETUP.md)를 보세요.

## 쓰는 법

**처음 한 번:** 다음 시험 날짜, 평일·주말 공부 시간, 쓰는 책과 "지금 어디까지 했는지"를 버튼으로 고릅니다. 숫자를 쓸 필요는 없습니다.

**그다음:** 계획 탭에 시험까지 단계별 계획과 이번 주 목표가 나오고, 오늘 탭에 그날 할 공부가 나옵니다.
- 다 하면 그냥 둡니다. 하루가 지나면 다 한 것으로 자동 기록됩니다. 못 한 것만 "못 했어요"를 누릅니다.
- **사진 올리기** 하나로 오늘 배운 곳(→ 복습 카드), 채점한 문제(→ 진도·정답률), 틀린 문제(→ 다시 풀기), 시험 공지(→ 과목별 시험일·범위), 책 목차(→ 분량)를 알아서 나눠 기록합니다.
- 이해도·암기 상태는 복습 카드 결과와 정답률로 자동 계산합니다. 학생이 스스로 매기지 않습니다.

| 탭 | 내용 |
|---|---|
| 오늘 | 한눈에 보기, 사진 올리기, 오늘 떠올릴 것 카드, 오늘 할 공부 |
| 계획 | 이번 시험 단계별 계획, 이번 주 목표, 과목별 한마디, 과목별 시험 날짜 |
| 내 책 | 책별 진도. 틀렸을 때만 눌러서 고치기 |
| 더보기 | 틀린 문제 모음, 복습 카드, 수행평가, 공부 기록, 설정 |

사진 읽기는 Claude 안에서 열면 바로 됩니다. Claude 밖(GitHub 주소)에서는 [AI_SETUP.md](AI_SETUP.md)의 작은 서버(`worker/`)가 필요합니다.

## 계획이 정해지는 방식 (`planner.js`)

- **오늘 계획량** = 요일별 공부 가능 시간 × 컨디션(좋음 1, 보통 0.85, 피곤 0.7) × 최근 7일 수행률(0.6~1.0)
- **교재별 우선순위 점수** = 중요도 × 단계 보정 × (1 + 2×남은 양 압박 + 시험 임박도 + 1.2×취약도 + 0.8×학습 공백 + 주간 할당 밀림)
  - 취약도: 교과서는 개념 이해도, 암기·단어는 암기 상태, 문제집은 정확도로 계산
  - 과목 단계가 "오답"이면 새 진도 대신 오답 쪽으로 기울임
  - 끝낸 문제집은 배정하지 않고, 쌓인 오답 정리를 대신 배정
- **하루 분량** = 남은 양 ÷ (시험까지 남은 날 − 2일 여유). 주간 할당 교재는 이번 주 남은 양 ÷ 남은 요일. 한 번에 30~90분
- 같은 과목은 하루 최대 2과제. 간격 복습, 오답 사진, 임박한 수행평가가 먼저 들어감
- **기록하면**: 교재 진도와 정확도가 갱신되고, 단위당 예상 시간이 실제 속도로 보정됨 (이전 값 70% + 이번 값 30%). 못 한 양은 다음 계획에 자동으로 다시 배정됨

## 처음 들어가 있는 교재 (`seed.js`)

- 국어: 모의고사 주 2회, 학원 숙제 주 250문제
- 수학: 쎈, 마플시너지(오답만), 고쟁이, 족보닷컴 군포고 기출(시험 21일 전부터)
- 영어: 지문 암기 주 7개, 학원 단어, 워드마스터, 시험 범위 지문 전체 분석 20개(시험 14일 전부터)
- 통합사회, 통합과학, 한국사: 교과서(·PPT) 빈칸 암기, 기출픽(비상), 족보닷컴 기출
- 정보: 교과서 개념, 단권화 노트, 평가문제집(삼양미디어)

**총량이 비어 있는 교재는 과목 탭에서 문제 수나 쪽수를 입력해 주세요.** 입력해야 남은 시간과 위험도가 정확해집니다. 단위당 예상 시간은 첫 추정치이고, 기록이 쌓이면 자동으로 맞춰집니다.

## 아이패드에서 쓰는 법

1. 저장소 Settings → Pages → Branch를 `main`의 `/ (root)`로 지정합니다. 주소: https://human8200-stack.github.io/New-project/
2. 아이패드 Safari로 주소를 열고, 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 동기화를 쓰려면 [FIREBASE_SETUP.md](FIREBASE_SETUP.md) 순서대로 설정한 뒤, 기기마다 **설정 → Google로 로그인**을 누릅니다. 동기화를 쓰지 않으면 가끔 **백업 파일 받기**를 해 두세요.

로컬에서 확인할 때: `python3 -m http.server` 실행 후 `http://localhost:8000`을 엽니다.
