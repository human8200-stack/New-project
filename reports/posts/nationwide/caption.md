# 전국 부엌 로드트립 캐러셀 (초안)

- 1장: 지도 표지 (레트로 자동차 + 도시 경로)
- 2장~: 도시마다 한 장씩 (사진 + STOP 번호 + 한 줄 이야기 + 작은 지도)
- 지금 2장은 **예시 사진**(2025-10 전 부치는 사진)으로 틀만 보여주는 것

## 도시 (예전 캡션 기준, 확인 필요)
2022-04 캡션 "서울.경기.세종.강릉.부산.제주 전국구 에이블" + 울산 GOM 강의
→ 서울, 강릉, 세종, 울산, 부산, 제주 (6곳) + 출발점 '우리 집 부엌'
- 집 위치는 공개 게시물에 지명을 쓰지 않음

## 필요한 것
도시마다: 사진 1~3장 + 한 줄 (누구와, 무엇을 만들었는지)

