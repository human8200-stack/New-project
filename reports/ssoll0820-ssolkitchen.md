# 월간 쏠키친 운영 가이드

- 첫 회: **2026-11-26 (목) 밤 9시, 40분**
- 메뉴: **겨울 밀푀유나베** (냄비 하나, 칼질 쉬움, 30분 안에 완성, 연말 모임에 바로 써먹기 좋음)
- 방식: 무료 · 선착순 20명 · 줌 · 신청은 DM 키워드 `쏠키친`
- 원칙: **사업 설명 없음.** 같이 만들고, 같이 먹고, 같이 웃는 40분.

## 1. 준비 (D-21 ~ D-14)

| 할 일 | 내용 |
|---|---|
| 줌 | 무료 계정은 40분 제한이라 40분에 맞춰 진행. 유료 계정이면 대기실을 켜두기 |
| 카메라 | 휴대폰 거치대를 하나 더 두고 **도마·냄비가 위에서 보이는 화면**을 공유 (손이 보여야 따라 하기 쉬움) |
| 레시피 카드 | 재료·순서를 1장짜리 이미지로 → 신청자에게 미리 DM |
| 도우미 | 팀원 2명: 채팅 질문 정리, 입장 도움, 캡처 담당 |
| 신청 명단 | 메모장/스프레드시트: 이름, 인스타 아이디, 어떻게 알게 됐는지, 참석 여부 |

**재료 (2~3인분)**
배추 1/4통, 깻잎 20장, 소고기 샤브샤브용 300g, 버섯 한 줌, 육수(물 800ml + 코인육수 2개 또는 멸치육수), 국간장 1T, 소금 약간, 찍어먹을 소스(간장+식초+연겨자)

- 특정 브랜드 냄비나 제품은 필요 없다고 안내하세요. "집에 있는 냄비 아무거나"라고 해야 신청 부담이 없습니다.

## 3. 신청 DM 응대

**신청 확인 (바로)**
```
쏠키친 신청 고마워요🌿 자리 맡아뒀어요!
재료 카드 보내드릴게요 (집에 있는 냄비면 충분해요)

혹시 저를 어떻게 알게 되셨어요?
그리고 요즘 저녁 준비하면서 제일 고민되는 게 있으면 알려주세요.
그날 같이 이야기 나눠볼게요😊
```
→ 두 질문의 답으로 **처음 온 분인지, 어떤 고민이 있는 분인지** 알 수 있습니다. 명단에 적어두세요.

**전날 리마인드**
```
내일 밤 9시 쏠키친이에요🍲
재료 카드 다시 보내드려요. 배추는 미리 씻어두시면 훨씬 편해요!
링크는 내일 1시간 전에 보내드릴게요.
```

**끝난 뒤 (D+1)**
```
어제 같이 요리해줘서 정말 고마웠어요♡
완성 사진 보내주시면 너무 기쁠 것 같아요.
다음 달 메뉴 생기면 제일 먼저 알려드릴게요🌿
```
→ 여기서 사업 이야기를 꺼내지 않습니다. 상대가 먼저 "무슨 일 하세요?"라고 물으면 그때 솔직하게 답하고, 자세한 이야기는 따로 시간을 잡으세요.

## 4. 당일 진행 (40분)

| 시간 | 내용 |
|---|---|
| 0~5분 | 인사, 각자 이름과 사는 지역 한마디, 카메라를 손 쪽으로 맞추기 |
| 5~12분 | 배추·깻잎·고기 쌓기 → 냄비에 세워 담기 |
| 12~25분 | 육수 붓고 끓이기. **끓는 동안 수다**: "요즘 저녁 어떻게 해결하세요?" |
| 25~32분 | 완성! 다 같이 냄비 들고 화면 캡처 (캡처 전에 "올려도 될까요?" 동의 받기) |

- 쏠님은 **진행만**, 질문 정리와 입장 도움은 도우미 팀원이 맡습니다.
- 늦게 들어온 분을 위해 단계마다 재료 카드를 화면에 다시 띄우세요.

## 5. "사업자들이 레시피 보려고 들어오면?"

충분히 그럴 수 있고, **막지 않아도 됩니다.** 대신 자리가 그분들로 채워지지 않게 설계하세요.

**① 레시피는 원래 나눠도 되는 것**
- 레시피는 어차피 캡션에도 올리는 공개 정보입니다.
- 사람들이 쏠키친에서 가져가는 건 레시피가 아니라 **분위기와 쏠님이라는 사람**이고, 이건 따라 할 수 없습니다.
- 다른 사람이 쏠키친 레시피를 퍼뜨리면 오히려 쏠님 이름이 같이 퍼집니다.

**② 자리 배분을 정해두기 (20석 기준)**
| 자리 | 누구 |
|---|---|
| 14석 이상 | **처음 오는 인친님** (우선) |
| 2~3석 | 에이블팀 도우미 (분위기 + 팀 문화 보여주기) |
| 3석 정도 | 다른 팀·다른 회사 사업자 등 그 외 |

- 신청 DM의 "어떻게 알게 되셨어요?" 답으로 구분하고, 처음 오는 분부터 자리를 확정하세요.
- 안내 문구에 `처음 오시는 분 우선`을 한 줄 넣어도 좋습니다.

**③ 다른 사업자가 와도 생기는 좋은 점**
- 같은 결의 사람이면 **콜라보 상대**가 될 수 있습니다 (함께 릴스, 함께 쏠키친).
- 참가 인원이 많아 보이면 다음 신청자에게도 좋은 신호가 됩니다.

**④ 지켜야 할 선**
- 이미 다른 사업자와 함께하는 분이 와도 사업 이야기를 꺼내지 않기 (회사 내 다른 그룹 존중 규칙).
- 참가자 연락처나 명단은 팀 밖으로 공유하지 않기.
