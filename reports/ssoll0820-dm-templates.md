# @ssoll0820 DM 답장 가이드

방법 1(인스타 자동 답장)과 방법 2(매일 저녁 Claude가 초안 작성)에서 같이 쓰는 문구입니다.

## 원칙
- 첫 답장(인사·신청 접수)만 자동. 그다음 대화는 쏠님이 직접.
- 수입·보너스·직급 이야기 금지. 먼저 사업 권유 금지. 회사는 물으면 솔직하게.
- 답장 끝에는 질문 하나 → 대화가 이어지게.
- 말투: 쏠님 말투 (존댓말, 따뜻하게, 🌿♡😊, "~요")

---

## 방법 1. Meta Business Suite 자동 응답 설정

경로: Meta Business Suite → 받은 메시지함 → 자동화 (메뉴 이름은 버전에 따라 조금 다를 수 있음)

| 종류 | 조건 | 보낼 문구 |
|---|---|---|
| 키워드 응답 | `쏠키친` | A. 쏠키친 신청 확인 |
| 키워드 응답 | `이야기` | B. 이야기 인사 |
| 즉시 답장 | 처음 DM 보낸 사람 | C. 첫 인사 |

인스타 앱 **저장된 답장**에는 D·E·F를 넣어두세요 (단축어 예: `/레시피`, `/공유`, `/감사`).

---

## 문구

### A. 쏠키친 신청 확인 (키워드 `쏠키친`)
```
쏠키친 신청 고마워요🌿 자리 맡아뒀어요!
재료 카드는 곧 따로 보내드릴게요 (집에 있는 냄비면 충분해요)

혹시 저를 어떻게 알게 되셨어요?
그리고 요즘 저녁 준비하면서 제일 고민되는 게 있으면 알려주세요.
그날 같이 이야기 나눠볼게요😊
```

### B. 이야기 인사 (키워드 `이야기`)
```
와주셔서 반가워요🌿
제가 일하는 방식, 하루 보내는 모습 솔직하게 나눠드릴게요.

먼저 하나만 여쭤봐도 될까요?
요즘 어떤 고민이 있어서 궁금해지셨어요? (육아, 일, 시간… 뭐든 좋아요)
```

### C. 첫 인사 (즉시 답장)
```
안녕하세요, 쏠이에요🌿 메시지 고마워요!
확인하고 제가 직접 답장 드릴게요 :)
```

### D. 레시피 프로그램 요청
```
관심 가져주셔서 고마워요🌿
지금은 쏠키친 참가자분들과 같이 써보고 있어요.
다음 쏠키친 신청해주시면 그날 같이 써봐요!
혹시 어떤 요리할 때 쓰고 싶으셨어요?
```

### E. 소비자 관리 / 공부 앱 요청
```
와 관심 가져주셔서 고마워요😊
이건 팀원들(우리 딸)만 쓰려고 만든 거라 공유는 어려워요.
대신 어디에 쓰고 싶으신지 알려주시면
비슷하게 해볼 수 있는 방법 같이 고민해볼게요!
```

### F. 쏠키친 끝난 뒤 감사
```
어제 같이 요리해줘서 정말 고마웠어요♡
완성 사진 보내주시면 너무 기쁠 것 같아요.
다음 달 메뉴 생기면 제일 먼저 알려드릴게요🌿
```

### G. 쏠키친 전날 리마인드
```
내일 밤 9시 쏠키친이에요🍲
재료 카드 다시 보내드려요. 배추는 미리 씻어두시면 훨씬 편해요!
링크는 내일 1시간 전에 보내드릴게요.
```

### H. "무슨 일 하세요?" / 사업에 관심
자동 답장 쓰지 않음. 쏠님이 직접:
1. 상대 상황을 먼저 묻기 (육아, 회사, 시간, 고민)
2. 왜 이 일을 하는지, 하루가 어떤지, 어느 회사와 하는지 솔직하게
3. 쏠키친이나 소규모 홈 모임에 초대
4. 결정은 상대가. 재촉 금지.

## 방법 2. 매일 저녁 확인 (Claude)

매일 정해진 시간에 Claude가 하는 일:
1. 지난 24시간 동안 온 새 DM 읽기
2. 분류: 쏠키친 신청 / 프로그램 요청 / 사업 관심 / 일반 / 스팸
3. 사람마다 위 문구를 바탕으로 맞춤 답장 초안
4. 쏠키친 신청자 명단 갱신
5. **보내지 않음.** 쏠님이 확인 후 직접 보내거나 "보내줘"라고 하면 그때 전송
   - 인스타는 상대의 마지막 메시지 후 24시간 안에만 답장할 수 있음
