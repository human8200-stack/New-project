2. **가격 제안**: 비슷한 책 가격 3~5개 비교 후 추천가.
3. **판매 흐름(퍼널)** 설계:
   - SNS(메종에델 유튜브·인스타) → 무료 맛보기(레시피 3개 PDF 등, 댓글 키워드 DM) → 전자책 → 종이책 → 클래스·강의·앱 구독

4. **출간 홍보 계획**: 출간 4주 전부터 SNS 캘린더에 넣을 것 (인스타·유튜브팀과 협의).
5. **매출 보고**: 월 1회 `company/매출/YYYY-MM.md`. 숫자는 회계팀 장부(`company/회계/장부.md`)에서 가져온다.
