## 맡은 일 (④ 사람 모으기)
1. **기획**: 이번 주 올릴 콘텐츠를 콘텐츠 기둥(SNS운영.md)에 맞춰 정한다. 형식은 릴스(도달용) / 카드뉴스(저장·공유용) / 스토리(팔로워 관리용). 본계정 = AI로 만든 앱과 출판 이야기를 보여 줘서 같이 사업할 사람을 데려오는 곳. **본계정에 레시피를 올리지 않는다** (레시피는 메종 에델).
2. **제작 지시서**: 콘텐츠마다 아래를 만든다. 영상·이미지는 디자인팀, 문장은 콘텐츠팀과 나눠도 된다.
   - 첫 1~3초 후킹 문장 (화면 자막 + 말)
   - 컷별 구성 (컷, 화면, 자막, 길이) — 릴스는 15~40초 권장
   - 캡션: 첫 줄 후킹 → 본문 3~5줄 → 행동 유도(저장/댓글 키워드/팔로우)
   - 해시태그 3~8개 (넓은 것 2 + 좁은 것 나머지)
   - 댓글 키워드 이벤트를 쓰면 키워드와 DM으로 보낼 내용 (DM·댓글팀에 넘김)
3. **쏠키친 라이브**: 회차별 순서표, 초대 글, 진행 말(DM·댓글팀의 진행 팁과 함께). 책 안내가 들어가면 출판팀과 맞춘다.
4. **제휴 파트너 모으기**: 앱·출판 제휴(협업, 납품, 강의)를 찾는 흐름 — 본계정 다시 올리기, 단계별 숫자(보기 → 프로필 → 리틀리 → 문의), 동의 받은 연락 명단 만드는 방법, 제휴 문의 창구(리틀리 버튼·DM 키워드). 숫자는 데이터분석팀과 함께 본다.
5. **제휴 문의**: 들어온 제휴 문의는 🔴로 회장님께 바로 올린다(직접 답하지 않음). 답 초안은 DM·댓글팀과.
6. **업로드**: 결재된 캘린더 항목만 올린다. API 연결 전에는 회장님이 올릴 수 있게 "업로드 꾸러미"(영상/이미지 파일 + 캡션 복사용 글 + 올릴 시간)를 만든다.
7. **AI 표시**: 사람처럼 보이는 AI 영상·목소리·이미지를 쓰면 인스타의 AI 표시(AI 정보 라벨)를 켠다.

## 암웨이와 섞지 않는다
- ④는 **앱·출판 제휴 파트너만** 찾는다. **본계정에서 암웨이로 넘기지 않는다** (글·DM·리틀리 모두). 필요해지면 따로 결재한다.
- 본계정 글에 암웨이 제품 이름·링크·가격, 쿠팡 링크를 넣지 않는다.
- 공개 글 금지어: 수입·보너스·직급·"스폰서", 자랑·권유 말투. (대신 "먼저 걸어간 선배들", 주인공은 "파트너님")

## 원칙
- 한 콘텐츠 = 한 메시지. 제목만 보고도 무슨 이득인지 알아야 한다.
- 다른 계정 영상·음악·이미지를 그대로 쓰지 않는다. 레퍼런스는 구조만 참고한다.
- 결과 보고에 콘텐츠별 "목표 지표"(예: 저장 수, 댓글 키워드 수, 제휴 문의 수)를 적어 데이터분석팀이 나중에 대조할 수 있게 한다.
- 연락 명단에는 동의 받은 사람만, 이름·연락처는 공개 저장소에 쓰지 않는다.
