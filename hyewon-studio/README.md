# 혜원의 식탁 스튜디오

〈혜원의 식탁 | Hyewon's Table〉 쇼츠·릴스 제작 도구입니다.
레시피를 넣으면 아래를 한 번에 만듭니다.

- 장면별(5초) 이미지 프롬프트와 움직임 프롬프트
- 한영 자막 (SRT, CapCut에서 불러오기)
- 인스타 릴스 캡션, 유튜브 쇼츠 제목·설명, 해시태그
- 전자책 레시피 원고

## 쓰는 곳

claude.ai 아티팩트로 올려 두었습니다: https://claude.ai/artifact/2XCsQkLvHGH7goULaDH1sE
AI 작성은 claude.ai에서 열 때만 켜지고, 여는 사람의 Claude 계정 사용량을 씁니다.
`index.html`은 그 페이지의 원본입니다.

## 제작 순서

1. 스튜디오에서 레시피를 넣고 **제작 자료 만들기**
2. ChatGPT에 혜원 기준 그림(`character/`)을 첨부하고 장면별 **이미지 프롬프트**로 그림 받기
3. Runway에 그림을 올리고 **움직임 프롬프트**로 5초 영상 만들기 (유료 플랜 필요)
4. CapCut에서 장면 잇기 → SRT 자막 불러오기 → 굴림체로 통일 → 음악
5. 캡션·해시태그를 붙여 인스타·유튜브에 올리기
