```
                 👑 회장님 (결재 · 로그인 · 결제)
                          │
                   🧑‍💼 사장 (Claude)
          지시 접수 · 업무 분담 · 검수 확인 · 보고
                          │
 ┌────────┬────────┬──────┴──┬────────┬────────┬────────┐
기획팀   리서치팀  디자인팀   개발팀   콘텐츠팀  검수팀   운영팀
계획서   조사·근거  화면·카드뉴스 앱·자동화 공지·캡션  통과/반려 배포·게시·기록
```

## 회장님이 말하는 법 (카톡처럼)
Claude 앱에서 이 저장소로 대화를 열고 그냥 말씀하시면 됩니다. 받는 사람은 사장입니다.

| 이렇게 말하면 | 회사가 하는 일 |
|---|---|
| "행운 추첨 앱 홍보할 밴드 글 써 줘" | 사장 → 콘텐츠팀(글) + 디자인팀(이미지 구성) → 검수 → 보고 + 결재(게시) |
| "공부 앱에 영어 단어 시험 기능 넣고 싶어" | 기획팀 계획서 → 디자인 → 개발 → 검수 → 미리보기 보고 → 결재(실제 반영) |
| "디자인팀, 추첨 화면 더 화려하게" | 디자인팀 바로 → 검수 → 보고 |
| "요즘 뭐 하면 좋을까?" | 사장이 회장님 메모와 업무일지를 보고 추천 3가지 |
| "1번 승인" / "2번 반려, 날짜 틀림" | 결재함 처리 → 운영팀 실행 또는 담당 팀 재작업 |
| "현황 보고해" | 끝난 일 · 진행 중 · 결재 대기 · 다음 제안 |

짧은 명령도 있습니다: `/work 맡길 일`, `/report`, `/approve 1 승인`

## 회장님이 직접 하시는 것은 세 가지뿐
1. **결재** — 돈, 바깥에 게시·발송, 삭제, 실제 서비스 반영
2. **로그인·연결** — 회사가 휴대폰 기준 1·2·3 단계로 안내해 드립니다
3. **결제**
