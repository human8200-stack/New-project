**회사의 목표: 돈을 버는 것** — 책, 메종에델 공구·쿠팡 파트너스, 메인 계정 제휴, 나중에 앱 판매. 전체 그림: [사업지도.md](사업지도.md)
- 기획본부: 무엇을 할지 정하고, 조사하고, 숫자로 확인하고, 아이디어를 냄 (마케팅팀: 사업별 타깃·핵심 메시지·캠페인·채널 전략 / 관계심리팀: 고객·파트너 마음 읽기, 말투 조언, 어려운 대화 대본 — 치료·진단 아님)
- 제작본부: 실제로 만듦 (화면·이미지·영상 구성, 앱, 글)
- SNS본부: 인스타·유튜브에 올리고, DM·댓글에 답함
- 출판본부: 원고를 만들고(편집), 책으로 내고(출판), 돈이 되게 함(수익화)
- 관리본부: 올리기 전에 점검하고, 결재 난 일을 실행하고, 기록함 (회계팀: 쓴 돈·번 돈 장부, 메종에델 편별 제작비, 예산 관리, 월말 정리)

SNS가 어떻게 돌아가는지: [SNS운영.md](SNS운영.md) · 책은 어떻게 나오는지: [출판사업.md](출판사업.md)

## 회장님이 말하는 법 (카톡처럼)
Claude 앱에서 이 저장소로 대화를 열고 그냥 말씀하시면 됩니다. 받는 사람은 사장입니다.

| 이렇게 말하면 | 회사가 하는 일 |
|---|---|
| "슬기로운 요리생활 홍보 글 써 줘" | 사장 → 콘텐츠팀(글) + 디자인팀(이미지 구성) → 검수 → 보고 + 결재(게시) |
| "공부 앱에 영어 단어 시험 기능 넣고 싶어" | 기획팀 계획서 → 디자인 → 개발 → 검수 → 미리보기 보고 → 결재(실제 반영) |
| "디자인팀, 추첨 화면 더 화려하게" | 디자인팀 바로 → 검수 → 보고 |
| "요즘 뭐 하면 좋을까?" | 사장이 회장님 메모와 업무일지를 보고 추천 3가지 |
| "1번 승인" / "2번 반려, 날짜 틀림" | 결재함 처리 → 운영팀 실행 또는 담당 팀 재작업 |
| "이번 주 인스타 뭐 올려?" / "주간 회의 하자" | 분석팀 성과 보고 + 아이디어 10개 → 다음 주 캘린더 결재 |
| "이 DM 어떻게 답해?" (캡처 첨부) | 고객응대팀이 분류하고 답 초안 |
| "레시피함 전자책 시작하자" | 편집팀 기획안 + 리서치(비슷한 책) + 수익화(가격·손익) → 결재 |
| "이걸로 얼마 벌 수 있어?" | 수익화팀 손익표 (보수적/보통/잘될 때) |
| "현황 보고해" | 끝난 일 · 진행 중 · 결재 대기 · 다음 제안 |

짧은 명령도 있습니다: `/work 맡길 일`, `/report`, `/approve 1 승인`, `/weekly`(주간 회의)

## 회장님이 직접 하시는 것은 세 가지뿐
1. **결재** — 돈, 바깥에 게시·발송, 삭제, 실제 서비스 반영
2. **로그인·연결** — 회사가 휴대폰 기준 1·2·3 단계로 안내해 드립니다
3. **결제**
