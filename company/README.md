## 회장님이 말하는 법 (카톡처럼)
Claude 앱에서 이 저장소로 대화를 열고 그냥 말씀하시면 됩니다. 받는 사람은 사장입니다.

| 이렇게 말하면 | 회사가 하는 일 |
|---|---|
| "슬기로운 요리생활 홍보 글 써 줘" | 사장 → 콘텐츠팀(글) + 디자인팀(이미지 구성) → 검수 → 보고 + 결재(게시) |
| "공부 앱에 영어 단어 시험 기능 넣고 싶어" | 기획팀 계획서 → 디자인 → 개발 → 검수 → 미리보기 보고 → 결재(실제 반영) |
| "디자인팀, 추첨 화면 더 화려하게" | 디자인팀 바로 → 검수 → 보고 |
| "요즘 뭐 하면 좋을까?" | 사장이 회장님 메모와 업무일지를 보고 추천 3가지 |
| "1번 승인" / "2번 반려, 날짜 틀림" | 결재함 처리 → 운영팀 실행 또는 담당 팀 재작업 |
| "이번 주 인스타 뭐 올려?" / "주간 회의 하자" | 분석팀 성과 보고 + 아이디어 10개 → 다음 주 캘린더 결재 |
| "이 DM 어떻게 답해?" (캡처 첨부) | DM·댓글팀이 분류하고 답 초안 |
| "레시피함 전자책 시작하자" | 편집팀 기획안 + 시장조사팀(비슷한 책) + 출판팀(가격) + 회계팀(손익) → 결재 |
| "이걸로 얼마 벌 수 있어?" | 회계팀 손익표 (보수적/보통/잘될 때) |
| "현황 보고해" | 끝난 일 · 진행 중 · 결재 대기 · 다음 제안 |

짧은 명령도 있습니다: `/work 맡길 일`, `/report`, `/approve 1 승인`, `/weekly`(주간 회의)
