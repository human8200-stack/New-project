# SNS 운영 설명서 (인스타그램 · 유튜브)

회장님이 몰라도 회사가 이대로 돌아갑니다. 회장님은 **월요일 결재 한 번 + 🔴 메시지 확인**만.

## 1. 채널 방향 — 결재 2번에서 정합니다
SNS의 목적은 **책을 살 독자를 모으는 것**입니다 ([출판사업.md](출판사업.md)).

**추천안 — 메종에델 중심 (요리)**
- 유튜브 메종에델(이미 있는 채널) + 같은 이름 인스타 → 레시피함 전자책·요리책 독자
- 기둥: 레시피 영상 40% / 바로 따라하는 팁 30% / 책 만드는 과정 20% / 소통 10%
- 건강 책은 출간 6개월 전쯤 건강 기둥을 추가하거나 별도 계정 (그때 결재)

아래는 처음 임시안이었던 것입니다 (참고).

**(이전 임시안) A — "AI 회사를 굴리는 학부모"**
코딩 모르는 학부모가 AI(Claude)로 아이 공부앱, 행사 추첨앱을 직접 만들고, AI 팀으로 회사를 운영하는 과정을 보여 주는 계정.
- 이미 만든 것(공부 루틴 v54, 행운 추첨)이 그대로 콘텐츠 → 소재가 끊기지 않음
- 회장님이 보내 주신 레퍼런스 릴스("클로드로 인스타 운영팀을 만들었어요")와 같은 분야, 지금 반응이 오는 주제

**콘텐츠 기둥 (A안 기준)** — 매주 이 비율로 섞음
| 기둥 | 비율 | 예 |
|---|---|---|
| 만들기 과정 | 40% | "코딩 몰라도 AI로 공부앱 만든 과정 3단계" |
| 바로 따라하기 팁 | 30% | "Claude한테 이렇게 말하면 계획표 짜 줍니다" |
| 결과·변화 | 20% | 아이 공부 기록 전후, 행사에서 추첨앱 쓴 장면 |
| 소통 | 10% | 댓글 질문 답변 영상, 투표 |

(이전) 다른 안: B "고등학생 공부 루틴·내신 관리" (학부모·학생 대상) / C "행운 추첨 앱 홍보" (행사 주최자 대상, 앱 사용자 늘리기)

## 2. 한 주 운영 순서
| 요일 | 하는 일 | 담당 | 회장님 |
|---|---|---|---|
| 월 | 지난주 성과 보고 + 아이디어 회의 → **다음 주 콘텐츠 캘린더 결재** | 분석팀 → 기획·인스타·유튜브팀 | ✅ 결재 1번 |
| 화~수 | 영상·카드뉴스·대본 제작, 검수 | 디자인·콘텐츠·각 SNS팀 → 검수팀 | |
| 목~일 | 캘린더대로 예약 업로드 | 운영·각 SNS팀 | |
| 매일 | DM·댓글 응대, 🔴는 회장님께 | 고객응대팀 | 🔴만 |

**기본 업로드 양 (시작 단계)**: 인스타 릴스 3 + 카드뉴스 1 / 주, 유튜브 쇼츠 3(릴스 재사용) / 주, 롱폼은 반응 확인 후.
처음 4주는 같은 시간대에 올리고, 그 뒤 분석팀이 가장 잘 되는 시간으로 바꿉니다.

## 3. 자동화 단계 (믿음이 쌓이는 만큼 올림)
| 단계 | 업로드 | DM·댓글 | 회장님 결재 |
|---|---|---|---|
| **1단계 (지금)** | 회사가 "업로드 꾸러미" 제작 → 회장님이 복사해서 올림 | 회사가 답 초안 → 회장님이 붙여넣기 | 콘텐츠마다 |
| **2단계 (연결 후)** | 결재된 캘린더대로 자동 예약 업로드 | 🟢 자동 답, 🟡 초안 결재 | 주 1번 캘린더 + 🟡🔴 |
| **3단계** | 2단계 + 잘된 콘텐츠 변형은 결재 없이 | 🟡 중 반복되는 것도 자동 | 주 1번 + 🔴만 |

단계 올리기도 회장님 결재로 합니다.

## 4. 연결하기 — 회장님이 하실 일 (로그인만)
자동 업로드·자동 답장은 회사가 회장님 계정에 "허락받은 열쇠"를 받아야 됩니다. 아래는 회장님만 할 수 있습니다. 회사가 옆에서 한 화면씩 안내합니다.

**인스타그램 (약 20분, 무료)**
1. 인스타 앱 → 설정 → 계정 유형 → **프로페셔널 계정**(크리에이터 또는 비즈니스)으로 바꾸기
2. developers.facebook.com 에 회장님 페이스북 계정으로 로그인 → 앱 만들기 (회사가 버튼 순서 안내)
3. 앱에 회장님 인스타 계정을 연결하고 "허용" 누르기 → 회사가 열쇠를 안전한 곳(GitHub 비밀 저장소)에 넣음
- 자동 업로드: 내 계정에 올리는 것은 위 단계만으로 됩니다.
- 자동 DM 답장: 남이 보낸 DM에 프로그램이 답하려면 **Meta 앱 검수 + 사업자 확인**이 필요해서 며칠~몇 주 걸립니다. 그 전에는 1단계 방식(초안 → 붙여넣기)으로 운영합니다.

**유튜브 (약 20분, 무료)**
1. 유튜브 채널 만들기 (구글 계정)
2. console.cloud.google.com 로그인 → 프로젝트 만들기 → YouTube 연결 켜기 (회사가 안내)
3. "허용" 누르기 → 회사가 열쇠를 저장
- 주의: 새 프로젝트로 올린 영상은 Google **감사(심사)를 통과하기 전까지 '비공개'로만** 올라갑니다. 감사 신청은 회사가 서류를 써 드리고, 통과 전에는 예약 업로드 대신 업로드 꾸러미로 운영합니다.
- 유튜브에는 DM이 없습니다. 댓글 답글은 연결 후 자동으로 가능합니다.

**대안 (돈이 들지만 빠름)**: 예약 업로드는 Meta Business Suite(무료)·YouTube Studio 예약 기능을 회장님이 쓰시는 방법, 인스타 DM 자동 답장은 ManyChat 같은 Meta 공식 협력 서비스(일부 무료, 기능 많으면 유료). 쓰려면 결재로 올립니다.

## 6. 꼭 지키는 것
- 다른 사람 영상·음악·이미지 무단 사용 금지 (레퍼런스는 구조만)
- AI로 만든 사람 얼굴·목소리를 쓰면 AI 표시 켜기 (인스타 AI 정보 라벨, 유튜브 합성 콘텐츠 표시)

## 7. 성과 목표 (첫 12주, 분석팀이 4주마다 조정)
- 꾸준함: 계획한 업로드의 90% 이상 지키기
- 인스타: 저장+공유가 조회의 3% 이상인 콘텐츠 매주 1개
- 유튜브 쇼츠: 끝까지 본 비율이 오르는 추세
- 팔로워 수는 마지막에 봅니다. 앞의 것이 되면 따라옵니다.
