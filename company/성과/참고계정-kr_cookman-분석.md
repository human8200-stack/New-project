## 4. 소리가 자연스러운 이유

| 확인한 것 | 결과 |
|---|---|
| 말·내레이션 | **없음.** 받아쓰기 프로그램이 "구독과 좋아요 부탁드려요"를 뱉었지만, 이건 말이 없는 소리에서 이 프로그램이 흔히 지어내는 문장(말이 아닐 확률 70% 이상으로 표시). 실제 말 없음 |
| 음악 | **없음 (또는 거의 안 들림).** 주파수 그림에 음악이면 생기는 가로줄(계속 이어지는 음)이 없음. 전부 세로줄(탁·톡·칙 같은 짧은 소리) + 잔잔한 바탕 소리 |
| 장면마다 소리가 따로 | 장면이 바뀌는 순간 **소리 결이 딱 바뀜** (높은 소리 한계가 1만 Hz ↔ 1만6천 Hz로 장면마다 다름). 하나로 이어 녹음한 소리가 아니라 **장면마다 다른 소리를 가져와 붙인 것** |
| 화면과 맞음 | 칼 닿는 순간, 두부 놓는 순간, 뚜껑 닫는 순간에 소리 뾰족점이 정확히 있음 (파형의 큰 뾰족점들) |
| 바탕 소리 | 각 장면 밑에 불 타닥, 지글지글, 물 끓는 소리가 **조용히 계속** 깔림 → 빈 틈이 없어서 "그 자리에 있는 느낌" |
| 크기 | 평균 약 -18dB, 가장 큰 곳 0dB (4개 모두 거의 같음) → **소리를 크게, 고르게** 맞춤. 휴대폰 스피커로 또렷이 들림 |
| 잡음 | 쉬익 하는 잡음 없음. 깨끗함 |

**어떻게 만들었을까 (추정):** 장면을 AI로 만든 뒤 → 장면마다 맞는 효과음(무료 효과음 모음 또는 소리까지 같이 만들어 주는 AI 영상 도구)을 붙이고 → 장면과 같이 잘라 → 음악 없이 크게 내보냄. heedong.ai는 인스타 **Edits 앱**(무료, 효과음 모음 있음)으로 편집했다는 표시가 있음. 어느 도구로 소리를 만들었는지는 화면으로는 **알 수 없음**.

**소리 비결 3줄**
1. 음악·말 없이 **요리 소리만** — 소리가 주인공.
2. **장면마다 그 동작 소리 하나**를 정확한 순간(칼이 닿는 프레임)에 붙이고, 장면과 같이 자름.
3. 밑에 **작은 바탕 소리**(불·지글·물)를 계속 깔고, 전체를 **크게 고르게** 맞춤.

## 5. 편집 문법

| 항목 | kr_cookman | heedong.ai |
|---|---|---|
| 길이 | 약 17~30초 | 약 26초 |
| 장면 길이 | 약 1~1.5초 | 약 1초 |
| 첫 1~2초 | **분위기 장면**: 두 손으로 나무 대문 열기 → 달밤 논 → 등불 (두부전골). 물에 단호박 씻는 손 (단호박) | **재료 첫 동작 바로**: 달걀 깨기 (토스트), 사람이 밤 그릇 들고 있기 (군밤) |
| 가운데 | 손질 → 익히기 → 담기 → 소스 붓기 (요리 순서 그대로, 클로즈업) | 같음. 소스가 흘러내리는 장면을 길게 |
| 끝 | AI 남자가 한 입 먹고 눈 감고 미소 + 강아지 → **처음 장면(대문)으로 돌아가 닫음** = 다시 보게 되는 고리 | AI 남자가 먹고 반응 |
| 화면 글자 | 영상 안에는 거의 없음. 표지 사진에만 큰 글자 | 없음 |
| 캡션 첫 줄 | "단호박 오리엔탈 샐러드 레시피 🥗 찐 단호박에…", "두부전골 레시피 🟡 밝은 달빛 아래…" = **요리 이름 + 레시피 + 감성 한 줄** | "비오는 날 프렌치 토스트" |
| 반복 요소 | 같은 남자 + 같은 강아지 + 한옥·시골 배경 (하이라이트 "Little Forest") | 같은 남자 |

## 6. 메종 에델이 바로 가져올 것 3개 (돈 안 드는 것부터)

**① 소리 붙이는 방식 바꾸기 — 0원**
- 지금 메종 에델도 "말 없이 손·요리 소리"인데, 이 계정처럼 **장면마다 효과음 1개를 동작 순간에 맞춰** 붙이고, 장면이 끝나면 그 소리도 같이 끊기.
- 밑에 바탕 소리(프랑스 시골 부엌: 장작 타닥, 냄비 지글, 새소리 조금) 1개를 처음부터 끝까지 작게.
- 음악은 넣지 않고, 전체 소리를 크게(평균 약 -18dB) 맞추기.
- 효과음은 무료 모음(인스타 Edits 효과음, 유튜브 오디오 보관함 등)에서.
- 확인 방법: 다음 편 하나만 이렇게 바꾸고, 평균 시청 시간·끝까지 본 비율을 지난 편과 비교.

**② 이미 만든 영상 조각을 더 짧게 잘라 쓰기 — 0원**
- 지금 장면당 3~5초 → **1~2초**로. 5초짜리 AI 조각 하나에서 "시작·가운데·끝" 다른 동작을 2~3개 잘라내면 **크레딧을 더 안 쓰고 장면 수만 2~3배**.
- AI 영상이 오래 보면 어색해지는 부분(손 모양 뭉개짐 등)도 덜 보임.
- 주의: 메종 에델 스타일 기준(`초안/메종에델-스타일기준.md`)과 회장님 반려 이유("쪽파 정지 사진", "껍질 느림")를 지켜서 — 멈춘 사진은 쓰지 않고 움직이는 조각만.

**③ 처음과 끝을 "고리"로 묶기 — 0원 ~ 소량 크레딧**
- 첫 1초: 분위기 장면(햇살 드는 부엌 창문 열기, 문 열기) → 끝: 완성 접시 + **처음 장면으로 돌아가 창문 닫기**. 다시 보기를 부르는 구조.
- 이미 있는 장면으로 하면 0원. 새로 만들면 장면 1~2개 추가 → **대략 100~150크레딧 정도** (EP.03 쪽파 새 사진·영상 약 140 기준, 정확한 값은 회계팀 확인). **실제 생성은 회장님 승인 전 하지 않음.**
- 끝에 "먹는 사람 얼굴"은 메종 에델 규칙(얼굴 없음·AI 표시)과 맞는지 먼저 확인 필요 → 지금은 손·접시로만 추천.

### 가져오지 않을 것
- AI 남자 주인공 얼굴: 메종 에델은 손·요리 중심이고, 얼굴을 쓰면 AI 표시 규칙(SNS운영.md)을 꼭 켜야 함.
- 애니메이션 그림체: 메종 에델은 실사 느낌이 정체성.
