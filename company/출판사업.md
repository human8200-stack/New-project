# 출판 사업 설명서

## 회사가 결국 하려는 것
회장님이 만든 것들(앱·유튜브·강의)은 전부 **책으로 모이는 재료**입니다.

```
 앱·유튜브·SNS (사람을 모음, 재료가 쌓임)
        ↓ 무료 맛보기 (레시피 3개, 건강 체크리스트)
   전자책 (빨리, 싸게, 반응 확인)
        ↓ 잘 팔리면
   종이책 (신뢰, 서점, 강연 기회)
        ↓
   클래스·강의·앱 구독 (가장 큰 수익)
```

## 책 3권
| 책 | 재료 | 형태 (추천) | 독자 (가정 — 결재로 확정) | 특별히 조심할 것 |
|---|---|---|---|---|
| ① 레시피함 전자책 | 레시피함 앱의 레시피 | 전자책 먼저 | 매일 집밥 고민하는 사람 | 계량 통일, 음식 사진 |
| ② 건강 책 | 건강강의 앱의 강의 내용 | 전자책 → 종이책 | 건강 관리 시작하려는 중장년 | 효능 단정 금지, 근거·출처, 전문가 감수 |
| ③ 메종에델 요리책 | 메종에델 유튜브 영상 | 종이책 (POD 또는 펀딩) | 메종에델 구독자 | 사진 품질, 영상과 다른 "책만의 가치" |

**추천 순서: ① → ③ → ②**
- ① 레시피가 이미 정리돼 있어서 가장 빠름 (첫 매출, 출판 과정 연습)
- ③ 메종에델 구독자가 첫 독자가 되고, ①의 반응으로 어떤 요리가 팔리는지 미리 앎
- ② 건강 책은 감수·근거 작업이 길어서, 앱 강의 반응을 더 쌓은 뒤 (그 사이 원고는 계속 진행)

## 책 한 권이 나오는 과정
| 단계 | 담당 | 회장님 |
|---|---|---|
| 1. 기획안 (독자, 차례, 제목, 비슷한 책) | 편집팀 + 리서치팀 + 수익화팀(가격·손익) | ✅ 결재 |
| 2. 재료 받기 (앱 내용, 레시피, 영상 목록, 사진) | 편집팀 | 📎 자료 전달 |
| 3. 원고 (장별) | 편집팀 → 검수팀 | 한 장씩 확인 (원하시면) |
| 4. 표지·내지 디자인 | 디자인팀 + 출판팀 | ✅ 표지 결재 |
| 5. 전자책 파일·인쇄 파일 | 출판팀 + 개발팀 | |
| 6. 출간 준비 홍보 (4주 전부터) | 수익화팀 + 인스타·유튜브팀 | ✅ 캘린더 결재 |
| 7. 등록·출간 | 출판팀 | 🔑 로그인·계약·결제 |
| 8. 매출 보고·개정 | 수익화팀·분석팀 | |

## 내는 방법 (출판팀이 책마다 추천)
| 방법 | 장점 | 단점 |
|---|---|---|
| PDF 전자책 (크몽 등 판매처, 자체 판매) | 가장 빠름, ISBN 불필요 | 서점에는 안 나옴 |
| 플랫폼 대행 (교보 퍼플, 부크크 등) | 플랫폼이 ISBN·유통 대행, 종이책 POD 가능 | 수수료가 큼 |
| 1인 출판사 신고 | 내 출판사 이름, 책을 계속 낼 때 유리 | 신고·사업자 등록·납본 절차 |

책을 계속 낼 계획이라 **1인 출판사**가 장기적으로 맞을 가능성이 큽니다. 첫 책은 플랫폼으로 빨리 내고, 두 번째 책 전에 출판사 등록을 검토하는 순서를 추천합니다 (결재 사항).
수수료·정산율·신고 비용은 출판팀이 각 공식 페이지에서 확인한 뒤 숫자로 올립니다. 세금은 세무사 확인.

## 꼭 지키는 것
- 건강 내용: 효능 단정 금지("고친다·낫는다"), 근거와 출처, 전문가 감수. 건강기능식품·특정 제품 추천은 광고 규정 확인.
- 사진·폰트·그림: 상업적 사용 가능한 것만.
- 회장님 원고·레시피 원본 파일은 저장소의 `books/` 에 모아 둠 (공개 저장소라서 출간 전 원고 공개 여부는 결재 — 결재 5번).
