# 울산 GOM — "그날 그 공간" 기획 2판 (암웨이사업팀, 2026-11-04)

> 1판 품질관리팀 반려 → 고친 판. 바뀐 것: 규정 대책 맞춤(밖으로 나가는 것 = 규정 확인), 별도 페이지 위치(사장 결정), AI 답 바로잡음, 사소한 것 5개.
> 참석자 이름·연락처·사진은 이 파일과 이 저장소 어디에도 쓰지 않는다.
> 이 기획은 **GOM 강의 자료가 아니다** (11/1 회장님 "GOM 강의 자료는 만들지 않는다"). 강의 전·쉬는 시간·끝난 뒤에 보여 주는 **분위기 화면**만 만든다.

## 회사가 정한 가정 (틀리면 한 줄로 고쳐 주세요)
- GOM = 회장님이 강의하고 손님(처음 오시는 분)과 파트너님이 함께 듣는 자리.
- 강의장에 화면(TV나 빔)이 있고, 회장님 노트북을 연결할 수 있다.
- 손님은 에이블팀 라운지에 들어오지 않는다 (3장).

---

## 1. 원리 한두 줄
GOM은 처음 온 사람이 "이 사람들은 어떻게 지내나"를 처음 보는 자리다.
사람은 설명을 듣고 끌리기보다, **즐겁게 지내는 사람들 옆에 있어 보고** 끌린다. 그래서 "우린 이런 거 해요"라고 말하는 대신 **그 하루를 잠깐 들여다보게** 한다.

## 2. 안 3개 (추천 맨 앞)

### 안 A (추천) — "울산 GOM 룸" 화면
- **어디에 두나 (사장 결정)**: 새 사이트를 만들지 않는다. 지금 쓰는 able-lounge 사이트 안에 **서버 연결이 하나도 없는 별도 페이지**(예: `/ulsan/`)로 둔다. 회장님이 가입·연결할 것 없음. 단, 올리는 것은 실제 배포라 결재 필요.
- **기본안 (규정 확인 전, 추천)**: **QR 없이 강의장 화면에서만** 보여 준다.
  - 강의 전·쉬는 시간: 강의장을 닮은 3D 방이 화면에서 천천히 돌아간다. 캐릭터들이 자전거·책·감사일기를 하고 있다. 소리는 작게.
  - 손님에게 주소를 나눠 주지 않는다. 강의장 밖으로 나가는 것이 없다.
- **다음 단계 (규정 원문 확인 후, 따로 결재)**: 쉬는 시간에 QR을 띄워 각자 폰에서 구경하고, 집에서도 다시 열 수 있게 한다. 이건 **강의장 밖으로 나가는 자료**라서 규정 확인이 먼저다. 그때 조건:
  - 검색에 안 잡히게 하는 표시(검색 제외)
  - 정해 둔 날짜(예: GOM 뒤 2주)가 지나면 "이 방은 닫혔어요" 화면으로 바뀜. 파일을 아예 내리는 것은 지우는 일이라 그때 결재.
  - 이름 입력·가입·기록 없음
- **끝났다고 보는 기준**: 팀 이름 없음, 명단 없음, 서버 연결 없음, 초대 키 없음, 검색 제외 표시 있음, **그 페이지에서 팀 라운지로 넘어가는 길(버튼·링크) 없음**. 순위판·점수·"보너스" 글자·로고·제품·포스터·가격·채팅도 없음. 회장님 노트북 화면과 아이폰 실제 주소에서 확인.
- **사람들이 느낄 것**: "어, 여기 이 방이네." 신기함과 웃음, 그리고 "이 사람들 매일 이렇게 지내는구나." 권하는 말이 하나도 없어 부담이 없다.
- **준비물**: 강의장 사진(사람 없을 때), 날짜, 화면 연결 가능 여부.
- **회사가 만들 것**: `/ulsan/` 페이지(화면용 자동 회전), 확인. 다음 단계 때 QR 그림 1장.
- **회장님 할 일**: 사진·날짜 주시기 → 완성본 ✅ 한 번 → 당일 노트북으로 그 페이지 열기.
- **걸리는 시간**: **사진 받은 뒤** 3~4일, 길게는 5일 (디자인 1일, 만들기 2일, 검수·확인 1일, 고칠 것 생기면 +1일). **GOM까지 5일이 안 남으면 안 A는 어렵고, 안 C만** 한다. 0원.
- **회장님이 예로 드신 "참석자가 QR로 들어와 자기 이름 캐릭터로 앉아 보기"는 이렇게 바꿨다**: 이름을 받으면 참석자 개인정보를 모으는 일이 되어 규정·동의 문제가 생긴다. 그래서 이름은 받지 않는다. 나중에 하더라도(따로 결재) 이름 대신 동물·색 별칭만 고르고, 그 사람 폰 안에만 남기고 서버에는 저장하지 않는다.

### 안 B — "오늘 함께한 자리" 캐릭터 카드
- **무엇을, 언제**: 끝나고 그날 밤, 강의장 3D 방에 캐릭터들이 둘러앉은 그림 카드 1장. "2026.○.○ 울산 · 오늘 함께한 자리".
- **사람들이 느낄 것**: 기념사진을 받은 기분. 집에서 다시 떠올리는 계기.
- **규정**: 카드는 강의장 밖으로 나가는 자료다 → **규정 원문 확인 후** 한다 (안 A 다음 단계와 같은 기준).
- **회사가 만들 것**: 카드 1장 (얼굴·이름·팀 이름 없음).
- **회장님 할 일**: 카드 ✅ → 손님을 모시고 온 파트너님께만 전달. 회사는 손님 번호를 받거나 직접 보내지 않는다.
- **걸리는 시간**: 안 A가 있으면 1일. 0원.

### 안 C — "10코어 하루 30초" 대기 화면
- **무엇을, 언제**: 강의 시작 전 입장할 때 강의장 화면에 반복 재생. 아침 자전거 → 책 → 강의 듣기 → 감사일기 → "오늘 마무리"까지 30초. 강의장 화면에서만, 나눠 주지 않음.
- **사람들이 느낄 것**: 앉아서 기다리는 동안 "귀엽다, 이게 뭐지?" 하는 궁금함.
- **준비물**: 없음 (만들어 둔 라운지 홍보 영상 장면을 다시 씀).
- **회사가 만들 것**: 30초 영상 1개(소리 작게, 글자 최소). 결재 55 공개 릴스 판을 그대로 쓰지 않고 **로고·제품·순위·점수·이름·타이머·"보너스" 글자·보너스존을 뺀 판**.
- **회장님 할 일**: 영상 ✅ → 당일 화면에 틀기.
- **걸리는 시간**: 1일. 0원 (편집만, 크레딧 안 씀).

## 3. 규정에 걸리는 점과 피하는 방법
| 걸리는 점 | 피하는 방법 |
|---|---|
| 규정 원문(행동강령·SNS·온라인 정책)을 아직 못 받음 | **강의장 밖으로 나가는 것(QR, 집에서 여는 주소, 카드, SNS)은 원문 확인 후.** 그 전에는 강의장 화면에서만 (안 A 기본안, 안 C) |
| 손님에게 팀 라운지 링크를 주면 팀원 이름 전체 명단·순위·양심 체크가 보임 (11/4 명단판부터 모두 공개) | 손님용은 서버 연결 없는 `/ulsan/` 페이지. 팀 라운지로 넘어가는 길 없음. 팀 라운지 초대 링크는 GOM에서 나누지 않는다 |
| 손님이 "팀 라운지 들어가 보고 싶어요"라고 할 때 | 답 한 줄: **"그 방은 저희 팀이 매일 기록하는 곳이라 팀 안에서만 써요. 오늘 방은 이 화면으로 마음껏 보세요."** (들어오려면 어떻게 하라는 말은 하지 않는다) |
| 로고·제품 허락은 "비공개 리더 라운지" 조건(말로 받음). 결재 55는 그 릴스 한정 | GOM 화면·카드·영상에서 로고·제품·포스터를 뺀다 |
| 수입·직급·성공 암시 | 순위판, 점수, "보너스" 글자, 직급, 자동차·여행 장면 없음. 화면 문구에 수입·보너스·직급·"스폰서" 없음 |
| 권유 (모집처럼 보이는 말) | 화면에 "같이 해요·함께하실 분" 같은 말 없음 |
| 건강 표현 | 10코어 화면에 제품 효과·몸이 좋아진다는 말 없음 |
| 개인정보 (참석자 이름·QR 수집) | 기본안은 QR 자체가 없음. 다음 단계에서도 QR은 주소만 열고 이름·번호·접속 기록을 받지 않는다. 참석자 얼굴을 쓰지 않는다 |
| 강의장 내부 사진 | 사람 없을 때 찍은 사진만. 장소 측 촬영 허락은 회장님이 현장에서 한 마디로 확인 |
| GOM 강의 자료를 만들지 않는다는 회장님 지시 | 강의 내용·사업 설명·숫자는 넣지 않는다. 분위기 화면만 |

"규정 확인 필요"로 멈춘 것: ① 행사장 화면에 회사가 만든 자체 영상을 틀어도 되는지 ② 손님에게 주소·카드를 나눠도 되는지. 원문을 받으면 시장조사팀이 확인한다. 그 전에는 **강의 시간 밖(입장·쉬는 시간)에 강의장 화면에서만** 튼다.

## 4. 이번 주 최소판과 받을 정보

### 최소판 (0원, 강의장 화면에서만)
**안 C 30초 대기 화면 + 안 A 기본안(QR 없음)**
- 1일차: 안 C 영상 → 회장님 ✅
- 사진 받은 뒤 3~4일(길게는 5일): 안 A `/ulsan/` 페이지 → 배포 결재 → 회장님 노트북·아이폰에서 확인 ✅
- GOM까지 5일이 안 남으면: 안 C만
- 당일 회장님 할 일: 입장 때 영상 틀기 → 쉬는 시간에 `/ulsan/` 화면으로 바꾸기

### 이것만 주세요 (하나씩, 순서대로)
1. **GOM 날짜와 시작 시각** (예: "11/15 토 오후 2시")
2. **강의장 사진 2장**: 사람 없을 때, 앞(강단 쪽)과 뒤(입구 쪽). 사진이 없으면 강의장 이름만 주셔도 회사가 비슷하게 만든다.
3. **화면 연결**: "노트북 연결 돼요 / 안 돼요" 한 마디

## 5. 비전과 잇는 말

### 비전 한 줄
- 암웨이 공식 목적: **"Helping People Live Better, Healthier Lives"** (사람들이 더 건강하고 더 나은 삶을 살도록 돕는다)
  - 출처: 암웨이 글로벌 공식 홈페이지 "Our Purpose"(amwayglobal.com). **이번에 직접 열어 확인하지 못함.** 클라우드에서는 암웨이 사이트 접속이 막혀 있어 회사가 알고 있는 내용 기준이다. 한국암웨이 공식 한국어 문구는 확인 필요 (회장님 휴대폰 화면 캡처 1장이면 확정).
- 라운지와 잇는 한 줄: **더 나은 삶은 큰 결심이 아니라 매일의 작은 습관에서 오고, 라운지는 그 습관을 혼자가 아니라 함께 하게 해 주는 자리다.**
- 원문 확인 전에는 무대에서 "암웨이의 비전은 ○○입니다"라고 인용하지 않고, 아래처럼 회장님 말로 한다.

### GOM에서 그대로 말할 문장
> **강의 내용이 아니라, 쉬는 시간에 화면을 소개하는 30초 말이다.**

**① 추천: "같이 하니까 오늘도 하게 돼요"**
> "이건 저희 팀이 매일 들르는 가상 라운지예요. 누구는 자전거를 타고, 누구는 책을 읽고, 누구는 감사일기를 써요. 대단한 걸 하는 게 아니에요. 작은 습관을 매일, 같이 하는 거예요. 혼자 하면 사흘이면 멈추는데, 옆에 누가 있으면 오늘도 하게 되더라고요. 오늘 이 강의장도 이 안에 만들어 봤어요."

**② "더 나은 삶은 하루씩"**
> "더 나은 삶은 한 번에 오지 않더라고요. 책 조금, 운동 조금, 하루 한 줄 감사. 저희는 이걸 각자 하지 않고 이 방에서 같이 해요. 누가 끝내면 화면에 축하가 떠요. 서로 응원하는 게 습관이 된 곳이에요."

**③ 짧게, 끝날 때**
> "오늘 이 자리를 화면 속에 그대로 옮겨 봤어요. 저희는 매일 이런 방에서 만나요."

(1판의 "집에 가서 열어 보세요"는 뺐다. 주소를 나눠 주는 것은 규정 확인 후 다음 단계이기 때문.)

### 피해야 할 표현
- "이거 하면 인생이 바뀝니다", "누구나 할 수 있어요", "성공한 사람들의 습관" (과장·성공 암시)
- "시간·경제적 자유", "일 안 해도", "평생 수입" (수입 암시)
- "저희 팀 다이아몬드가…", 순위·점수 자랑 (직급·자랑)
- "같이 하실 분?", "들어오시려면 저희 팀으로 오세요" (권유)
- "건강해져요", "살 빠져요", 제품 이야기 (건강 표현)
- "하루 만에 뚝딱", "누구나 쉽게 만들어요" 같은 자랑 말투. **AI는 숨기지 않는다.** 물어보면 정해 둔 답 그대로: **"AI로 직접 만들어 봤어요."**
- "암웨이 비전은 ○○입니다" (원문 확인 전 단정 인용)

## 결재 지점
1. 최소판 승인: 안 C 영상 + 안 A 기본안(QR 없이 강의장 화면에서만), 0원
2. `/ulsan/` 페이지를 able-lounge 사이트에 올리기 (실제 배포, 회장님 손은 필요 없음)
   - **위험 한 줄: QR·집에서 다시 여는 주소·카드는 강의장 밖으로 나가는 자료라 규정 원문 확인 전에는 하지 않는다.**
3. 완성본 ✅ (영상 1회, 화면 1회)
4. 따로: 다음 단계(QR + 검색 제외 + 날짜 지나면 닫힘), 별칭 앉기, 안 B 카드, SNS 게시, 페이지 내리기
