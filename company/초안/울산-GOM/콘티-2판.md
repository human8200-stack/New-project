## 1. 두 화면 공통 규칙

### 넣지 않는 것 (기획 2판 그대로 + 라운지에서 빼야 하는 것)
- 점수, 이름, 순위, 타이머, "보너스" 글자, 로고, 제품, 팀 이름, QR, 가격, 직급, 채팅.
- 지금 라운지에서 **그대로 가져오면 걸리는 것** (녹화 전에 꼭 끈다):
  - 캐릭터 머리 위 **이름표** → 끈다 (이름 없는 캐릭터).
  - 위쪽 "10코어 0/10", 내 이름 칸, 미니맵, 조이스틱, 소리·밤·정면·오늘 마무리 버튼, 요가·자전거 **타이머 말풍선** → 전부 숨긴다.
  - **전광판**(순위·꾸준상·"축하합니다" 깜빡임·이름) → 빼거나 빈 나무판으로 바꾼다.
  - **감사일기 판 쪽지의 이름**과 "파트너님께 미팅" 같은 사업 냄새 나는 문장 → 이름 없는 짧은 쪽지로 바꾼다 (2장).
  - **제품이 있는 자리**: 더마 아키텍트 존, 리플렉서 존, 정수기·공기청정기·가습기, 영양제, 제품 공간 간판, 비전 포스터, 컴퓨터실 화면(쇼핑·고객관리) → 카메라에 안 잡히게 하거나 그 자리를 뺀다.
  - 입장 화면의 "ABLE TEAM" 글자 → 쓰지 않는다.
- 권유하는 말: "같이 해요", "함께하실 분", "들어오세요"는 쓰지 않는다.

### 꼭 넣는 것
- **AI 표시**: **화면 오른쪽 위**에 처음부터 끝까지 **"AI로 만든 화면"**. 가장자리 5%는 비운다. 크림색 띠 위에 화면 높이 **5%** 크기로 넣어 강의장 뒷줄에서도 보이게 한다 (4장). 숨기지 않는다. 누가 물으면 답은 "AI로 직접 만들어 봤어요."
- 캐릭터는 모두 **지어낸 캐릭터**다. 실제 팀원·참석자 얼굴·이름과 이어지지 않게 한다.

### 캐릭터 (8명)
- 지금 라운지 캐릭터를 그대로 쓴다 (둥근 머리, 짧은 팔다리, 파스텔 옷). 새로 그리지 않는다.
- 옷 색 8가지: 세이지·테라코타·크림·분홍·하늘·겨자·연보라·밤색. 이름 대신 **옷 색으로 구분**한다.
- 남녀를 섞는다 (여 5, 남 3 정도).

- 지붕: 컷 1에서 열리고, 컷 7 끝에서 **다시 덮인다**.

## 3. 안 A — "울산 룸" 화면

### 방 모양 (사진이 없을 때 기본: 일반 세미나실)
`[사진]` 표시 = 강의장 사진(사람 없을 때 앞·뒤 2장)이 오면 바꾸는 부분.

| 부분 | 기본으로 잡는 모양 | 사진 오면 |
|---|---|---|
| 방 크기 | 가로 14m × 세로 18m, 천장 3m | `[사진]` 비율 맞춤 |
| 앞 | 낮은 단 + 큰 화면 1개 + 작은 연단 | `[사진]` 화면 위치·개수 |
| 의자 | 6줄 × 8석, 가운데 통로 1개, 짙은 남색 | `[사진]` 줄 수·색·통로 |
| 뒤 | 입구 문 1개(양쪽 문), 문 옆 다과 테이블(컵·주전자만) | `[사진]` 문 위치 |
| 옆 | 한쪽 벽에 창문 3개, 크림색 커튼 | `[사진]` 창 유무 |
| 바닥·벽 | 회갈색 카펫, 미색 벽 | `[사진]` 색 |
| 천장 | 네모 조명 줄 | `[사진]` 조명 모양 |
| 화분 | 앞쪽 양 끝에 하나씩 (라운지 화분 재사용) | 그대로 |

- 사진에서 **가져오지 않는 것**: 현수막, 로고, 포스터, 제품, 행사 이름 글자, 사람.
- 사진이 11/9까지 안 오면 이 기본 모양으로 간다.

### 방 안 큰 화면에 띄울 것
- 크림 바탕에 **"오늘, 울산"** 한 줄. "어, 여기 이 방이네"를 만드는 장치다.
- 날짜·팀 이름·행사 이름은 넣지 않는다.

### 카메라
- 방 대각선 위(사람 눈보다 조금 높이)에서 **60초에 한 바퀴** 천천히 돈다.
- 네 곳에서 3초씩 아주 느려진다: ① 입구 ② 의자 줄 가운데 ③ 앞 화면 ④ 다과 테이블.
- 한 바퀴가 끝나면 끊김 없이 다음 바퀴로 넘어간다.

- `D` 키를 누르면 오른쪽 아래에 작은 글씨로 **초당 화면 수, 크롬 메모리(MB), 화면 꺼짐 막기 켜짐/꺼짐, 영상 받아 둠 완료/미완료**가 나온다. 다시 누르면 숨겨진다.

### (나) 기본 대비책 — 바탕화면 MP4 1개
- 파일: 회장님 노트북 **바탕화면**의 `울산-대기화면.mp4` (안 C 30초 영상).

### (다) 검사 두 가지 (체크리스트에도 넣음)

## 8. 사장님께 확인할 것
1. 안 A에 **"끝난 뒤" 버튼(`3`)** 을 하나 더 넣었다. 끝난 뒤 글자를 쉬는 시간과 다르게 하려면 따로 바꿀 방법이 필요하다.
