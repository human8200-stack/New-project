## 1. 두 화면 공통 규칙

### 넣지 않는 것 (기획 2판 그대로 + 라운지에서 빼야 하는 것)
- 점수, 이름, 순위, 타이머, "보너스" 글자, 로고, 제품, 팀 이름, QR, 가격, 직급, 채팅.
- 지금 라운지에서 **그대로 가져오면 걸리는 것** (화면 녹화 전에 꼭 끈다):
  - 캐릭터 머리 위 **이름표** → 끈다 (이름 없는 캐릭터).
  - 위쪽 **"10코어 0/10"**, 내 이름 칸, 미니맵, 조이스틱, 소리·밤·정면·오늘 마무리 버튼, 요가·자전거 **타이머 말풍선** → 전부 숨김.
  - **전광판**(순위·꾸준상·"축하합니다" 깜빡임·이름) → 전광판 자체를 빼거나 빈 나무판으로.
  - **감사일기 판 쪽지의 이름**과 "파트너님께 미팅" 같은 사업 냄새 나는 문장 → 이름 없는 짧은 쪽지로 바꿈 (아래 2장).
  - **제품이 있는 자리**: 더마 아키텍트 존, 리플렉서 존, 정수기·공기청정기·가습기, 영양제, 제품 공간 간판, 비전 포스터, 컴퓨터실 화면(쇼핑·고객관리) → 화면에 안 잡히게 카메라를 피하거나 그 자리를 뺀다.
  - 입장 화면의 "ABLE TEAM" 글자 → 안 씀.
- 권유 말: "같이 해요", "함께하실 분", "들어오세요" 없음.

### 꼭 넣는 것
- **AI 표시**: 화면 오른쪽 아래 구석에 항상 작게 **"AI로 만든 화면"**. 숨기지 않는다. 누가 물으면 답: "AI로 직접 만들어 봤어요."
- 캐릭터는 모두 **지어낸 캐릭터**. 실제 팀원·참석자 얼굴·이름과 이어지지 않게.

### 캐릭터 정하기 (8명)
- 지금 라운지 캐릭터 그대로 (둥근 머리, 짧은 팔다리, 파스텔 옷). 새로 그리지 않는다.
- 옷 색 8가지를 서로 다르게: 세이지·테라코타·크림·분홍·하늘·겨자·연보라·밤색. 이름 대신 **옷 색으로 구분**.
- 남녀 섞어서 (여 5, 남 3 정도). 머리 모양 다양하게.

## 2. 안 C — 30초 대기 화면 콘티

- 크기: 1920×1080, 30프레임, **정확히 30.0초**.
- 카메라: 느리게. 멀미 나지 않게 한 컷 안에서 회전 15도 이하.
- **반복 이음새**: 첫 장면과 마지막 장면이 **같은 화면**(지붕 위에서 본 라운지 전체, 아침빛)이다. 끝에서 카메라가 그 자리로 돌아가 멈추고 → 처음으로 이어지면 끊김이 안 보인다. 마지막 0.5초는 첫 프레임과 똑같이 맞춘다.
- 소리: **무음.** 이유 — 강의장은 자체 음악·안내 방송이 있고, 회장님이 음량을 따로 맞출 수 없다. 소리가 없어도 다 알 수 있게 장면을 짰다. (기획 2판의 "소리 작게"를 "무음"으로 바꿨다 — 품질관리팀 확인 부탁)
- 글자: 장면 설명 자막 없음. **마지막 한 줄만.**

| 컷 | 초 | 화면 | 움직임 | 글자 | 소리 | 느낌 |
|---|---|---|---|---|---|---|
| 1 | 0.0–4.0 | 지붕 위에서 본 라운지 전체, 아침 햇빛. 지붕이 스르륵 투명해지며 안이 보임. 입구로 **세이지 옷** 캐릭터가 조금 쭈뼛하며 들어옴. 안쪽에서 **테라코타 옷**이 알아보고 손 흔들며 걸어 나옴 (머리 위 손 흔드는 말풍선) | 카메라 천천히 내려앉으며 입구 쪽으로 | 없음 | 없음 | 같이 — 맞아 주는 사람 |
| 2 | 4.0–9.0 | 운동존 자전거 두 대. 테라코타가 세이지를 옆 자전거로 데려가 나란히 앉음. 둘이 같이 페달 → 바퀴 빨라짐 → 서로 손을 뻗어 **하이파이브** (손 닿는 순간 작은 반짝임 한 번) | 옆에서 나란히 따라가는 카메라 | 없음 | 없음 | 재밌다 |
| 3 | 9.0–14.0 | 독서존 소파. **크림 옷**이 소파 끝에 **혼자** 책 읽는 중. **분홍 옷**이 책 두 권 들고 와 **옆에 털썩 앉고** 한 권을 건넴. 둘이 동시에 책장 넘김 | 정면에서 아주 천천히 다가감 | 없음 | 없음 | 같이 — 혼자 옆에 누가 앉음 |
| 4 | 14.0–18.0 | 카페 코너. **하늘 옷**이 머그컵 **두 잔**을 들고 걸어와 강의 듣던 **겨자 옷**에게 한 잔 건넴. 겨자가 고개 끄덕, 둘이 컵 살짝 부딪침 | 고정, 살짝 확대 | 없음 | 없음 | 같이 — 챙김 |
| 5 | 18.0–23.0 | 요가 매트 세 장, 셋이 나란히 (연보라·밤색·세이지). 가운데 밤색이 한 발 들기를 하다 **휘청** → 양옆이 동시에 팔 잡아 줌 → 셋 다 머리 위에 웃는 얼굴 말풍선 | 앞에서 낮게 | 없음 | 없음 | 재밌다 + 같이 |
| 6 | 23.0–27.0 | 감사일기 판. 크림 옷이 노란 쪽지를 붙임 ("같이 걸어서 좋았어요"). 지나가던 캐릭터 셋이 차례로 쪽지에 **하트 스티커 톡·톡·톡** | 판 정면, 하트 하나 붙을 때마다 아주 살짝 다가감 | 쪽지 글 (읽히지 않아도 됨) | 없음 | 재밌다 + 같이 |
| 7 | 27.0–30.0 | 모두 라운지 가운데로 모여 둥글게 서서 서로 손 흔듦 → 카메라가 뒤로·위로 빠지며 **컷 1 첫 화면과 같은 자리**에서 멈춤. 27.3초에 마지막 문장 나타남(0.4초 서서히) → 29.3초에 사라지기 시작 → 30.0초 완전히 사라짐 | 뒤로 빠지며 올라감 → 멈춤 | **마지막 문장** | 없음 | 끝 = 처음 |

### 감사일기 쪽지 (이름 없이, 화면에 붙어 있는 것)
- "같이 걸어서 좋았어요" / "오늘 커피 고마워요" / "옆자리 덕분에 끝까지 읽었어요" / "아침 햇살에 감사" / "웃게 해 줘서 고마워요"
- 제품·사업·몸이 좋아진다는 말 없음.

### 마지막 문장 후보 (추천 맨 앞)
1. **"작은 습관을 매일, 같이"** — 추천. 회장님 30초 말 ①과 같은 말이라 화면과 말이 이어진다. 10자.
2. **"옆에 있으면, 오늘도 하게 돼요"** — 따뜻하지만 조금 길다. 13자.
- 둘 다 권유가 아니라 "우리는 이렇게 지낸다"는 말. 금지어 없음.

### 만드는 방법 (돈 안 드는 쪽으로 정함)
- 지금 라운지 3D 그대로 화면 녹화한다 (Runway 등 생성 도구 안 씀 → **0원, 크레딧 0**). 그래서 생성 도구 프롬프트는 없다.
- **주의 — 일정 바뀜**: 기획 2판은 "기존 홍보 영상 장면 재사용, 1일"이었다. 그런데 기존 홍보 영상은 "대화 기능이 없으니 마주 보는 장면을 하지 않는다"로 만들어져서 **하이파이브·건네기·옆에 앉기·휘청·하트 붙이기 동작이 없다.** 새 동작을 넣어야 하므로 **2일**로 본다. 이 동작은 안 A에도 그대로 쓰니 손해는 없다.

## 3. 안 A — "울산 룸" 화면

### 방 모양 (사진 없을 때 기본: 일반 세미나실)
`[사진]` 표시 = 강의장 사진(사람 없을 때 앞·뒤 2장)이 오면 바꾸는 부분.

| 부분 | 기본으로 잡는 모양 | 사진 오면 |
|---|---|---|
| 방 크기 | 가로 14m × 세로 18m, 천장 3m | `[사진]` 비율 맞춤 |
| 앞 | 낮은 단 + 큰 화면 1개 + 작은 연단 | `[사진]` 화면 위치·개수 |
| 의자 | 6줄 × 8석, 가운데 통로 1개. 의자 색 짙은 남색 | `[사진]` 줄 수·색·통로 |
| 뒤 | 입구 문 1개 (양쪽 문), 문 옆 다과 테이블 (컵·주전자만) | `[사진]` 문 위치 |
| 옆 | 한쪽 벽 창문 3개, 커튼 크림색 | `[사진]` 창 유무 |
| 바닥·벽 | 바닥 회갈색 카펫, 벽 미색 | `[사진]` 색 |
| 천장 | 네모 조명 줄 | `[사진]` 조명 모양 |
| 화분 | 앞쪽 양 끝에 하나씩 (라운지 화분 재사용) | 그대로 |

- 사진에서 **가져오지 않는 것**: 현수막, 로고, 포스터, 제품, 행사 이름 글자, 사람.
- 사진이 끝내 안 오면 이 기본 모양 그대로 간다 (그래도 "강의장 같다"는 느낌은 난다).

### 방 안 화면(앞쪽 큰 화면)에 띄울 것
- 크림 바탕에 **"오늘, 울산"** 한 줄. "어, 여기 이 방이네"를 만드는 장치.
- 날짜·팀 이름·행사 이름은 넣지 않는다.

### 카메라
- 방 대각선 위(사람 눈보다 조금 높이)에서 **60초에 한 바퀴** 천천히 돈다.
- 네 곳에서 3초씩 아주 느려짐: ① 입구 ② 의자 줄 가운데 ③ 앞 화면 ④ 다과 테이블.
- 바퀴가 끝나면 끊김 없이 다음 바퀴.

### 캐릭터가 하는 일 (8명, 이름표 없음)
| 자리 | 하는 일 | 전하는 느낌 |
|---|---|---|
| 입구 | **맞이 캐릭터(테라코타)** 가 문 옆에 서 있다. 20초마다 새 캐릭터가 들어오면 손 흔들며 몇 걸음 마중 | 같이 — 와 주면 반겨 줌 |
| 의자 줄 | 빈 의자 하나 위에 **"오늘의 자리"** 작은 표(크림색 방석 + 머리 위 작은 팻말). 들어온 캐릭터가 그 자리에 앉으면 옆자리 캐릭터가 고개 돌려 손 인사. 그다음 다른 빈 의자에 새 "오늘의 자리" 표가 생김 | 같이 — 내 자리가 마련돼 있음 |
| 의자 줄 가운데 | 둘이 나란히 앉아 책 한 권을 같이 봄. 한 명이 가리키면 다른 한 명이 고개 끄덕 | 같이 |
| 의자 뒷줄 | 기지개 켜다 팔이 옆 사람 어깨에 툭 → 둘이 마주 보고 웃는 말풍선 | 재밌다 |
| 다과 테이블 | 컵 두 개 들고 하나를 건넴, 컵 살짝 부딪침 | 같이 — 챙김 |
| 창가 | 둘이 창밖 보며 나란히 서 있음, 가끔 한 명이 어깨 톡 | 같이 |

- 사람 수가 계속 늘지 않게: 한 명이 들어와 앉을 때 다른 한 명이 일어나 다과 테이블로 간다. 방 안은 늘 8명.

### 강의 전 vs 쉬는 시간

| | 강의 전 | 쉬는 시간 |
|---|---|---|
| 빛 | 맑은 아침빛, 조금 밝게 | 오후빛, 조금 더 따뜻한 노란빛 |
| 의자 | 대부분 비어 있음. 하나둘 들어와 앉는 중 | 거의 다 일어나 있음. 빈 의자 많음 |
| 캐릭터 | 맞이 캐릭터가 바쁨. "오늘의 자리" 표가 계속 생김 | 의자 줄 사이에서 **하이파이브**, 다 같이 **기지개(스트레칭)**, 다과 테이블에 서너 명 모임, 창가 둘 |
| 앞 화면 | "오늘, 울산" | "오늘, 울산" (같음) |
| 아래 한 줄 | **"어서 오세요"** | **"잠깐 쉬어 가요"** |
| 번갈아 | 30초 영상 ×2 → 룸 60초 → 반복 | 룸만 계속 |

- 끝난 뒤: 쉬는 시간 화면을 그대로 쓴다 (따로 만들지 않음).

### 회장님이 누르는 것
- 화면 왼쪽 아래 버튼 2개: **"강의 전"** / **"쉬는 시간"** (각 높이 64px 이상, 노트북 터치·마우스 둘 다).
- 키보드로도: `1` 강의 전, `2` 쉬는 시간, `F` 전체 화면.
- 마우스를 3초 안 움직이면 버튼과 마우스 화살표가 **사라진다** (강의장 화면에 버튼이 보이지 않게). 마우스를 움직이면 다시 나타남.
- 처음 열면 "강의 전"으로 시작.

## 4. 색 · 글씨 · 글자 수

### 색 (라운지에 이미 있는 색만 씀, 새 색 없음)
| 쓰임 | 색 | 라운지 이름 |
|---|---|---|
| 글자 | `#3b2f25` 짙은 갈색 | ink |
| 글자 뒤 띠 | `#f7f1e6` 크림, 불투명도 92% | cream |
| 띠 테두리·강조 한 군데 | `#c9824f` 주황빛 갈색 | accent |
| 보조 | `#7f9a7a` 세이지, `#e9dcc6` 베이지 | sage, beige |

- **글자는 3D 위에 바로 올리지 않는다.** 꼭 크림 띠 위에. 빔은 밝은 색을 날려 버려서 띠 없이는 안 읽힌다.
- 흰 바탕에 연한 글자, 빨강·초록만으로 구분하는 것 금지.
- 깜빡임 금지: 1초에 3번 넘게 번쩍이는 것 없음 (라운지 전광판 깜빡임은 빼기).

### 글씨 크기 (강의장 맨 뒤 약 15m에서 읽히게)
기준은 **화면 높이에 대한 비율**로 정한다 (TV·빔 크기가 달라도 같게 보이게). 1080 화면 기준 픽셀을 괄호에 적음.

| 글 | 크기 | 굵기 |
|---|---|---|
| 마지막 문장 / 아래 한 줄 | 화면 높이의 **10%** (108px) | 굵게(700) |
| 방 안 화면 "오늘, 울산" | 3D 안 글자라 카메라가 멀 때도 화면 높이 4% 이상 보이게 판 크기 조정 | 굵게 |
| "오늘의 자리" 팻말 | 장식. 앞줄에서만 읽혀도 됨 | 보통 |
| "AI로 만든 화면" | 화면 높이 **3.5%** (38px), 불투명도 80% | 보통 |

- 글꼴: 라운지와 같은 순서 (Apple SD Gothic Neo → Noto Sans KR → 맑은 고딕). Windows 노트북에서는 맑은 고딕으로 나온다.

### 글자 위치
- 가장자리 **5%** 는 비운다 (빔이 가장자리를 자름).
- 문장은 **화면 위쪽 3분의 1 ~ 가운데** 에. 아래쪽은 앞사람 머리에 가린다. 그래서 "아래 한 줄"도 실제 위치는 **화면 가운데보다 약간 아래(세로 60% 지점)** 가 한계, 그 밑으로 내리지 않는다.
- 버튼(강의 전·쉬는 시간)은 숨겨지므로 왼쪽 아래 둬도 된다.

### 한 화면 글자 수
- **한 번에 한 줄, 12자 안팎, 많아도 14자** (띄어쓰기 빼고).
- 두 줄 이상 금지.
- 화면에 떠 있는 시간: 최소 2초 (안 C 마지막 문장은 약 2초 꽉 차게 + 서서히 나타나고 사라짐).
- 이번 화면에 나오는 글은 이게 전부: 마지막 문장 1개, "어서 오세요", "잠깐 쉬어 가요", "오늘, 울산", "오늘의 자리", "AI로 만든 화면", 감사 쪽지 5장.
