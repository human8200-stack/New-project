# 크롬 Claude 지시문 — 네이버 블로그를 "엄마의 영양 노트"로 꾸미기 (회장님 11/11)

회장님 원문: "블로그 만들자" → 빈 블로그를 건강 블로그(엄마의 영양 노트)로 먼저 "ㅇㅋ" → "크롬 클로드를 통해서 자동으로 올릴거야"

너는 회장님 크롬에서 일하는 Claude야. **blog.naver.com/human820** 블로그 설정만 바꾼다. 글은 쓰지 않는다. **아무것도 지우지 않는다**(글·카테고리·이웃 삭제 금지). 로그인·비밀번호·결제 화면이 나오면 멈추고 회장님께 묻는다. 바꾸기 전 지금 설정(블로그명·별명·소개·스킨 이름)을 메모해 두고 끝에 회장님께 알려 준다(되돌릴 수 있게).

## 1. 기본 정보 (관리 → 기본 설정 → 블로그 정보)
- 블로그명: `엄마의 영양 노트`
- 별명: `영양 노트 엄마`
- 소개글:
```
의사도 약사도 아닌 엄마가 10년 넘게 공부한 건강 이야기
내 몸이 궁금할 때, 저장해 두고 꺼내 보는 노트
진단·치료를 대신하지 않아요
```
- 블로그 프로필 이미지: 노션 "엄마의 영양 노트 — 프로필" 페이지(https://app.notion.com/p/4152e9d6f35181e4b704dd6a6d9e9a61) 맨 위 "✅ 확정 프로필 사진"(엄마 그림+연필). 파일 고르는 창을 직접 못 누르면 거기서 멈추고 회장님께 "프로필 사진 파일을 이 채팅에 끌어다 놓아 주세요"라고 부탁한다.
- 블로그 주제(있으면): "건강·의학" 또는 가장 가까운 것.

## 2. 꾸미기 (관리 → 꾸미기 설정)
- 스킨: 밝고 단순한 기본 스킨(흰색·연한 초록 계열, 큰 사진 대문 없는 것). 지금의 빨간 띠·딸기 접시 대문은 쓰지 않는다. 고른 스킨 이름을 메모.
- 타이틀: 글자 "엄마의 영양 노트"만(이미지 없음).
- 지금 왼쪽 프로필의 "HOW ARE YOU?" 그림은 1번 프로필 사진으로 바뀌면 된다.

## 3. 카테고리 (관리 → 메뉴·글·동영상 관리 → 블로그 → 카테고리)
- 새 카테고리 `영양 노트` 만들고 맨 위로, 글쓰기 기본 카테고리로 지정.
- 그 아래 하위 카테고리: `장 공부` (첫 글들이 들어갈 곳).
- 기존 "여행 스케치", "videolog", "이벤트"는 **지우지 말고** 공개 설정만 "비공개"로(가능하면). 안 되면 그대로 둔다.
