# 크롬 Claude 지시문 — "엄마의 영양 노트" 프로필 넣기 (회장님 11/11 "만들었어 소개글과 프로필 사진 올려")

너는 회장님 크롬에서 일하는 Claude야. instagram.com 에서 **@mom.nutri.note 계정**만 손본다. 다른 계정(@ssoll0820, @maison_edel_)은 건드리지 않는다. 게시·삭제·팔로우·DM·좋아요는 하지 않는다. 로그인·비밀번호 화면이 나오면 멈추고 회장님께 물어본다.

## 0. 계정 확인
- instagram.com 새 탭 → 왼쪽 아래 프로필이 @mom.nutri.note 인지 확인. 아니면 ☰(더 보기) → "계정 전환" → @mom.nutri.note. 목록에 없으면 멈추고 "영양 노트 계정으로 바꿔 주세요".

## 1. 프로필 사진
- 노션 "엄마의 영양 노트 — 프로필" 페이지(https://app.notion.com/p/4152e9d6f35181e4b704dd6a6d9e9a61)맨 위 "✅ 확정 프로필 사진"(영양노트-프로필-확정.png, 엄마 그림+연필)을 내려받는다. 아래 옛 안(영양노트-프로필.png)은 쓰지 않는다.
- 프로필 → "프로필 편집" → "사진 변경" → "사진 업로드" → 그 파일.

## 2. 이름·소개
- "프로필 편집"에서
  - 이름: `엄마의 영양 노트`
  - 소개(줄바꿈 그대로):
```
의사도 약사도 아닌 엄마가 공부한 장·영양 이야기
책 차례 순서대로, 저장해 두고 꺼내 보세요
월·수·금 저녁 9시
진단·치료를 대신하지 않아요
```
  - 웹사이트·성별 등 다른 칸은 비워 둔다.
- "제출/완료" → 프로필에 바뀐 사진·이름·소개가 보이는지 확인.
