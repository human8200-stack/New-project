# 크롬 Claude 지시문 — "엄마의 영양 노트" No.01 게시 (회장님 11/11 "오늘 것만 예외적으로 하나 올려 줘" → "2번")

너는 회장님 크롬에서 일하는 Claude야. instagram.com 에서 **@mom.nutri.note 계정에만** 게시물 1개를 올린다. 다른 계정(@ssoll0820, @maison_edel_)은 절대 건드리지 않는다. 팔로우·DM·좋아요·삭제는 하지 않는다. 로그인·비밀번호 화면이 나오면 멈추고 회장님께 물어본다.

## 0. 계정 확인
- instagram.com 새 탭 → 왼쪽 아래 프로필이 @mom.nutri.note 인지 확인. 아니면 ☰(더 보기) → "계정 전환" → @mom.nutri.note. 목록에 없으면 멈추고 "영양 노트 계정으로 바꿔 주세요".

## 1. 카드 8장 내려받기
- 노션 "엄마의 영양 노트 — 게시 결재" 페이지(https://app.notion.com/p/4152e9d6f35181929800c26e42b03ca4) 맨 아래 **"⭐ No.01 최종 8장"** 의 No01-final-1.png ~ No01-final-8.png 를 내려받는다. (그 위의 9장은 옛것 — 쓰지 않는다.)

## 2. 올리기
- 왼쪽 메뉴 "만들기(＋)" → "게시물" → 컴퓨터에서 선택 → 8장을 **1→8 순서대로** 선택(순서가 틀리면 편집 화면에서 맞춘다).
- 자르기: 원본(4:5 세로) 그대로. 필터·편집 없음.
- 문구 칸에 노션 페이지 맨 아래 "No.01 최종 게시물 글"을 줄바꿈 그대로 붙여 넣는다.
- 위치·태그·음악 넣지 않는다. 고급 설정의 AI 라벨은 켜지 않는다(AI 그림 아님).
- "공유".

## 끝나면
- 올라간 게시물 주소를 확인하고 회장님께 한 줄: "영양 노트 No.01 올렸어요 (주소)". 안 됐으면 무엇이 막혔는지.
