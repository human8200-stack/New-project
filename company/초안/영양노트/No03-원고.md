## 편집팀 메모 (게시물에는 넣지 않음)

### 사실 확인
- **뷰티르산 = 큰창자 벽 세포의 주된 에너지원**: 사람 큰창자 세포 연구(Roediger 1980)에서 뷰티르산 하나만 줬을 때 산소 소비의 약 70%대를 차지. "주된 밥"은 이 뜻. 작은창자 세포는 다른 것(글루타민 등)을 주로 써서 "큰창자 벽 세포"로 한정함. 숫자는 카드에 넣지 않음
- **섬유 → 균 → 뷰티르산**: 사람이 못 쪼갠 식이섬유를 큰창자 균이 발효해 짧은사슬지방산(아세트산·프로피온산·뷰티르산)을 만듦 — 2-4·2-5·2-10과 같은 출처(Holscher 2017). 뷰티르산은 특정 무리의 균이 만들고, 다른 균이 먼저 쪼갠 것을 이어받아 만들기도 해서 "장 속 균들이"로 씀(모든 균이 만든다고 읽히지 않게)
- **저항성 전분**: 지은 밥을 식히면 녹말 일부가 다시 뭉쳐(노화) 소화가 덜 되는 녹말이 늘고, 식혔다가 다시 데운 밥에서도 늘어 있었음(Sonia 2015, 흰쌀밥). 감자도 같은 원리로 흔히 설명(감자 자체 수치 출처는 이번에 확인 안 함). 카드에는 혈당 이야기를 넣지 않음(병과 이어지기 쉬움)
- **"벽돌은 그 밥으로 새로 쌓여요"(8장)**: No.02 "벽은 며칠마다 새로 쌓아요" + 뷰티르산이 에너지원이라는 두 사실을 이은 쉬운 말. 뷰티르산이 이음매를 조이는 데 관여한다는 세포 실험(Peng 2009)은 있으나 세포 실험이라 카드에 쓰지 않음
- **조눌린**: Fasano 연구팀이 2000년에 보고한 단백질, 장 세포 사이 이음매(밀착연접)를 여는 신호로 작용(2000 Lancet·J Cell Sci). 2009년 같은 연구팀이 '프리합토글로빈-2'로 밝힘. 카드 "2000년 미국의 한 연구팀"은 이 뜻(사람 이름은 출처에만)
- **모르타르가 조였다 풀었다**: 2-5 "이음매는 늘 같은 너비로 닫혀 있는 게 아니라 … 느슨해지기도 조이기도 해요"(Camilleri 2019)와 같은 내용
- **글루텐 성분·일부 균이 조눌린을 부름**: 글리아딘(밀 글루텐 성분)이 장 세포의 받는 곳(CXCR3)에 붙어 조눌린 분비를 부른다(Lammers 2008, 세포·쥐·사람 조직), 장 속 균에 노출된 작은창자 조직이 조눌린을 냄(El Asmar 2002, 떼어 낸 조직 실험) → 카드에 "실험실 연구"로 밝힘. El Asmar는 이것을 균을 씻어 내는 방어로 해석 — 카드에는 넣지 않음(가설)
- **피로 재는 값 논란**: 널리 쓰이는 시판 조눌린 측정 키트가 프리합토글로빈-2를 잡지 못하고 다른 단백질을 잡는다는 보고 2건(Scheffler 2018, Ajamian 2019). Ajamian은 "측정법이 나아질 때까지 장벽 지표로 보는 데 신중하라"고 결론 → 카드 "의견이 갈려요"
- "밀을 끊으라는 뜻은 아니에요": 밀·글루텐 이야기가 '끊으라'로 읽히지 않게 넣은 문장. 근거 문장이 아니라 오해 막는 안내 → 감수 대상

3. 7장 아래 작은 글씨: rules.js 고정 문장(FOOD_FIRST)에 비타민A 때문에 "임신 중이거나"를 더함(No.02와 같은 방식). No.02의 "음식으로 먼저, 음식으로 골고루 먼저"는 같은 말이 겹쳐 "음식으로 골고루 먼저"로 줄임
4. 6장 식이섬유 아래 작은 글씨 두 문장은 기능성 문장이 아니라 일반 설명 — 기능성 문장과 다른 줄로 떼어 둠
5. 출처 줄: 시리즈와 같은 "건강 강의를 공부하며 정리한 노트". 이 노트는 연구 논문 비중이 커서 "건강 강의와 연구 자료를 공부하며 정리한 노트"로 바꾸는 안도 있음 — 사장 판단
6. 카드 제목 표현: 주제 이름 "장벽을 지키는 것들"은 조눌린이 이음매를 '여는' 신호라 조금 어긋남 → 카드 1장은 "벽돌의 밥, 문지기"로 씀. 다음 노트 안내 줄에는 지시대로 "장벽을 지키는 것들"

### 의료인 감수가 필요한 곳
1. 5장 전체 — 글루텐·균과 조눌린(실험실 연구 수위), "피로 재는 값 … 의견이 갈려요", "밀을 끊으라는 뜻은 아니에요"(밀을 피해야 하는 분이 있으니 안내가 더 필요한지)
2. 4장 "문지기" 비유 — 조눌린이 이음매를 여는 '신호'라는 설명이 과하지 않은지
3. 8장 "남은 밥은 냉장고에 식혀 두기" + 실온 보관 주의 문장 — 식중독 안내 수위(편집팀 기억: 밥을 실온에 오래 두면 바실루스 세레우스 위험. 식약처 안내 페이지 확인 필요)
4. 6장 식이섬유 "조금씩 늘려요" — 2-10과 같은 기준
5. 7장 비타민A·흡연자, 임신 문장 — No.02와 같은 말

### 디자인팀에 넘길 그림 목록 (모두 단순 선 그림, AI 그림·사진 없음)
1. 1장: No.02 벽돌 한 줄 + 벽돌 위 작은 밥그릇 + 이음매 옆 문지기(열쇠고리 든 작은 동그라미)
2. 2장: 네 칸 흐름 나물 접시 → 균 → 물방울(뷰티르산) → 벽돌 한 줄, 아래 "섬유 → 균 → 뷰티르산 → 장벽 세포"
3. 3장: 밥상(잡곡밥·콩자반·나물·찐 감자) + 식힘 눈송이 + 감자에서 큰창자 균으로 점선
4. 4장: 벽돌 두 개 사이 이음매가 작은 문처럼 살짝 열림 + 문지기 + 신호 물결
5. 5장: 두 칸 "알려진 것"(밀 이삭·균 → 문지기) / "아직 연구 중"(시험관·물음표)
6. 6·7장: 그림 없이 번호 목록, 영양소 이름 형광펜
7. 8장: 체크 칸 + 잡곡밥 공기 + 작은 냉장고 문
- 벽돌·모르타르 모양과 선 굵기는 No.02 4·5·6장과 똑같이. 문지기는 1·4·5장에서 같은 모양(시리즈 캐릭터처럼, 무섭지 않게). 균 동그라미는 No.04(장 속 균) 캐릭터와 같은 모양으로 맞추면 이어짐
- 의학 교과서 같은 몸속 그림, 분자 구조 그림은 쓰지 않음
