# 엄마의 영양 노트 — 블로그 글쓰기 앱

회장님이 휴대폰으로 **네이버 블로그 "엄마의 영양 노트"(blog.naver.com/human820)** 글을 만드는 앱이에요.
노트를 고르고 한마디만 말하면, 제목 3개·본문·태그가 나와요. 네이버는 다른 앱이 대신 글을 올리는 길이 막혀 있어서, 마지막 올리기는 회장님 손으로 해요 (버튼 하나 + 붙여 넣기 + 발행).

- 상태: 내 컴퓨터 시험 완료, **공개됨 — https://noma-note.netlify.app (11/11)** — 공개는 회장님 결재가 필요해요.
- 만든 날: 2026-11-11 (개발팀). ARTPLAY 블로그 앱(`company/초안/ARTPLAY-블로그/앱/`)을 복사해서 고쳤어요.
- 회장님 원문(11/11): "결국 블로그 어플 만든 걸로 가야하네" → "내 블로그 만드는 어플 만들자" / "나는 너무 복잡하다" → 손을 최소로 (노트 불러오기, 보내기 버튼 하나)

## 회장님이 쓰는 법 (아이폰)

**처음 한 번**
1. 회사가 드린 주소를 사파리로 열어요.
2. **접속 코드**를 넣고 [시작하기]. (코드 없이 [체험해 보기]도 돼요. 체험은 예시 글만 나오고 돈이 들지 않아요.)
3. 사파리 아래 가운데 **공유 버튼(네모에 위 화살표)** → **홈 화면에 추가**.

**글 만들 때 (1분)**
1. **① 노트 고르기** — 회사가 카드·원고를 만든 노트(✓ 표시)는 고르기만 하면 카드 사진과 원고가 한 번에 들어가요. (처음 열면 가장 최근 노트가 골라져 있어요)
2. **② 회장님 한마디** — 키보드의 마이크를 누르고 경험·느낌 한두 줄을 말해요. 비워 두면 글에 "[회장님 한 줄]" 자리가 남아요 (회사가 지어내지 않아요).
3. **[글 만들기]** → 30초~1분, 화면을 켠 채로 기다려요.

**블로그에 올리기 (3단계)**
1. 맨 위 큰 버튼 **[블로그에 붙여 넣을 글 복사 (그림 포함)]** 을 눌러요. 글·그림·태그가 한 번에 복사돼요. 문단·줄 나눔이 그대로 있고, 카드 그림이 글 사이사이 제자리(카드 1 → 첫 문단 → 카드 2 → 입 이야기 → …)에 들어가요.
2. **네이버 블로그 앱** → 글쓰기 → 본문 칸을 **길게 눌러 [붙여넣기]**.
3. 이 앱으로 돌아와 **[제목 복사]** → 블로그 제목 칸에 붙여 넣고 **[발행]**.

- **그림이 안 들어오면** (글만 들어올 때): 붙인 글은 그대로 두고, 아래 **"그림이 안 따라오면"** 칸의 **[사진 순서대로 보내기]** 를 눌러요. 글이 다시 복사되고 공유 창이 떠요 → **블로그**를 누르면 사진이 맨 위에 들어간 글쓰기가 열려요 → 글 칸에 붙여넣기. (이 방법은 사진이 맨 위 한 묶음이에요)
- 본문 속 **"📷 사진 3"** 같은 줄은 그 자리에 그림이 들어간다는 표시예요. 줄을 옮기면 그림 자리도 바뀌어요. 복사할 때 그림으로 바뀌고 글자로는 남지 않아요.

- 보내기 전에 **"올리기 전에 확인할 점"** 을 봐요. **빨간 글**은 꼭 고칠 것(금지어·병 단정·영양소 문장 틀림)이에요. 본문을 그 자리에서 고치면 바로 다시 검사해요.
- 휴대폰이 공유 창을 못 열면 아래 버튼이 **[사진 순서대로 저장]** 으로 바뀌어요. 사진이 01, 02… 순서로 저장되니, 블로그 앱에서 사진 버튼 → 01부터 순서대로 고르고 글 칸에 붙여 넣으면 돼요.
- 직접 찍은 사진(밥상·장보기)이나 다른 원고는 **[더 넣기]** 에서 넣어요 (사진 최대 10장). 얼굴·아이·제품 상표가 보이는 사진은 빼 주세요 — AI가 보이면 알려 줘요.
- 마음에 안 들면 [다시 만들기]. 만든 글은 [지난 글]에 10개까지 남아요 (이 휴대폰에만).

## 회사가 알아 둘 것

**구조**
```
블로그앱/
  public/                      화면
    index.html app.css app.js  화면과 버튼 (app.js는 모듈)
    rules.js                   ★ 영양소→식약처 문장 표, 금지어, 고정 문장, 규칙 검사기 (서버 AI 지시문도 이 파일을 씀)
    demo.js                    체험 예시 글 (No.01)
    notes/notes.json           ★ 회사가 만든 노트 목록 (카드 그림 + 원고). 새 노트는 여기 한 칸 + notes/노트폴더/ 에 카드
    notes/no01/                No.01 카드 8장
    sw.js manifest icons/
  netlify/functions/           서버 함수 3개
    check.mjs   /api/check   접속 코드 확인, 오늘 남은 글
    photos.mjs  /api/photos  회장님이 직접 넣은 사진만 읽기 (회사 노트 카드는 원고에 글이 있어 읽지 않음 → 돈 아낌)
    write.mjs   /api/write   글쓰기 (흘려 보냄)
  netlify/lib/
    prompt.mjs   AI 지시문 (글 모양·말투·건강 글 규칙). 영양소 표는 rules.js에서 끼워 넣음
    guard.mjs    접속 코드, 하루 한도, 틀린 코드 잠금
    claude.mjs   Claude API 연결, 쉬운 오류 문구
  netlify.toml  dev-server.mjs(내 컴퓨터 시험용)
```

**새 노트 넣는 법 (사장)**: `public/notes/notes.json`에 한 칸 더하고(`id, no, title, toc, next, source, cards[{file, desc}], manuscript`), 카드 PNG를 `public/notes/noXX/`에 넣어요. 그다음 `app.js`의 `APP_VERSION`과 `sw.js`의 `CACHE`를 하나 올려요.

**글 규칙 (rules.js + prompt.mjs)** — 기준: 건강계정-계획.md 7장, 블로그-계획.md 5장 4·7번, 회장님.md 영양 노트 줄들
- 말투 "~해요", 이모지 없음, AI 티 나는 말 금지(알아보겠습니다·결론적으로·다양한·~에 대해 등). 회장님 1인칭 경험("저는 ~했어요")은 한마디에 있는 것만
- 병 낫는다·막는다·없앤다·면역력 높인다 단정 금지, 영양소 효능은 【챙겨 볼 영양소】 칸에서 식약처 문장으로만(칸 밖에서 영양소 이름+효능 말이 한 문장에 나오면 빨간 글), 칸 안 영양소 줄은 "번호. 이름 — 문장" 모양만(다르면 빨간 글), "자가진단"→"생활 점검표", 치료 체험담 금지, 제품·회사·사업·링크·영양제 권유 금지
- 영양소 설명은 표의 식약처 고시형 문장 그대로만(비타민C·E는 "항산화 작용을 하여…"까지), 관련 영양소 빠짐없이, 비타민B군은 B1·B2·B6처럼 나눠 씀(태그도), 표에 없으면 "확인 필요"
- 비타민A = "(베타카로틴)" + 베타카로틴 문장 + 흡연자 상담, 비타민K = 와파린 상담, 오메가3 = 약 상담, 칸 끝 "음식으로 골고루 먼저 챙겨요…"
- 끝: "진단·치료를 대신하지 않아요. 치료 중이면 담당 의사와 먼저." + 출처 한 줄
- **사진 자리 (11/11 회장님 아이폰 시험 뒤 바꿈)**: 회장님 원문 "문단 나누기 줄 나누기 하나도 안 되고 그냥 한 줄로 쫙… 그림 따로 글 따로야". → AI가 본문에 "📷 사진 n" 줄을 노트 카드 순서대로 넣고(질문 카드는 맨 앞, 소제목 카드는 그 【소제목】 앞, 영양소·정리·마무리 카드도 그 칸 앞), 앱이 복사할 때 그 줄을 그림으로 바꿔요. 복사는 HTML(문단마다 `<p>`, 빈 줄은 `<p><br></p>`, 【소제목】은 굵게) + 글(text/plain)을 같이 넣어요. 복사 방법은 ① ClipboardItem(아이폰 사파리 13.4부터) ② 안 되면 숨은 칸을 골라 `execCommand('copy')` ③ 그래도 안 되면 글만. 회사 노트 카드는 이 사이트 주소(`https://noma-note.netlify.app/notes/…png`)로, 회장님이 직접 넣은 사진은 작게 줄인 JPEG(긴 변 1080, data 주소)로 넣어요. 직접 넣은 사진은 방금 만든 글에서만 들어가고, 자리 표시가 없는 그림은 맨 위에 순서대로 들어가요. 태그는 본문 끝에 같이 붙여 넣어요 (네이버가 본문 속 #태그를 태그로 받음 — 실제 화면 확인 필요)
- **영양소 표는 품질관리팀이 식약처 원문과 한 번 대조해야 해요.** 병 이름이 든 문장(골다공증 위험 감소)은 일부러 뺐어요.

**시험 기록 (2026-11-11, 개발팀)**
- 문법 검사 전부 통과. Playwright(아이폰 13 화면)로: 체험 모드 → No.01 카드 8장·원고 자동 불러오기 → 한마디 → 글 만들기 → 보내기(글 복사 다음 공유 창, 사진 8장 JPEG 순서대로) → 본문 고치면 빨간 글 바로 뜸 → 지난 글. 공유가 안 되는 기기에서는 [글 복사 + 사진 저장]으로 바뀌고 사진 8장 내려받기.
- 하루 한도: 동시에 10번 눌러도 한도를 넘지 않음, 차례로 누르면 한도(시험 3)까지 통과 후 막힘, 되돌리기 됨.
- 가짜 API 서버로 실제 흐름 시험: 접속 코드 틀림 안내, 직접 넣은 사진 1장만 읽기(노트 카드 8장은 안 보냄), 글 흘려 받기, 남은 글 20→19, 사진 속 상표 알림.
- 규칙 검사기 (품질관리팀 1차 반려 뒤 다시): 금지어 문장 16개 모두 걸림, 영양소 칸 안 모양이 다른 줄 3개("5. 비타민B6: …", "- 비타민B6 — …", "비타민B6은 …") 모두 걸림, 칸 밖 단정 5개("비타민C는 감기를 막아 줘요", "변비가 없어져요" 등) 모두 걸림, 태그 #비타민B·#비타민B군 걸림, 단백질·몰리브덴 문장의 "효소"와 지명(남양주·덴마크·광동)은 안 걸림, 영양소 규칙 9가지(묶음 B군, 식약처 문장 아님, 다른 말 섞임, 베타카로틴·와파린 문장 없음, 표에 없는 영양소, 음식 먼저 문장·안내 문구·출처 빠짐) 모두 걸림, 바른 비타민A·K 문장은 통과.
- **실제 Claude API 호출은 못 했어요** — 작업 환경에 API 키가 없어서. 배포 전 회사 키로 1번 시험해야 해요.
- **아이폰 사파리에서 "블로그" 앱으로 사진 보내기는 아직 확인 못 했어요** (아래).

6. 본문 속 #태그가 네이버에서 태그로 잡히는지.
