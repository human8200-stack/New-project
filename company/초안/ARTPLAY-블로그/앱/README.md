# ARTPLAY 블로그 글쓰기 앱 (독립판)

ARTPLAY 인테리어 사장님이 **claude.ai 계정 없이** 휴대폰으로 쓰는 앱이에요.
시공 사진을 넣고 버튼 몇 개를 누르면 네이버 블로그 글 초안(제목 3개·본문·해시태그)이 나와요. 사장님은 복사해서 네이버 블로그 앱에 붙여 넣으면 돼요. 자동으로 올리지는 않아요.

- 상태: 시험 완료, **아직 공개(배포) 전** — 공개는 회장님 결재가 필요해요.
- 만든 날: 2026-11-09 (개발팀)
- 글 규칙: 글틀 3판 = `글틀.md` 2판 + `조사-잘되는글.md` 6장 결과

---

## 사장님이 쓰는 법 (아이폰)

**처음 한 번**
1. 회사가 드린 주소를 사파리로 열어요.
2. **접속 코드**를 넣고 [시작하기]를 눌러요. (코드 없이 [체험해 보기]도 돼요. 체험은 예시 글만 나오고 돈이 들지 않아요.)
3. 사파리 아래 가운데 **공유 버튼(네모에 위 화살표)** → **홈 화면에 추가**를 누르면 앱처럼 열려요.
4. 오른쪽 위 **[설정]** 에서 연락처와 **ARTPLAY 안내**(상담 지역, 직접 시공 여부, 하자보수 기간, 업체 등록, 상담 때 준비할 것)를 한 번 넣고 [저장]을 눌러요. **사실인 것만** 넣어 주세요. 비워 두면 그 줄은 글에서 빠져요.

**현장마다 (1분)**
1. **① 사진** — 전·공사 중·후 줄의 [+]를 눌러 사진을 골라요 (전·후 각 6장, 공사 중 3장). 얼굴·차량 번호·집 주소가 보이는 사진은 빼 주세요.
2. **② 꼭 고르기** — 공간, 평수, 고객 게시 동의.
3. **③ 넣으면 좋은 것** — 공사 기간, 한 줄 메모(고민 + 쓴 자재 + 신경 쓴 것). 키보드 마이크로 말해도 돼요.
4. 협찬·할인이 있었다면 **④ 더 자세히**를 펼쳐 꼭 골라 주세요 (법에 따라 제목과 첫 줄에 표시돼요).
5. 맨 아래 **[글 만들기]** → 30초~1분 기다려요. 이때는 화면을 켠 채로 두세요.

**블로그에 올리기**
1. 마음에 드는 **제목을 눌러** 고르고, 본문은 그 자리에서 고칠 수 있어요.
2. **"올리기 전에 확인할 점"** 을 꼭 읽어요.
3. **[전체 복사]** → 네이버 블로그 앱 → 글쓰기 → 본문을 길게 눌러 붙여넣기.
4. 글 속 "📷 사진 1" 자리에 같은 번호 사진을 넣고, 그 줄은 지워요.

**알아 두기**
- 마음에 안 들면 [다시 만들기]. 만든 글은 [지난 글]에 10개까지 남아요 (이 휴대폰에만).
- 사진은 휴대폰에서 줄여서 글 만들 때만 보내고, 어디에도 저장하지 않아요.
- 하루에 만들 수 있는 글 수가 정해져 있어요 (기본 20편). 화면 맨 위에 남은 수가 보여요.
- 게시 동의가 "동의 안 받음"이면 글을 만들지 않아요.

## 회사가 알아 둘 것

**구조**
```
앱/
  public/                화면 (index.html, app.js, app.css, demo.js 체험 예시 글, sw.js, manifest, icons/)
  netlify/functions/     서버 함수 3개
    check.mjs            /api/check  접속 코드 확인, 오늘 남은 글
    photos.mjs           /api/photos 사진 읽기 (사진마다 짧은 설명, 가려야 할 것)
    write.mjs            /api/write  글쓰기 (글이 나오는 대로 흘려 보냄)
  netlify/lib/
    prompt.mjs           ★ 글 규칙 전부 (글틀·말투·제목 공식·금지 표현·입력 칸). 글을 바꾸려면 이 파일만 고쳐요
    guard.mjs            접속 코드, 하루 한도, 틀린 코드 잠금
    claude.mjs           Claude API 연결, 쉬운 오류 문구
  netlify.toml           Netlify 설정
  dev-server.mjs         내 컴퓨터에서 시험하는 작은 서버 (배포에는 안 쓰임)
```

**환경 변수 (Netlify에만 넣어요. 코드·채팅에 넣지 않아요)**

| 이름 | 꼭? | 뜻 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 꼭 | Claude API 키. 없으면 "AI 연결 열쇠가 아직 없어요" 안내가 나오고, 체험 모드만 돼요 |
| `SHOP_CODES` | 꼭 | `가게이름:접속코드`. 여러 가게는 쉼표로. 예) `artplay:바다-7351-소나무`. 코드는 6글자 넘게 |
| `DAILY_LIMIT` | 아니요 | 가게마다 하루 글 수 (기본 20) |
| `ALL_DAILY_LIMIT` | 아니요 | 모든 가게를 합친 하루 최대 글 수 (기본 60). 돈이 새지 않게 하는 마지막 안전줄 |
| `CLAUDE_MODEL` | 아니요 | 기본 `claude-sonnet-5-5`. 더 좋은 글이 필요하면 `claude-opus-5-5` (비용 약 2배) |
| `WRITE_EFFORT` | 아니요 | 글쓰기 생각 깊이 `low`/`medium`/`high` (기본 medium) |

**막는 장치**
- 접속 코드가 없으면 글을 만들 수 없어요. 같은 곳에서 15분 안에 5번 틀리면 15분 잠겨요.
- 하루 한도를 넘으면 "내일 다시"라고 안내해요. 기록은 Netlify Blobs(무료 저장소)에 숫자만 남아요. 사진·글·고객 정보는 서버에 남지 않아요.
- 화면에서 금지 표현(최고·1위·완벽·평생 등)과 협찬 표시를 한 번 더 점검해 알려 줘요.

**시험하는 법 (내 컴퓨터)**
```
cd company/초안/ARTPLAY-블로그/앱
SHOP_CODES=artplay:시험코드-1234 node dev-server.mjs
```
→ http://localhost:8888 . 키 없이 체험 모드와 "키 없음" 안내를 볼 수 있어요.

**바꾸면 같이 할 것**: 화면 파일(public/)을 고치면 `app.js`의 `APP_VERSION`과 `sw.js`의 `CACHE`를 하나 올려요.
