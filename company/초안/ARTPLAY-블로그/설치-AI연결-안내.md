# 인테리어 블로그 앱 — 다른 컴퓨터에서 쓰기 + AI 연결 (2026-11-11)

## A. 다른 컴퓨터에서 쓰기 (ARTPLAY 사장님 노트북 등) — 설치할 것 없음
1. 크롬을 열고 주소창에 **artplay-blog.netlify.app** 입력
2. 접속 코드 입력 → [시작하기] (코드는 회장님이 따로 전달. 한 번 넣으면 그 컴퓨터가 기억)
3. (선택) 바탕화면 아이콘 만들기: 크롬 오른쪽 위 **⋮ → 전송, 저장 및 공유 → 바로가기 만들기** → "창으로 열기" 체크 → 만들기
   - 메뉴 이름은 크롬 버전마다 조금 다를 수 있음("앱으로 설치" / "바로가기 만들기")
- 휴대폰(아이폰): 사파리로 주소 열기 → 아래 가운데 공유 버튼 → 홈 화면에 추가
- AI 열쇠는 기기마다 앱 [설정]에 넣음 (아래 B). 서버(넷리파이)에는 넣지 않음.

## B. AI 연결 — 사장님이 자기 열쇠를 앱 설정에 넣기 (2026-11-11 회장님 지시, 앱 1.5.0부터)
AI 사용료는 **ARTPLAY 사장님 계정**에서 나가요. 회사(회장님) 열쇠는 이 앱에 넣지 않아요. 넷리파이에서 할 일은 없어요.
1. 사장님 노트북 크롬에서 **console.anthropic.com** 로그인 (사장님 계정)
2. 왼쪽 **Billing(결제)** → 크레딧 충전 (예: 5달러, 글 한 편 약 160원 → 약 40편)
3. **Limits(한도)** 에서 월 한도를 걸어 두기 (예: 10달러 — 그 이상 쓰이지 않음)
4. 왼쪽 **API Keys** → **Create Key** → 이름 "blog" → 만들기 → 나온 열쇠 **Copy** (창을 닫으면 다시 볼 수 없음 — 복사 전 닫지 않기)
5. 블로그 앱 오른쪽 위 **[설정]** → **AI 열쇠** 칸에 붙여넣기(Ctrl+V) → **[열쇠 저장]**
   - 같은 순서가 앱 [설정] → **[열쇠 만드는 법]** 에도 적혀 있음
   - 열쇠는 그 노트북(또는 휴대폰)에만 저장됨. 다른 기기에서 쓰면 그 기기에서도 한 번 넣기
6. [글 만들기]로 한 편 만들어 보기. "열쇠가 맞지 않아요"가 나오면 console.anthropic.com에서 열쇠를 다시 복사해 넣기

## 주의
- 열쇠는 채팅·카톡·메일에 붙여 넣지 않기. 앱 [설정] 칸에만.
- 열쇠가 새 나갔다고 생각되면 console의 API Keys에서 그 열쇠를 **Delete** 하고 새로 만들어 앱에 다시 넣기.
