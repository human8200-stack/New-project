# 인테리어 블로그 앱 — 다른 컴퓨터에서 쓰기 + AI 연결 (2026-11-11)

## A. 다른 컴퓨터에서 쓰기 (ARTPLAY 사장님 노트북 등) — 설치할 것 없음
1. 크롬을 열고 주소창에 **artplay-blog.netlify.app** 입력
2. 접속 코드 입력 → [시작하기] (코드는 회장님이 따로 전달. 한 번 넣으면 그 컴퓨터가 기억)
3. (선택) 바탕화면 아이콘 만들기: 크롬 오른쪽 위 **⋮ → 전송, 저장 및 공유 → 바로가기 만들기** → "창으로 열기" 체크 → 만들기
   - 메뉴 이름은 크롬 버전마다 조금 다를 수 있음("앱으로 설치" / "바로가기 만들기")
- 휴대폰(아이폰): 사파리로 주소 열기 → 아래 가운데 공유 버튼 → 홈 화면에 추가
- 다른 컴퓨터에는 AI 열쇠를 넣지 않음. 열쇠는 서버(넷리파이)에 한 번만 넣으면 모든 컴퓨터에서 작동.

## B. AI 연결 (회장님이 한 번만, 노트북 크롬)
1. **console.anthropic.com** 로그인
2. 왼쪽 **Billing(결제)** → 크레딧 5달러 충전 (글 한 편 약 160원 → 약 40편)
   - 같은 화면 **Limits(한도)** 에서 월 한도를 10달러로 걸어 두면 더 쓰이지 않음
3. 왼쪽 **API Keys** → **Create Key** → 이름 "blog" → 만들기 → 나온 키 **Copy** (창을 닫으면 다시 볼 수 없음 — 복사 전 닫지 않기)
4. 새 탭 **app.netlify.com** → 왼쪽 **Team settings(팀 설정) → Environment variables** → **ANTHROPIC_API_KEY** 옆 **Edit** → 값 칸에 붙여넣기(Ctrl+V) → **Save**
   - 팀 설정에 넣으면 영양 노트 앱·인테리어 앱 둘 다 한 번에 켜짐
5. 회사에 "넣었어" 한 마디 → 회사가 두 앱을 다시 올리고(재배포) 실제 글 한 편으로 시험

## 주의
- 키는 채팅·카톡에 붙여 넣지 않기. 넷리파이 칸에만.
- 키가 새 나갔다고 생각되면 console의 API Keys에서 그 키를 **Delete** 하고 새로 만들기.
