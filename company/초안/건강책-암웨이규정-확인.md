# 건강 책 × 한국암웨이 BSM(사업 보조 자료) 규정 확인 (암웨이사업팀, 2026-11-10)

계기: 회장님 "나는 대상이 네트워크 하는 사람들이야. 그러면 제품이름을 말하는게 아니라, 비타민 명칭으로 말하면 될 것 같아"

## 결론
- BSM 기준은 "제품 이름이 있나"가 아니라 "누구에게·무엇을 위해 쓰이나". BSM 정의 = "ABO·예비 ABO·소비자를 지원·동기 부여·교육하기 위해 사용되는 서적…" (암웨이 이름 조건 없음).
- 한국 규정: ABO는 어떤 형태의 BSM도 판매·요금 부과 불가, BSM 홍보로 수익 창출 불가, 사전 서면 승인 필요, 사업 미팅·교육은 무료 (QAS 프로그램·콘텐츠 기준 2022-01-27, 디지털 커뮤니케이션 기준 2020-09-01).
- → "네트워크 사업자용 책"을 하위 파트너·암웨이 강의 현장에서 팔면 BSM 판매로 보일 위험이 높음. 일반 독자용 건강 책을 서점·스마트스토어·암웨이와 무관한 공개 강의에서 팔면 위험 낮음.
- 11/3 판단("7조는 회사가 만든 자료만")과 원문이 다를 수 있음: QAS는 "BSM을 제작한 ABO 이름"을 적게 함 → 사업자가 만든 자료도 대상. ABLE CRM 판매(결재 16)에도 영향.

## 판매 경로별 위험
| 경로 | 위험 |
|---|---|
| 암웨이 사업 미팅·세미나(청중 ABO) | 매우 높음 |
| 하위 파트너에게 직접 권유·단체 주문 | 높음 |
| 암웨이와 무관한 공개 강의(도서관·문화센터·북토크) | 낮음 |
| 스마트스토어·온라인 서점 (암웨이·ABO·사업·직급 표현 없이) | 낮음 |

## 확실하지 않은 것
- "암웨이 이름 없는 일반 서적은 BSM 아님" 예외 문구 못 찾음(반대 문구도 없음). 윤리강령 7조 본문 원문 미확인(노션 요약만). PDF보다 새 버전 있는지 미확인.
- 회장님 확인 위치: 한국암웨이 로그인 → 비즈니스 → 사업 가이드 → 사업 규정 → "7. 사업 보조 자료(BSM)" 캡처 → 노션 암웨이 사업실.
