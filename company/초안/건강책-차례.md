# 건강 책 차례 (2판, 편집팀, 2026-11-11 — 1판 2026-11-10)

회장님 원문(11/10): "건강책 제목 전에 목차를 책처럼 이미지화해서 보여주기, 글로 나열해도 좋고, 목차가 제일 중요해, 읽기 쉽고 이해하기 쉽고 읽어보고싶고, 찾기 싶고, 필요한 목차여야지"
회장님 원문(11/10, 2차): "고객에게 어떻게 전할까는 아니야 / 공부하는 책이야"
회장님 원문(11/10~11, 3차): "장애 관련 된 얘기가 없네 장이 너무 중요한데" → 사장 추천안에 "ㅇㅋ 장 중심으로 키워"

## 바뀐 점

**1판 (11/10)**
1. 장 제목을 "제가 공부한 것" 같은 큰 묶음 대신 **주제 하나씩**(장·혈당·혈관·간·면역·근육·여성·아이·눈피부)으로 나눠, 궁금한 주제를 바로 펼칠 수 있게 했습니다.
2. 흐름을 **왜(1부) → 내 몸에서 무슨 일(2부) → 무엇을 먹고(3부) → 어떻게 생활(4부) → 정리(5부)** 로 바꾸고, 영양소는 11장에 **이름으로** 모았습니다(비타민D 등).
3. 꼭지 제목을 실제로 자주 듣는 말·궁금증으로 바꾸고, 장마다 첫머리에 "이런 분께" 한 줄을 넣었습니다. (예전 6장 질문 30은 16장으로 옮김)
4. **(11/10 2차) "고객에게 전하는 책"이 아니라 "내가 스스로 공부하는 책"으로 바꿨습니다.** 5부 "고객에게 어떻게 전할까"를 없애고 "다시 펼쳐 확인하기 — 자주 묻는 질문 30"으로, 꼭지 상자는 "한 줄 정리 / 오늘 해 볼 것"으로, 장 제목·"이런 분께"에서 고객·홈미팅·전하는 말을 모두 뺐습니다.

**2판 (11/11) — 장(腸)을 책의 중심으로**
5. **2장을 "장 — 건강 공부는 장에서 시작해요"로 키웠습니다.** 꼭지 4개·10쪽 → **9개·20쪽**. 장이 하는 일 → 장벽 → 장 속 균 → 사람마다 다른 장 → 장과 면역·피부·기분과 잠 → 장이 보내는 신호 → 장을 돕는 하루 순서로, 장 강의 15개를 모두 나눠 썼습니다. "모든 병은 장에서" 같은 말은 쓰지 않고, 2-5~2-8은 전문가 감수 표시(🩺)를 붙였습니다. 2-8 끝에는 "이럴 땐 바로 병원(전문의와 상담)" 상자를 둡니다.
6. **다른 장과 이었습니다.** 6-2(면역 3단계 방어에 장 점막), 10-3(계절과 장, 피부), 14-3(저녁밥과 잠, 새 꼭지), 11-8 프로바이오틱스·11-9 식이섬유에 "(→ 2-○)" 표시를 달아 2장으로 바로 넘어가게 했습니다. 15장 2주차도 "장을 위한" 채소로 바꿨습니다.
7. **쪽수는 256쪽 그대로.** 2장 +10쪽만큼 6장·7장·10장·11장·13장에서 2쪽씩 줄였습니다(내용이 좁은 꼭지를 1쪽으로).
8. **제목 다듬기.** 장 제목과 첫 꼭지가 같던 곳(4-1, 7-1, 5장 부제) 고침 · "~이유"로 끝나는 제목 15개 → 4개 · 긴 제목(1-2, 1-3, 부록 1) 줄이고 "건강 정보 바르게 읽기" 겹침 없앰 · "유난히 지치는"(5-3·6-5), 10장 "지친/지치는" 3번, "의사도 약사도 아닌"(프롤로그·1-2) 겹침 없앰 · "2030" → "20~30대".

**모든 꼭지(2~3부) 끝에 상자 두 개:** "한 줄 정리"(이 꼭지에서 기억할 한 문장) / "오늘 해 볼 것"(내 생활에서 바로 해 볼 작은 일 하나)
표시: 🩺 = 전문가 감수 꼭 필요 · [회장님] = 회장님 확인 필요(지어내지 않음) · (→ 2-○) = 2장 그 꼭지와 이어서 읽기
