## 틀 (C안)
- **위쪽**: 린넨 바탕 + 창 그림자 + **그 요리의 주재료 하나만** 은은한 그림으로 (토마토 솥밥 = 토마토, 에그 단호박 = 꼭지 달린 미니 단호박). 재료 모음·완성 사진·장식은 넣지 않음
- 왼쪽 위 작게 `M A I S O N   E D E L`, 오른쪽 위 `Recipe No.○○` (번호 = EP 번호, 모으는 느낌)
- **아래**: 반투명 아이보리 판 — 한국어 제목(고운바탕 Bold) / 영어 이름(Cormorant Garamond Italic) · 시간 / 재료 2줄 / 만드는 법 5줄 / "저장해 두세요 🤍"
- 색: Ivory #F8F6F2 · Beige #E8DDCF · Taupe #A89A8A · Olive #6B7258 · Charcoal #3E3E3E (+ 번호만 차분한 토마토색)
- 글자: 본문 30~31px 이상. 세로판은 글자가 위에서 1,600px 안 (아래는 인스타 화면 글자 자리)
- 내용: 레시피함 원문 계량 그대로, 짧게 줄여 씀. **제품명·냄비 이름 없음** ("냄비", "찜기"). 암웨이 제품은 일반 이름으로 (예: 회장님 11/8 "암웨이거야" → "곰국 블록"). 원문에 없는 값은 쓰지 않음. 인분이 재료 개수와 안 맞으면 "인분"은 빼고 시간만 (EP.04)

## 만드는 법 (스크립트: 이 폴더 `recipe_card.py`)
1. `RECIPES`에 새 요리 한 덩어리 추가: `no`, `ko`, `en`, `meta`, `main`(주재료 그림 이름), `ing`(2줄), `steps`(5줄)
2. 주재료 그림이 새것이면 `draw_○○(layer, cx, cy, r)` 함수를 하나 만들고 `MAINS`에 넣음 (토마토·단호박 함수를 본떠서)
3. 실행 (글꼴 폴더를 `--fonts`로, 기본값은 클라우드 작업 폴더 `ref/`):
   - 사진 게시물: `python3 -I recipe_card.py tomato_sotbap 카드.png --fonts <글꼴폴더>`
   - 영상 끝용 세로: `python3 -I recipe_card.py tomato_sotbap 카드-세로.png --tall --fonts <글꼴폴더>`
4. 줄이 너무 길면 스크립트가 멈추고 어느 줄인지 알려 줌 → 글을 줄여서 다시
5. 만든 뒤 꼭 열어 보고 겹침·잘림 확인
- 글꼴(무료, OFL): GowunBatang-Regular/Bold, CormorantGaramond-Italic/Medium — Google Fonts. 파일이 커서(8MB) 저장소에는 넣지 않음. 하트는 시스템 NotoColorEmoji
