## 2. 장면 설계 (요약)

| 항목 | 정한 것 |
|---|---|
| 주인공 하나 | **칼날이 막 닿은 밤색 계란 1개** (시선 = 칼날과 계란 꼭대기가 만나는 점) |
| 카메라 각도 | 식탁 앞에서 **약 60도로 비스듬히 내려다봄**. 눈높이·바로 위 아님. 고정 |
| 빛 | 왼쪽 창 옆 햇살, 오전 9~11시, 실내등 끔. 오른쪽 아래로 깊은 그림자. 노랗지 않게 |
| 손 | 오른손 하나, 오른쪽 끝에서 손목까지. 손잡이만 쥠. 장식 없음 |
| 식탁 | 노션 기준 **짙은 갈색 결 고운 원목**(EP.01·02와 같은 식탁), 크게 흐리게 |
| 구도 (9:16) | **찬기가 화면 가로를 거의 꽉 채움**(약 90%), 계란은 정중앙. 위아래는 흐린 식탁만 → 편집 때 위에 요리 이름, 아래(79%)에 계량 글자 자리 |
| 칼 | 과도, 칼날은 계란보다 조금만 김, 전부 찬기 안. 손잡이 수평 |

### 왜 이 순간인가 (영상 시작 사진)
- 다음 영상 움직임은 "칼이 위에서 똑바로 내려가 계란을 긴 쪽으로 반 가른다"이다. 칼날이 **이미 계란 꼭대기에 닿아 살짝 눌린** 순간이어야 영상 기능이 칼을 들어 올리지 않고 **아래로만** 움직인다(지난 시험: 칼이 들려 나가고 노른자가 공중에 뜸).
- 칼날이 좌우로 서 있어야 반쪽이 앞·뒤로 갈라져, 회장님이 정한 끝 모양(칼 없이 단면 위로, 앞뒤로 나란한 두 반쪽)과 이어진다.
- 손잡이가 수평이고 칼날 전체가 테두리 안이어야 칼이 내려갈 때 테두리에 걸리지 않는다.

## 3. 피해야 할 것 (지난번 틀린 것 + 이번에 생길 수 있는 것)

6. 칼날·손잡이에 각인·로고·글자

**계란·양념**
7. 이미 잘린 계란, 노른자 보임, 형광 노랑 노른자 (영상 시험 실패)

## 4. 회장님께 보여 드릴 때 합격 기준 (5줄)

1. 작은 과도가 똑바로 서서 **칼날이 계란 꼭대기에 닿아 있고**, 계란은 아직 안 잘렸으며 손잡이는 수평이다.
2. 오른쪽에서 들어온 손 하나가 손잡이만 쥐고, **손가락이 녹거나 붙거나 많지 않다**. 반지·매니큐어·얼굴 없음.
3. **시라쿠스 파란 테두리 찬기가 화면 가로를 거의 꽉 채우고**, 밤색 계란 1개와 양파·쪽파·빨강 파프리카·깨가 담겨 있다.
4. **위에서 비스듬히 내려다봄(눈높이·바로 위 아님)**, 짙은 갈색 원목 식탁에 왼쪽 옆 햇살, 노랗지 않은 색이다.
5. 칼·그릇·화면 어디에도 **로고·각인·글자가 없고**, 다른 냄비·팬·인덕션도 보이지 않는다.

## 5. 실행 전 유튜브팀·검수팀이 볼 것

- 4번 칸이 **회색판**인지(기본값 중형프라이팬 아님), 5번이 **찬기 단독(cf1a226e)**, 6번이 **과도(d65daba2)**인지 한 번 더 본다.
- 지시문 틀의 "Camera at pan height or slightly above"와 이 장면의 "약 60도"가 부딪힌다. 1번 칸 [카메라]에 "눈높이 아님"을 넣어 장면 쪽을 따르게 했다. 결과가 눈높이로 나오면 다시 만들지 말고 먼저 사장에게 보고.
- **글 정리 단계가 7단락을 120~220단어로 줄인다.** 회장님 참고 틀은 "짧게 줄이지 않기"인데, 작업 틀 고정 글이 길이를 줄이게 되어 있다. 칼 방향·빨강 파프리카·인덕션 없음이 빠질 수 있다. → 실행 기록에서 **글 정리 결과(영어 지시문)**를 꼭 저장해서 검수팀에 같이 넘긴다. (작업 틀 고정 글의 단어 수를 늘리는 것은 작업 틀 수정이라 디자인팀이 하지 않음 — 6번 참고)
- (작업틀-사용법 8번) 입력 3개 연결이 실제로 안 되면: 1번 칸에 위 영어판 뒤에 `Pot: none. Tableware: Syracuse blue-rim side-dish bowl.`를 붙여 넣는다. 이 경우도 크레딧이 다시 들므로 **먼저 사장에게 보고 후** 진행.
