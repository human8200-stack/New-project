## 2. 장면 설계

| 항목 | 정한 것 |
|---|---|
| 주인공 하나 | **칼날이 막 닿은 밤색 계란 1개** (눈이 가는 곳 = 칼날과 계란 꼭대기가 만나는 점) |
| 카메라 각도 | 식탁 앞에서 **약 60도로 내려다봄**. 카메라 고정. (각도표: 위에서 1·3·7 / 가까이 2·5·6 / 넓게 4 그대로) |
| 빛 | **왼쪽 창에서 들어오는 옆 햇살**, 오전 9~11시. 따뜻하지만 노랗지 않은 낮빛. 계란 오른쪽 아래로 부드럽고 깊은 그림자. 창살 그림자는 식탁 위에 옅게만(계란·칼 위를 가리지 않게). 앞에서 비추는 평평한 빛 없음 |
| 손 | **오른손 하나**, 화면 오른쪽 끝에서 들어옴. 손가락·손목까지만(손목 위·소매·얼굴 없음). 한국인 성인 여성 손, 반지·시계·매니큐어 없음, 짧고 깔끔한 손톱, 손가락 5개. 엄지와 검지·중지가 **손잡이만** 감싸 쥔다(칼날·계란에 손가락 닿지 않음) |

### 왜 이 순간인가 (영상 시작 사진)
- 다음 영상 움직임은 "칼이 위에서 똑바로 내려가 계란을 긴 쪽으로 반 가른다"이다. 칼날이 **이미 계란 꼭대기에 닿아 살짝 눌린** 순간이어야 영상 기능이 칼을 들어 올리거나 다른 데로 옮기지 않고 **아래로만** 움직인다(지난 시험: 칼이 들려 나가고 노른자가 공중에 뜸).
- 칼날이 좌우로 서 있어야 반쪽이 앞·뒤로 갈라져, 회장님이 정한 끝 모양(칼 없이 단면 위로, 앞뒤로 나란한 두 반쪽)과 이어진다.
- 손잡이가 수평이고 칼날 전체가 테두리 안이어야 칼이 내려갈 때 테두리에 걸리지 않는다.

## 3. 피해야 할 것 (지난번 틀린 것 + 이번에 생길 수 있는 것)

**손**
1. 녹은 손, 손가락 6개·4개, 뭉개진 손가락, 손이 칼 손잡이를 뚫고 지나감
2. 반지·시계·팔찌·매니큐어, 손목 위 팔·소매·얼굴
3. 손가락이 칼날이나 계란에 닿음, 손 두 개

**칼**
4. 산도쿠 같은 긴 칼, 칼날이 그릇보다 김 (v2 위에서자르기-2 반려 이유)
5. 칼이 계란 위에 떠 있음(닿았는지 모호), 손잡이가 위로 들림, 칼끝이 아래로 기움, 칼날이 눕혀져 넓은 면이 위를 봄
6. 칼날·손잡이에 각인·로고·글자

**계란·양념**
7. 이미 잘린 계란, 노른자 보임, 형광 노랑 노른자 (영상 시험 실패)
8. 흰 계란·연베이지 계란 (v2 장면1-과도는 너무 연함), 새까만 계란
9. 계란 2개 이상, 그릇 2개 이상, 반찬 그릇 여러 개
10. **대파 굵은 고명** (레시피가 쪽파·빨강 파프리카로 바뀜), 깨가 두껍게 덮임, 파프리카가 크게 썰려 색이 튐

**그릇·도구**
11. 다른 냄비가 섞여 나옴: 중형프라이팬(기본값 사진), 고정 사진 속 인덕션 가장자리, EP.01 손 사진 속 은색 팬, EP.02 리조또 팬
12. 그릇 테두리가 파랑이 아님, 안쪽 가는 테라코타 줄 빠짐, 그릇 바닥·옆에 글자·도장

**공간·빛**
13. 노란빛·주황빛·황금빛 (EP.01 색 보정 기준과 다름)
14. 다른 식탁: 밝은 중간 갈색 낡은 판자(v2 장면1-과도), 대리석·흰 식탁, 흠집·얼룩
15. 창살 그림자가 너무 진해서 계란·칼을 가림, 앞에서 비춘 납작한 빛
16. 음식이 화면 절반 미만 (v2 장면1-과도는 위쪽 식탁이 화면 약 40%)
17. 꽃·허브·소품 여러 개, 창문·화병·레인지가 화면에 보임
18. 화면 글자·자막·워터마크(MAISON EDEL 포함), 로고
19. 눈높이 각도 또는 바로 위에서 내려다본 평면 사진

## 4. 회장님께 보여 드릴 때 합격 기준 (5줄)

1. **칼과 계란:** 작은 과도가 똑바로 서서 계란 꼭대기에 닿아 있고(살짝 눌림), 계란은 아직 안 잘렸다. 칼날 전체가 찬기 안에 있고 손잡이는 수평이다.
2. **손:** 오른쪽에서 들어온 손 하나, 손가락 5개가 손잡이만 쥐고 있다. 반지·매니큐어·소매·얼굴이 없다.
3. **음식:** 밤색 계란 1개 + 양념(양파·쪽파·빨강 파프리카·깨)이 시라쿠스 파란 테두리 찬기에 담겨 화면 절반 이상을 차지한다. 다른 냄비·그릇·인덕션은 없다.
4. **집과 빛:** 짙은 갈색 원목 식탁, 왼쪽 옆 햇살과 깊은 그림자, 노랗지 않은 색. EP.01·02와 같은 집처럼 보인다.
5. **글자 없음:** 칼·그릇 어디에도 로고·각인·글자가 없고, 화면 위아래에 요리 이름·계량 글자를 넣을 흐린 식탁 자리가 있다.

## 5. 실행 전 유튜브팀·검수팀이 볼 것

- 4번 칸이 **회색판**인지(기본값 중형프라이팬 아님), 5번이 **찬기 단독(cf1a226e)**, 6번이 **과도(d65daba2)**인지 한 번 더 본다.
- 지시문 틀의 "Camera at pan height or slightly above"와 이 장면의 "약 60도"가 부딪힌다. 1번 칸에 "눈높이 아님"을 넣어 장면 쪽을 따르게 했다. 결과가 눈높이로 나오면 다시 만들지 말고 먼저 사장에게 보고.
- 글 정리 단계가 120~220단어로 줄이면서 칼 방향·고명이 빠질 수 있다. 실행 기록에서 **글 정리 결과(영어 지시문)**를 꼭 저장해서 검수팀에 같이 넘긴다.
- (작업틀-사용법 8번) 입력 3개 연결이 실제로 안 되면: 1번 칸에 위 영어 대응문 뒤에 `Pot: none. Tableware: Syracuse blue-rim side-dish bowl.`를 붙여 넣는다. 이 경우도 크레딧이 다시 들므로 **먼저 사장에게 보고 후** 진행.
