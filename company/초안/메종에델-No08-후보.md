## ⭐ 1. 마늘 등갈비 튀김 (추천)

**제목 안 ("특징 + 요리 이름")**
1. ⭐ 기름 한 컵으로 튀기는 마늘 등갈비 튀김
2. 바삭 소리까지 맛있는 마늘 등갈비 튀김
3. 웍 하나로 끝내는 마늘 등갈비 튀김
- 표지: 작게 "기름 한 컵으로 튀기는" / 크게 "마늘 등갈비 튀김"

**출처**: 『슬기로운요리생활』 70쪽(03 메인 디쉬) · 레시피함 "마늘 등갈비 튀김"(고기 · 4인분 · 40분 · tool: 웍). 책 본문과 계량 대조는 아직 못 함.

**레시피함 원문 (읽은 그대로)**
- 재료: 등갈비 800g · 전분가루 5T · 포도씨유 1컵 · 땅콩·깨 약간
- [소스] 다진 마늘 3T · 간장 2T · 굴소스 1t · 맛술 1T · 설탕 1T · 다진 땅콩·깨 약간 · 후추 약간
- 만드는 법:
  1. 등갈비를 물에 담가 핏물을 빼고 씻은 후 키친타월로 물기를 닦아준다.
  2. 등갈비에 전분가루를 골고루 묻혀준다.
  3. 웍에 포도씨유를 두르고 인덕션 튀김모드 180도에서 예열한 후 등갈비가 노릇해질 때까지 튀긴다.
  4. 튀긴 등갈비는 건져내고 기름은 따라 버린다.
  5. 웍에 소스를 넣고 인덕션 5단에서 끓인 후 튀긴 등갈비를 넣어 골고루 섞는다.
  6. 완성된 요리에 다진 땅콩과 깨를 뿌려 완성한다.

**소리가 좋은 순간**
1. 전분 묻힌 등갈비를 180℃ 기름에 넣는 순간 — "치이이익" (가장 큰 소리)
2. 튀겨지는 동안 — 잔잔한 "타닥타닥" 기름 튀는 소리
3. 소스가 끓는 웍 — 마늘 간장이 "바글바글"
4. 튀긴 등갈비를 소스에 넣고 뒤적일 때 — 끈적한 "착, 착" + 나무 주걱이 웍에 닿는 소리
5. 다진 땅콩·깨를 뿌릴 때 — 작게 "사르르"
- **마지막 먹는 소리**: 손이 등갈비 한 대를 들어 화면 위(입 쪽)로 → 겉이 "바삭" + 뼈에서 살 뜯는 소리 + 씹는 소리

**쓸 냄비·팬**: 퀸 웍 (레시피함 tool 그대로). 기준 사진 `company/초안/메종에델-기준장면/레시피함/냄비-웍.png`, 실물 `냄비-웍-실물1~3`. 튀김망 사진(`냄비-웍-실물0-튀김망(튀김할때만).jpg`)도 있음. 로고·글자 안 보이게. 뚜껑 덮는 단계는 레시피에 없음 → 뚜껑 장면 없음.

**그릇**: 시라쿠스 (No.05 시라쿠스 → No.06 코스타노바 → No.07 에뚜알 퓨터 → No.08 시라쿠스 차례)

**계절감**: 해가 일찍 지는 초겨울 저녁. 창밖은 어둑하고 부엌 불빛과 튀김 김이 빛에 비침. 윤기 나는 마늘 간장색이 따뜻해 보임.

**새 영상과 크레딧** (Seedance 2 표준 4초 = 개당 120)
- 3개안 = 360 (한 편 예산 그대로): ① 기름에 등갈비 넣기(치이익) ② 소스에 버무리기(바글바글·착착) ③ 먹기(바삭)
  - 이때 핏물 빼기·전분 묻히기·땅콩 뿌리기 장면은 화면에 없고 레시피 카드에만 남음
- ⭐ 4개안 = 480 (예산보다 120 많음, 회장님께 여쭤야 함): 3개 + ④ 전분 묻히기(손으로 굴리는 "사락사락")
- 첫 장면 풍경(요리 전 창가)은 지난 편 영상 재활용(0원) 또는 새 영상(+120) — 회장님 결정
- 그림은 회장님 ChatGPT(0원). 영상은 그림 ✅ 뒤 장면마다 회장님이 "만들어/실행"이라고 하실 때만

**회장님 녹음이 필요한 소리**
- 1순위: 등갈비 바삭 씹는 소리 + 뼈에서 살 뜯는 소리 (휴대폰으로 입 가까이 10초 정도)
- 있으면 좋음: 실제로 만드실 때 기름에 넣는 "치이익"과 소스 버무리는 소리 (없으면 실제 녹음 CC0 효과음 사용, AI 소리는 안 씀)

**확인할 것**: 튀길 때 기름 1컵이 웍에서 얼마나 깊은지(장면 그림 기준) · 튀김망 쓰시는지 · 책 70쪽 계량과 같은지

## 2. 클램 차우더

**제목 안**
1. ⭐ 조개로 국물 내는 클램 차우더
2. 팬 하나로 끓이는 겨울 클램 차우더
3. 뚜껑 열면 조개가 웃는 클램 차우더
- 표지: 작게 "조개로 국물 내는" / 크게 "클램 차우더"

**출처**: 『슬기로운요리생활』 36쪽(01 애피타이저) · 레시피함 "클램 차우더"(해산물 · 4인분 · 35분 · tool: 대형프라이팬). 레시피함에 밴드판 "클램차우더"(tool: 대형소스팬, 양파 0.5개·생크림 약간)도 있어 **팬이 둘로 적혀 있음** → 회장님 확인 필요. 아래는 책 쪽(대형프라이팬) 원문.

**레시피함 원문**
- 재료: 동죽조개 800g(다양한 조개 가능) · 감자 2개 · 양파 2개 · 베이컨 3줄 · 생크림 300ml · 조개 육수 0.5컵 · 버터 10g · 소금·후추 약간
- 만드는 법:
  1. 조개는 해감을 시킨 후 깨끗하게 씻는다.
  2. 대형프라이팬에 조개를 넣고 뚜껑을 덮어 인덕션 5단에서 7분간 익힌다.
  3. 조갯살을 건져내고 남은 육수는 따로 보관한다.
  4. 같은 팬에 인덕션 5단에서 버터를 녹인 후 감자, 양파, 베이컨을 넣어 1분간 더 볶는다.
  5. 볶은 재료에 조갯살과 조개 육수, 생크림을 추가하고 인덕션 5단에서 15분간 더 끓인다.
  6. 마지막으로 소금과 후추를 뿌려 마무리한다.

**소리가 좋은 순간**
1. 조개 씻기 — 껍데기끼리 "달그락달그락"
2. 뚜껑 덮인 팬 → 뚜껑 열 때 "칙" + 입 벌린 조개 (장면 바뀌는 순간 소리 맞추기에 딱)
3. 감자 깍둑 썰기 — "탁탁탁" 칼질
4. 버터 녹이고 베이컨·감자 볶기 — "지글지글"
5. 생크림 넣고 끓이기 — 걸쭉하게 "보글보글"
- **마지막 먹는 소리**: 숟가락으로 떠 화면 위로 → "후루룩" + 조갯살·감자 씹는 소리 + 숟가락이 그릇에 닿는 소리. 바삭한 소리는 없음

**쓸 냄비·팬**: 퀸 대형프라이팬(책 쪽 원문) + 뚜껑. **뚜껑 덮고 익히는 단계(2번)가 있어 뚜껑 덮은 장면 꼭 넣음.**

**그릇**: 시라쿠스

**계절감**: 첫눈 올 것 같은 흐린 초겨울 낮, 김이 창빛에 피어오름. 가장 "겨울 수프" 같은 요리.

**새 영상과 크레딧**
- 3개안 = 360: ① 뚜껑 열기(칙 + 조개) ② 볶기(지글지글) ③ 먹기(후루룩)
  - 크림 끓이기(보글보글)는 ② 영상 끝을 쓸 수 없어 빠짐 → 소리 하나가 빠지는 게 아쉬움
- ⭐ 4개안 = 480: 3개 + ④ 크림 넣고 보글보글
- 조개 씻기는 새 영상이 하나 더 필요(+120). 넣지 않으면 레시피 카드에만

**회장님 녹음이 필요한 소리**
- 1순위: 수프 떠먹는 "후루룩" + 씹는 소리 + 숟가락이 그릇에 닿는 소리
- 있으면 좋음: 조개 껍데기 달그락, 뚜껑 여는 "칙"

**다른 점 / 걱정**: 11/8 쏠키친 라이브 1회 메뉴라 "라이브에서 만든 그 요리" 연결은 좋지만, 본계정에서 이미 한 요리라 새로움은 덜함. 먹는 소리가 바삭이 아니라 부드러움.

## 3. 독일식 감자전 (뢰스티)

**제목 안**
1. ⭐ 감자채로 바삭하게 굽는 독일식 감자전
2. 기름 조금으로 굽는 감자 뢰스티
3. 바삭 소리 나는 감자 뢰스티
- 표지: 작게 "감자채로 바삭하게 굽는" / 크게 "독일식 감자전"

**출처**: 레시피함 "독일식 감자전(뢰스티)"(야채·샐러드 · 4인분 · 20분 · tool: 대형프라이팬). **책에는 없음.**

**레시피함 원문**
- 재료: 감자 200g · 전분 1t · 베이컨 2줄 · 포도씨유 약간 · 치즈 적당량 · 계란 적당량 · 송화소금 약간
- 만드는 법:
  1. 감자와 베이컨을 잘게 채 썬다.
  2. 채 썬 감자에 전분과 베이컨을 넣고 송화소금으로 밑간 후 섞는다.
  3. 팬을 예열한 후 양면을 바삭하게 구워준다.
  4. 다른 팬에 계란 후라이를 만든다.
  5. 감자전 위에 치즈를 올리고 만들어둔 계란 후라이를 올린다.

**소리가 좋은 순간**
1. 감자 채 썰기 — 빠른 "사각사각 탁탁" 칼질
2. 달군 팬에 감자채를 펴 놓는 순간 — "치이익"
3. 굽는 동안 가장자리 — 잔잔한 "지글지글"
4. 뒤집개로 뒤집기 — 노릇한 면이 나오며 "착"
5. 다른 팬에 달걀 "톡" 깨기 → "지글"
- **마지막 먹는 소리**: 포크로 한 조각 잘라 화면 위로 → "바삭" 씹는 소리 (노른자 흐르는 장면도 가능)

**쓸 냄비·팬**: 퀸 대형프라이팬(감자전) + **"다른 팬"(계란 후라이)은 원문에 이름이 없음** → 회장님 확인 필요(중형프라이팬일 듯). 뚜껑 단계 없음.

**그릇**: 시라쿠스

**계절감**: 햇감자 철 늦가을 아침 브런치. 노릇한 감자색과 창가 아침 햇살.

**새 영상과 크레딧**
- 3개안 = 360: ① 감자 채 썰기 ② 뒤집기(지글 → 노릇한 면) ③ 먹기(바삭)
  - 팬에 펴기·달걀 후라이·치즈 올리기는 빠짐
- ⭐ 4개안 = 480: 3개 + ④ 팬에 감자채 펴기(치이익) 또는 달걀 "톡"

**회장님 녹음이 필요한 소리**
- 1순위: 감자전 "바삭" 씹는 소리
- 있으면 좋음: 실제 감자 채 써는 소리

**다른 점 / 걱정**: 가장 단순하고 바삭 소리는 최고지만, 책에 없어 책 판매로 안 이어짐. "치즈·계란 적당량"이라 유튜브 계량 자막을 숫자로 못 씀 → 회장님께 양을 여쭤야 함.

## 세 후보 모두 같은 것 (노션 규칙 그대로)
- 소리: 음악 없음. AI 생성 소리 쓰지 않음, 실제 녹음 효과음(CC0, 출처표). 요리할 때는 요리 소리만, 먹는 장면엔 먹는 소리. 장면 바뀌는 순간에 소리 맞추기
- 마지막 장면 = 먹기. 음식을 든 손이 입 쪽(화면 위)으로 올라가며 씹는 소리까지(회장님 녹음 1순위). 얼굴은 입술·턱까지만 또는 화면 밖
- 모든 장면이 움직이는 영상. 정지 사진·사진에 다가가기 안은 넣지 않음. 손은 실제 사람 속도, 붓고 뿌리는 동작은 천천히
- 팬은 레시피에 적힌 퀸 냄비 그 크기 그대로, 로고·이름 안 보이게. 암웨이 제품 이름·링크·가격 넣지 않음
