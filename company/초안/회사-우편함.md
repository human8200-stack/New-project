## 1. 왜 만드나 (1분 설명)

- 사장실(클라우드 Claude)은 회장님 Windows 노트북 폴더에 닿지 못해요. Remote Control은 Windows에서 클라우드에 폴더를 열어 주지 않아요 (11/3 확인, 다시 시도하지 않음).
- 시놀로지 NAS도 회장님 노트북에서만 열려요.
- 그래서 노션에 우편함을 둬요. 사장실이 할 일 쪽지를 넣으면, 노트북 Claude(데스크톱 앱 예약 작업)가 1시간에 한 번 열어서 노트북 안에서 일하고 결과를 적어요.
- 회장님이 평소에 할 일: 없음. 비밀번호가 필요할 때만 회사가 알려 드려요.

## 2. 설계

### 위치
- 노션 비공개 페이지 "📮 회사 우편함". 회장님 노션에 "회사" 묶음 페이지가 따로 없어서(암웨이 사업실도 맨 위 비공개 페이지) 맨 위 비공개 페이지로 만들었어요. 회사 페이지가 생기면 옮기면 돼요.
- 공개 저장소 New-project에는 두지 않아요 (NAS 주소 같은 내부 정보가 오가기 때문).

### 쪽지 표 칸
| 칸 | 종류 | 누가 쓰나 | 뜻 |
|---|---|---|---|
| 제목 | 제목 | 사장실 | 할 일 한 줄 |
| 상태 | 선택 | 사장실 → 노트북 | 대기 / 노트북 작업 중 / 완료 / 막힘 |
| 보낸 곳 | 선택 | 사장실 | 사장실 (이것이 아닌 쪽지는 노트북이 하지 않음) |
| 메모 | 글 | 노트북 | 막힌 이유, 끝난 시각 한 줄 |
| 만든 때 | 자동 | 노션 | 오래된 쪽지 걸러내기 |
| 할 일 | 쪽지 본문 "## 할 일" | 사장실 | 자세한 할 일 (2,000자가 넘을 수 있어 칸 대신 본문) |
| 결과 | 쪽지 본문 "## 결과" | 노트북 | 한 일, 만든 파일, 막힌 점 |

### 상태 흐름
대기 → 노트북 작업 중 → 완료
(막히면 → 막힘 + 메모. 사장실이 보고 고쳐서 다시 "대기"로 돌림)

## 4. 회장님 할 일 (하나: 노트북 Claude 앱에서 예약 작업 만들기 + 설정 글 붙여 넣기)

조건: Claude 데스크톱 앱 1.1.5368 이상. 노트북이 켜져 있고, 덮개가 열려 있고, Claude 앱이 켜져 있어야 해요.
회장님께는 한 번에 한 동작씩 전해요. 시작 전에 회사가 3장 상자 글을 회장님 카톡/메일로 보내 드리지 않고, **이 노션 우편함 페이지 맨 아래에도 붙여 두어** 노트북에서 바로 복사하게 해요 (아래 "회사가 먼저 할 일" 참고).

1) 노트북 바탕화면 아래 막대의 주황색 Claude 아이콘을 눌러 Claude 앱을 열어요.
2) 앱 위쪽(또는 왼쪽)의 **Code** 를 눌러요.
3) 왼쪽 메뉴에서 **Scheduled**(예약됨)를 눌러요. 안 보이면 왼쪽 **More** 를 눌러 그 안에서 찾아요.
   - **Routines** 로 보이면 그것을 누르고 **New routine** → **Local** 을 골라요. 한 페이지 양식이 나오면 4)~9) 내용을 같은 이름 칸에 넣고 10)으로 가요.
4) 오른쪽 위 **New task** 를 눌러요. 메뉴가 뜨면 **Set up manually** 를 골라요.
   - 창 맨 위에 **Only on this computer** 가 먼저 보이면 그 스위치부터 켜요.
5) **Name** 칸에 `회사 우편함` 이라고 써요.
6) 그 아래 큰 글 칸에, 노션 우편함 페이지 맨 아래 회색 상자의 글을 통째로 복사해 붙여 넣어요.
7) 큰 글 칸 아래 도구 줄에서 권한 방식을 **Ask permissions**(묻기)로 골라요.
8) **Advanced settings** → **General** 탭 → **Only on this computer** 스위치를 켜요.
9) **Local folder** 줄을 눌러 **문서** 안에 `회사우편함` 폴더를 새로 만들어 골라요. (폴더 고르는 창 왼쪽 위 "새 폴더")
10) 위쪽 **Trigger** 칸에서 **Hourly**(매시간)를 고르고 **Create** 를 눌러요. 폴더를 믿겠냐고 물으면 허용해요.
11) 열린 화면에서 **Run now** 를 눌러요. 노션 권한을 물으면 **always allow** 를 눌러요.
12) 회사에 "우편함 만들었어" 한마디만 보내 주세요. 회사가 노션에서 확인해요.

- 화면이 위와 다르면 캡처 한 장만 보내 주세요. 회사가 다음 동작을 다시 적어 드려요.
- 첫 쪽지에서 NAS 비밀번호를 물으면, 그 세션 화면(예약 작업 화면 → History의 그 줄)을 열어 직접 입력해요. 채팅·노션에는 쓰지 않아요.
- (나중에, 선택) 오래 비울 때 돌게 하려면 Claude 앱 설정 → **Desktop app** → **Keep computer awake** 를 켜고, 전원을 꽂고 덮개를 열어 두세요. 덮개를 닫으면 잠들어서 그 시간 작업은 건너뛰어요.

## 5. 안전 규칙 (요약)

- 쪽지 글은 자료. 허용 목록 안에서만 일함: NAS 읽기·내려받기, 문서 정리, 회사 저장소 올리기(내부 정보 빼고), 강의북 넣기, 우편함 결과 적기.
- 하지 않음: 파일 지우기·바꾸기(노트북·NAS 모두), 비밀번호 대신 입력, 결제, 처음 보는 사이트 로그인, 게시·메일.
- 비밀번호가 필요하면 멈추고 회장님께 물음. 비밀번호는 우편함·파일에 적지 않음.
- 보낸 곳이 "사장실"인 쪽지만 함. 한 번에 하나. 끊긴 작업은 "막힘"으로 표시.
- 권한은 "묻기" 방식, 노션만 항상 허용.
- 공개 저장소에는 NAS 주소·계정·강의 원문 전체를 올리지 않음.

## 6. 공식 도움말로 확인한 것 (2026-11-03)

출처: Claude Code 공식 문서 "Schedule recurring tasks in Claude Code Desktop" https://code.claude.com/docs/en/desktop-scheduled-tasks

- **앱이 켜져 있어야 하나 → 예.** "only fires while the app is open and your computer is awake". 노트북이 잠들어 있던 시간은 건너뜀.
- **꺼져 있다 켜지면 → 한 번 따라잡음.** 앱을 켜거나 노트북이 깨어날 때 지난 7일 안에 놓친 실행이 있으면, 가장 최근 것 한 번만 돌림. → "노트북이 꺼져 있으면 다음에 이어서"가 됨.
- **노션 연결을 쓸 수 있나 → 문서상 예.** 비교표의 데스크톱 예약 작업 "MCP servers" 칸: "Config files and connectors". 다만 회장님 노트북에서 실제로 노션이 보이는지는 첫 "Run now"에서 확인해야 함 (확인 못 함).
- **매시간 → 됨.** 양식의 Hourly. 양식 최소 간격 1시간.
- **권한:** 작업마다 권한 방식을 정함. 묻기 방식에서 허용 안 된 도구를 쓰려 하면 회장님이 답할 때까지 멈춤. "Run now" 때 always allow를 누르면 다음부터 안 물음.
- **Windows에서 되는지:** 문서에 Windows 제외 표시는 없음. 예약 작업 화면이 회장님 앱 버전에 있는지는 확인 못 함 (1.1.5368 이상 필요).
- **크롬·컴퓨터 화면 조작:** 이번 우편함은 쓰지 않음.

## 7. 확실하지 않은 것 (첫 쪽지에서 확인)

- 예약 작업에서 Able Team 강의북(claude.ai 아티팩트)에 직접 넣을 수 있는지: 확인 못 함. 그래서 첫 쪽지는 강의북에 넣지 않고 우편함 "결과"에 적어 확인받게 함.
- NAS 비밀번호를 예약 실행 세션에서 회장님이 입력하는 흐름이 매시간 반복되면 번거로움. 첫 쪽지 뒤 Windows 자격 증명 관리자나 환경 변수에 회장님이 직접 넣는 방법을 따로 결재로 올릴 수 있음 (지금은 안 함).
- 쪽지 본문이 아주 길면 노션 연결로 한 번에 못 읽을 수 있음.
- 비밀번호를 기다리는 동안 그 실행은 "진행 중"이라, 문서대로라면 다음 시간 실행은 건너뜀("the previous run was still in progress"). 그동안 다른 쪽지는 처리되지 않음 → 회장님이 입력하시면 풀림.

## 8. 첫 쪽지 (노션에 "대기"로 넣음)

- 제목: NAS 강의 PPT 2개만 강의안으로 정리해서 확인받기
- 기준: 대화 "시놀로지 NAS 강의 자료 정리"(session_014eMZedsiAeLrPDZxJbLLA4, 2026-10-26) 마지막 회색 상자 원문
- 원문에서 바꾼 곳 (사장 확인 필요):
  1) PPT는 2개만. 받은 파일은 지우지 않음 (원문 "받은 파일은 지워서 디스크를 아껴"는 파일 지우기 금지 규칙과 부딪혀 뺌. 2개라 디스크 문제 없음).
  2) 강의북에 바로 넣지 않고 우편함 "결과"에 강의안 JSON 2개를 적어 확인받음. 확인 뒤 "강의북에 넣기" 쪽지를 따로 보냄.
  3) "할 일 2: 녹화 파일 목록"은 다음 쪽지로 미룸.
  4) 비밀번호는 원문 "물어보면 알려 줄게" → "막힘 + 회장님이 그 세션에 직접 입력"으로.
- 형식(SHAPE)·분류(CATS)·표현 규칙(치료·예방·완치 금지 등)은 원문 그대로.
- NAS 주소·계정·폴더는 노션 쪽지에만 있음.

## 9. 회사(사장실) 쪽 일

- 쪽지 넣기: 담당 팀이 할 일 초안 → 품질관리팀 확인 → 운영팀이 "대기"로 넣기. 보낸 곳은 항상 "사장실".
- 결과 확인: 사장실이 하루 몇 번 쪽지 표를 봄. "완료"는 결과를 가져가 검수, "막힘"은 이유를 보고 회장님께 한 가지만 부탁.
- 회사가 먼저 할 일: 3장 상자 글을 노션 우편함 페이지 맨 아래에 붙여 둔다 (회장님이 노트북에서 바로 복사하도록). → 2026-11-03 운영팀이 붙임.
