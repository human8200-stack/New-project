- 쿠팡 "오픈 API"(회사가 링크를 자동으로 만드는 방법)는 쿠팡 최종 승인 뒤 회장님 계정에서 열쇠를 받아야 해요. 승인 여부·조건은 **확인 필요**(공식 안내 화면을 회사가 못 엶). 지금은 쓰지 않아요.
- 회장님께 부탁드릴 것 (한 가지만, 휴대폰 기준):
  1. 아이폰 사파리에서 **partners.coupang.com** 열고 로그인
  2. 위쪽 **링크 생성(상품 링크)** → 검색칸에 **"강력분"** → 쓰실 상품의 **링크 생성** → **단축 URL 복사** (나머지 "드라이 이스트", "블랙 올리브 슬라이스", "엑스트라버진 올리브유"도 같은 방법)
  3. 복사한 링크 4개를 회사 채팅에 그대로 붙여 넣기 ("포카치아 링크" 한 줄만 써 주시면 돼요). 링크는 비밀 값이 아니라 채팅으로 받아도 돼요.
  - 버튼 이름은 회사가 화면을 직접 못 봐서 조금 다를 수 있어요.
  - **회장님이 실제로 쓰시거나 사실 만한 상품만** 골라 주세요(페이지 제목이 "에델이 고른 부엌 살림과 재료"예요). 회사는 "강력 추천" 같은 말은 쓰지 않아요.
