# 한 접시 키친(가칭) — 기획서 1판 (기획팀, 2026-11-04)

가칭: 한 접시 키친 (이름은 회장님 결재 때 정함)
원본: 회장님 음성 지시 (2026-11-04). 원문과 다르면 회장님 말씀을 따른다.
고객 이름·연락처·구매 기록은 이 공개 저장소에 쓰지 않는다.
규정 판단은 [암웨이규정-확인.md](암웨이규정-확인.md)(암웨이사업팀)를 따른다.

## 1. 한 줄 목표와 대상
- 목표: 회장님 고객이 게임처럼 요리를 하나 끝내면 진짜 레시피 하나를 얻어 가고, 그 요리에 쓴 생활용품을 자연스럽게 다시 보게 한다.
- 대상: 회장님의 암웨이 고객(소비자). 회장님이 보낸 초대 링크로만 들어오는 닫힌 공간. 누구나 보는 공개 화면이 아니다.
- 라운지와 다른 점: 라운지 = 리더가 10코어를 하는 곳 / 한 접시 키친 = 고객이 요리를 하는 곳. 둘은 따로 운영한다.

## 2. 고객이 얻어 가는 것 (선물보다 이것이 먼저)
- 레시피 카드: 끝까지 만들면 휴대폰에 사진으로 저장하는 A4 레시피 한 장
- 요리 힌트: 단계마다 한 줄 ("양파는 약불에서 갈색이 될 때까지")
- 완성 그림: 내가 만든 요리가 접시에 담겨 나옴
- 도장: 요리를 하나 끝낼 때마다 도장판에 하나
- (3단계부터) 내가 집에서 만든 요리 사진 모음 — 고객 휴대폰 안에만 저장, 회사로 올리지 않음

## 3. 게임 흐름
1. 들어오기 — 초대 링크를 누르면 바로 부엌 화면. 가입 없음(1단계).
2. 레시피 고르기 — 큰 카드 3장 중 하나를 누름 (요리 시간과 재료 개수 표시)
3. 단계별 요리 — 한 화면에 한 단계. 버튼 하나("썰기", "볶기")를 누르면 다음 단계로
4. 재료가 떠오르기 — 그 단계에 쓰는 재료와 생활용품(소금, 키친타월 등)이 캐릭터 머리 위로 통통 귀엽게 떠올랐다가 사라짐
5. 완성 — 접시에 담긴 요리 + "레시피 카드 저장" 버튼
6. 오늘 쓰신 재료 — 쓴 것을 한 장에 모아 보여 줌. 암웨이 제품은 작은 카드로, 카드마다 "더 보기", "사러 가기"
7. 도장 — 도장판에 쾅. "10개 모으면 선물" 안내

원칙: 글씨는 크게, 한 화면에 버튼 하나, 긴 스크롤 없음(회장님이 싫어하시는 것).

## 4. "선물만 받으려는 사람" 문제 — 회사 추천안
회사의 생각: 선물만 노리는 분을 막기보다, 선물을 받으려면 자연스럽게 진짜 요리를 하게 만든다. 집에서 한 번 요리해 본 분이 제품도 다시 찾는다.

추천안 A (추천) — "진짜 도장"은 고객이 직접 체크
- 게임에서 완성하면 연습 도장(회색), 집에서 실제로 만든 뒤 고객이 "집에서 만들었어요"를 직접 체크하면 진짜 도장(색깔)
- 사진은 고객 휴대폰에만 둔다. 회사로 올리지 않는다(서버 = 인터넷 저장 공간에 저장 안 함).
- 진짜 도장은 하루 1개까지 → 빨라도 10일. 도장판 완성과 선물은 1인 1번
- 선물은 진짜 도장 10개에만 줌. 구매와 상관없이 줌(산 사람에게만 주는 조건 없음 → 경품 규정 위험이 가장 적음)
- 선물: 공식 생활용품 샘플(포장 그대로)이나 주방 소품, 1인 1번, 5천 원 안쪽, 상품권·기프티콘·현금 아님, 건강기능식품 제외 (결재 필요)
- 선택지(한 줄): 회장님 확인을 원하면 사진은 확인 뒤 바로 지우고 동의를 받는다 — 규정팀 다시 확인 필요

추천안 B — 선물을 물건이 아니라 "경험"으로
- 도장 10개 = 회장님 쿠킹 모임 초대나 1:1 요리 상담 30분
- 돈이 거의 들지 않고, 선물만 원하는 분은 자연스럽게 빠짐
- 단점: 회장님 시간이 듦

추천안 C — 중간 보상을 0원 디지털로
- 도장 3개마다 "다음 레시피 3개 열림", 10개 때만 실물 선물
- 요리에 관심 있는 분은 계속 오고, 선물 비용은 끝까지 온 분에게만 듦
- A나 B와 같이 쓸 수 있음

회사 추천: A + C를 같이. B는 회장님이 시간을 내실 수 있을 때 선물 종류로 추가.

## 5. 구매로 이어지는 흐름
- "사러 가기"(회장님 지시대로 이 이름)는 암웨이 공식 몰 상품 페이지로만 연결. 다른 쇼핑몰은 없음.
- 링크를 넣어도 되는지는 한국암웨이 서면 승인 질문 2번으로 확인한다.
- 버튼 이름 대안: "공식 몰에서 보기" — 결재 때 고를 수 있음
- 링크를 넣으면 안 된다는 답이 오면: "사러 가기" 대신 "회장님께 물어보기" 버튼 → 회장님 카톡·문자로 연결(자동 발송 없음, 고객이 직접 누름)
- 게임 안에는 가격을 쓰지 않는다(가격은 공식 몰 화면에서 봄). 할인·"지금 사세요" 같은 권유 말투 금지.
- ABLE CRM과 잇는 방법(단계적으로)
  - 1~2단계: 연결하지 않음. 회사는 "어느 레시피를 몇 명이 끝냈나", "어느 제품 카드를 몇 번 눌렀나"만 이름 없이 셈 → 회장님께 매주 한 줄로 보고
  - 3단계 이후(동의한 분만): 별명 + 끝낸 레시피 + 관심 표시한 제품을 회장님 확인 화면에 보여 줌 → 회장님이 ABLE CRM에 직접 메모. 자동으로 넘기는 연결은 개인정보 동의서와 결재를 거친 뒤에 생각함
  - 나중에 가능한 것: 고객이 관심 표시한 제품이 떨어질 때쯤 ABLE CRM 재구매 알림(알림 시기 = 앱출시팀, 보낼 문구 = 암웨이사업팀)

## 6. 규정 — 확인 필요 목록 (암웨이사업팀이 확인, 기획팀은 판단하지 않음)
1. 선물·경품: 사업자가 고객에게 개인 선물·도장 보상을 주는 것이 암웨이 규정에서 되는지, 구매 조건 없이 주면 괜찮은지, 금액 한도가 있는지
2. 고객용 화면에 암웨이 이름·로고·제품 이름·제품 사진을 써도 되는지 (11/3 지원팀 답은 "리더 전용 비공개 라운지"에 대한 것이었음 → 고객용은 따로 확인)
3. 공식 몰 링크: 공식 몰 상품 페이지 링크를 게임 안에 넣어도 되는지 (서면 승인 질문 2번)
4. 가격 표시: 게임에 가격을 쓰지 않는 방식이 맞는지
5. 효능 표현: 제품 카드 설명에 쓸 수 있는 말의 범위 (건강기능식품은 넣지 않는 것을 추천)
6. 레시피 출처: 퀸 쿠킹클래스 카드처럼 회사 자료인 레시피는 쓰지 않고 회장님 본인 레시피만 쓰는 것이 맞는지
7. 개인정보: 별명·선물 받을 연락처를 받을 때 동의 문구, 보관 기간, 보관 장소(공개 저장소·공개 노션 금지). 요리 사진은 받지 않음(고객 휴대폰에만)
8. 다른 사업과 섞지 않기: 메종에델 공구·쿠팡 파트너스 링크, 책(『슬기로운요리생활』) 판매 안내를 이 게임에 넣지 않음 (기획팀 추천 = 넣지 않음)
9. 공개 글 금지어: 수입·보너스·직급·"스폰서", 자랑·권유 말투 — 안내문·초대 문구 모두

## 7. 처음 작게 시작하는 판
레시피 3개 고르는 기준
- Able Team Recipe Book(213개) 중 회장님 본인 레시피
- 15분 안쪽, 재료 7개 이하, 집에 있는 재료
- 생활용품 2~3개가 자연스럽게 쓰이는 요리 (어떤 제품인지는 암웨이사업팀이 고름)
- 고르기: 편집팀이 후보 6개 → 회장님이 3개 고름(버튼으로)

기존 라운지에서 다시 쓰는 것 (전체의 약 3분의 1로 추정)
- 다시 씀: 지금 라운지와 같은 무료 도구로 만든 입체(3D) 화면 틀, 캐릭터, 톡 눌러 움직이기, 초대 링크 방식, 사이트 올리는 곳, 저장 공간(3단계)
- 새로 만듦: 레시피 단계 화면, 재료 떠오르기 움직임, 완성 접시, "오늘 쓰신 재료" 카드, 도장판, 레시피 카드 저장, "집에서 만들었어요" 체크
- 라운지는 이미 리더들이 쓰는 실제 서비스이므로, 라운지 코드(프로그램)를 그대로 옮기지 않고 같은 틀로 따로 만든다(서로 고장 내지 않게).

단계 (됐다 = 회장님 아이폰 실제 주소에서 돌아감)
1. 시제품 (혼자, 저장 없음, 약 1주, 0원): 레시피 3개, 단계별 요리, 재료 떠오르기, 완성, 오늘 쓰신 재료(제품 칸은 "제품 예시"로 비워 둠), 도장판(휴대폰에만 저장), 레시피 카드 저장. 10초 안에 뜸.
- 한국암웨이 서면 승인 (2단계 전에 꼭): 회장님 → 사업자 지원 문의(질문 5개) → 서면 답 받음(문자·메일 캡처)
2. 진짜 제품과 링크 (서면 승인 뒤, 약 1주): 제품 카드, "사러 가기" 또는 "회장님께 물어보기", 이름 없는 숫자 세기
3. 진짜 도장과 선물 (1~2주): 초대 링크별 계정, "집에서 만들었어요" 체크(하루 1개), 선물 신청, 개인정보 동의
4. 고객 10명 시험 (한국암웨이 서면 승인 받은 뒤, 2주): 회장님이 고른 고객 10명에게만 → 결과 보고 뒤 넓힐지 결정

업무 분담 (책임 팀: 암웨이사업팀)
1. [암웨이사업팀] 6장 확인 목록 답 정리 — 끝 기준: 항목마다 "됨 / 안 됨 / 회장님 문의 필요" (2와 동시에)
2. [편집팀] 레시피 후보 6개 + 단계별 힌트 한 줄 (1과 동시에)
3. [디자인팀] 부엌 화면, 재료 떠오르기 모양, 도장판, 레시피 카드 (2 끝난 뒤)
4. [개발팀] 1단계 시제품 (3 끝난 뒤)
5. [콘텐츠팀] 안내 문구·초대 문구 (금지어 확인)
6. [앱출시팀] 3단계용 개인정보 동의문 1쪽
7. [회계팀] 선물 예산, 무료 사용량 매주 확인
8. [품질관리팀] 점검 기준: 회장님 아이폰 실제 주소, 글씨 크기, 화면당 버튼 하나, 금지어 없음, 다른 사업 링크 없음, 확인 안 된 제품 이름 없음

## 8. 결재가 필요한 지점
- 기획서·1단계 착수 승인 (0원)
- 이름(가칭 한 접시 키친)
- 진짜 제품 이름·링크 넣기 (한국암웨이 서면 승인 받은 뒤). 버튼 이름: "사러 가기"(회장님 지시) / 대안 "공식 몰에서 보기"
- 선물 종류와 예산: 공식 생활용품 샘플(포장 그대로)이나 주방 소품, 1인 1번, 5천 원 안쪽, 상품권·기프티콘·현금 아님, 건강기능식품 제외 (시험 10명이면 최대 5만 원)
- 저장 공간 연결(지금 라운지와 같은 무료 도구)과 개인정보 동의문 (3단계)
- 고객에게 초대 링크 보내기 = 바깥 공개 (4단계, 한국암웨이 서면 승인 받은 뒤)
- 돈이 더 드는 경우: 저장 공간 무료 범위를 넘으면 월 25달러 — 그때 결재

## 예상 비용
1~3단계 무료(지금 라운지와 같은 무료 도구). 돈은 실물 선물만 듦 — 결재로 정함.

## 하지 않을 것
가격·할인 표시, 구매해야 주는 선물, 건강기능식품 효능 표현, 요리 사진을 회사로 올리기, 메종에델 공구·쿠팡 파트너스·책 판매 연결, 공개 SNS 게시, 자동 메시지 발송, 라운지 코드 수정, 유료 3D·AI 그림
