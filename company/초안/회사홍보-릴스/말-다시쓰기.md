## 3. 회장님 낭독 대본 (1인칭, 35.7초)

- 기준: 한국어 1초에 약 4글자 (띄어쓰기 빼고 소리 나는 글자로 셈. "AI"는 "에이아이" 4글자로 셈).
- 합계 113글자 → 1초 4글자로 읽으면 약 28초. 35.7초 안에 넉넉히 끝납니다.
- 화면 자막(A안)과 뜻을 같게 맞췄습니다. 마음을 전하는 사람은 **보는 분(당신)** 입니다. "저희" = 회장님과 AI 팀.
- "들어갈 수 있는 글자" = 장면 길이(초) × 4, 소수점 아래는 버림.

| 초 | 장면 | 회장님이 읽을 말 | 글자 / 들어갈 수 있는 글자 |
|---|---|---|---|
| 0~4초 | 쌓이는 쪽지 | 제 책상엔 늘 메모가 쌓여 있었어요. | 14 / 16 |
| 4~9.6초 | 조직도 | 그래서 회사를 꾸렸고, 일은 AI 팀이 나눠 맡아요. | 22 / 22 |

## 4. 지킨 것 점검 (A·B·대본 모두)
| 점검 | 결과 |
|---|---|
| 금지어: 수입·보너스·직급·"스폰서" | 없음 |
| "곁의 분들", "얼굴" | 없음 |
| 사람 챙기는 쪽: 알림·자동·관리·고객·명단 | 없음 ("알려 주는"도 "챙기는"·"귀띔"으로 바꿈) |
| "~하세요" 권유·가르치는 말, "~만 하면 돼요" | 없음 ("~해 주세요"는 원래 핵심 문장의 부탁 말투만) |
| 자랑 말투·숫자 | 없음. A안은 "저희"로 더 낮춤 |
| 암웨이 떠올리는 말 (제품·건강·파트너·리더·팀 이름) | 없음 |
| 핵심 문장 (A안) "남은 일은 저희가 할게요 / 당신은 마음만 건네 주세요" | 원래 뜻("나머지는 우리가 할게요 / 당신은 마음만 전해 주세요") 유지. A안 자막·A안 캡션·대본 세 곳 같은 문장 (대본만 "당신은" 뺌) |
| 대본의 "~만 하면 돼요" | 없음 |
| 자막 한 화면 2줄 이하 | 모두 2줄 |

---

확인 필요:
1. "우리" → "저희"(A안·대본): 더 낮은 말이라 골랐습니다. 회장님 귀에 "우리"가 더 편하시면 A안에서 "저희"만 "우리"로 되돌리면 됩니다.
2. "당신"이 어색하시면: A안 자막·캡션의 핵심 문장에서 "당신은"을 빼고 "남은 일은 저희가 할게요 / 마음만 건네 주세요"로 줄여도 뜻이 같습니다 (대본은 이미 뺀 형태).
3. B안 캡션의 이모지(😅) 하나: 빼도 됩니다.
4. 낭독 대본 끝 "고맙습니다"는 콘텐츠팀이 넣은 것입니다. 원래 영상 끝에는 말이 없었습니다.
