1. **조직도 자막 "그래서 팀을 나눴어요 / 일은 AI 팀이 맡아요".** "회사를 꾸렸어요 → 할 일이 많아서요 → 그래서 팀을 나눴어요"로 한 문장처럼 이어짐. 9판 6번 "그래서 일은 AI 팀이 나눠 맡아요"는 이 둘째 줄로 옮겨 합침 (같은 말이 두 번 나오지 않게 원래 자리에서는 지움).
   - 다른 안: "이렇게 팀을 나눴어요 / 일은 AI 팀이 맡아요"
2. **조직도 뒤에는 같은 책상으로 돌아옴.** 1번 끝 화면(쪽지 6장)을 그대로 멈춰 두었다가 다시 이어 가서, 쌓이는 장면이 끊겨 보이지 않음. 7번 "레시피는 A4 한 장으로"가 3번 "A4에 옮겨 적고, 뽑고"와 맞서 보여 다리 자막 없이도 흐름이 통함.

## 3. 개발팀 지시서

### 3-0. 시계를 장면마다 따로 — 조직도를 숫자 안 고치고 옮기는 방법
장면 1~6은 한 책상(`#sPile`) 안에 있어서 조직도를 사이에 끼우려면 책상 시간을 멈춰야 함. 9판의 HOLD(0.6초 멈춤)를 장면별 시계로 넓힘. **그래서 `#sOrg`·`#sCore`·`#s5`·장면 1~6 안의 숫자는 하나도 안 고침.**

`seek()`를 아래로 바꿈 (`HOLD_AT`, `HOLD` 두 줄은 지움):

```js
// 10판: 장면마다 시계가 따로 있음. v = 영상 초 → 그 장면의 코드 초
const CLOCK = {
  sPile: v => v < 2.0 ? v : v < 2.6 ? 2.0 : v < 3.3 ? v - 0.6 : v < 7.7 ? 2.7 : v - 5.0, // 2.0에서 0.6초, 2.7에서 4.4초(조직도) 멈춤
  sOrg:  v => v + 12.3,   // 코드 15.6 = 영상 3.3
  s2:    v => v - 0.6,    // 9판과 같음
  sMix:  v => v - 0.6,    // 9판과 같음
  sCore: v => v - 1.8,    // 8번이 1.2초 늘어서 0.6 + 1.2
  s5:    v => v - 1.8,
};
// 보이는 영상 구간 [시작, 끝, 들어올 때 바꿈, 나갈 때 바꿈]. 0 = 바로 (처음·끝)
const SHOW = {
  sPile: [[0, 3.3, 0, 0.4], [7.7, 20.6, 0.4, 0.4]],
  sOrg:  [[3.3, 7.7, 0.4, 0.4]],
  s2:    [[20.6, 25.0, 0.4, 0.4]],
  sMix:  [[25.0, 29.2, 0.4, 0.4]],
  sCore: [[29.2, 33.4, 0.4, 0.8]],
  s5:    [[33.4, 38.8, 0.8, 0]],
};
const secOf = new WeakMap();
window.seek = function(ms){
  const v = ms/1000;
  for (const a of document.getAnimations()) {
    let id = secOf.get(a);
    if (!id) { id = a.effect.target.closest(".scene").id; secOf.set(a, id); }
    a.pause(); a.currentTime = Math.max(0, CLOCK[id](v)) * 1000;
  }
  scenes.forEach(sc=>{
    const op = Math.max(...SHOW[sc.id].map(([a,b,fi,fo])=>{
      const fin  = fi===0 ? 1 : clamp((v-(a-fi/2))/fi);
      const fout = fo===0 ? 1 : clamp(((b+fo/2)-v)/fo);
      return Math.min(fin, fout);
    }));
    sc.style.opacity = op;
    // 천천히 다가가기: 9판처럼 data-s/e(코드 시각)로 계산, t 대신 그 장면 시계를 씀
    const t = CLOCK[sc.id](v), s = +sc.dataset.s, e = +sc.dataset.e;
    const p = clamp((t-(s-0.2))/((e+0.2)-(s-0.2)));
    sc.style.transform = `scale(${(1 + 0.04*p).toFixed(4)})`;
  });
};
```
- 책상이 멈추는 때(코드 2.7)는 1번 자막이 다 사라지고(capOut 2.4+0.3) 휴대폰이 뜨기(2.7) 바로 전이라 화면이 비어 있음. 멈춘 동안 책상은 안 보임.
- `TOTAL = 38800`. `fOf()`·`data-f`는 이제 안 씀 (SHOW로 옮김). `#sCore`의 `data-f="0.8"`은 지워도 됨.
- 아래 3-1~3-3 숫자는 모두 **코드 시각**. 괄호 안은 영상 시각.
