## 원칙 (매주 같음)
- 매일 저녁 7시, @maison_edel_ 스토리 1개. 게시는 사장이 품질관리팀 검수를 붙인 뒤.
- **미엘 중심, 귀엽고 다시 보고 싶은 5~7초 짤.** 예고·광고 글(날짜·시간·"만나요"·판매·장보기 안내) 없음.
- 글은 **미엘 말투 한마디 한 줄만** (예: "뭐 끓이는 거야옹?"). 요리 이름은 말하지 않고, 다음 화·금 요리는 **장면·재료로 살짝 복선**(뚜껑 틈 김, 당면 한 가닥, 빨간 토마토 덩굴).
- 흐름: 요리 장면 1~3초(보는 맛: 김, 보글, 쭉 늘어남, 토마토 따기) → 미엘이 바라보는 듯한 컷 + 한마디. 움직이는 중에 넘어가고 멈춤 없음.
- 크레딧 0. 생성 도구(런웨이 등) 안 씀. 이미 만든 편집본(손·팔 사라짐, 떠 있는 물건, 초록 꼭지·꼭지 구멍 토마토를 이미 뺀 것)과 미엘 영상(video/8.mp4)만 씀. 9.mp4(먹기)·E3/E3b(먹는 장면)는 쓰지 않음.
- 소리: 실제 녹음만. 편집본 구간은 편집본 소리 그대로(FSD50K CC0 + 회장님 녹음), 미엘 원본 구간은 마당 새소리 245703 + 바람 244296 + 미엘 야옹 110011(입 벌리는 순간). 음악·AI 소리·사람 목소리 없음. No.05 편집본의 "영상 자체 소리" 컷(양파·볶기)은 쓰지 않음.
- 규격: 1080×1920, 24fps, H.264(High, 닫힌 GOP) + AAC 128kbps 48kHz, 편집 목록 없음·moov 앞(인스타 API 스토리 규격).
- 글씨: 썸네일 C 틀과 같은 고운바탕 Bold, 흰 글자 + 엷은 그림자, 화면 위 340px(위·아래 250px 안 비움). 미엘 컷이 나올 때 0.3초에 걸쳐 나타남.
- 금지: 수입·보너스·직급·스폰서, 상품명, 암웨이, AI 문장. AI 표시는 올릴 때 라벨로 켬(API `is_ai_generated`).
- 영상·그림 파일은 공개 저장소에 두지 않음 → 클라우드 작업 폴더(scratchpad)와 노션 페이지에만.

## 인스타 API로 스토리 올릴 때 안 되는 것 (Meta 문서 확인 11/9)
출처: developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media, …/content-publishing
- **스티커 전부 안 됨**: 링크 스티커, 투표, 위치 스티커, 질문·퀴즈·카운트다운·음악 스티커 ("Publishing stickers (i.e., link, poll, location) is not supported"). 링크가 필요하면 프로필 링크로.
- **캡션(글) 없음** → 글은 영상 안에 넣음 (이미 그렇게 함).
- **인스타 음악 못 붙임** (음악 라이브러리는 앱에서만). 우리는 음악 안 씀.
- **릴스·게시물을 스토리로 공유 안 됨** (앱의 "스토리에 공유" 기능 없음). 릴스 홍보는 영상을 따로 올려야 함.
- **필터·쇼핑 태그·공동 작업자(collaborators) 안 됨.**
- 사람 언급(@)은 스티커 없이 `user_tags`로만 됨.
- **예약 게시 기능 없음** → 우리 예약 작업이 7시에 바로 올림. 만든 컨테이너는 24시간 안에 게시해야 함.
- 영상은 **공개 주소**에서 가져가거나 resumable 업로드. 노션 파일 주소는 약 1시간 뒤 만료 → 예약 작업이 게시 직전에 노션에서 새 주소를 받아야 함.
- 규격: MP4/MOV, H.264/HEVC, AAC 48kHz·128kbps, 23~60fps, 3~60초, 100MB 이하, 가로 1920px 이하.
- 한도: 24시간에 API 게시 100개(`content_publishing_limit`로 확인). 스토리는 24시간 뒤 사라짐.
- AI 표시: `is_ai_generated=true`로 켤 수 있음(문서에 있음, 스토리 제외 문구 없음 — 첫 게시 때 실제로 붙는지 확인).
- 우리 쪽 막힌 곳: 노션 기록상 메타 앱 Maison Edel Studio는 개발 모드이고 게시 권한(content_publish) 추가가 필요하다고 되어 있음 → 첫 API 게시 전에 권한 확인 필요.
