- 암웨이사업팀: 지킬 것 목록(10코어 원문, 존, "검증 아님" 문구, 관리자 범위, 브랜드 표시 규칙), 리더 안내문 확인

- 시장조사팀: 아이폰 3D 성능, 무료 상업 이용 음원(녹음 저작권 포함)
- 앱출시팀: 이름 공개 동의문·개인정보 안내 1쪽
- 콘텐츠팀: 라운지 안내 문구·초대 안내문 (금지어 확인)

- 회계팀: 무료 사용량 매주 확인(70% 넘으면 보고)

## 단계 (됐다 = 회장님 아이폰 실제 주소)
1. 3D 시제품(혼자, 저장 없음, 약 1주): 10초 안에 뜸, 톡 눌러 이동, 11개 존, 5분 끊김 없음, 음악 4종, 타이머, 전광판 모양
2. 10코어 기록·전광판(계정+DB, 1~2주): 초대 링크, 일·주·월 기록, 다른 폰 전광판 축하, "본인 체크 · 검증 아님", 더마 아키텍트 집계 제외
3. 30명 실시간(약 1주): 폰 5 + 가짜 25 접속, 1초 안 반영, 사용량 숫자 보고
4. 팀 공개(약 1주): 동의문, 초대 안내(결재), 1주 무사고, 매주 백업

## 비용: 무료 예상 (조건: 톡 눌러 이동 방식)
- Supabase 무료: 동시 200명, 실시간 메시지 월 200만(받는 사람마다 1개씩 셈), 500MB. 추정 월 약 50만 개(25%). 1주 미사용 시 멈춤, 자동 백업 없음.
- 사이트: 기획팀 추천 Cloudflare Pages(무료 전송량 제한 없음). Netlify 무료는 월 300크레딧을 계정 전체가 나눠 써서 3D 파일이 무거우면 ABLE CRM·메종에델 페이지까지 멈출 위험.
- 돈 드는 경우: Supabase Pro 월 25달러 — 그때 결재.

## 위험과 대책
- 아이폰 성능: 단순 모양, 그림자 최소, 느린 폰은 가벼운 화면 + 기록 버튼 화면
- 화면 끄면 음악·타이머 멈춤: 타이머는 시작 시각 기준 계산
- 개인정보: 동의한 분만 이름, 별칭 가능, 관리자 범위 제한, 공개 저장소·공개 노션 금지
- 암웨이 규정: 팀 안 닫힌 도구, 수입·직급·실적 숫자 없음, 로고·제품 표시는 암웨이사업팀 확인 + 회장님 ✅
- "보너스존" 이름: "보너스"가 수입을 떠올릴 수 있어 회장님께 여쭘(마음대로 안 바꿈)
- 음악 저작권: 공개·무료 상업 이용 녹음만, 강의 음원은 올리지 않음
- 1판에 채팅·음성 없음
