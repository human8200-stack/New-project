# 에이블 라운지 홍보 영상 — 녹음 대본 (6판 기준, 콘텐츠팀 초안 2026-11-03, 게임 해설 말투)

자막은 영상에 그대로 두고, 목소리는 게임 방송하듯 화면을 보면서 실시간으로 해설해요.
전체 약 108초 = 말 96초(감사일기 장면 안 쉼 1초 포함) + 장면 사이 쉼 12번 × 1초
(계산 기준: 1초에 4글자, 숫자·영어는 읽는 소리로 셈, 장면마다 올림)

녹음 팁: 보면서 편하게 말하듯이, 틀려도 괜찮아요.

## 지킨 것
- 이름은 "텐코어"로 적었어요. 음원존은 강의예요.
- 금지어(수입·직급·스폰서)와 회사 이름은 없어요.
- 회장님 예문("와, 여기 보세요", "혼자 텐코어 하는 것보다…", "저도 스스로 운동을 하는 거죠. 하나 둘, 하나 둘")을 살렸어요.

## 확인 필요
1. 장면 순서는 지난번 받은 순서대로(음악존 → 텐코어 자리들 → 운동 → 감사일기 → 순위 → 마무리) 썼어요. 6판 영상에서 운동이 실제로 어디에 나오는지 맞춰 봐야 해요.
2. "여기서 오른쪽으로 가면~", "SNS 정리 고르고"는 화면 움직임을 짐작해서 썼어요. 6판 화면과 방향·버튼이 다르면 고쳐야 해요.
3. 장면별 초는 계산으로 낸 숫자예요. 108초라 110초 안이지만 여유가 적어요. 줄여야 하면 순위 장면과 입장 장면을 먼저 줄여요.
4. 공기청정기·가습기·카페·간판 장면은 말 없이 화면만 보여 줘요.
