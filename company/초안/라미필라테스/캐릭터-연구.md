> 회장님 지시: "요가하는 사람 가상 라운지 보내준 거 있지, 캐릭터들 연구해 보자"

## 0. 한 줄 결론
지금 라미는 "작은 사람"이고, 요가 라운지는 "장난감"이에요.
**머리를 더 크게(키의 절반 가까이), 팔다리를 더 짧고 통통하게, 맨살을 줄이고 몸을 한 덩어리로** 만들면 징그럽지 않고 귀여워져요.

## 1. 참고 화면에서 본 캐릭터 (멜레릴라 요가 라운지)

보이는 화면: 열대 나무 데크, 대나무 기둥·야자잎, 매트 위 "머리서기" 장면. 위에 "1 / 30명", "자연 소리 켜짐", 캐릭터 위에 옷 이름 "골든 올리브 점프수트". 아래 카드 "YOUR LITTLE PLACE · 25번 매트 · 머리서기 · 고요한 균형" + [내 자리 고르기] + 동작 버튼 3개(명상 · 사바사나 · 머리서기).

같은 계열(회장님이 11월에 보낸 다른 가상 공간: 온라인 도서관, 밥 먹는 식탁, 순례길)도 캐릭터 만드는 법이 거의 같아서 함께 참고함.

| 항목 | 요가 라운지 캐릭터 |
|---|---|
| 몸 비율 | **약 2등신.** 머리 높이 ≈ 몸통+다리 높이. 머리가 키의 45~50% |
| 머리 | 아주 크고 거의 완전한 공. 목이 없음(머리가 몸 위에 바로 얹힘). 머리카락은 머리를 덮는 큰 덩어리 하나(검은 갈색), 잔머리·가닥 없음 |
| 얼굴 | 눈 = **까만 점 2개**(작은 세로 타원). 눈이 얼굴 가운데보다 **조금 아래**, 양옆으로 넓게. 입 = 아주 작은 "u" 한 줄. 볼은 연한 분홍 동그라미(다른 계열 캐릭터). 코·눈썹·속눈썹 없음 |
| 피부색 | 따뜻한 살구색(하얗지 않음) |
| 팔다리 | 짧은 원기둥/캡슐. 굵기가 길이의 절반 가까이. 끝은 둥글게 막힘(손가락 없음). 팔은 내리면 배 높이까지만 옴 |
| 관절 | **안 보임.** 팔꿈치·무릎 구분 없이 한 덩어리처럼 굽음 |
| 옷 | 한 색 **점프수트**(올리브 카키), 헐렁한 덩어리. 팔다리까지 같은 색이라 몸이 한 덩어리로 보임. 허리·가슴·엉덩이 굴곡 없음. 발은 짙은 갈색 작은 블록(신발/발) |
| 재질 | 무광, 낮은 채도(올리브·카키·나무색). 외곽선 없음. 반짝임 없음 |
| 그림자·조명 | 따뜻한 낮빛 한 방향, 그림자 부드럽고 연함. 바닥에 동그란 그림자 정도 |
| 화면 위 글자 | 캐릭터 위에 옷 이름 알약 하나(작게), 그 외 캐릭터 주변 글자 없음 |

### 동작 표현
- **머리서기:** 몸 전체를 위아래로 뒤집음. 머리는 매트(나무 블록 위)에 닿고, 몸통과 다리는 곧게 위로 붙여 올림. 얼굴은 거꾸로지만 눈 뜨고 웃음 → 힘든 동작인데도 "귀엽게 버티는" 느낌. 다리가 짧아서 거꾸로 서도 길쭉하지 않고 통통한 기둥처럼 보임.
- **명상(버튼으로 봄, 장면은 못 봄):** 같은 계열 캐릭터 기준으로 추정 — 매트에 앉아 다리 접고, 손은 무릎 위, 눈은 감은 ∩ 모양.
- **사바사나(추정):** 매트에 등 대고 눕기, 팔은 몸 옆으로 살짝 벌림, 눈 감음.
- 동작 이름은 화면 큰 자막("그리고 머리서기")과 아래 카드 한 줄로 알려 줌. 캐릭터는 몸으로만 보여 줌.

### 왜 "귀엽고 징그럽지 않게" 보이나 — 이유 3가지
1. **사람 비율이 아니라 아기·장난감 비율.** 머리가 키의 절반, 목 없음, 팔다리 짧은 막대 → 뇌가 "사람"으로 안 보고 "인형"으로 봄. 5등신 라미가 징그러웠던 건 사람에 가까운데 어딘가 어색했기 때문(어색한 골짜기).
2. **몸의 굴곡과 맨살이 거의 없음.** 한 색 점프수트가 몸을 한 덩어리로 덮음. 허리·엉덩이·가랑이·관절 모양이 안 보임. 손가락·발가락도 없음.
3. **얼굴이 아주 단순하고 아래쪽에 있음.** 점 눈 2개 + 작은 입. 눈이 낮고 넓게 → 아기 얼굴 느낌. 여기에 무광·낮은 채도·부드러운 빛이 더해져 "말랑한 물건"처럼 보임.

### 3-2. 몸통 (가랑이 V자 없애기 — 제일 중요)
- 지금 몸통은 캡슐 2개(아래 레깅스 0.098, 위 크롭탑 0.1)라 아래쪽이 볼록하게 V로 보임.
- 추천: **둥근 통 하나**(캡슐 반지름 0.11, 길이 0.08, `scale.z 0.9`)를 두 색으로 나눠 보이게.
  - 방법: 위쪽 60%는 탑 색, 아래 40%는 레깅스 색. 같은 위치에 캡슐 2개를 겹치되 **아래 캡슐 반지름을 위 캡슐보다 0.002 작게**, 아래 캡슐 가운데를 위 캡슐보다 0.05만 낮게 → 아래로 튀어나오지 않음.
  - 허리띠(지금 토러스 0.012)는 유지, 두께 0.014로 조금 굵게 → 색 경계를 깔끔하게.
- 다리는 몸통 아래에 **몸통 안으로 0.02 파고들게** 붙여 틈 없애기.

## 4. 개발팀에 넘길 것 (요약)
1. `lounge.js` `BODY` 값과 `buildAvatar()` 안 수치를 3-1, 3-3 표대로 바꾼다.
2. 몸통 아래 V자 볼록을 없앤다(3-2). 다리를 몸통 안으로 0.02 넣어 틈 없앤다.
3. 눈을 평소 점 눈, 명상·사바사나·인사 때만 ∩로 바꾼다(`A.eyes` 둘 다 만들어 두고 보이기/숨기기).
4. 색 코드를 3-4로 바꾼다(피부 빛남 0.4 → 0.28).
5. 비율이 바뀌면 앉기·자전거·요가 자세의 `hipsY`, 이름표 높이(`tag.position.y 0.76 → 약 0.68`), 들고 있는 물건(쉐이커·책) 위치를 다시 맞춘다.
6. 바꾼 뒤 휴대폰 화면에서 서 있기·앉기·요가 캡처 3장 → 회장님 확인.
7. 공용 앱이면 버전 올리기 규칙을 따른다.
