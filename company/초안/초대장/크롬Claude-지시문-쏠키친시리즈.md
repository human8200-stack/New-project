# 크롬 Claude 지시문 — 인스타 본계정 「쏠키친」 시리즈 만들기
(세컨드웨이브 사장 작성, 2026-11-08 · 회장님 승인 "시리즈관리 니가 넣어주라")

## 하는 일
인스타그램 본계정 @ssoll0820 에 새 기능 "시리즈"를 만들고, 지금까지 올린 **요리 게시물(릴스)**을 에피소드로 넣는다.

## 안전 규칙 (꼭 지키기)
- 로그인·비밀번호·결제 화면이 나오면 멈추고 회장님께 넘긴다. 비밀번호를 입력하거나 저장하지 않는다.
- **아무것도 지우지 않는다.** 게시물 삭제·보관·수정, 캡션 변경 금지.
- 게시물을 새로 올리지 않는다. 시리즈 만들기와 에피소드 넣기만 한다.
- 계정이 @ssoll0820 이 아니면 멈춘다 (메종 에델 @maison_edel_ 아님).

## 순서
1. 크롬에서 https://www.instagram.com/ssoll0820/ 을 연다. 회장님 계정으로 로그인돼 있는지 확인한다.
2. 프로필이나 "만들기(＋)" 메뉴에 **"시리즈" / "시리즈 만들기"**가 있는지 찾는다.
   - **없으면 여기서 멈추고** "인스타 웹에서는 시리즈 만들기가 없어요. 휴대폰 앱에서만 됩니다"라고 회장님께 보고한다. (이 기능은 지금 휴대폰 앱에서 시험 중이라 웹에 없을 가능성이 높다.)
3. 있으면:
   - 커버 사진: 아래 주소의 그림을 내려받아 쓴다 (세로 3:4).
     https://raw.githubusercontent.com/human8200-stack/New-project/claude/focus-90days/company/%EC%B4%88%EC%95%88/%EC%B4%88%EB%8C%80%EC%9E%A5/%EC%8F%A0%ED%82%A4%EC%B9%9C-%EC%8B%9C%EB%A6%AC%EC%A6%88%EC%BB%A4%EB%B2%84.jpg
   - 제목: `쏠키친`
   - 설명:
     ```
     『슬기로운 요리생활』 저자의 부엌에서.
     매일 저녁, 우리 집 식탁 이야기 🍲
     ```
   - "만들기"를 누른다.
4. 에피소드 넣기: 본계정 릴스 중 **요리 영상만** 오래된 것부터 차례로 넣는다.
   - 넣지 않는 것: AI·회사 이야기(「AI로 만든 회사, 세컨드웨이브」), 암웨이·사업 이야기, 라운지, 여행·일상, 사람 얼굴이 주인공인 것.
   - 애매하면 넣지 말고 목록에 "애매함"으로 적는다.
5. 끝나면 회장님께 짧게 보고: 시리즈를 만들었는지, 넣은 에피소드 목록(날짜 + 첫 줄 캡션), 애매해서 뺀 것 목록, 화면 캡처 1장.
