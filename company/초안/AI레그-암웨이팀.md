## 한 줄 결론
- **AI는 레그(사업자)가 될 수 없습니다.** 사업자는 등록 계약을 맺는 **사람**만 됩니다.
- **AI는 "사람이 하는 일"을 빠르고 꾸준하게 돕는 도구로는 쓸 수 있습니다.** 특히 매출 쪽(재구매·정기 구매 놓치지 않기)에서 효과가 큽니다.
- 단, **사람인 척, 동의 없는 자동 메시지, 효능·가격 약속, 가짜 계정**은 모두 안 됩니다.
- 앱·AI 도구를 파트너에게 나눠 주려면 **암웨이 사전 서면 승인**이 필요할 가능성이 큽니다(윤리강령 7조, SNS 정책). 원문 확인 필요.

## 1. AI가 레그(사업자) 자체가 될 수 있나? → 안 됩니다

| 근거 (요약 기준) | 내용 |
|---|---|
| 윤리강령 1조 | 윤리강령은 **사업자 등록 계약의 일부** → 계약을 맺고 책임지는 주체가 있어야 함 |
| 윤리강령 3조 | 부부는 하나만 등록, 미성년자·공무원·교원·학생은 등록 불가 → **사람 기준**으로 만든 등록 제도 |
| 윤리강령 3조 | 6개월 활동 없으면 자격 취소 → 사람이 실제로 활동해야 함 |
| 윤리강령 4조 | **실적 조작 금지** → AI나 가짜 이름으로 계정을 만들어 실적을 쌓으면 정면 위반 |
| 윤리강령 6조 | 라인 변경·재등록 제한 → 가짜·대리 등록으로 라인을 꾸미는 것 금지 |
| 법인 등록 가능 여부 | **확인 필요** (요약에 없음. 되더라도 AI가 아니라 법인 뒤의 사람이 책임짐) |

**정리**: 레그는 "사람 + 그 사람에게서 나오는 매출"입니다. AI가 만들 수 있는 것은 **레그가 아니라, 사람 레그가 매출을 꾸준히 만들도록 돕는 흐름**입니다.

## 3. 매출(PV) 쪽 — 고객 흐름에서 AI가 할 수 있는 일 / 안 되는 일

흐름: **고객 찾기 → 첫 구매 → 재구매 → 정기 구매**

### 할 수 있는 일 (조건 지키면)
| 일 | 어떻게 | 조건 |
|---|---|---|
| **재구매 알림** | 고객이 산 날짜 + 제품 사용 기간으로 "다 떨어질 때쯤"을 앱이 계산(앱출시팀) → AI가 안내 문구 초안(암웨이사업팀) → 파트너가 보고 직접 보냄 | 광고 수신 동의한 고객만. 밤 9시~아침 8시 피하기. 문구에 효능·가격·할인 없음. "필요 없으면 알림 끄기" 안내 |

## 4. 천만 PV는 어떤 규모인가

### 회사 기록에 있는 것 (공식 플랜 요약, 노션)
- **1,000만 PV = 공식 세일즈&마케팅 플랜에서 한 그룹이 가장 높은 비율 구간에 닿는 기준선**입니다(그룹 한 달 실적 기준).
- 21%에 닿은 하위 그룹 실적은 내 개인그룹 실적에서 빠집니다. 즉 "천만 PV 그룹"은 **그 그룹 안 사람들과 고객이 한 달에 만든 PV 합계**입니다.
- 자세한 비율표·자격 조건은 노션 비공개 "🔒 암웨이 사업실 → 공식 자료 요약"에 있습니다(공개 저장소에는 옮기지 않음).

### 회사 기록에 없는 것 → 확인 필요
- **제품 1원당 PV가 얼마인지** (PV와 소비자 가격의 비율) — 없음
- **고객 한 명이 한 달에 평균 몇 PV를 사는지** — 없음 (실적 화면 캡처를 아직 못 받음, 노션 "그다음 부탁" 목록)
- 그래서 **고객 몇 명 × 얼마**는 정확히 계산할 수 없습니다.

### 대신, 감 잡기용 표 (가정 숫자 — 실제 아님)
한 달 천만 PV = (사람 수) × (한 사람 평균 PV)

| 한 사람이 한 달에 사는 양 (가정) | 필요한 사람 수 (고객 + 파트너 본인 구매 합) |
|---|---|
| 평균 5만 PV | 200명 |
| 평균 10만 PV | 100명 |
| 평균 20만 PV | 50명 |

- 이 표는 "평균 구매가 두 배가 되면 필요한 사람이 절반"이라는 **모양만** 보여 줍니다. 5만·10만·20만은 회사가 고른 예시 숫자입니다.
- 진짜 계산을 하려면 회장님께 **딱 하나**만 받으면 됩니다: 사업자 앱의 **한 달 그룹 실적 화면 캡처 1장**(노션 비공개 "자료 올리는 곳"). 받으면 사업 설계실(노션 비공개)에서 "평균 PV × 사람 수"를 실제 숫자로 바꿉니다. 이 공개 파일에는 옮기지 않습니다.

### 현실 이야기
- 천만 PV는 **한두 명의 큰 구매가 아니라, 많은 사람의 반복 구매**로 만들어지는 숫자입니다. 그래서 AI가 가장 도움이 되는 곳은 "새 사람 찾기"보다 **"이미 산 고객이 끊기지 않게"(재구매·정기 구매)** 입니다.
- 정기 구매 비율, 재구매 주기, 끊긴 고객 수 같은 숫자도 지금은 **없음 → 확인 필요**. ABLE CRM에 이미 기록이 있다면 회장님 노트북에서 숫자만 뽑아 노션 비공개에 두는 방법이 있습니다.

## 5. 규정 안에서 AI가 레그를 실제로 돕는 일 7가지

### 공통 원칙 (모든 도구에)
1. AI는 **"AI 도우미"라고 먼저 밝힌다.** 사람인 척하지 않는다.
2. **사람이 보내고, 사람이 결정한다.** AI는 초안과 알림까지.
3. **공식 자료 문구만.** 효능·질병·가격·할인·돈 이야기 없음.
4. **동의한 사람에게만, 정해진 시간에만.**
5. **파트너에게 나눠 주는 도구는 먼저 암웨이 승인**(7조·SNS 정책 "앱 개설 콘셉트 사전 서면 승인"). 승인 전에는 회장님 본인용·시제품만.
6. **다른 사업과 섞지 않는다.** 메종에델 공구·쿠팡 파트너스·책 독자를 암웨이로 끌어오는 흐름을 만들지 않는다.

| **지인 소개** | ✅ 가능 (조건 지키면) | 소개받은 사람에게 처음 연락할 때 이름·사업자임을 밝힘(8조). 소개받았다고 동의 없이 광고 메시지를 보내면 안 됨(4조). 소개해 준 분께 사례(돈·선물)하는 것은 **확인 필요** |
| **유료 검색 광고** | ❌ 불가 | SNS 정책 "안 되는 것"에 검색·협찬형 광고 명시 |

### 암웨이사업팀 추천 순서 (규정상 안전한 것부터)
1. **브랜드센터 체험 초대** + **홈미팅** — 공식 자료·공식 공간, 사람이 직접 만남
2. **지인 소개** → 만난 뒤 동의 받고 **카카오 채널·문자 소식지**로 관계 이어가기 (AI는 소식지 초안·재구매 시기)
3. **네이버 블로그·기업 강의** — 사전 서면 승인 확인 후
4. 전단·현수막·플리마켓 — 원문 확인 전까지 하지 않음
5. 맘카페·유료 광고 — 하지 않음

### 이번 추가 질문으로 늘어난 "확인 필요"
- 공식몰 **고객 등록 방법, 사업자 추천 코드·링크** 유무와 이름
- 카카오 채널·네이버 블로그 개설이 **사전 서면 승인** 대상인지, 신청 방법
- 개인 사업자의 **전단·현수막·부스**를 허용하는지
- 게시물 "홍보하기"(부스트)가 유료 광고에 포함되는지
- 고객이 먼저 물은 밤 시간 질문에 AI가 답하는 것이 광고 메시지 규정에 걸리는지
- 지인을 소개해 준 분께 사례하는 것이 되는지
