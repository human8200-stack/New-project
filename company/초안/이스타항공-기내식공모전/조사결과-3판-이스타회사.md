# 이스타항공 회사 조사와 연결고리 (시장조사팀, 2026-11-02)

## 회사
- 2007년 설립, 전북 군산에서 시작. 2025-02 군산공항 철수 → 전북도 반발 (연결고리로 쓰지 않음)
- 대주주: VIG파트너스(2023-01, 지분 100%). 비행기 24대(보잉 737)
- 이름 뜻 "동방의 별": 별별카페, 별별스토어처럼 "별"을 씀. 상징색은 진홍색(#D41C24, 비공식 출처)
- 거점: 인천, 김포, 김해(부산을 키우는 중), 청주

## 노선과 손님
- 중심 노선: 일본(도쿄·후쿠오카 증편), 제주, 중화권(타이베이·홍콩·상하이)
- 2025 외국인 손님 약 102만 명, 그중 절반이 중화권. 제주→타이베이는 외국인 96%
- 2026 새 노선: 인천→홍콩(3월), 부산→알마티(5월, 무슬림 손님 많음)
- 가족 행사: 어린이날 이벤트, 반려견 캠페인

## 기내식 (2026-09)
- 신메뉴: 제육덮밥, 프라이드치킨, 닭가슴살 포케, 불고기 치아바타, 짜장밥
- 기존 메뉴: 비빔밥, 불고기라이스, 함박스테이크, 라구미트볼 펜네파스타(채식), 할랄라면 등
- 사전 주문(72시간 전)과 기내 현장 판매
- 2026-09부터 펄프 용기

## 연결고리 후보
1. 닭고기 + 덮밥은 이스타가 이미 잘 파는 모양 → 냉이 닭갈비 (냉이는 봄 재료라 출시 시기 확인 필요)
2. 빨간 상징색 → 닭갈비 양념, 토마토 미트소스
3. 가족·어린이·결식아동 기부 → 완자
4. 외국인 손님 절반이 중화권 → "처음 먹는 한국 맛"
5. 주의: 라구미트볼 파스타가 이미 있음 → 찹쌀완자는 "한국식"이 분명해야 함
6. 주의: 할랄·채식 손님 → 미트소스에 돼지고기가 들어가면 맞지 않음. 구운 채소는 채식 방향과 맞음
7. 펄프 용기에서 소스가 새거나 눅눅해지지 않는지 확인
8. 군산·전북 이야기는 피함
- 책의 다른 연결 메뉴: 양파카레(88, 이스타에 카레 없음), 라따뚜이(84, 채식)
