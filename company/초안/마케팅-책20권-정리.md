# 마케팅 책 20권 핵심 정리 — 회장님 사업에 바로 쓰기 (초안)

> 2026-11-26 · 마케팅팀 작성 · 회장님 원문: "마케팅에 관한 모든 책의 내용들을 정리해 봐 일단"
> 사장 가정: "모든 책"은 다 할 수 없으니, 많이 읽히고 인정받는 책 20권을 골라 핵심만 정리.
> 책 문장을 옮기지 않고 우리 말로 다시 썼어요. 번역 제목·출판사·연도 중 확실하지 않은 것은 "확인 필요"로 적었어요 (시장조사팀 확인 예정).

**읽는 법**: 맨 앞 "공통 원칙 TOP 10"과 "이번 달 할 것 5개"만 읽으셔도 됩니다. 책별 내용은 필요할 때 찾아 보세요.

**표시 뜻**
- 🟢 바로 쓰기 좋음
- ⚠️ 암웨이 쪽에 쓸 때 조심 (소득 과장·모집 말투·공개 SNS 모집·제품 효과 단정)
- 🚫 암웨이 쪽에는 쓰지 않음

## 1. 20권이 공통으로 말하는 원칙 TOP 10

1. **한 사람을 정해라.** 모두에게 팔면 아무에게도 안 팔린다. 가장 먼저 닿을 한 사람을 그린다.
2. **고객이 주인공, 우리는 안내자.** 내 자랑이 아니라 고객의 문제와 바뀐 모습을 말한다.
3. **한 단어를 차지해라.** 사람 머릿속에 우리를 떠올릴 자리 하나(예: "바쁜 엄마의 집밥")를 정하고 계속 같은 말을 한다.
4. **먼저 주고, 나중에 판다.** 무료 맛보기·도움·정보가 신뢰를 만들고, 신뢰가 판매가 된다.
5. **쉽고, 구체적이고, 이야기로.** 추상적인 말보다 한 장면·한 숫자·한 사람 이야기가 기억에 남는다.
6. **말하고 싶게 만들어라.** 사람들은 자기가 멋져 보이고, 도움이 되고, 감정이 움직이는 것을 남에게 전한다.
7. **진짜 증거를 보여라.** 후기·사례·과정 공개가 광고 문구보다 힘이 세다. (단, 가짜·과장은 법 위반)
8. **작은 팬 무리부터.** 처음부터 많은 사람이 아니라, 우리를 진짜 좋아하는 소수를 먼저 만든다.
9. **다음 한 걸음을 정해 줘라.** 보고 끝나지 않게 "댓글에 ○○ 남기기", "무료 PDF 받기"처럼 행동 하나를 분명히 준다.
10. **관계는 길게 본다.** 한 번 팔고 끝이 아니라, 다시 오고 소개하게 만드는 것이 남는 장사다.

## 2. 회장님이 이번 달 당장 해 볼 것 5개

(실행은 각 팀이 합니다. 회장님은 결재만 하시면 돼요.)

1. **『슬기로운 요리생활』 한 줄 자리 정하기** — "바쁜 날에도 집밥을 포기하지 않게 돕는 책"처럼 한 문장을 정하고, 모든 글·영상 끝에 같은 말을 쓴다. (마케팅팀 안 → 회장님 승인 → 콘텐츠팀)
2. **무료 맛보기 1개 만들기** — 책 속 레시피 3개를 PDF로. 메종에델 영상 댓글에 "레시피" 남기면 받는 흐름. (출판팀·콘텐츠팀 제작, 게시는 결재 후)
3. **진짜 후기 10개 모으기** — 이미 책을 산 2,000명 중 아는 분께 "요리해 본 사진 한 장 + 한 줄"을 부탁. 대가를 드리면 "협찬/제공" 표시. (출판팀)
4. **당근 요리모임에서 "먼저 주기"** — 모임에서는 팔지 않고, 레시피 하나를 같이 만들어 보는 시간. 책은 원하는 분께만 안내. (당근 모임 판매 글 규칙은 확인 필요)
5. **ABLE CRM 무료 체험 5명** — 암웨이가 아닌 1인 판매자(공방·보험·뷰티) 5명에게 무료로 써 보게 하고, "어떤 문제가 풀렸는지" 한 줄씩 받기. 이게 첫 판매 문장이 된다. (앱출시팀)

## 4. 책별 정리

### ① 마켓 4.0 (Marketing 4.0)
- 저자: 필립 코틀러 외 · 한국어판 제목 『필립 코틀러의 마켓 4.0』 (정확한 제목·출판사 확인 필요)
- **한 줄**: 요즘 고객은 광고보다 주변 사람과 온라인 후기를 믿는다. 그래서 "알게 됨 → 끌림 → 물어봄 → 삼 → 추천함" 다섯 단계를 설계해야 한다.
- **핵심 개념**
  1. 고객 길(5단계): 알기 → 끌리기 → 물어보기 → 사기 → 추천하기. 마지막 "추천"이 목표.
  2. 물어보는 단계가 중요: 사기 전에 친구·후기·검색으로 확인한다. 이때 답이 준비돼 있어야 한다.
  3. 온라인과 오프라인을 섞어라: 화면에서 알게 되고, 만나서 믿게 된다.
  4. 사람다운 브랜드: 완벽함보다 솔직함·따뜻함이 끌린다.
- **회장님 사업에 이렇게 써요**
  - 책: 메종에델 영상(알기) → 무료 레시피(끌리기) → 후기 모음(물어보기) → 구매 → 요리 사진 올려 주기(추천). 단계마다 빈 곳을 채운다.
  - 요리모임: 당근 모임은 "만나서 믿게 되는" 오프라인 단계. 온라인 콘텐츠와 연결.
- ⚠️ 암웨이: 고객 길 개념은 소비자 관리에 쓸 수 있지만, 공개 SNS에서 사업 모집 단계로 쓰면 안 됨.

### ② 포지셔닝 (Positioning)
- 저자: 알 리스, 잭 트라우트 · 『포지셔닝』 (번역판 여러 판 있음, 출판사 확인 필요)
- **한 줄**: 상품을 바꾸는 게 아니라, 고객 머릿속에서의 자리를 정하는 싸움이다.
- **핵심 개념**
  1. 머릿속 사다리: 사람은 분야마다 2~3개 이름만 기억한다.
  2. 처음이 유리: 1등이 못 되면, 내가 처음인 작은 분야를 새로 만든다.
  3. 단순하게: 메시지는 짧고 하나여야 머리에 들어간다.
  4. 이름이 중요: 무엇인지 바로 떠오르는 이름이 낫다.
- **회장님 사업에 이렇게 써요**
  - 책: "요리책" 전체에서는 이길 수 없으니 "바쁜 엄마가 실제로 해 먹은 집밥 기록"처럼 좁은 자리를 차지.
  - 메종에델: "AI로 만든 유럽풍 요리 채널"이라는, 아직 비어 있는 자리.
  - ABLE CRM: "고객 관리 앱"이 아니라 "1인 판매자가 휴대폰 하나로 고객 챙기는 앱".
- 주의: 다른 회사보다 낫다고 비교하는 말은 근거 없으면 표시광고법 위반.

### ③ 마케팅 불변의 법칙 (The 22 Immutable Laws of Marketing)
- 저자: 알 리스, 잭 트라우트 · 『마케팅 불변의 법칙』
- **한 줄**: 마케팅에는 어기면 실패하는 규칙들이 있다 — 대부분 "좁혀라, 하나를 차지해라"로 모인다.
- **핵심 개념**
  1. 리더십 법칙: 더 좋은 것보다 먼저인 것이 이긴다.
  2. 집중 법칙: 한 단어를 차지하라.
  3. 확장의 함정: 이것저것 다 하면 브랜드가 흐려진다.
  4. 희생 법칙: 무엇을 하지 않을지 정해야 한다.
- **회장님 사업에 이렇게 써요**
  - 전체: 한 계정에 여러 사업을 섞지 않는다 (지금 회사 규칙과 같음 — 암웨이 / 메종에델 / 책 분리).
  - 책 홍보 글에는 책 하나만. 앱·공구를 같이 붙이지 않는다.

### ④ 브랜드 갭 (The Brand Gap)
- 저자: 마티 뉴마이어 · 『브랜드 갭』 (한국어판 출판사 확인 필요)
- **한 줄**: 브랜드는 우리가 말하는 것이 아니라, 고객이 "느끼는 것"이다.
- **핵심 개념**
  1. 브랜드 = 고객 마음속 느낌.
  2. 다르게: "우리는 무엇이 다른가" 한 문장으로 답할 수 있어야 한다.
  3. 같이 만들기: 고객이 참여할수록 브랜드가 커진다.
  4. 시험하기: 로고·글을 내놓기 전 몇 사람에게 보여 주고 반응을 본다.
- **회장님 사업에 이렇게 써요**
  - 메종에델: 화면 색·음악·말투를 매번 같게 — "이 채널 느낌"이 브랜드.
  - 책 표지·상세페이지 바꿀 때, 아는 분 5명에게 먼저 보여 주고 고른다.

### ⑤ 나는 왜 이 일을 하는가 (Start with Why)
- 저자: 사이먼 시넥 · 『나는 왜 이 일을 하는가』 (출판사 확인 필요)
- **한 줄**: 사람은 "무엇을 파는지"보다 "왜 하는지"에 마음이 움직인다.
- **핵심 개념**
  1. 골든 서클: 왜 → 어떻게 → 무엇 순서로 말한다.
  2. 믿음이 같은 사람이 모인다.
  3. 일관성: 말과 행동이 같아야 신뢰가 쌓인다.
- **회장님 사업에 이렇게 써요**
  - 본계정: "지쳐 멈춘 듯할 때 다시 밀려오는 두 번째 파도" — 회사 이름의 "왜"가 그대로 소개글이 된다.
  - 책: "왜 이 책을 썼는지" 이야기를 상세페이지 맨 위에.
- ⚠️ 암웨이: "왜"를 말할 때 돈·자유·시간 같은 소득 암시로 흐르기 쉬움 → 쓰지 않음. 생활·건강한 습관 이야기까지만.

### ⑥ 설득의 심리학 (Influence)
- 저자: 로버트 치알디니 · 『설득의 심리학』
- **한 줄**: 사람이 "예"라고 하게 만드는 마음의 원리 6가지(최근 판은 7가지)가 있다.
- **핵심 개념**
  1. 받으면 돌려주고 싶다(상호성).
  2. 작은 약속을 하면 지키고 싶다(일관성).
  3. 남들이 하면 따라 한다(사회적 증거).
  4. 좋아하는 사람, 믿을 만한 사람 말을 듣는다(호감·권위).
  5. 귀하면 더 갖고 싶다(희소성). 최근 판: 같은 편이라는 느낌(일체감).
- **회장님 사업에 이렇게 써요**
  - 책: 무료 레시피(상호성) → 진짜 후기(사회적 증거) → 2,000권이라는 사실(근거 있는 숫자).
  - 공구: 기간·수량이 진짜로 정해져 있을 때만 "○일까지" 표시.
- ⚠️ 암웨이: 희소성("지금 아니면 늦어요"), 사회적 증거("다들 하고 있어요")를 사업 권유에 쓰면 압박 판매·모집 말투 → 쓰지 않음.
- 주의(전체): 가짜 마감, 가짜 후기는 표시광고법 위반.

### ⑦ 스틱! (Made to Stick)
- 저자: 칩 히스, 댄 히스 · 『스틱!』
- **한 줄**: 머리에 붙는 메시지는 6가지 특징이 있다 — 단순, 의외, 구체, 믿을 만함, 감정, 이야기.
- **핵심 개념**
  1. 단순하게: 핵심 하나만.
  2. 의외성: "어? 그래?" 하는 순간이 관심을 잡는다.
  3. 구체적으로: 눈에 그려지는 말.
  4. 감정과 이야기: 숫자보다 한 사람의 이야기.
  5. 지식의 저주: 내가 아는 걸 남도 안다고 착각하지 말 것.
- **회장님 사업에 이렇게 써요**
  - 영상 첫 3초: 의외의 한 줄("냉장고 남은 재료 3개로 저녁").
  - 책 소개: "레시피 ○개"보다 "퇴근 후 20분 저녁" 같은 장면으로 (시간은 실제 레시피 기준일 때만).

### ⑧ 컨테이저스 (Contagious)
- 저자: 조나 버거 · 『컨테이저스 전략적 입소문』 (제목 확인 필요)
- **한 줄**: 사람들이 말을 퍼뜨리는 이유 6가지(STEPPS)를 알면 입소문을 설계할 수 있다.
- **핵심 개념**
  1. 말하면 내가 멋져 보이는 것(소셜 화폐).
  2. 자주 떠오르게 하는 계기(트리거): 예) "월요일 저녁 = 이 레시피".
  3. 감정: 놀람·감동·웃음이 퍼진다.
  4. 눈에 보이게(공공성), 쓸모 있게(실용 가치), 이야기 속에 담기.
- **회장님 사업에 이렇게 써요**
  - 메종에델: "저장해 두고 싶은" 실용 레시피 + 정해진 요일 연재(트리거).
  - 요리모임: 모임에서 만든 요리 사진을 참여자가 올리고 싶게 예쁜 접시·카드 준비.
- ⚠️ 암웨이: 입소문을 "사업 소개 퍼뜨리기"로 쓰면 공개 모집이 됨 → 제품·생활 정보 공유 범위까지만, 규정 확인 후.

### ⑨ 티핑 포인트 (The Tipping Point)
- 저자: 말콤 글래드웰 · 『티핑 포인트』
- **한 줄**: 작은 변화가 어느 순간 크게 퍼진다 — 소수의 특별한 사람, 기억에 남는 내용, 환경이 열쇠.
- **핵심 개념**
  1. 소수의 법칙: 아는 사람이 많은 사람(연결자), 정보를 잘 아는 사람(전문가), 설득을 잘하는 사람이 퍼뜨린다.
  2. 고착성: 한 번 들으면 잊히지 않는 내용.
  3. 환경의 힘: 작은 분위기 차이가 행동을 바꾼다.
- **회장님 사업에 이렇게 써요**
  - 책: 동네 맘카페·요리모임 운영자 같은 "연결자" 몇 명에게 책을 먼저 선물 (대가 표시 필요 시 "제공받음" 안내).
  - 요리모임: 모임 분위기(정리된 테이블, 따뜻한 첫 인사)가 재참여를 만든다.

### ⑩ 카네기 인간관계론 (How to Win Friends and Influence People)
- 저자: 데일 카네기 · 『데일 카네기 인간관계론』 (번역판 여러 개)
- **한 줄**: 사람은 자기를 진심으로 알아주는 사람에게 마음을 연다.
- **핵심 개념**
  1. 비판하지 말고 인정하라.
  2. 상대 이름을 기억하고, 상대 이야기에 관심을 가져라.
  3. 말하기보다 듣기.
  4. 상대가 원하는 것의 말로 이야기하라.
  5. 논쟁에서 이기려 하지 말라.
- **회장님 사업에 이렇게 써요**
  - 암웨이: 소비자 관리의 기본 — 구매 후 안부, 생일 기억 (ABLE CRM이 돕는 일). 🟢
  - DM·댓글: 답장은 상대 이야기를 먼저 받아 주고 시작 (DM·댓글팀 말투와 같음).

### ⑪ 기브 앤 테이크 (Give and Take)
- 저자: 애덤 그랜트 · 『기브 앤 테이크』
- **한 줄**: 길게 보면 남을 잘 돕는 사람(기버)이 성공한다 — 단, 자기를 지키면서 줄 때.
- **핵심 개념**
  1. 세 종류: 주는 사람, 받기만 하는 사람, 맞바꾸는 사람.
  2. 똑똑한 기버: 돕되 시간·에너지 한계를 정한다.
  3. 느슨한 인맥: 오래 연락 안 한 사람이 새 기회를 준다.
  4. 작은 도움(5분 도움)이 쌓인다.
- **회장님 사업에 이렇게 써요**
  - 본계정: 제휴 파트너를 찾을 때 먼저 도움(앱·자료 공유)부터.
  - 암웨이: 파트너님을 돕는 "먼저 걸어간 선배들" 태도와 같음. 🟢
- ⚠️ 암웨이: "주다 보면 돌아온다"를 소득 이야기로 바꾸지 않는다.

### ⑫ 세일즈 바이블 (The Sales Bible)
- 저자: 제프리 지토머 · 한국어판 『세일즈 바이블』 (출간 여부·제목 확인 필요)
- **한 줄**: 사람들은 "팔리는 것"은 싫어하지만 "사는 것"은 좋아한다 — 믿음과 관계를 먼저 만들어라.
- **핵심 개념**
  1. 고객은 가격보다 믿음으로 산다.
  2. 질문으로 고객의 진짜 이유를 찾는다.
  3. 거절은 끝이 아니라 정보다.
  4. 만족한 고객의 소개가 가장 강한 판매 도구.
- **회장님 사업에 이렇게 써요**
  - ABLE CRM: 판매 전 체험자에게 "무엇이 불편했나" 질문 목록 준비.
  - 책: 단체 구매(학교·모임) 제안 때 질문부터.
- ⚠️ 암웨이: 이 책의 적극적인 판매·끈질긴 연락 방식은 방문판매법·회사 규정상 압박 판매가 될 수 있음 → 관계·질문 부분만 쓴다.

### ⑬ SPIN 판매 (SPIN Selling)
- 저자: 닐 라컴 · 한국어판 제목 확인 필요 (『당신의 세일즈에 SPIN을 걸어라』로 알려짐)
- **한 줄**: 큰 판매는 설명보다 "좋은 질문 4단계"로 이뤄진다.
- **핵심 개념**
  1. 상황 질문: 지금 어떻게 하세요?
  2. 문제 질문: 어떤 점이 불편하세요?
  3. 영향 질문: 그게 계속되면 어떤 일이 생기나요?
  4. 해결 가치 질문: 해결되면 무엇이 좋아질까요?
- **회장님 사업에 이렇게 써요**
  - ABLE CRM 체험자 상담: "고객 연락처 어디에 정리하세요?" → "놓친 적 있으세요?" → 앱 소개.
  - 암웨이 소비자 상담(제품 사용 상담)에서 질문 순서로 쓸 수 있음. 🟢 (사업 권유에는 쓰지 않음)

### ⑭ 보랏빛 소가 온다 (Purple Cow)
- 저자: 세스 고딘 · 『보랏빛 소가 온다』
- **한 줄**: 평범하면 안 보인다. 눈에 띄는 "특별함"을 상품 안에 넣어라.
- **핵심 개념**
  1. 무난함이 가장 위험하다.
  2. 모두가 아니라 관심 많은 소수(얼리어답터)를 노려라.
  3. 이야기할 거리를 상품 안에 넣는다.
- **회장님 사업에 이렇게 써요**
  - 메종에델: AI 영상 + 실제 레시피라는 조합 자체가 "보랏빛 소". AI 표시는 꼭.
  - 책: 책 안에 QR로 영상 레시피 연결 같은 "말할 거리" (출판팀 검토).

### ⑮ 마케팅이다 (This Is Marketing)
- 저자: 세스 고딘 · 『마케팅이다』
- **한 줄**: 마케팅은 소리치기가 아니라, 작은 무리의 사람들을 더 나은 쪽으로 바꾸도록 돕는 일이다.
- **핵심 개념**
  1. 최소 시장: 나 없으면 아쉬워할 가장 작은 무리를 정한다.
  2. "우리 같은 사람은 이렇게 한다": 소속감이 행동을 바꾼다.
  3. 공감: 고객의 두려움·바람을 이해한다.
  4. 꾸준함: 매주 같은 시간에 보여 주는 것이 신뢰.
- **회장님 사업에 이렇게 써요**
  - 요리모임: "우리 모임 사람들은 일주일에 한 번 새 요리를 해 본다" 같은 모임 문화.
  - 책: 최소 시장 = "아이 키우며 저녁 메뉴가 고민인 30~40대 엄마".

### ⑯ 1,000명의 진짜 팬 (1,000 True Fans)
- 저자: 케빈 켈리 · 책이 아니라 짧은 글(에세이). 한국어로는 『타이탄의 도구들』(팀 페리스) 등에 소개됨 (수록 여부 확인 필요)
- **한 줄**: 큰 인기 없이도, 내 것을 꾸준히 사 주는 진짜 팬 1,000명이면 작은 사업이 굴러간다.
- **핵심 개념**
  1. 진짜 팬 = 내가 내는 건 거의 다 사는 사람.
  2. 직접 연결: 플랫폼 너머 연락 통로(메일·밴드)를 갖는다.
  3. 여러 상품 사다리: 무료 → 전자책 → 종이책 → 클래스.
- **회장님 사업에 이렇게 써요**
  - 책·메종에델: 회사 판매 흐름(무료 PDF → 전자책 → 종이책 → 클래스·앱)이 바로 이 생각.
  - 연락 통로: 무료 PDF 받을 때 메일 동의 받기 (개인정보 동의·처리방침 필요).
- ⚠️ 암웨이: "팬 1,000명 = 수입" 같은 계산은 소득 암시 → 쓰지 않음.

### ⑰ 무기가 되는 스토리 (Building a StoryBrand)
- 저자: 도널드 밀러 · 『무기가 되는 스토리』
- **한 줄**: 고객을 영웅으로, 우리를 안내자로 놓고 7단계 이야기로 메시지를 짜라.
- **핵심 개념**
  1. 주인공은 고객: 원하는 것이 있다.
  2. 문제: 겉 문제(저녁 메뉴) + 속 마음(엄마로서 미안함).
  3. 안내자: 공감 + 실력 근거.
  4. 계획과 행동 요청: 쉬운 3단계 + "지금 해 보기" 버튼.
  5. 실패 피하기와 성공 모습: 안 하면 어떤지, 하면 어떤지.
- **회장님 사업에 이렇게 써요**
  - 책 상세페이지 순서: "저녁마다 고민이죠?(문제) → 저도 그랬어요(공감) → 2,000권 독자(근거) → 3단계(계획) → 지금 무료 레시피 받기(행동)".
  - ABLE CRM 소개 페이지도 같은 틀.
- ⚠️ 암웨이: "실패 피하기"를 "지금 안 하면 손해"로 쓰면 압박 → 사업 쪽엔 쓰지 않음.

### ⑱ 훅 (Hooked)
- 저자: 니르 이얄 · 『훅: 일상을 사로잡는 제품의 비밀』 (제목 확인 필요)
- **한 줄**: 사람이 습관처럼 다시 쓰는 제품은 "계기 → 행동 → 보상 → 투자" 고리를 갖고 있다.
- **핵심 개념**
  1. 계기: 알림(바깥) + 감정(안, 예: 심심함·불안).
  2. 쉬운 행동: 한 번에 할 수 있게.
  3. 매번 조금 다른 보상.
  4. 투자: 사용자가 넣은 데이터가 많을수록 떠나기 어렵다.
- **회장님 사업에 이렇게 써요**
  - ABLE CRM: "오늘 연락할 고객 3명" 알림(계기) → 한 번 누르면 메시지 초안(행동) → 고객 반응(보상) → 고객 기록 쌓임(투자).
  - 공부 루틴·레시피함 앱에도 같은 고리.
- 주의: 미성년자 앱(공부 루틴)은 알림을 지나치게 쓰지 않는다.

### ⑲ $100M 오퍼 ($100M Offers)
- 저자: 알렉스 호르모지 · 한국어판 출간 여부·제목 확인 필요
- **한 줄**: 사람들이 "안 사면 바보 같다"고 느낄 만큼 가치 있는 제안을 만들어라.
- **핵심 개념**
  1. 가치 = (원하는 결과 × 될 거라는 믿음) ÷ (걸리는 시간 × 수고).
  2. 문제를 다 적고, 하나씩 푸는 것을 묶어 준다(번들).
  3. 보너스·보장으로 위험을 줄여 준다.
  4. 좁은 고객에게 맞춘 이름.
- **회장님 사업에 이렇게 써요**
  - 책: 종이책 + 영상 레시피 QR + 장보기 목록 PDF 묶음 ("수고"를 줄여 주는 묶음).
  - 요리 클래스: 재료 준비해 둠 + 레시피 카드 + 단톡방 1주 질문 (가격은 출판팀·결재).
- 🚫 암웨이: 암웨이 제품은 공식 가격·조건을 따라야 함 → 내 마음대로 묶음·할인·보장 만들지 않음.
- 주의(전체): "효과 보장", "100% 환불" 같은 말은 실제로 지킬 수 있고 조건을 적을 때만. 이 책의 강한 말투(공격적 마감)는 우리 회사 방식과 다름.

### ⑳ 마케팅 설계자 (DotCom Secrets)
- 저자: 러셀 브런슨 · 한국어판 『마케팅 설계자』 (제목·출판사 확인 필요)
- **한 줄**: 고객이 무료 → 작은 구매 → 큰 구매로 단계를 밟도록 "판매 흐름(퍼널)"을 설계하라.
- **핵심 개념**
  1. 가치 사다리: 무료 → 낮은 가격 → 중간 → 높은 가격.
  2. 미끼(무료 선물)로 연락처를 받는다.
  3. 후속 연락(메일 순서)으로 관계를 만든다.
  4. "꿈의 고객"이 어디 모여 있는지 먼저 찾는다.
- **회장님 사업에 이렇게 써요**
  - 책: 메종에델 영상 → 댓글 "레시피" → 무료 PDF → 전자책 → 종이책 → 클래스. (회사 판매 흐름 그대로)
  - 메일 후속 5통: 레시피 팁 3통 + 책 소개 1통 + 후기 1통 (발송은 결재 후).
- 🚫 암웨이: 공개 퍼널로 사업 파트너를 모으는 것은 공개 SNS 모집에 해당할 수 있음 → 쓰지 않음.
- 주의: 메일 발송은 수신 동의 필수, 광고 메일은 제목에 "(광고)" 표시 (정보통신망법).

## 6. 암웨이 쪽에 절대 가져오지 않는 기법 (모아 보기)
- 소득·시간 자유·"팬 1,000명이면 ○원" 같은 계산 (소득 암시)
- 희소성·마감 압박("지금 아니면"), 사회적 증거로 사업 권유("다들 시작했어요")
- 공개 SNS·퍼널·무료 선물로 사업 파트너 모으기
- 내 마음대로 묶음 할인·보장 만들기 (공식 가격·조건 따름)
- 제품 효과 단정 (건강기능식품은 인정된 기능성 문구만)
- 공개 글 금지어: 수입·보너스·직급·"스폰서" → 대신 "먼저 걸어간 선배들", "파트너님"
- 한 글에 암웨이와 책·메종에델 공구·쿠팡 파트너스를 같이 넣지 않음
