# 건강 책 시장조사 — 가제 『엄마의 영양 노트』
작성: 시장조사팀 · 조사한 날: 2026-11-11 · 요청: 회장님(11/11) "내용이 진짜 중요해" / "유투브에서도 서익환 교수님을 챙겨봐"

## 조사 결과
강의를 많이 듣고 건강 책을 많이 읽은 네트워크 사업자에게 "이미 아는 내용"이 되지 않는 장(腸) 중심 영양 공부 책을 만들기 위한 조사입니다.

핵심 3줄:
- 최근 3년 건강 베스트셀러는 의사 저자가 대부분입니다. 장 하나만 다룬 책보다 "해독·배출·항염·혈당"으로 묶은 책이 팔렸습니다.
- 독자 불만은 "뻔하다·반복", "다른 책과 같다", "근거 없음·의사 아닌데" 세 가지입니다. 칭찬은 "쉽고 체계적", "바로 실천할 수 있음"에 몰립니다.
- 의사가 아닌 엄마 저자가 이길 수 있는 점은 "정리하는 틀"과 "솔직한 출처"입니다. 감수자, 참고문헌, "확인된 것 / 아직 모르는 것" 구분이 신뢰를 만듭니다.

### 2. 네트워크 사업자가 이미 아는 것 (추정)
- 사업자 추천 도서 목록은 공개 자료에 없음.
- 이미 알 가능성이 높은 것: 장은 제2의 뇌, 장내 미생물·유익균, 독소·해독, 만성 염증, 혈당 스파이크, 채소·과일식, 영양 결핍, 호전반응.
- 부족할 가능성이 높은 것: 연구로 확인된 말과 주장을 가려내는 힘, 영양소끼리의 관계를 한 장으로 보는 정리, 규정을 지키며 답하는 말.

### 3. 의사가 아닌 저자가 신뢰를 얻은 방법
- 한약사 저자: 본인 이야기 + 장마다 독자 체험담 + 참고 자료 + "10만 부" 사회적 증거.
- 유튜버 저자: 원리는 짧게, 레시피로 "바로 해 볼 수 있음".
- 실패 신호(환자 혁명): 의사로 오해될 표현, 공포 말투, 제품 판매 의심.

### 4. 결론
**꼭 있어야 할 것 5가지**
1. 출처 표기: "국가 영양소 섭취기준 / 연구 결과 / 강의에서 들은 말" 구분 표시, 책 끝 참고문헌.
2. "확인된 것 / 아직 모르는 것 / 흔한 오해" 칸 — 이미 들은 독자에게 가장 새로운 부분.
3. 한 장에 보는 정리 그림: 장 → 흡수 → 영양소 관계도, 영양소 한 쪽 카드, 찾아보기.
4. 엄마의 공부 이야기: 강의를 들으며 헷갈렸던 질문을 꼭지 제목으로(질문·비교형).
5. 감수자 1명(약사 또는 영양사), 공부 기록장 쪽.

**피해야 할 것 5가지**
1. 의사로 오해될 표현, 효능 단정
2. 공포 말투, 병원·약 깎아내리기
3. 같은 말 되풀이, 레시피로 쪽수 채우기
4. 제품·회사를 떠올리게 하는 말
5. 장내 미생물·제2의 뇌 같은 기본 설명을 길게 하기

**적정 쪽수·가격**: 260~300쪽, 정가 18,000~19,800원(2024 신간 평균 19,526원, 출판문화협회 2025-05, https://view.asiae.co.kr/article/2025052314180516145).

확실하지 않은 것: 교보·예스24 연간 순위와 판매 부수, 내 몸 혁명 쪽수, 사업자 추천 도서(추정), 리뷰 표본 적음, 서익환 약사 강의 짜임(공개 자료 없음).
