# 노트북 없이 회사가 연결하는 방법
조사일: 2026-11-01 / 시장조사팀
가정: 회장님이 쓰시는 Claude 요금제는 Pro 이상으로 보았습니다(확인 못 함). 회장님 노트북은 일반 Windows(x64) 노트북으로 보았습니다(확인 못 함).

## 핵심 3줄
- 노트북 크롬 일: 회사가 노트북에 직접 밀어 넣는 공식 방법은 지금 쓸 수 없습니다. 노트북이 노션 "할 일함"을 매시간 가져가 처리하는 방식(추천)이나, 아이폰 Dispatch로 한 줄을 보내는 방식(2안)이 됩니다.
- 링크: 인스타 프로필 링크와 리틀리는 API로 고칠 수 없습니다. 회사 링크 페이지 주소를 한 번만 걸어 두고, 내용은 회사가 고칩니다.
- 스마트스토어: 유입 추적 링크(NT 파라미터)는 회사가 지금 만들 수 있습니다. 판매 숫자 자동 조회(커머스API)는 한국 고정 IP 서버가 필요해서 2단계로 둡니다.

## 1. 네이버 커머스API(스마트스토어 API)
- 쓰는 순서: 커머스API센터 가입 → 계정 생성 → "내 스토어 애플리케이션" 등록. 등록하면 ID와 시크릿(비밀 값)이 나옵니다. (https://github.com/commerce-api-naver/commerce-api/discussions/2291)
- 국내 사업자만 발급받을 수 있고, 판매자가 직접 운용하는 용도로만 씁니다. ID와 시크릿을 제3자에게 넘기면 약관 위반 소지가 있습니다. (2026-02-23 공식 답변, https://github.com/commerce-api-naver/commerce-api/discussions/3251)
- 호출 IP 제한(확인됨): 등록한 IPv4에서만 부를 수 있고 최대 3개까지 등록합니다. 다른 곳에서 부르면 403 오류가 납니다. 클라우드는 IP가 바뀌므로 고정 IP가 필요하고, 한국 IP를 권장합니다. (2025-02 공식 FAQ, 위 2291 — 약 1년 된 자료)
- 호출 속도는 초당 2건입니다. (https://github.com/commerce-api-naver/commerce-api/discussions/3734)
- 토큰 규칙이 2026-08-21에 다시 공지됐습니다. 규칙을 어기면 호출이 시간당 1회로 제한됩니다. (https://github.com/commerce-api-naver/commerce-api/discussions/3751)
- 할 수 있는 일(제3자 자료로 확인): 주문, 상품·재고, 정산, 문의, 물류, 판매자 정보. (https://packagist.org/packages/sejongtf/laravel-naver-commerce) 공식 문서 사이트는 우리 쪽에서 열리지 않았습니다.
- 못 하는 일: 리뷰 API는 없습니다. (2026-04-28 공식 답변, https://github.com/commerce-api-naver/commerce-api/discussions/3463) 통계·유입 경로와 마케팅 링크 API는 못 찾음.
- 휴대폰으로 등록이 끝까지 되는지: 못 찾음.
- 고정 IP 서버: AWS 라이트세일 가장 싼 IPv4 요금제가 월 5달러이고, 붙여 둔 고정 IP는 무료입니다. 서울 요금은 확인 못 함. (https://aws.amazon.com/ko/lightsail/pricing/)

## 2. 리틀리
- 공개 API나 자동 연결 기능: 못 찾음. (확인 2026-11-01)
- 대안: 회사가 무료 GitHub Pages(깃허브가 주는 무료 웹페이지)에 링크 페이지를 만들고 언제든 고칩니다. 바깥에 보이는 변경이므로 문구는 회장님 ✅를 받고 올립니다. 리틀리는 예비로 남겨 둡니다.

## 3. 인스타 프로필 링크
- Graph API에서 소개글(biography)과 링크(website)는 읽기만 됩니다. 수정은 "지원하지 않음"으로 나옵니다. (https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/)
- 그래서 회사 링크 페이지 주소를 인스타 앱에서 한 번만 걸어 두는 방식이 답입니다.

## 4. 스마트스토어 유입 추적 링크(NT 파라미터)
- 형식: 상품주소?nt_source=값&nt_medium=값&nt_detail=값&nt_keyword=값. 앞의 2개는 필수이고 영어만 됩니다. 결과는 통계 > 마케팅 분석 > 사용자 정의 채널에서 봅니다. (https://inside.ampm.co.kr/insight/2054 — 대행사 블로그, 공식 문서 아님)
- 회사가 채널별 링크(본계정, 메종에델 인스타, 유튜브, 밴드)를 만들어 링크 페이지 버튼에 넣습니다. 회장님은 하실 일이 없습니다.

## 5. 링크·스마트스토어 추천안(1단계) — 회장님이 한 번만 하실 일(휴대폰, 0원)
1) 회사가 보내 드리는 링크 페이지 주소를 열어 보시고 "승인"이라고 답해 주세요.
2) 인스타그램 앱 → 오른쪽 아래 내 프로필 → "프로필 편집" → "링크" → litt.ly/ssoll0820을 새 주소로 바꾸고 저장해 주세요.
3) 메종에델 계정도 바꾸실 거면, 위쪽 계정 이름을 눌러 계정을 바꾼 뒤 2)를 한 번 더 해 주세요.
- 2단계(나중에 결재): 고정 IP 서버 결제와 커머스API센터 앱 등록을 한 번 하시면 됩니다. PC로 하시는 걸 권합니다.

## 6. 노트북 크롬과 연락하는 방법 (회장님이 붙여 넣지 않게)

### 6-1. 확인한 공식 기능
| 기능 | 무엇을 하나 | Windows | 요금제 | 조건 | 출처 |
|---|---|---|---|---|---|
| Dispatch | 아이폰 Claude 앱으로 보낸 일을 노트북 데스크톱 앱이 처리 | 됨(Windows x64) | Pro·Max·Ultra | 컴퓨터가 깨어 있고 앱이 열려 있어야 함. "제한된 베타" | https://support.claude.com/en/articles/13947068 , https://claude.com/docs/cowork/guide/dispatch |
| 데스크톱 예약 작업(로컬) | 정해 둔 시간마다 노트북에서 새 작업을 자동 시작 | 페이지에 OS 제한 없음 | 문서에 따로 없음 | 앱이 열려 있고 컴퓨터가 깨어 있을 때만 실행. 잠든 동안 놓친 작업은 깨어난 뒤 1번만 실행. 덮개를 닫으면 잠자기 | https://code.claude.com/docs/en/desktop-scheduled-tasks |
| Remote Control(원격 제어) | 노트북에서 돌고 있는 Claude Code를 휴대폰·웹에서 이어서 조종 | 문서에 Windows 제한 없음 | Pro·Max·Ultra·Team·Enterprise | 노트북의 앱이 계속 켜져 있어야 함 | https://code.claude.com/docs/en/remote-control |
| Projects "내 컴퓨터에서 실행" | 클라우드 회사 대화에서 노트북으로 일을 넘김 | 확인 못 함 | Pro·Max·Ultra, 순차 출시 | 데스크톱 앱 설정 켜기, 매번 "Allow once" 허락 | https://code.claude.com/docs/en/claude-projects |
| Claude in Chrome 바로가기·예약 | 저장해 둔 지시문을 정해진 시간에 크롬에서 실행 | 크롬 전용 | 유료 요금제 | 제3자 자료로는 컴퓨터가 깨어 있고 크롬이 열려 있어야 함 | https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome |
| 데스크톱 앱 + 크롬 연결 | 데스크톱 앱에서 크롬을 조종 | 문서에 Windows 문제 해결 항목 있음 | 유료 요금제 | 크롬 커넥터 켜기. 로그인 화면·CAPTCHA에서는 멈춤 | https://code.claude.com/docs/en/chrome |

덧붙이는 사실
- 데스크톱 앱 설정에 "Keep computer awake"가 있습니다. 다만 덮개를 닫으면 잠자기로 칩니다.
- 예약 작업이 처음 돌 때 권한 질문이 나옵니다. 처음에 "항상 허용"을 골라 두면 다음부터는 묻지 않습니다.
- Dispatch는 권한 질문에 10분 안에 답하지 않으면 그 동작을 건너뜁니다.
- 크롬 확장에서 로그아웃하면 저장해 둔 바로가기와 예약이 사라집니다.
- 클라우드 예약 작업은 노트북이 꺼져 있어도 돌지만, 노트북 크롬과 파일은 쓸 수 없습니다.
- 우리 클라우드에서 회장님 컴퓨터 폴더 목록이 비어 있고, Windows 폴더는 지원되지 않는다고 나옵니다(Mac/Linux만).

### 6-2. 추천안 — "노션 할 일함" + 노트북 예약 작업 (회장님이 붙여 넣을 일 0번)
- 회사(클라우드)가 노션 "💻 노트북 할 일함" 페이지에 지시문 전문을 씁니다.
- 노트북 데스크톱 앱의 예약 작업이 매시간 그 페이지를 읽고, 크롬으로 처리한 뒤 결과와 캡처를 같은 페이지에 적고 "완료"로 바꿉니다.
- 결제·게시·삭제처럼 결재가 필요한 일은 "회장님 ✅ 있음"인 것만 하게 지시문에 적어 둡니다.

회장님이 한 번만 하실 일(노트북, 집에 계실 때 한 번, 약 15분):
1) 노트북에 Claude 데스크톱 앱과 크롬 확장 "Claude"를 설치하고 같은 계정으로 로그인. 앱 설정에서 크롬 연결과 노션 연결 켜기.
2) 데스크톱 앱 예약 작업에 회사가 드리는 문장을 넣고 "매시간"으로 만든 뒤 "지금 실행"을 한 번 눌러 질문마다 "항상 허용".
3) Windows 설정 → 시스템 → 전원에서 "전원 연결 시 절전 안 함", 앱 설정 "Keep computer awake" 켜기. 나가실 때 전원을 꽂고 덮개를 열어 두기.

안 되는 점:
- 노트북이 꺼져 있거나 덮개가 닫혀 있거나 앱·크롬이 닫혀 있으면 아무것도 하지 않습니다.
- 최대 1시간을 기다릴 수 있습니다.
- 로그인이 풀리거나 CAPTCHA가 나오면 멈춥니다. 회사는 보안 장치를 피해 가는 방법을 쓰지 않습니다.
- 예약 작업 안에서 크롬 연결이 되는지는 공식 문서로 직접 확인하지 못했습니다. 첫 설정 날 시험이 필요합니다.
- 화면을 보고 클릭하는 일이라 실수할 수 있습니다.

### 6-3. 2안 — Dispatch (아이폰에서 한 줄)
- 회사가 노션 할 일함에 지시문을 써 두면, 회장님은 아이폰 Claude 앱 Dispatch에 "노트북 할 일함 처리해 줘" 한 줄만 보내십니다.
- 안 되는 점: 한 줄은 보내셔야 함. "제한된 베타"라 계정에 메뉴가 보이는지 확인 못 함. 권한 질문에 10분 안에 답해야 함.

### 6-4. 지금은 안 되는 것
- Projects "내 컴퓨터에서 실행"으로 클라우드가 노트북에 직접 일을 넘기는 방법: 순차 출시 중, Windows 지원 확인 못 함. 나중에 열리면 회장님 할 일이 "Allow once" 누르기 하나로 줄어듭니다.

## 확실하지 않은 것
- 회장님 Claude 요금제, 노트북이 x64인지: 확인 못 함.
- Dispatch가 회장님 계정에 열려 있는지: 확인 못 함.
- 노트북 예약 작업 안에서 크롬 연결이 안정적으로 되는지: 첫날 시험 필요.
- 커머스API 휴대폰 등록 가능 여부, 통계 API 유무: 못 찾음.
- NT 파라미터: 실제 링크 하나로 시험 필요.
