# 노트북 없이 회사가 연결하는 방법
조사일: 2026-11-01 / 시장조사팀 (품질관리팀 반려 후 1차 수정, 공식 문서 다시 열어 확인)
가정: 회장님이 쓰시는 Claude 요금제는 Pro 이상으로 보았습니다(확인 못 함). 회장님 노트북은 LG Windows 노트북입니다. 칩이 x64(일반 인텔·AMD 칩)인지는 확인 못 함.

## 핵심 3줄
- 노트북 크롬 일: 회사가 노트북에 직접 일을 밀어 넣는 공식 방법은 지금 쓸 수 없습니다. 추천안은 노트북 데스크톱 앱의 예약 작업이 노션 "할 일함"을 매시간 읽어 처리하는 방식입니다. **추천안은 첫날 시험으로 크롬이 되는지부터 확인한다.**
- 링크: 인스타 프로필 링크와 리틀리는 API(프로그램끼리 연결하는 문)로 고칠 수 없습니다. 회사 링크 페이지 주소를 한 번만 걸어 두고, 내용은 회사가 고칩니다.
- 스마트스토어: 유입 추적 링크(NT 파라미터, 어디서 들어왔는지 붙이는 꼬리표)는 회사가 지금 만들 수 있습니다. 판매 숫자 자동 조회(커머스API)는 한국의 고정 IP(바뀌지 않는 인터넷 주소) 서버가 필요해서 2단계로 둡니다.

## 1. 노트북 크롬과 연락하는 방법 (회장님이 평소에 붙여 넣지 않게)

### 1-1. 확인한 공식 기능
| 기능 | 무엇을 하나 | Windows | 요금제 | 조건 | 출처 |
|---|---|---|---|---|---|
| 데스크톱 예약 작업(로컬) | 정해 둔 시간마다 노트북에서 새 작업을 자동 시작 | 페이지에 OS 제한 없음 | 문서에 따로 없음 | 앱이 열려 있고 컴퓨터가 깨어 있을 때만 실행. 잠든 동안 놓친 작업은 깨어난 뒤 1번만 실행(지난 7일 중 가장 최근 것). 덮개를 닫으면 잠자기. 화면 양식에서 가장 짧은 주기는 1시간 | https://code.claude.com/docs/en/desktop-scheduled-tasks |
| Claude in Chrome 확장(크롬에 붙이는 Claude) 바로가기·예약 | 저장해 둔 지시문(바로가기)을 정해진 주기로 크롬에서 실행 | 크롬 전용(다른 브라우저·휴대폰 안 됨) | 유료 요금제(Pro·Max·Ultra·Team·Enterprise) | 문서에 나온 주기는 매일·매주·매월·매년. 매시간은 문서에 없음. 백그라운드 작업은 크롬이 열려 있는 동안 계속됨. 컴퓨터가 깨어 있어야 하는지는 문서에 없음 | https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome |

| Remote Control(원격 제어) | 노트북에서 돌고 있는 Claude Code(코드 작업용 Claude)를 휴대폰·웹에서 이어서 조종 | 문서에 Windows 제한 없음 | Pro·Max·Ultra·Team·Enterprise | 노트북에서 계속 켜져 있어야 함 | https://code.claude.com/docs/en/remote-control |
| Projects "내 컴퓨터에서 실행" | 클라우드 회사 대화에서 노트북으로 일을 넘김 | 확인 못 함 | Pro·Max·Ultra, 공개 베타(시험판)·순차 출시 | 매번 "Allow once"(이번만 허용) 누르기. "Require trusted devices"가 켜져 있으면 안 됨 | https://code.claude.com/docs/en/claude-projects |

덧붙이는 사실
- 데스크톱 앱 "Keep computer awake"(컴퓨터 깨워 두기) 위치: 설정 > Desktop app (또는 설정 > This computer > System). 다만 덮개를 닫으면 잠듭니다. (desktop-scheduled-tasks 문서)
- 예약 작업은 만든 뒤 "Run now"(지금 실행)를 눌러 권한 질문마다 "always allow"(항상 허용)를 고르면, 다음부터 같은 도구는 묻지 않습니다. (desktop-scheduled-tasks 문서)
- 데스크톱 앱은 회장님 claude.ai 계정에 연결된 커넥터(노션 같은 연결 기능)를 노트북 작업에 그대로 넘겨줍니다. (desktop 문서)
- Dispatch는 권한 질문에 10분 안에 답하지 않으면 그 동작을 자동으로 거절하고 넘어갑니다. (dispatch 문서)
- 크롬 확장 사이트 권한: 확장 아이콘 → 옆창 오른쪽 위 점 세 개 → "Extension settings" → Permissions에서 "Your approved sites"(항상 허용한 사이트)를 보고 하나씩 취소할 수 있습니다. 개인 요금제에서 "이 사이트만 허용" 목록(허용 목록)을 만드는 기능은 문서에 없고, 그건 Team·Enterprise 관리자 기능입니다. (https://support.claude.com/en/articles/12902446-claude-in-chrome-permissions-guide)
- 클라우드 예약 작업은 노트북이 꺼져 있어도 돌지만, 노트북 크롬과 파일은 쓸 수 없습니다. (desktop-scheduled-tasks 문서)
- 우리 클라우드에서 회장님 컴퓨터 폴더 목록이 비어 있고, Windows 폴더는 지원되지 않는다고 나옵니다(Mac/Linux만).

### 1-2. 추천안 — "노션 할 일함" + 노트북 데스크톱 예약 작업 (평소 붙여 넣을 일 0번)
- 회사(클라우드)가 노션 "💻 노트북 할 일함" 페이지에 지시문 전문을 씁니다.
- 노트북 데스크톱 앱의 예약 작업이 매시간 그 페이지를 읽고, 크롬으로 처리한 뒤 결과와 캡처를 같은 페이지에 적고 "완료"로 바꿉니다.
- 첫날 시험: 설정이 끝나면 "Run now"로 한 번 돌려서, 예약 작업 안에서 크롬이 실제로 움직이는지부터 확인합니다. 안 되면 2안으로 바꿉니다.

#### 안전장치
- **"회장님 ✅"는 결재함 승인에서만 인정합니다.** 회장님만 누르는 자리(결재함의 "승인")만 승인으로 봅니다. 노션 할 일함에 회사가 쓴 ✅ 같은 표시는 승인으로 보지 않습니다.
- **노트북 지시문에 고정으로 넣는 문장:** "결제·게시·삭제·로그인·비밀번호 입력·메시지 보내기는 어떤 경우에도 하지 않고 '회장님 확인 필요'로 남긴다."
- **노트북이 할 수 있는 일은 정해 둔 목록 안에서만:** 화면 읽기, 캡처, 링크 복사, 저장 없이 확인. 목록에 없는 일은 하지 않고 "회장님 확인 필요"로 남깁니다.
- **크롬 허용 사이트는 필요한 곳만:** 네이버 스마트스토어센터, 노션, 리틀리, 인스타. 확장 설정 "Your approved sites"에 이 네 곳만 남기고 나머지는 취소합니다. (개인 요금제에는 "이 사이트만" 목록 기능이 없어서, 다른 사이트는 막히는 게 아니라 매번 허락을 묻습니다 — 지시문에서 다른 사이트는 가지 말라고 적어 둡니다.)
- **암웨이 개인정보가 찍히지 않게:** 노션에 올리는 캡처에 암웨이 고객·파트너 이름·연락처 등이 보이면 캡처하지 않거나 가린 뒤 올립니다. 암웨이 화면은 캡처 대상에서 뺍니다.
- **always allow를 누르면 그 뒤로는 묻지 않으므로, 게시·결제·삭제는 지시문 문장으로만 막습니다.**
- **오래된 일은 건너뛰기:** 할 일함에 올라온 지 12시간이 지난 일은 하지 않고 "기한 지남"으로 적습니다. (노트북이 잠들었다 깨면 놓친 작업이 늦게 한 번 돌기 때문)

#### 회장님이 한 번만 하실 일 (노트북, 한 단계에 한 동작)
- 예약 작업은 데스크톱 앱 1.1.5368 이상에서만 됩니다. (desktop-scheduled-tasks 문서)

1) 노트북 크롬 주소창에 claude.com/download 를 열고 Windows용 데스크톱 앱을 설치합니다.
2) 데스크톱 앱에 회장님 계정으로 로그인합니다.
3) 크롬 웹 스토어에서 "Claude"를 찾아 확장을 설치합니다.
4) 크롬 확장에 같은 계정으로 로그인합니다.
5) 데스크톱 앱 위쪽 **Code** 탭을 누릅니다.
6) 왼쪽 메뉴에서 **Scheduled**를 누릅니다. (안 보이면 왼쪽 **More** 안에 있습니다)
   - "Scheduled" 대신 **Routines**로 보이면: Routines → **New routine** → 메뉴에서 **Local**을 고릅니다. 그러면 한 페이지짜리 양식이 열리고, 이름·설명·지시문·폴더·주기(Hourly)를 그 한 페이지에서 넣습니다. 이 경우 아래 7)~15) 대신 그 양식을 채우고 **Create**를 누른 뒤 16)으로 갑니다.
7) **New task**를 누릅니다. (메뉴가 뜨면 **Set up manually**)
   - 창 맨 위에 **Only on this computer**가 먼저 보이면: 아무것도 넣기 전에 그것부터 켭니다. 그러면 로컬용 빈 양식으로 바뀌고, 이름·설명·지시문·작업 폴더·주기를 넣은 뒤 **Create**를 누르고 16)으로 갑니다.
8) **Name** 칸에 회사가 드리는 이름을 넣습니다.
9) 그 아래 칸에 회사가 드리는 지시문을 넣습니다. (처음 한 번만)
10) 아래 **Advanced settings**를 펼칩니다.
11) **General** 탭을 누릅니다.
12) **Only on this computer**(이 컴퓨터에서만)를 켭니다.
13) **Local folder** 줄에서 회사가 정해 드린 폴더를 고릅니다.
14) 위 **Trigger** 칸에서 **Hourly**(매시간)를 고릅니다.
15) **Create**를 누릅니다. (폴더를 믿겠냐고 물으면 허용)
16) 열린 화면에서 **Run now**를 누릅니다.
17) 권한 질문이 나올 때마다 **always allow**를 누릅니다.
18) 데스크톱 앱 설정 > **Desktop app**에서 **Keep computer awake**를 켭니다.
19) Windows 설정을 엽니다.
20) **시스템**을 누릅니다.
21) **전원 및 배터리**를 누릅니다.
22) **화면 및 절전**을 누릅니다.
23) "전원 연결 시" 절전 항목을 "안 함"으로 바꿉니다. (정확한 글자는 확인 못 함)
24) 나가실 때 전원을 꽂아 둡니다.
25) 나가실 때 덮개를 열어 둡니다.
- 화면이 위와 다르면 회사가 첫날 캡처를 보고 안내합니다.

안 되는 점:
- 노트북이 꺼져 있거나 덮개가 닫혀 있거나 앱·크롬이 닫혀 있으면 아무것도 하지 않습니다.
- 최대 1시간을 기다릴 수 있습니다.
- 로그인이 풀리거나 CAPTCHA(자동입력 방지 문자)가 나오면 멈춥니다. 회사는 보안 장치를 피해 가는 방법을 쓰지 않습니다.
- 예약 작업 안에서 크롬이 되는지는 공식 문서로 확인 못 함. 첫날 시험이 필요합니다.
- 화면을 보고 클릭하는 일이라 실수할 수 있습니다.

### 1-3. 크롬 원격 데스크톱으로 할 수 있는 것 (회장님 노트북에 설치되어 있음)
- 이건 **회장님이 아이폰에서 노트북 화면을 보고 만지는 도구**입니다. 회사(클라우드 Claude)가 이걸로 노트북에 들어가지는 않습니다.
  - 들어가려면 회장님 구글 로그인과 PIN(접속 비밀번호)이 필요한데, 회사 규칙상 비밀 값은 받지 않습니다.
- 쓸모 1: 추천안(노션 할 일함 + 예약 작업)이 로그인 화면이나 CAPTCHA(자동입력 방지 문자)에서 멈췄을 때, 회장님이 밖에서 아이폰으로 풀어 주실 수 있습니다.
- 쓸모 2: 노트북의 Claude 앱이나 크롬이 꺼져 있으면, 밖에서 다시 켜실 수 있습니다.
- 조건(확인됨): 노트북과 아이폰 모두 인터넷에 연결되어 있어야 합니다. 목록에서 노트북 이름이 흐리게 보이면 "오프라인이거나 사용할 수 없는 것"입니다.
- 조건(확인 못 함): 노트북이 켜져 있고 잠자기가 아니어야 한다는 문장은 공식 도움말에 직접 없습니다. 잠든 노트북은 인터넷이 끊겨 흐리게 보일 것으로 봅니다(추정). 그래서 1-2의 18)~25) 설정(깨워 두기, 절전 안 함, 덮개 열기)이 여기에도 필요합니다.
- 같은 구글 계정으로 로그인해야 하는지: 도움말에 직접 문장 없음, 확인 못 함.

노트북에서 한 번만 (공식 도움말 컴퓨터용 안내 기준):
1) 노트북 크롬 주소창에 remotedesktop.google.com/access 를 엽니다.
2) "원격 액세스 설정"에 노트북 이름이 "온라인"으로 보이면 이미 끝난 것입니다. 아이폰 순서로 갑니다. ("온라인" 글자는 확인 못 함)
3) 안 보이면 파란 다운로드 버튼을 누르고 설치합니다. (도움말에는 "다운로드"라고만 나오고, 색은 확인 못 함)
4) "사용 설정"을 누릅니다. (버튼 이름 확인 못 함 — 도움말은 "화면 안내에 따라 설치"라고만 함)
5) 노트북 이름을 정합니다. (이 단계는 도움말에 없음, 확인 못 함)
6) PIN(6자리 이상)을 두 번 넣습니다. (자릿수와 두 번 넣는 것은 도움말에 없음, 확인 못 함)
7) Windows가 허용할지 물으면 "예"를 누릅니다. (도움말 원문: 접근을 주려면 컴퓨터 비밀번호를 넣어야 할 수 있음)
- PIN은 회장님만 아시는 숫자이고, 회사에 알려 주지 않습니다.

아이폰에서 쓰는 순서 (공식 도움말 화면 이름 기준):
1) 아이폰에서 **Chrome 원격 데스크톱** 앱을 엽니다. (없으면 앱스토어에서 "Chrome Remote Desktop" 설치)
2) **메뉴**를 누르고 **원격 액세스**를 누릅니다.
3) 목록에서 노트북 이름을 누릅니다.
4) PIN을 넣습니다.
5) **화살표**를 누릅니다.
6) 화면에 나오는 가상 트랙패드(손가락으로 움직이는 마우스)로 노트북을 만집니다.
- 원격으로 들어갔는데 Windows 잠금 화면이 보이면, 회장님 Windows 비밀번호(또는 PIN)를 넣어야 합니다.
- 앱에서 구글 로그인하는 단계는 도움말에 따로 없습니다. 처음 열 때 로그인 화면이 나오면 노트북과 같은 구글 계정으로 로그인하시면 됩니다(확인 못 함).
- 출처: https://support.google.com/chrome/answer/1649523 (iPhone·iPad 안내)

### 1-4. 2안 — 크롬 확장 자체의 예약 바로가기
- 크롬 확장 창에 "노션 할 일함 처리" 지시문을 바로가기로 저장하고, 확장 옆창 오른쪽 위 시계 아이콘으로 예약해 둡니다. 확장이 크롬 안에서 노션 할 일함을 열어 처리합니다. (https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)
- 안전장치는 1-2와 똑같이 지시문에 넣습니다.
- 안 되는 점: 문서 기준 가장 짧은 주기는 하루 1번(문서에 나온 주기: 매일·매주·매월·매년). 최대 하루를 기다릴 수 있음. 크롬이 열려 있어야 함. 컴퓨터가 잠들었을 때 어떻게 되는지는 문서에 없음.

### 1-5. 3안 — Dispatch (써 본 적이 있으면)
- 공식 안내에 "새 사용자에게는 열리지 않음"이라고 되어 있습니다. 회장님이 예전에 Dispatch를 써 보신 적이 있을 때만 씁니다.
- 회사가 노션 할 일함에 지시문을 써 두면, 회장님은 아이폰 Claude 앱 Dispatch에 "노트북 할 일함 처리해 줘" 한 줄만 보내십니다.
- 안 되는 점: 한 줄은 보내셔야 함. 권한 질문에 10분 안에 답하지 않으면 그 동작은 거절됨.

### 1-6. 지금은 안 되는 것
- Projects "내 컴퓨터에서 실행"으로 클라우드가 노트북에 직접 일을 넘기는 방법: 순차 출시 중, Windows 지원 확인 못 함. 나중에 열리면 회장님 할 일이 "Allow once" 누르기 하나로 줄어듭니다.
- Projects는 "Require trusted devices"(믿을 수 있는 기기만 허용)가 켜져 있으면 안 됩니다. (https://code.claude.com/docs/en/claude-projects)

## 2. 함께 조사한 것 — 링크·스마트스토어

### 2-1. 네이버 커머스API(스마트스토어 API)
- 쓰는 순서: 커머스API센터 가입 → 계정 생성 → "내 스토어 애플리케이션" 등록. 등록하면 ID와 시크릿(비밀 값)이 나옵니다. (https://github.com/commerce-api-naver/commerce-api/discussions/2291)
- 국내 사업자만 발급받을 수 있고, 판매자가 직접 운용하는 용도로만 씁니다. ID와 시크릿을 제3자에게 넘기면 약관 위반 소지가 있습니다. (2026-02-23 공식 답변, https://github.com/commerce-api-naver/commerce-api/discussions/3251)
- 호출 IP(인터넷 주소) 제한(확인됨): 등록한 IPv4(인터넷 주소)에서만 부를 수 있고 최대 3개까지 등록합니다. 클라우드는 주소가 바뀌므로 고정 IP(바뀌지 않는 인터넷 주소)가 필요하고, 한국 주소를 권장합니다. (2025-02 공식 FAQ, 위 2291 — 약 1년 된 자료)
- 호출 속도는 초당 2건입니다. (https://github.com/commerce-api-naver/commerce-api/discussions/3734)
- 토큰(출입증) 규칙이 2026-08-21에 다시 공지됐습니다. 규칙을 어기면 호출이 시간당 1회로 제한됩니다. (https://github.com/commerce-api-naver/commerce-api/discussions/3751)
- 할 수 있는 일(제3자 자료로 확인): 주문, 상품·재고, 정산, 문의, 물류, 판매자 정보. (https://packagist.org/packages/sejongtf/laravel-naver-commerce) 공식 문서 사이트는 우리 쪽에서 열리지 않았습니다.
- 못 하는 일: 리뷰 API는 없습니다. (2026-04-28 공식 답변, https://github.com/commerce-api-naver/commerce-api/discussions/3463) 통계·유입 경로와 마케팅 링크 API는 못 찾음.
- 휴대폰으로 등록이 끝까지 되는지: 못 찾음.
- 고정 IP 서버: AWS 라이트세일(아마존의 작은 서버) 가장 싼 IPv4 요금제가 월 5달러이고, 붙여 둔 고정 IP는 무료입니다. 서울 요금은 확인 못 함. (https://aws.amazon.com/ko/lightsail/pricing/)

### 2-2. 리틀리
- 공개 API나 자동 연결 기능: 못 찾음. (확인 2026-11-01)
- 대안: 회사가 무료 GitHub Pages(깃허브가 주는 무료 웹페이지)에 링크 페이지를 만들고 언제든 고칩니다. 바깥에 보이는 변경이므로 문구는 회장님 ✅(결재함 승인)를 받고 올립니다. 리틀리는 예비로 남겨 둡니다.

### 2-3. 인스타 프로필 링크
- 인스타 Graph API(인스타가 주는 연결 문)에서 소개글(biography)과 링크(website)는 읽기만 됩니다. 수정은 "지원하지 않음"으로 나옵니다. (https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/)
- 그래서 회사 링크 페이지 주소를 인스타 앱에서 한 번만 걸어 두는 방식이 답입니다.

### 2-4. 스마트스토어 유입 추적 링크(NT 파라미터)
- 형식: 상품주소?nt_source=값&nt_medium=값&nt_detail=값&nt_keyword=값. 앞의 2개는 필수이고 영어만 됩니다. 결과는 통계 > 마케팅 분석 > 사용자 정의 채널에서 봅니다. (https://inside.ampm.co.kr/insight/2054 — 대행사 블로그, 공식 문서 아님)
- 회사가 채널별 링크(본계정, 메종에델 인스타, 유튜브, 밴드)를 만들어 링크 페이지 버튼에 넣습니다. 회장님은 하실 일이 없습니다.

### 2-5. 링크·스마트스토어 추천안(1단계) — 회장님이 한 번만 하실 일(휴대폰, 0원)
1) 회사가 보내 드리는 링크 페이지 주소를 열어 보시고 결재함에서 "승인"해 주세요.
2) 인스타그램 앱 → 오른쪽 아래 내 프로필 → "프로필 편집" → "링크" → litt.ly/ssoll0820을 새 주소로 바꾸고 저장해 주세요.
3) 메종에델 계정도 바꾸실 거면, 위쪽 계정 이름을 눌러 계정을 바꾼 뒤 2)를 한 번 더 해 주세요.
- 2단계(나중에 결재): 고정 IP 서버 결제와 커머스API센터 앱 등록을 한 번 하시면 됩니다. PC로 하시는 걸 권합니다.

## 확실하지 않은 것
- 크롬 원격 데스크톱 노트북 설정 화면의 버튼 이름("사용 설정", "온라인"), 이름 정하기, PIN 자릿수: 공식 도움말에 없음, 확인 못 함.
- 회장님 Claude 요금제, LG 노트북 칩이 x64인지: 확인 못 함.
- 데스크톱 예약 작업 안에서 크롬이 안정적으로 되는지: 확인 못 함, 첫날 시험 필요.
- 크롬 확장 예약: 문서 기준 가장 짧은 주기는 하루 1번.
- 크롬 확장에서 로그아웃하면 저장한 바로가기·예약이 사라지는지: 확인 못 함(공식 문서에 없음).
- Windows 11 절전 항목의 정확한 글자: 확인 못 함(위치는 설정 → 시스템 → 전원 및 배터리 → 화면 및 절전).
- Dispatch가 회장님 계정에 열려 있는지: 확인 못 함(새 사용자에게는 안 열림).
- 커머스API 휴대폰 등록 가능 여부, 통계 API 유무: 못 찾음.
- NT 파라미터: 실제 링크 하나로 시험 필요.
