## 3. 링크 만드는 방법 → 추천: 회장님이 직접 "간편 링크 만들기"에 검색 주소 7개

쿠팡 파트너스 공식 사이트(partners.coupang.com)는 지난번 회사 환경에서 접속 거부(403)라 이번에는 다시 열지 않음. 메뉴 이름은 안내 글(2차 자료) 기준이고, 공식 화면으로는 **확인 못 함**.

| 방법 | 회장님 할 일 | 판단 |
|---|---|---|
| **간편 링크 + 쿠팡 검색 주소** (추천) | 회사가 준 주소 7개를 하나씩 붙여 넣기 (첫날 1개로 시험) | 상품을 고를 필요 없음, 품절 없음, 특정 상품 추천이 아님 |
| 상품 링크 (상품마다) | 상품 고르기·확인 + 링크 | 고르는 일·품절 관리가 더 많고, 안 써 본 상품을 고르게 됨 |
| 오픈 API (자동) | 최종 승인 뒤 열쇠(API 키)를 환경 변수에 넣기 | **나중 방법만.** 최종 승인(누적 판매 약 15만 원 뒤 심사, 2차 자료) 뒤에 열림 |
| 크롬 Claude 등 대신 만들기 | — | **하지 않음**: 쿠팡 자동 사용 위험, 회장님 쇼핑 계정까지 걸림 |
| 남이 만든 앱(팡트너스 등) | — | **쓰지 않음**: 파트너스 정보를 남의 앱에 맡기고 "우회 링크" 기능이 있어 규정 위반 위험 |
| 링크 주소를 회사가 직접 조립 | — | **쓰지 않음**: 쿠팡이 만들어 준 링크만 씀 |

**회장님 첫 단계 (하나만, 아이폰)**: 사파리 → partners.coupang.com 로그인 → 왼쪽 위 줄 3개(≡) 메뉴 → "링크 생성" → "간편 링크 만들기" → 칸에 1번 주소(달걀) 붙여 넣기 → "링크 생성" → 나온 화면 캡처 1장. (메뉴 이름이 다르면 보이는 화면 그대로 캡처)

출처(2차 자료): [choicemon 링크 생성 안내](https://choicemon.com/coupang-partners-link-guide/) · [tilnote](https://tilnote.io/pages/68c6e7e1a6444bec2c0d532d) · [choicemon 가입·승인](https://choicemon.com/coupang-partners-signup-guide/) · [jab-guyver 승인 조건](https://jab-guyver.co.kr/3067) · [팡트너스 앱 설명](https://apps.apple.com/qa/app/%ED%8C%A1%ED%8A%B8%EB%84%88%EC%8A%A4/id6474643352)
