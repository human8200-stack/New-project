## 2판에서 바뀐 것 (품질관리팀 반려 · 암웨이사업팀 같은 판단, 11/2)
1. **책 버튼 뺌 (완전히).** 누르면 스마트스토어 상품명 『(퀸Ti) 슬기로운 요리생활』이 보여, 쿠팡 수수료 링크와 한 화면에 묶이면 안 됨. **회장님 결정(11/2): 이 페이지에서 책 버튼은 하지 않음.** 책은 필요하면 인스타 프로필의 다른 링크 칸으로 따로 다룸 (이 장보기 페이지와 섞지 않음).
2. **EP.01 카라멜 사과 케이크 블록 뺌.** 퀸 쿠킹 클래스 레시피라 쿠팡과 붙이면 한국암웨이 윤리강령 7조·9조에 걸림. 인스타 버튼 작은 사진도 케이크 → 마약계란으로 바꿈.
3. **크롬 Claude로 링크를 대신 만드는 계획 지움.** 쿠팡 자동 사용은 위험하고 회장님 쇼핑 계정까지 걸림. **링크는 회장님이 직접, 7개만** 만듦.
4. 리조또 사진을 더 선명한 원본(썸네일 1080×1920)에서 다시 자름.
5. **요리 블록을 "펼치기"로 바꿈 (회장님 지시 11/2).** 처음엔 사진 카드 + 요리 제목 + 작은 화살표(⌄)만 보이고, 카드를 누르면 아래로 재료 버튼이 펼쳐짐, 다시 누르면 접힘. 펼친 목록 맨 위에도 "쿠팡 파트너스 링크 · 수수료를 받아요". 맨 위 띠와 장보기 칸 큰 대가 표시 상자는 그대로. 누르는 곳: 제목 줄 76px, 화살표 44px, 재료 버튼 52px.

## 3. 링크 만드는 방법 → 추천: 회장님이 직접 "간편 링크 만들기"에 검색 주소 7개

쿠팡 파트너스 공식 사이트(partners.coupang.com)는 지난번 회사 환경에서 접속 거부(403)라 이번에는 다시 열지 않음. 메뉴 이름은 안내 글(2차 자료) 기준이고, 공식 화면으로는 **확인 못 함**.

| 방법 | 회장님 할 일 | 판단 |
|---|---|---|
| **간편 링크 + 쿠팡 검색 주소** (추천) | 회사가 준 주소 7개를 하나씩 붙여 넣기 (첫날 1개로 시험) | 상품을 고를 필요 없음, 품절 없음, 특정 상품 추천이 아님 |
| 상품 링크 (상품마다) | 상품 고르기·확인 + 링크 | 고르는 일·품절 관리가 더 많고, 안 써 본 상품을 고르게 됨 |
| 오픈 API (자동) | 최종 승인 뒤 열쇠(API 키)를 환경 변수에 넣기 | **나중 방법만.** 최종 승인(누적 판매 약 15만 원 뒤 심사, 2차 자료) 뒤에 열림 |
| 크롬 Claude 등 대신 만들기 | — | **하지 않음**: 쿠팡 자동 사용 위험, 회장님 쇼핑 계정까지 걸림 |
| 남이 만든 앱(팡트너스 등) | — | **쓰지 않음**: 파트너스 정보를 남의 앱에 맡기고 "우회 링크" 기능이 있어 규정 위반 위험 |
| 링크 주소를 회사가 직접 조립 | — | **쓰지 않음**: 쿠팡이 만들어 준 링크만 씀 |

**회장님 첫 단계 (하나만, 아이폰)**: 사파리 → partners.coupang.com 로그인 → 왼쪽 위 줄 3개(≡) 메뉴 → "링크 생성" → "간편 링크 만들기" → 칸에 1번 주소(달걀) 붙여 넣기 → "링크 생성" → 나온 화면 캡처 1장. (메뉴 이름이 다르면 보이는 화면 그대로 캡처)

출처(2차 자료): [choicemon 링크 생성 안내](https://choicemon.com/coupang-partners-link-guide/) · [tilnote](https://tilnote.io/pages/68c6e7e1a6444bec2c0d532d) · [choicemon 가입·승인](https://choicemon.com/coupang-partners-signup-guide/) · [jab-guyver 승인 조건](https://jab-guyver.co.kr/3067) · [팡트너스 앱 설명](https://apps.apple.com/qa/app/%ED%8C%A1%ED%8A%B8%EB%84%88%EC%8A%A4/id6474643352)

  - 한 요리에 보이는 재료가 하나도 없으면 펼쳤을 때 "재료 링크를 준비하고 있어요."
  - 회사 확인용: 주소 끝에 `?preview`를 붙이면 링크가 빈 재료도 "링크 자리"로 보임 (공개 화면에는 안 씀)
  - 새 요리를 더하려면 노션 "요리" 선택지 + `index.html`에 사진 카드 하나가 필요 → 회사가 함 (사진은 회장님 ✅)
- **지금 반영 방법**: 회장님이 "장보기 반영해줘" → 회사가 노션 표를 읽어 `장보기-재료.js`를 고침 → 품질관리팀 확인(암웨이 제품·금지어·링크가 쿠팡 주소인지) → 다시 올림 (공개 뒤라면 공개 주소에 반영, 첫 공개는 결재)
- **반영할 때마다 쓰는 점검표**
  - [ ] 링크는 link.coupang.com 같은 쿠팡 파트너스 주소인지 확인
  - [ ] 링크는 '상품 링크 → 단축 URL'(link.coupang.com/a/…)로 만든 것. 배너용 coupa.ng는 쓰지 않음 (배너 링크는 중간에 "쇼핑하기" 화면이 나옴, 11/2)
  - [ ] 암웨이 제품·암웨이를 떠올리게 하는 말(퀸, 아이쿡, 인덕션 등)이 재료에 없는지
  - [ ] 공개 금지어(수입·보너스·직급·"스폰서")와 "추천"·"꼭" 같은 말이 없는지
  - [ ] 요리 이름이 `index.html`의 요리 카드(data-dish)와 똑같은지
  - [ ] `장보기-재료.js`에 노션 주소·회장님 정보 같은 내부 정보를 적지 않았는지 (공개 페이지와 같이 나가는 파일)
  - [ ] 대가 표시 2곳(맨 위 띠: 원문 전체·13.5px 굵게·본문과 다른 올리브색·스크롤해도 붙어 있음 / 펼친 목록 맨 위 "쿠팡 파트너스 링크 · 수수료를 받아요")이 그대로인지
- **나중 (개발팀 몫, 지금은 하지 않음)**: 공개한 뒤 하루 한 번 노션 표를 읽어 `장보기-재료.js`를 자동으로 고치는 방법
  - 노션 연결 열쇠(통합 토큰)가 필요하고, **그 열쇠는 환경 변수로만 받음** (채팅·파일·노션에 쓰지 않음)
  - 자동으로 바꿔도 쿠팡 주소가 아닌 링크, 암웨이 이름이 든 재료는 넣지 않게 걸러야 함
