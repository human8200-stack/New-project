## 3. 링크 만드는 방법 비교 → 추천: 간편 링크 + 검색 주소

쿠팡 파트너스 공식 사이트(partners.coupang.com)는 지난번 회사 환경에서 접속 거부(403)라 이번에는 다시 열지 않음. 아래는 안내 글(2차 자료) 기준이고, 공식 화면으로는 **확인 못 함**.

| 방법 | 회장님 할 일 | 지금 가능? | 판단 |
|---|---|---|---|
| **간편 링크 + 쿠팡 검색 주소** (추천) | 회사가 준 주소 23개를 "간편 링크 만들기" 칸에 붙여 넣기. 노트북 크롬 Claude에 지시문 1번 붙여 넣으면 대신 함 | 가능 (가입 직후 링크 생성 가능, 2차 자료) | 상품을 고를 필요 없음, 품절 없음, 특정 상품 추천이 아님 |
| 상품 링크 (상품마다) | 상품 23개 고르기·확인 + 링크 23개 | 가능 | 고르는 일·품절 관리가 더 많음. 회장님이 안 써 본 상품을 고르게 됨 |
| 오픈 API (자동) | 최종 승인 후 열쇠(API 키)를 환경 변수에 넣기 1번 | **지금 안 됨**: 최종 승인(누적 판매 약 15만 원 뒤 심사, 2차 자료) 후에 열림 | 나중 단계. 승인되면 회사가 자동으로 만듦 |
| 남이 만든 앱(팡트너스 등) | 앱 설치·계정 연결 | — | **쓰지 않음**: 파트너스 정보를 남의 앱에 맡기고 "우회 링크" 기능이 있어 쿠팡 규정 위반 위험 |
| 링크 주소를 회사가 직접 조립 | 없음 | — | **쓰지 않음**: 쿠팡이 만들어 준 링크만 씀 (추적·규정 문제) |

## 4. 공개 방법 비교 (예쁨 1순위) → 추천: 직접 만든 페이지 + 무료 GitHub Pages(새 저장소)

| 기준 | **직접 만든 페이지** (추천) | 인포크링크 | 리틀리 (새 계정) | 링크트리 |
|---|---|---|---|---|
| 디자인 자유도 | 무엇이든 (이 미리보기 그대로) | 정해진 블록 안에서 | 정해진 블록 안에서 | 정해진 테마 안에서 |
| 큰 사진 블록 | 됨 | 됨 (회장님 캡처에서 확인) | 됨 ("50가지 이상 블럭") | 됨 |
| 색·글꼴 바꾸기 | 메종에델 색·고운바탕·Cormorant 그대로 | 확인 못 함 | 확인 못 함 ("디자인 시스템" 문구만) | 무료는 기본 테마·글꼴 몇 개, 직접 글꼴은 유료 |
| 로고·광고 붙나 | 안 붙음 | 확인 못 함 (요금 화면 안 열림) | 무료는 리틀리 로고 있음, 제거는 프로 월 2,450원(할인가) | 무료는 링크트리 로고 있음, 제거는 유료 |
| 공구 일정 칸 | 됨 (미리보기에 있음) | 있음 ("Schedule" 기능) | 확인 못 함 ("예약하기" 기능은 있음) | 없음(확인한 범위) |
| 돈 | 0원 | 무료로 시작 (유료 차이 확인 못 함) | 0원 (로고 빼면 유료) | 0원 (로고 빼면 유료) |
| 회장님 가입 | 없음 | 필요 | 필요 (본계정 리틀리와 따로) | 필요 |
| 회사가 계속 고치기 | 됨 (회사가 바로 고침) | 회장님 로그인 화면에서만 (크롬 Claude) | 같음 | 같음 |

- 직접 만든 페이지 주소: 이 저장소가 아닌 **메종에델 전용 새 공개 저장소**에 페이지 파일만 올려 무료 GitHub Pages로 연다 (예: `human8200-stack.github.io/maison-edel/`).
  - 이 저장소(New-project)로 열지 않는 이유: 주소에서 저장소로 바로 들어갈 수 있고, 저장소에 암웨이 사업 문서가 있어 "다른 사업과 섞지 않는다" 규칙에 걸림
  - 주소에 GitHub 계정 이름(human8200-stack)이 보임. 나중에 원하시면 도메인(유료)을 붙일 수 있음
  - 새 저장소 만들기·Pages 켜기를 회사가 할 수 있는지는 **확인 필요** (이번 환경에서 Pages 설정 조회가 막힘). 막히면 회장님 GitHub 화면에서 1번 누르기가 생길 수 있음
  - Netlify는 회사에 연결 열쇠가 없어 회장님 로그인이 필요 → 2순위
- 출처: [리틀리 요금제](https://start.litt.ly/plan) · [인포크링크](https://link.inpock.co.kr/) · [링크트리 요금 정리(2차 자료)](https://app.unilink.us/blog/linktree-pricing-2026)
