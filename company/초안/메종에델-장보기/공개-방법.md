# 메종에델 "요리별 장보기" 페이지 — 공개 방법 (운영팀, 2026-11-02)

> 아직 공개하지 않았습니다. 공개는 결재함 41번 회장님 승인 뒤에만 합니다.
> 대상: 이 폴더의 6판 (품질관리팀 검수 통과) — `index.html`, `장보기-재료.js`, `사진/` 2장

## 1. 추천안 — 넷리파이(Netlify) + 새 비공개 GitHub 저장소

**한 줄:** 회장님이 처음에 한 번만 (① 새 저장소 만들기 ② 넷리파이에 그 저장소 연결) 하시면, 그 뒤로 재료가 늘 때마다 회사가 파일을 올리고 페이지는 저절로 바뀝니다. 회장님은 다시 하실 일이 없습니다.

| | ① 추천: 넷리파이 + GitHub 저장소 | ② GitHub Pages (공개 저장소) | ③ Netlify Drop (끌어다 놓기) |
|---|---|---|---|
| 돈 | 무료 (무료 요금제) | 무료 | 무료 |
| 회장님이 처음 하는 일 | 저장소 만들기 + 넷리파이 연결 (약 5분, 한 번) | 저장소 만들기 + Pages 켜기 (약 3분, 한 번) | 폴더 끌어다 놓기 + 로그인해서 내 사이트로 만들기 |
| 재료가 늘면 | **회사가 올림 → 자동 반영** | 회사가 올림 → 자동 반영 | **회장님이 노트북에서 매번 다시 끌어다 놓기** |
| 회사가 계속 고칠 수 있나 | 됨 | 됨 | 안 됨 (회사가 하려면 비밀 열쇠가 필요 — 받지 않음) |
| 규정 | 무료 요금제로 상업 사이트 가능 | **GitHub 규정: "돈 거래를 주로 돕는 사이트"에 쓰지 말 것** — 쿠팡 링크 중심 장보기 페이지는 걸릴 수 있음 | 넷리파이와 같음 |
| 저장소 공개 여부 | 비공개로 둘 수 있음 (페이지만 공개) | 저장소가 공개여야 무료 | 저장소 없음 |
| 회장님이 이미 쓰는 곳 | 넷리파이 계정 있음 (ABLE CRM 배포) | GitHub 계정 있음 | — |

**왜 ①인가**
- ② GitHub Pages는 가장 짧지만, GitHub 안내문에 "온라인 사업을 돌리거나 돈 거래를 주로 돕는 사이트에 무료 호스팅으로 쓰지 말 것"이라고 적혀 있습니다 (docs.github.com, Pages 제한 문서, 2026-11-02 확인). 이 페이지는 쿠팡 파트너스 링크가 중심이라, 나중에 막히면 주소를 바꿔야 합니다. 그래서 처음부터 ①로 갑니다.
- ③ Netlify Drop은 로그인 없이 바로 올라가지만, 고칠 때마다 회장님이 노트북에서 새 폴더를 그 사이트의 "Deploys(배포)" 화면에 다시 끌어다 놓아야 합니다 (넷리파이 안내문). 회사 파일은 클라우드에 있어서 회장님이 매번 압축 파일을 내려받아야 하므로 "회장님 할 일 최소" 조건에 맞지 않습니다.
- ③-2 그 밖의 방법: 클라우드플레어 페이지(새 계정·로그인이 하나 더 늘어남), claude.ai 아티팩트(주소가 claude.ai라 브랜드 페이지로 어색하고, 인스타 안 브라우저에서 쿠팡 링크가 열리는지 확인되지 않음) — 둘 다 ①보다 쉽지 않아 뺐습니다.

**무료 한도 (넷리파이 요금 안내, 2026-11-02 확인)**
- 무료 요금제 300크레딧. 올리기 1번 = 15크레딧, 보는 양 1GB = 20크레딧.
- 이 페이지는 약 35KB(글꼴은 구글에서 따로 받음)라서 1GB ≈ 약 2만 8천 번 보기입니다.
- 재료 반영은 회장님이 "장보기 반영해줘" 하실 때 모아서 한 번에 올립니다 → 한 달 몇 번이면 충분합니다.
- 무료 요금제에서 추가 충전(자동 결제)은 유료 요금제에만 있다고 안내되어 있어, 넘어도 돈이 나가지 않는 것으로 압니다. 다만 한도를 넘으면 어떻게 되는지(멈춤 여부)는 요금 안내 화면에 적혀 있지 않아 **모릅니다** → 공개 뒤 첫 달에 운영팀이 회장님 넷리파이 화면 캡처로 남은 크레딧을 한 번 확인합니다.
- 회장님 계정이 2025년 9월 전에 만든 옛 무료 요금제라면 한도가 다르게 보일 수 있습니다 (그것도 무료).

## 2. 회장님이 하실 일 (결재 41번 승인 뒤, 한 번만)

> **노트북(크롬) 추천.** 휴대폰 사파리로도 되지만 GitHub·넷리파이 설정 화면이 작게 나옵니다.
> 비밀번호나 열쇠는 회사에 보내지 않으셔도 됩니다. 로그인은 회장님 화면에서만 하세요.

**1단계 — 새 저장소 만들기 (GitHub, 약 1분)**
1. github.com 에 로그인 → 오른쪽 위 **＋** 버튼 → **New repository** 누르기
2. Repository name 칸에 `maison-edel` 입력
3. 아래 **Private**(비공개) 고르기 → 맨 아래 초록 **Create repository** 누르기
4. 회사에 "저장소 만들었어" 한마디 → 회사가 파일을 올립니다 (회사 쪽: add_repo로 붙여 공개용 파일 4개만 올림)

**2단계 — 넷리파이에 연결 (회사가 "파일 올렸어요" 말씀드린 뒤, 약 3분)**
1. app.netlify.com 로그인 (ABLE CRM 때 쓰신 계정) → 왼쪽 **Sites**(또는 Projects) → 오른쪽 위 **Add new site** → **Import an existing project**
2. **GitHub** 버튼 → 창이 뜨면 **Configure Netlify on GitHub** → "Only select repositories"에서 `maison-edel` 고르고 **Save**(또는 Install)
3. 목록에서 `maison-edel` 누르기 → 설정 칸은 **그대로 두고**(회사가 미리 맞춰 둠) 맨 아래 **Deploy** 누르기

**3단계 — 주소 이름 정하기 (선택, 약 30초)**
1. 사이트 화면 → **Site configuration** → **Change site name**
2. `maison-edel` 입력 → **Save** → 주소가 `https://maison-edel.netlify.app` 이 됩니다 (이미 쓰는 이름이면 회사가 다음 이름을 드립니다)
3. 회사에 "됐어" 한마디 → 회사가 회장님 휴대폰 기준으로 실제 주소에서 확인하고 보고합니다

그 뒤로는 회장님 할 일이 없습니다. 재료는 지금처럼 노션 "🛒 장보기 재료" 표에 더하고 "장보기 반영해줘"라고만 하시면 됩니다.

**B. 섞이면 안 되는 것 (이 초안 폴더에 있지만 올리지 않음)**

- [ ] 노션 주소, 내부 메모, 회장님 개인 정보가 파일 안에 없는지 글자 찾기 (`notion`, `노션`, `암웨이`, 이메일, 전화번호) — 2026-11-02 6판 기준 없음 (`장보기-재료.js` 설명 줄의 "암웨이 제품은 넣지 않는다" 규칙 한 줄만 있음 → 공개 화면엔 안 보이지만 파일을 열면 보이므로 **올리기 전 지움**)

**C. 고칠 것**
- [ ] `index.html` 맨 아래 `<p class="preview">미리보기 · 아직 공개 전이에요</p>` 한 줄 지우기 (지금 161번째 줄)
- [ ] 그 줄의 꾸밈(`.preview`)이 다른 곳에 안 쓰이는지 확인 (안 쓰이면 그대로 둬도 됨)
- [ ] 주소 끝 `?preview` 확인용 기능: 남겨도 되지만, 남기면 누구나 "링크 자리" 빈칸을 볼 수 있음 → 커머스팀에 남길지 물어 정함

**D. 핵심 파일이 비어 있지 않은지 (예전 `sw.js` 빈 파일 사고 방지)**
- [ ] `index.html` 크기 0이 아님 (6판 약 10.5KB), `</html>`로 끝남
- [ ] `장보기-재료.js` 크기 0이 아님 (약 1.3KB), `window.MAISON_EDEL_SHOP` 이 있고 재료 줄 수가 노션 표와 같음 (지금 7개, 쿠팡 링크 1개)
- [ ] 사진 2장이 진짜 그림 파일 (각 약 9~13KB, 200×200)
- [ ] 올린 뒤 새 저장소에서 같은 크기로 보이는지 다시 확인

**E. 내용 규칙 (공개 전 마지막)**
- [ ] 맨 위 대가 표시 문장이 쿠팡 파트너스 공식 문장과 같음 — 공식 화면 캡처로 대조 (커머스팀, `진행중.md`의 남은 숙제)
- [ ] 쿠팡 링크는 `rel="sponsored"`로 열림 (6판에 들어 있음)
- [ ] 공개 글 금지어 없음: 수입·보너스·직급·"스폰서" / 암웨이 이름·제품 없음 (6판 기준 없음)
- [ ] 쿠팡 파트너스에 새 주소(넷리파이)를 활동 채널로 등록해야 하는지 커머스팀 확인 — 필요하면 회장님 로그인 1단계로 따로 올림

**F. "됐다"의 기준**
- [ ] 회장님 휴대폰(아이폰 사파리, 인스타 안 브라우저)으로 실제 주소를 열어 사진 2장·달걀 버튼·대가 표시가 보이고, 달걀 버튼이 쿠팡으로 열림
- [ ] 한글 파일 이름(사진, 재료 파일)이 실제 주소에서도 열림 — 안 열리면 영어 이름으로 바꿔 다시 올림
