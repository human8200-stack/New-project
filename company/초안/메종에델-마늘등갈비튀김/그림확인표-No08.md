## 2. 영상용으로 꼭 볼 것 (시작·끝 그림 짝)
런웨이는 시작 그림 → 끝 그림 사이를 움직임으로 채워요. 짝이 어긋나면 영상에서 물건이 "스르륵" 바뀌어요.

| 짝 | 같아야 하는 것 | 달라도 되는 것 |
|---|---|---|
| ①-시작 ↔ ①-끝 | 카메라 각도(약 60도)·볼과 쟁반 위치·크기·빛 | 볼 속 등갈비 수, 가루 묻은 정도, 타월 모양 |
| ②-시작 ↔ ②-끝 | 웍 위치·크기·손잡이 2개·카메라(약 25도) | 튀김 색, 젓가락 위치 |
| ③-시작 ↔ ③-끝 | 웍 위치·크기·카메라(약 65도) | 소스 양, 주걱 위치 |
| ④-시작 ↔ ④-끝 | 접시 위치·크기·테 무늬, 냅킨 위치 | 땅콩·깨, 손 유무 |
| ⑤-시작 ↔ ⑤-끝 | 접시 위치·등갈비 더미 모양(한 조각만 빠짐) | 손 높이 |
| ④-끝 → ⑤-시작 | 같은 접시·같은 등갈비·같은 식탁 | 카메라가 조금 낮고 가까워짐(주문서대로) |

⚠️ **①은 미리 알려 둠**: ①-시작(볼에 등갈비 약 5조각 남음) → ①-끝(볼이 비고 모두 하얗게)은 4초 한 동작으로는 이어지기 어려워요. 이건 그림이 틀린 게 아니라 주문서 구성 때문이에요. 처리 방법은 `움직임지시문-No08.md` ①번 칸에 적어 두었어요(크레딧 쓰기 전 품질관리팀이 고름).

## 3. 이 정도면 넘어감 (다시 그리지 않음)
- 등갈비 조각 수가 1~2개 다름, 김의 양, 땅콩·깨 양, 창밖 잎 수
- 시라쿠스 안쪽 가는 색 선이 조금 흐림 (바깥 초록 선이 보이면 통과)
- 웍 손잡이 모양이 사진과 조금 다름 (짧은 손잡이 2개·긴 손잡이 없음이면 통과)

## 4. 다시 그려야 함 (그 그림만, 같은 대화에서 "이것만 고쳐 줘")
- 얼굴·입술·몸통이 보임 / 글자·로고·각인이 보임
- 물이 빨갛거나 핏방울 / 연기·불꽃
- 웍에 긴 손잡이 하나 / 웍이 화면을 꽉 채울 만큼 커 보임 / 깊은 튀김 냄비처럼 보임
- ④·⑤ 접시가 시라쿠스가 아님 (초록 테 없음, 다른 색 접시)
- 손이 등갈비를 "누가 그렇게 들어" 모양으로 잡음 (손바닥 전체로 움켜쥠, 손가락 6개 등)
- 시작·끝 짝의 카메라 각도나 그릇 위치가 크게 다름 (영상이 어색해짐)
