# 프롬프트 학습노트: 『Prompt Archive Vol.01』(DEARMOOEE)에서 배운 것

- 작성: 디자인팀 / 2026-11-01 (회장님 지시: "프롬프트 아카이브를 검색해서 영상 만드는데 학습하도록 해")
- 읽은 것: 자료 본문 전체(73쪽, 프롤로그~저작권 안내, 예시 9개, 부록 3개)
- **저작권:** 회장님이 산 자료다. 원문 문장·예시 프롬프트·사진은 여기에 옮기지 않았다. 짧은 용어(탑뷰, 확산광, 저채도 등)만 쓰고, 배운 것은 우리 말로 바꿔 적었다. 자료 원본은 저장소에 넣지 않는다.
- 크레딧 사용: 0

## 1. 배운 원칙 11개

1. **촬영 준비 순서대로 쓴다.** 무엇을 → 어디서 → 무엇과 함께 → 어느 각도로 → 어떤 빛 → 어떤 색 → 어떤 질감 → 어떤 렌즈 → 한 줄 스타일. 이 9칸이 다 차면 짧아도 잘 나온다.
2. **길이보다 구체성.** 긴 글이 정답은 아니다. 9칸의 핵심 단어가 빠짐없이 들어가면 짧은 글도 비슷한 결과가 나온다. 길게 쓰는 이유는 "쓰는 사람이 장면을 먼저 보기 위해서"다.
3. **질감이 사실감을 만든다.** AI 그림이 가짜처럼 보이는 가장 흔한 이유는 질감 설명이 없어서다. 주인공의 표면(촉촉함, 결, 광택, 무광)을 손으로 만지듯 적는다.
4. **사실감은 '고르지 않음'에서 나온다.** 과일마다 모양이 다르고, 색이 살짝 얼룩지고, 조각 크기가 조금씩 다르다고 적는다. "고르게", "똑같이"는 AI가 복사·붙여넣기한 듯한 그림을 만든다.
5. **빛은 종류·방향·그림자 세 가지를 정한다.** 직사광(그림자 선명)인지 확산광(그림자 부드러움)인지, 어느 창에서 오는지, 그림자가 어디로 얼마나 길게 떨어지는지.
6. **색은 3~5개 이름으로 묶고 '저채도'로 정리한다.** 색 이름을 통일하면 장면끼리 같은 채널처럼 보인다.
7. **오브제는 필요한 것만.** 하나씩 "어디에, 몇 개, 어떤 재질"로 적고, 나머지는 여백으로 둔다.
8. **카메라 기종은 필수가 아니다.** 실제 설정값이 아니라 분위기 단어처럼 작동하고, 넣어도 차이가 작을 때가 많다. 쓸모 있는 것은 **렌즈 화각(넓게/자연스럽게/가까이/매크로)과 심도(배경 흐림)** 쪽이다.
9. **한글로 생각하고, 마지막 기술 정보만 영어로.** 언어보다 구체성이 중요하다. 쓰는 사람이 읽고 이해할 수 있는 글이어야 고칠 수 있다.
10. **한 번에 완성하려 하지 않는다.** 처음 그림을 받은 뒤에는 새로 쓰지 않고 "배경만 더 어둡게, 나머지는 그대로"처럼 **바꿀 것 하나 + 나머지 유지**로 고친다. 작은 흠은 지우기·부분 고치기로 처리한다.
11. **틀을 고정해 두면 늘 같은 형식으로 나온다.** 분석·작성 틀을 저장해 두고 매번 같은 순서로 쓰게 한다. (참고 사진 분석과 실제 생성은 다른 창에서 해야 참고 사진을 그대로 베낀 그림이 덜 나온다. 남의 사진을 거의 똑같이 재현하지 않는다.)

## 2. 메종 에델 장면 사진 지시문 틀: 지금 7단락과 비교

### 비교
| 자료의 9칸 | 지금 우리 7단락 (`프롬프트참고/README.md`) | 판단 |
|---|---|---|
| 주제 | ① 한 줄 정의 | 있음 |
| 공간 | 고정 규칙(에델의 집)에만 | 있음. 단 맨 뒤에 한 번 더 붙여 반복됨 → 한 번만 |
| 오브제 | ② 주인공 + ④ 소품 배치 | 있음 |
| 구도 | ⑤ 카메라 | 있음 |
| 빛 | ⑥ 빛 | 방향은 있음. **빛 종류(직사/확산)와 그림자 모양이 비어 있음** |
| 색감 | ⑦ 색과 분위기 | 있음 |
| **질감** | ⑦ 끝에 "필름 입자, 촉감" 몇 단어 | **가장 약함 → 따로 한 단락으로** |
| 카메라·렌즈 | ⑤에 각도·초점만 | 렌즈 느낌 한 줄 더하기 (기종 이름은 빼기) |
| 마무리 스타일 | 없음 (고정 규칙이 대신) | 짧은 한 줄로 정리 |
| (없음) | ③ 손 | 우리만의 칸. 유지 |

### 새 틀 제안: 8단락
1. **한 줄 정의** — 장르 + 그 순간. ("실제 사진 같은 가정 요리 화보 사진, ○○가 막 시작되는 순간")
2. **주인공과 순간** — 화면 어디에, 무엇이, 어떤 모양으로(예: 계란은 **타원형, 바닥이 살짝 눌림**), 어떤 찰나인지.
3. **질감 (새로 추가)** — 주인공 표면을 2~4문장. 광택/무광, 수분, 결·기공·섬유, 그리고 **자연스러운 불균일함**(색이 아래쪽이 더 진함, 조각 크기가 조금씩 다름). "고르게"는 쓰지 않는다.
4. **손** — 지금과 같음 (손가락·손목까지, 실제로 닿기, 장식 없음).
5. **소품과 공간** — 위·아래·왼쪽·오른쪽에 무엇이, 각각 재질 한 단어씩. 에델의 집은 여기서 한 번만.
6. **카메라** — 높이·각도 + **렌즈 느낌 한 줄**(주인공 매크로 / 가까이 85mm 느낌 / 넓게 50mm 느낌) + 초점 위치 + 배경 흐림 정도.
7. **빛** — **종류**(부드러운 확산광 또는 맑은 아침 직사광 중 하나) + 방향(왼쪽 창) + 그림자가 떨어지는 쪽과 길이 + 하이라이트 위치 + 창틀 그림자는 주인공을 덮지 않게.
8. **색과 마무리** — 색 3~5개, 저채도, 노란기 없는 중성 낮빛, 필름 입자 + **스타일 한 줄**.
   - 맨 끝 한 문장에만 꼭 필요한 금지(로고·글자·워터마크 없음, 차가운 음식이면 김 없음, 다른 조리도구 없음)를 모은다. 금지 문장을 단락마다 흩지 않는다.

## 3. 음식·식탁 장면 표현 묶음 (노션 규칙과 부딪히지 않는 것만)

### 빛
| 쓰기 | 뜻 / 쓰는 곳 |
|---|---|
| soft side window light, morning | 오전 창가 옆빛. 기본값 (노션: 오전 9~11시 측면) |
| diffused daylight / sheer curtain light | 커튼 통과한 확산광. 그림자 부드러움. 손·칼 장면 |
| clear morning sun from the side, crisp but soft-edged shadows | 맑은 날 옆 햇살. 깊은 그림자가 필요한 장면 (노션: 깊은 그림자) |
| backlight from the window behind | 뒤 창 빛. 김·물줄기가 빛나게 (노션: 옆이나 뒤) |
| gentle highlights, highlights not blown out | 은은한 하이라이트, 하얗게 날리지 않게 |
| soft shadows falling to the lower right | 그림자 방향을 꼭 적는다 |
| faint caustic light | 유리 계량컵·유리 볼을 통과한 물결빛. 장면 2(물 붓기)·5(유리 볼)에만 |

## 4. 영상 움직임 지시문에: 쓸 수 있는 것 / 쓸 수 없는 것

이 자료는 **정지 사진용**이다. 영상은 노션 규칙 "승인된 사진에서 시작, 지시문은 움직임만"이 먼저다.

### 쓸 수 있는 것
- **질감 단어를 움직임의 성질로.** 움직이는 물질이 어떤 성질인지 한두 단어(예: 노른자는 jammy, 간장은 thin, 물은 clear). 무르기·점도가 움직임 모양을 정한다. 이미 장면 1 주문서의 "jammy yolk"가 이 방식.
- **카메라 용어.** "카메라 고정, 줌·밀기 없음"처럼 화면 시선을 정하는 말.
- **장면을 읽고 빠진 것 찾기.** 지시문을 보내기 전에 시간 순서대로 읽어 보며 시작·중간·끝이 다 있는지 확인 (자료의 "먼저 읽는다" 습관을 시간표에 적용).
- **바꿀 것 하나 + 나머지 유지.** 다시 만들 때 처음부터 새로 쓰지 않고 실패한 한 가지만 고친다 (다시 만들기 문장 방식과 같음).
- **같은 지시문도 결과가 매번 다르다.** 그래서 검수 기준(자연스러움 5줄)을 미리 정하는 지금 방식이 맞다.

### 쓸 수 없는 것
- **공간·오브제·색감·마무리 스타일 묘사.** 시작 사진에 이미 있다. 다시 적으면 영상 기능이 장면을 새로 그려 사람·그릇이 바뀐다 (노션: 움직임만).
- **카메라 기종·렌즈·조리개 숫자.** 정지 사진의 분위기 단어라 움직임에 도움이 없고, 장면 재해석만 부른다.
- **빛 묘사.** 영상 중에 빛이 바뀌는 원인이 된다.
- **긴 소설식 글.** 영상은 짧고 순서가 분명해야 한다 (한두 줄~80단어 안팎).
- **"cinematic" 같은 스타일 말.** 카메라가 움직이거나 연출이 커질 수 있다 (우리 판단).
- **대화로 조금씩 고치기.** 사진은 고치기가 싸지만 영상은 다시 만들 때마다 크레딧(120)이 든다. 그래서 고치기는 사진 단계에서 끝낸다.

## 5. 마약계란 장면 1(시험1)을 이 원칙으로 보면: 약했던 점 3줄

1. **질감을 "고르게"로 써서 가짜처럼 나왔다.** 지시문이 계란을 "evenly soaked", 고명을 "float evenly"라고 해서, 계란은 매끈한 공(타원형이 아니라 구슬)처럼, 고명은 모눈처럼 똑같은 네모와 깨가 바닥을 빽빽하게 덮었다. 계란의 타원 모양, 흰자의 잔기공, 아래쪽이 더 진한 색, 손으로 썬 조각 크기 차이를 적었어야 했다.
2. **금지·규칙 문장이 장면 묘사보다 많았다.** "no/not/never"가 여러 단락에 흩어지고 고정 규칙을 맨 끝에 한 번 더 붙여, 정작 표면이 어떻게 생겼는지 쓸 자리가 없었다. 금지는 맨 끝 한 문장으로 모으고, 그 자리에 질감 단락을 넣어야 한다.
3. **빛 종류와 렌즈 느낌을 정하지 않았다.** 방향만 정해서 창 그림자 덩어리가 식탁 위쪽을 크게 차지했고, 주인공인 계란은 화면에서 작다(노션 촬영 문법: 음식이 화면 절반 이상, 매크로). "부드러운 확산광 + 매크로처럼 가까이"를 적었으면 계란 표면이 살아났을 것이다.

(회장님은 이 사진을 11/1 승인하셨다. 위 3줄은 다음 장면부터 고칠 점이다.)

## 6. 런웨이 "장면 만들기" 고정 글: 바꿀 문장 제안 (유튜브팀이 반영, 디자인팀은 바꾸지 않음)

대상: `런웨이-작업틀-사용법.md` 4-1의 고정 글(3판). 새 판 저장은 0원이지만 실행은 크레딧이 든다. 반영 뒤 **첫 장면 1장 시험(24크레딧)은 회장님 승인 후**.

| # | 지금 문장 | 바꿀 문장 (제안) | 이유 |
|---|---|---|---|
| 1 | `Output only the prompt: exactly 7 paragraphs, ...` | `Output only the prompt: exactly 8 paragraphs, ...` | 질감 단락 추가 |
