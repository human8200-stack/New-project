# 메종 에델 냄비 기준 (2026-11-01 회장님 지시)

- 퀸 냄비는 **레시피마다 다르다.** 한 가지로 고정하지 않는다.
- **냄비는 레시피함 앱(Able Team Recipe Book)에서 가져온다.** 레시피마다 "tool"(냄비)이 적혀 있고, 냄비 7개마다 사진이 있다.
  - 퀸 냄비 7가지: 대형프라이팬, 중형프라이팬, 웍, 웍세트, 대형소스팬, 중형소스팬, 소형소스팬
  - 211개 레시피 가운데 197개에 냄비가 적혀 있다. 적혀 있지 않으면 회장님께 묻는다.
- 조리 방법도 레시피함에 적힌 그대로 영상에 담는다.
- 사진 저장 위치: `레시피함/` 폴더
- 영상에는 로고·글자·제품 이름이 보이지 않게 한다.

## 마약계란(레시피함 이름: 마약달걀) — 바로잡음
- 냄비: **중형프라이팬** (그동안 중형 소스팬으로 잘못 만들었다)
- 방법: 중형프라이팬에 키친타월을 깔고 물 1/2컵 → 달걀을 넣고 뚜껑을 덮어 인덕션 4단에서 7분(완숙은 15분) → 찬물에 담갔다가 껍질 까기 → 소스(간장·물·물엿 각 70ml, 다진 양파·쪽파·빨강 파프리카, 깨)에 30분 이상 냉장
- 완성 사진은 레시피함에 없다.
