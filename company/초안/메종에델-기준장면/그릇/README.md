# 메종 에델 그릇 기준 (2026-11-01 회장님 지시)
늘 같은 그릇 금지. 에피소드마다 돌아가며 사용. 화면에 상표·글자·각인은 안 보이게.
- **코스타노바(Costa Nova)**: 크림·세이지·차콜 무광 스톤웨어, 점 박힌 질감, 둥근 테 (코스타노바-1~3.jpg, 공식 사이트)
- **시라쿠스 메이플**: 아이보리 바탕에 테두리 색 줄(초록·파랑·빨강), 찬기·공기·대접·접시 (시라쿠스메이플-1.png, 회장님 캡처) — 한식 반찬에 어울림
- **에뚜알 퓨터(Etoile Pewter)**: 흰 자기에 은은한 주석 테두리, 구슬 무늬 테, 주석 쟁반·잔 (에뚜알퓨터-1~3.png, 신세계V 캡처) — 고급 상차림
