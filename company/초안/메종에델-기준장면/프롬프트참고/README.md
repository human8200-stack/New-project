# 지시문(프롬프트) 쓰는 법 참고 — 회장님이 보내 주심 (2026-11-01)

출처: 인스타 @dearmooee "이번 주 이미지 프롬프트" 화면 사진. 남의 글이라 **문장을 베끼지 않고 쓰는 틀만** 참고한다.

## 그 지시문의 틀 (7단락)
1. **한 줄 정의**: "초고해상도 포토리얼리스틱 ○○ 에디토리얼 사진" + 어떤 순간인지
2. **주인공과 순간**: 화면 어디에, 무엇이, 어떤 찰나인지 (예: 병에서 우유 방울이 떨어지는 순간)
3. **손·사람**: 얼굴은 화면 밖, 손과 팔만. 손가락 위치, 피부 결, 옷감까지
4. **소품 배치**: 화면 위·아래·왼쪽·오른쪽에 무엇이 어떻게 놓였는지 하나씩. "소품은 최소한, 시선은 동작에"
5. **카메라**: 높이·각도(예: 약 45도 내려다봄, 90도 위에서), 세로 비율, 초점, 배경 흐림
6. **빛**: 어느 창에서 오는 자연광인지, 실내등 끔, 그림자 깊이, 하이라이트 날리지 않게
7. **색과 분위기**: 낮은 채도 색 묶음, "과도한 노란기·빈티지 필터 없이 중성 화이트 밸런스", 필름 그레인, 촉감, 분위기 한 줄

## 메종 에델에 쓰는 법
- 장면마다 이 7단락으로 쓴다. 짧게 줄이지 않는다.
- 노션 규칙(에델의 집, 손, 빛, 그릇, 로고 없음)을 3·4·6·7단락에 넣는다.
