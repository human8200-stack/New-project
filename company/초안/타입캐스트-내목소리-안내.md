# 타입캐스트로 회장님 목소리 만들기 (2026-11-02, 시장조사팀 조사)

요금: 베이직 월 9,900원부터 내 목소리 1개(퀵 클로닝, 녹음 약 1분). 상업적 이용 가능. 한 달 약 60분 내려받기.
- 더 좋은 품질(5분 녹음): 플러스 29,000원부터
- 슬롯이 1개라 다시 만들려면 지우고 새로 만들어야 함

순서 (회장님은 한 번에 하나씩)
1. **녹음**: 아이폰 '음성 메모' 앱에서 `목소리-녹음대본.md`를 읽기 (1분 정도, 150초 이하, 조용한 방)
2. **녹음 파일 노트북으로 옮기기**: 음성 메모 → 공유 → 메일로 나에게 보내기(또는 카카오톡 나에게)
3. **가입·결제**: 노트북 크롬에서 typecast.ai 가입 → 요금제 '베이직' 결제 (회장님 결제)
4. **목소리 만들기**: 'AI 보이스 에디터' → 보이스 클로닝 [+] → 이름·성별(여)·언어(한국어) → 녹음 파일 올리기 → 본인 인증·동의
   - 버튼 이름이 옛날 안내 기준이라 다를 수 있음
   - 화면이 다르면 캡처를 보내 주시면 회사가 짚어 드림
5. **글 읽히기**: '+ 새로 만들기' → 캐릭터에서 [커스텀] → 내 목소리 → 회사가 준 글 붙여 넣기 → 오른쪽 아래 다운로드 → MP3
6. 받은 MP3를 채팅에 보내 주시면 회사가 영상에 맞춰 넣음

확인 못 한 것
- 휴대폰만으로 목소리 만들기가 되는지 → 노트북 크롬 추천
- 지금 화면의 버튼 이름
- 본인 인증 방식
