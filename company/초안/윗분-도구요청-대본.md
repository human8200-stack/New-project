# 윗분이 도구를 나눠 달라고 하실 때 — 대화 대본 (초안)

> 관계심리팀 초안 · 2026-11-01 · 회장님 결재 전
> **의학적·심리 치료 조언이 아닙니다.** 관계를 지키는 말과 진행을 돕는 참고용입니다.
> 개인 이름은 쓰지 않았습니다. 상대는 "윗분"으로 적습니다.
> **암웨이 규정은 암웨이사업팀이 확인 중입니다.** 이 대본은 규정 판단을 하지 않습니다. 확인 결과가 나오면 대본을 다시 맞춥니다.
> 가격은 수익화팀이 정합니다. 이 대본에는 금액을 넣지 않았습니다.

---

## 0. 한눈에 (먼저 읽기)

- **추천 대응**: 레시피함은 "같이 써 보세요"(범위 정해서), 소비자 관리 프로그램은 "아직 다듬는 중이에요, 준비되면 제일 먼저 말씀드릴게요".
- **그 자리에서 정하지 않는다.** "좋아요"도 "안 돼요"도 말고, "정리해서 ○일까지 다시 말씀드릴게요".
- **거절이 아니라 "지금은 / 이만큼 / 나중에 정식으로"** 로 말한다.

## 1. 윗분이 요청하는 마음 읽기 (추측)

> 아래는 **추측**입니다. 확인하려면 맨 아래 "직접 물어볼 질문"을 쓰세요.

| 겉으로 하는 말 | 진짜 원하는 것일 수 있는 것 (추측) |
|---|---|
| "그거 우리도 나눠 줘요" | **도구 자체** — 고객 관리·레시피 정리가 실제로 불편해서 |
| "우리 팀도 쓰게 해 줘요" | **팀 관리 편의** — 팀 분들에게 줄 무언가가 필요해서. 리더로서 "우리 팀도 챙긴다"는 모습 |
| "와, 이거 직접 만든 거예요?" | **회장님 인정·칭찬** — 요청이라기보다 감탄. 꼭 받으려는 게 아닐 수 있음 |
| "같은 팀인데 같이 쓰면 좋잖아요" | **함께하는 문화** — 나누는 게 당연하다는 기대. 거절하면 "선 긋는다"로 느낄까 봐 회장님이 부담 |
| "얼마면 돼요?" | **정식으로 쓰고 싶음** — 오히려 비용 이야기를 편하게 해도 되는 신호 |

**망설임 포인트 (윗분 쪽)**: 공짜로 달라고 하기 미안함, 회장님이 바쁜데 부탁해도 되나.
**회장님이 거절하기 어려운 진짜 이유 (추측)**: 오래 함께한 관계, "아끼는 사람"처럼 보일까 봐, 윗분이 서운해하면 사업 분위기에 영향이 갈까 봐.

### 직접 물어볼 질문 (부드럽게 마음 확인)
- "어떤 게 제일 불편하세요? 고객 정리 쪽이에요, 레시피 쪽이에요?"
- "리더님만 쓰실 거예요, 팀 분들도 같이요?"
- "지금은 어떻게 관리하고 계세요?"

→ 답을 들으면 "도구가 필요한 건지 / 칭찬인지 / 팀에 줄 게 필요한지" 구분이 됩니다. 칭찬이면 "감사해요, 아직 다듬는 중이에요 😊"로 충분합니다.

## 2. 회장님 마음 지키기 — 원칙 5가지

1. **바로 답하지 않아도 된다.** "정리해서 다시 말씀드릴게요"는 거절이 아니라 성의입니다. 단, **다시 말할 날짜**를 꼭 같이 말합니다(시간을 벌되 미루지는 않기).
2. **"안 돼요" 대신 "지금은 / 이만큼 / 나중에".** 문을 닫지 않고 순서를 정하는 말입니다.
3. **이유는 진짜인 것만, 짧게.** 실제 이유가 충분합니다.
   - 소비자 관리 프로그램: 고객 정보가 들어가서 **안전하게 다듬는 중**, 정식으로 낼 준비 중
   - 둘 다: 회사 안에서 **확인할 것이 남아 있음** (규정·운영 — 확인 중)
4. **나누고 싶은 마음은 먼저 말한다.** "저도 같이 쓰시면 좋겠어요"를 앞에 두면 뒤의 "다만"이 서운하지 않습니다.
5. **회장님 혼자 지지 않는다.** "회사(세컨드웨이브)에서 정식으로 정리 중이라"는 말은 사실이고, 회장님 개인이 거절하는 모양이 되지 않게 해 줍니다.

## 3. 상황별 대본 (카톡·전화용 짧은 말)

### ① 아직 준비 중이라 바로는 어렵다
> 이럴 때: 소비자 관리 프로그램을 달라고 하실 때 / 아직 아무것도 정하지 않았을 때

**첫마디 (바로 복사용)**
> 리더님, 관심 가져 주셔서 정말 감사해요 😊 저도 같이 쓰시면 좋겠어요. 다만 이건 고객 정보가 들어가는 거라, 아직 안전하게 다듬는 중이에요. 정리되면 제일 먼저 말씀드릴게요!

**상대 반응별 이어 말하기**
- **"그냥 지금 있는 대로 줘도 돼요"**
  > 마음은 너무 감사해요. 그런데 고객 정보가 들어가는 거라 제가 더 조심스러워요. 혹시라도 불편 생기면 제가 더 미안할 것 같아서요. 조금만 기다려 주세요 🙏
- **"언제쯤 돼요?"**
  > 지금 확인하고 있는 게 있어서, ○월 ○일쯤 어떻게 되는지 먼저 말씀드릴게요.
  (날짜는 회장님이 편한 날로. 모르면 "다음 주 안에 진행 상황 말씀드릴게요")
- **(서운한 기색) "우리끼리 뭘 그래요~"**
  > 우리끼리라서 더 제대로 드리고 싶어요 😊 대충 드렸다가 불편하시면 그게 더 속상할 것 같아요.

**마무리**
> 먼저 물어봐 주셔서 힘이 나요. 준비되는 대로 꼭 연락드릴게요!

---

### ② 같이 써 보시게 하되 범위를 정한다
> 이럴 때: 레시피함처럼 이미 곁의 분들과 쓰고 있는 것 / 소비자 관리 프로그램은 회사 확인이 끝난 뒤에만

**첫마디 (바로 복사용)**
> 리더님, 레시피함은 지금 저희 곁에서 같이 쓰고 있는 거라 같이 쓰셔도 좋아요 😊 우선 리더님 먼저 써 보시고, 불편한 점 알려 주시면 제가 고쳐 볼게요.

**범위를 정하는 말 (하나 골라 쓰기)**
- 사람: "우선 리더님만 먼저 써 보시고요"
- 기간: "한 달 정도 써 보시고 어떠셨는지 말씀해 주세요"
- 방법: "링크는 제가 따로 보내 드릴게요. 다른 분께 넘기실 땐 저한테 한 번만 말씀해 주세요"

**상대 반응별 이어 말하기**
- **"우리 팀 전체에 돌려도 되죠?"**
  > 리더님이 먼저 써 보시고 괜찮으면 그때 같이 넓혀요. 사람이 많아지면 제가 챙길 게 생겨서, 순서대로 하고 싶어요 😊
- **"소비자 관리 프로그램도 같이 써 볼래요"**
  > 그건 고객 정보가 들어가는 거라 아직 준비 중이에요. 정리되면 제일 먼저 말씀드릴게요! (→ 대본 ①로)
- **"좋아요, 써 볼게요"**
  > 써 보시고 편하게 말씀만 해 주세요. 그게 저한테 제일 큰 도움이에요 🙏

**마무리**
> 같이 써 주셔서 감사해요. 리더님 말씀 듣고 더 좋게 만들어 볼게요!

---

### ③ 정식으로 나중에 제공 (비용 이야기를 부드럽게)
> 이럴 때: 윗분이 "얼마예요?" 하고 먼저 물으실 때 / 회사가 정식 출시를 정한 뒤
> 금액은 아직 정하지 않았습니다(수익화팀). 금액을 즉석에서 말하지 않습니다.

**첫마디 (바로 복사용)**
> 리더님, 이건 제가 회사에서 정식으로 내려고 준비하는 거예요. 제대로 관리하고 고쳐 드리려면 나중엔 이용료가 조금 있을 것 같아요. 정해지면 제일 먼저 알려 드릴게요 😊

**상대 반응별 이어 말하기**
- **"우리 사이에 돈을 받아요?"**
  > 저도 그 마음 알아서 말 꺼내기가 조심스러웠어요. 그래도 오래 고장 없이 쓰시게 하려면 관리가 필요해서요. 정해지면 리더님께 제일 먼저, 제일 편하게 말씀드릴게요.
- **"얼마인데요?"**
  > 아직 정하는 중이에요. 정해지면 바로 말씀드릴게요. 쓰실지는 그때 편하게 정하시면 돼요.
- **"좋아요, 나오면 알려 줘요"**
  > 네! 관심 가져 주셔서 정말 힘이 나요 🙏

**마무리**
> 안 쓰셔도 전혀 괜찮아요. 물어봐 주신 것만으로도 감사해요 😊

## 4. 하지 말 것

| 피할 말 | 이유 |
|---|---|
| "네, 드릴게요!" (그 자리에서) | 즉석 약속. 나중에 범위·비용을 바꾸면 "말이 바뀌었다"가 됨 |
| "일단 공짜로 쓰세요" → 나중에 "이제 돈 내셔야 해요" | 공짜 약속 후 번복이 관계에 가장 큰 상처. 처음부터 "체험 / 나중에 정식"을 나눠 말하기 |
| "제가 이거 만드느라 얼마나 고생했는데요" | 죄책감 주는 말. 상대가 미안해서 물러나게 만드는 압박 |
| "다른 분들은 다 기다리는데…" | 비교하며 몰아가는 말 |
| "지금 아니면 못 드려요", "이번만" | 거짓 긴급함·희소성 압박 (회사 금지) |
| "이거 쓰면 팀이 커져요" 같은 말 | 성과·소득을 떠올리게 하는 말 (회사 금지) |
| 말없이 답을 미루기 | 거절보다 더 서운함. 꼭 "○일까지 말씀드릴게요" |
| 암웨이 규정이 "된다 / 안 된다"고 단정 | 아직 확인 중. "회사에서 확인하고 있어요"까지만 |

## 5. 추천 대응 하나

**레시피함은 ②(먼저 리더님만, 한 달 써 보기), 소비자 관리 프로그램은 ①(안전하게 다듬는 중, ○일까지 진행 상황 연락).**
비용 이야기(③)는 **윗분이 먼저 물으실 때만**, 금액 없이 "정해지면 제일 먼저"로.

이유: 이미 곁의 분들과 쓰는 레시피함을 나누면 "아낀다"는 서운함이 없고, 소비자 관리 프로그램은 고객 정보라는 진짜 이유가 있어 회장님이 미안해하지 않아도 됩니다. 나중에 정식 판매로 갈 때도 "공짜 → 유료 번복"이 생기지 않습니다.

## 회장님 확인 필요 (보내기 전 ✅)
1. 레시피함을 윗분께 나눠도 되는지 — **암웨이사업팀 규정 확인 결과** 먼저
2. 소비자 관리 프로그램을 윗분(암웨이 팀)께 정식 판매하는 것 자체가 괜찮은지 — 암웨이사업팀 확인 중 (사업 섞지 않기 원칙과 닿음)
3. 대본 ①에 넣을 "다시 연락드릴 날짜"
4. 말투가 회장님 평소 말투와 맞는지 (호칭 "리더님"이 맞는지)
