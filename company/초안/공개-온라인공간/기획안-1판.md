# 공개 온라인 공간 — 기획안 1판 (기획팀, 2026-11-13)

> 회장님: "우리는 이렇게 만들 수 없나?" / "요리는 어떻게 하면 좋을까? … 내가 보내준 사진들을 생각하며 더 깊이 고민해봐"
> 참고: 온라인 절 '산사'(일주일 100만 명, 서버 터짐), 온라인 순례길, 온라인 성당. 초안 — 만들기·공개·게시는 결재 뒤.

## 5줄 요약
1. 만들 수 있다. 라운지 기술(3D·귀여운 캐릭터·이름표·응원·축하 소리)로 2주.
2. 추천안 「밥 짓는 집」(가칭): 에델의 집 같은 온라인 부엌. 도마를 톡톡 → 모두의 큰 솥에 재료가 들어감.
3. 3분마다 솥이 다 되면 수십 명의 작은 요리사가 긴 식탁에서 다 같이 "잘 먹겠습니다" → 캡처되어 퍼질 장면.
4. 사업과는 '부엌 주인 문패' 하나로만 연결(광고 없음). 쏠키친 라이브 날엔 '같이 기다리는 곳'.
5. 첫 판 0원, 크게 퍼지면 월 약 7~8천 원부터. 회장님 결정: 이름 + 시작 승인.

## 1. 왜 퍼졌나 — 원리 8가지
1. 이미 있는 감정을 빌림(절) → 요리는 "밥 먹었어?", 저녁 짓는 소리·엄마 부엌
2. 할 일 하나, 목적 없음("유용과 무용 사이") → 도마 "탁탁탁"
3. 혼자인데 함께(대화 없음, 정해진 인사만)
4. 순위·경쟁 없음
5. 모인 사람들이 장면을 만듦("작은 스님 수십 명") + 이름표 캡처
6. 투박해서 믿음(한 사람이 만든 느낌)
7. '누가 만들었나' 이야기 + "서버 터졌어요" 솔직함 → 우리: "요리책 낸 엄마가 AI랑 차린 온라인 부엌"
8. 링크 하나, 0초 입장
- 비슷한 사이트가 쏟아지는 중 → 빨리, 그러나 '진짜 주인(진짜 부엌·레시피·라이브)이 있는 곳'으로.
- 근거: 토스 앱인토스 블로그 산사 인터뷰(toss.im/apps-in-toss/blog/sansa), 경북매일 2026-10-31, supple, Asia News Network, Cloudflare 요금 문서.

## 2. 3안
- 🥇 1안 「밥 짓는 집」: 도마 톡 → 솥. 에델의 집 느낌(크림 벽·나무 식탁·큰 솥, 글자·로고 없음), 창밖은 실제 시간, 앞치마 요리사, 미엘이 돌아다님, 실제 녹음 소리. 이름표 = 자동 음식 별명("바삭한 누룽지"). 인사 버튼 3개("밥 먹었어요?" / "맛있게 드세요" / "잘 먹었습니다"). 3분마다 "잘 먹겠습니다" + 오늘의 한 그릇 카드.
- 🥈 2안 「밥 먹고 가요」: 혼밥하는 사람에게 차려 주는 밥집. 감정은 진하지만 쓸쓸할 수 있고 모이는 장면이 약함.
- 🥉 3안 「저녁 뭐 먹지 장터」: 시장에서 재료 3개 → 오늘 메뉴. 쓸모가 커서 도구 같음, 2주 안에 어려움. 나중에 레시피함과 잇기 좋음.

## 3. 추천안 자세히
### 사업 연결(광고 없이, 문패 하나)
- 문패 "이 부엌은 쏠이 차렸어요" → 본계정 'AI랑 부엌 차린 이야기'
- 쏠키친 라이브 날: 창에 불, 7:30 다 같이 저녁 짓기 → 8시 라이브 보러 가기
- 오늘의 한 그릇 카드 아래 "이 요리는 『슬기로운요리생활』에 있어요" — ⚠️ 정식 제목에 '퀸Ti' → 암웨이사업팀 확인 뒤에만 켬
- 레시피함은 출시 뒤 연결, 메종 에델은 액자 하나(쿠팡·공구 링크 없음)

### 첫 판(2주) 넣을 것
링크 입장(로그인 없음) · 부엌 한 칸 · 별명 이름표 200 · 도마 톡 · 3분 솥 한 바퀴(시계 동기화) · 인사 3개 · 자리 고정(걷기 없음) · 50명씩 방 나누기 · 소리 켜기/끄기 · 미엘 · 문패 · 숫자만 세기 + 구경 모드
### 뺄 것
채팅·자유 글, 로그인, 점수·순위, 꾸미기, 후원·결제·광고, 쿠팡·공구, 암웨이 이름·제품
- 2판 후보: 메뉴 고르기 판, 쪽지, 영어판, 12월 첫 주말 "다 같이 김장하는 날"
### 일정
1주차(11/14~20) 조사·시안·카드 14장·별명 200·개발 시작 / 2주차(11/21~27) 개발 마무리·아이폰 확인·검수 / 공개 11월 마지막 주(결재) / 첫 큰 모임 12/13 쏠키친 라이브

### 사람이 몰릴 때
- 화면은 Cloudflare Pages(무료), 실시간은 부엌마다 Durable Object 하나(최소 신호, 15초 묶음), 50명씩 방, 한도 가까우면 '구경 모드'(혼자 도는 부엌 + "지금 ○천 명이 함께")
- Supabase(라운지 서버)는 안 씀: 무료 동시 200명, 메시지 받는 사람마다 셈
- 비용: 첫 판 0원 / 크게 퍼지면 월 5달러(약 7~8천 원) / 산사 수준이면 월 1만 원 안팎(개발팀 재계산)
- ⚠️ Cloudflare 무료 하루 한도는 계정 전체 공유(공부 알림·라운지와 같은 계정) → 하루 6만 건 넘으면 자동 구경 모드

### 홍보 순서
조용히 열기(스토리 "오늘 저녁 7시 부엌 문 열어요", 첫 30~100명) → 본계정 릴스 8시 → 스레드 → 메종 에델 0크레딧 게시물 → 3일 뒤 트렌드 계정·기자 → 몰리면 솔직하게 "2호 부엌 열었어요" → 12/13 라이브 → 김장·연말
- 성공 기준(2주): 누적 방문 1만, 문패 누름 300, 본계정 새 팔로우 주 30 / 3천 이하면 릴스 소재로만

### 위험
베끼기 논란(스님·절 모양 안 씀, "온라인 절 보고 우리 부엌도 열어 봤어요" 솔직히), 서버 비용(구경 모드·회계팀 주간 확인), 악성 글(자유 글 없음), 개인정보(받지 않음), 암웨이 섞임(코드·서버·주소 분리), 금지어·건강 효과 문구 없음, 빨리 식음(계절 행사), 아이폰 성능

### 업무 분담 (책임 팀: 본계정팀)
시장조사(비슷한 곳·상표·소리 허락·한도) / 디자인(시안 1장) / 편집(카드 14장·별명 200) / 개발(새 비공개 저장소) / 암웨이사업(책 표기) / 본계정(문 여는 날 흐름) / 마케팅(기자 목록) / 회계(사용량) / 품질관리 / 운영(배포)
