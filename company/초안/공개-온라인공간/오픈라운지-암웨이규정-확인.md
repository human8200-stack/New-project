**공개 체험판은 "내 공간에 올려 두고 사람이 스스로 찾아오는 방식"이라 규정상 허용되는 쪽입니다. 다만 공식 기준에 "웹사이트·앱은 콘셉트 사전 서면 승인"이 있어서, 공개 전에 윤리강령부에 메일 한 통으로 승인을 받아 두는 것이 가장 안전합니다. 다른 사업자 팀에 "만들어 드려요"로 돈 받고 파는 것은 위험이 높아 지금은 하지 않기를 추천합니다.**

## 2·3. 암웨이 간판·공식 포스터·삿포로 여행 포스터를 공개 화면에 쓰기 — 회장님 확인으로 정리

- **회장님 원문: "본사가 넣어도 된다 했어", "화면 포스터 가능"** → 회사는 이 확인을 기준으로 공개 화면에 포스터를 씁니다.
- 공식 기준에 적힌 조건이라 **함께 지킬 것** (원문 확인):
  - 상표·암웨이 제작 자료는 **사전 서면 승인**이 원칙이고, 승인된 자료도 **편집·재가공 금지** (10·13쪽) → 포스터는 **원본 그대로**, 글자 덧붙이기·자르기·색 바꾸기 안 함.
  - amway.co.kr 그림을 캡처·저장해 쓰는 것은 안 됨 (10쪽 예시 b) → 본사가 준 파일만.
  - 소득·라이프스타일은 "현실적이고 과장되지 않게, 본인 경험만" (9쪽) → 여행 포스터 옆에 "누구나 갈 수 있어요" 같은 말, 금액·직급·보너스 글자 넣지 않음. 포스터만 걸어 둠.
- **'샤넬백'** 은 제3자(다른 회사) 상표입니다. 공식 기준은 제3자 상표·지적 재산도 사전 서면 승인 목록에 넣고, 제휴처럼 보이게 쓰지 말라고 함 (13·14쪽). 고객센터에서 괜찮다는 답을 받으셨으니 쓰되, 그 답도 **서면(메일·문자 캡처)** 으로 남겨 두기 권함.
- 권하는 것 한 가지: 본사 허락을 **메일로 한 번** 받아 두기 (아래 질문 2). 말로 받은 답은 나중에 증명이 어렵습니다.

## 4. 모르는 사람에게 보이는 공간이 "모집"으로 보이는 기준과 피하는 법

**공식 기준 (원문 확인, 1~4쪽)**
- **풀(Pull) = 허용**: ABO가 **직접 소유·운영하는 공간**에 올려 두고, 다른 사람이 **스스로 찾아와** 참여하는 것. 공개 페이스북·블로그·해시태그도 허용 예시.
- **푸시(Push) = 동의한 사람에게만**: 수신 동의 안 한 사람에게 보내면 스팸. 예: 모르는 사람에게 DM, 남의 유튜브 댓글에 내 링크, 남의 블로그에 사업 영상 → 금지.
- "사업 알고 싶으면 DM 주세요"는 **내 공간에서는 허용** (3쪽 예시). 즉 공개 공간 자체가 금지는 아님.
- **ABO 전용**(비공개로만): 그룹 미팅·교육·행사 정보 (3쪽).
- **어떤 경우에도 금지**: 스폰서십 라인(LOS) 정보, 사내 기밀 (3쪽).
- 보상 플랜(보너스·자격) 정보를 ABO 아닌 사람도 보는 곳에서 다루면 사전 서면 승인 (8쪽).
- 팔로우·좋아요의 대가로 어떤 보상도 주면 안 됨 (9쪽).

**오픈 라운지에 대입 — 피하는 법**

| 지키는 것 | 이유 |
|---|---|
| 회장님 소유 주소에만 올리고, 사람은 스스로 들어오게 (본계정 프로필·게시물 링크) | 풀 방식 = 허용 |
| 모르는 사람 DM·남의 게시물 댓글로 링크 뿌리지 않음 | 푸시 = 스팸 |
| 라운지 안에 **사업 소개·가입 버튼·"같이 해요"·문의 양식 없음** | 체험 공간이 모집 창구로 보이지 않게 |
| 순위·보너스·직급·수입·LOS(누구 밑 누구) 화면 없음. 미팅·세미나 일정 없음 | 8쪽·3쪽 |
| 아이템(어깨 가방·손목보호대)은 **휴대폰 안 가상 아이템**만. 실물·상품권 없음, 팔로우 조건 없음 | 9쪽 보상 금지 |
| 체험자 기록·이름·연락처 받지 않음 (지금 오픈판 설계와 같음) | 개인정보, 동의 없는 연락 방지 |
| 구석 "만든 사람 · 쏠 @ssoll0820"은 **이름·계정만**. 책·앱·공구·"라운지 만들어 드려요" 같은 다른 사업 안내 붙이지 않음 | 5쪽 암웨이 공간에 다른 사업 금지 |
| 들어온 분이 먼저 DM으로 물으면 회장님이 직접 1:1로 답 (자동 답장 아님, 🔴로 올림) | 3쪽 허용 예시, 회사 DM 규칙 |
| 법(방문판매법) 쪽: 다단계 판매원 모집 때 허위·과장 금지 조항 | 조문 원문 **확인 못 함** — 소득 말을 아예 안 쓰면 걸릴 일 없음 |

## 5. 본사에 아이디어·도구를 제안하는 창구

- **공식으로 확인된 것**: BSM·웹·앱 **승인 신청 창구 = 윤리강령부 rulekorea@amway.com** (14쪽). 이름·회원번호·내용·사용 용도를 적어 냄.
- **"아이디어 제안" 전용 창구** (제안 게시판, 협업 부서 등): **확인 못 함**. 공개 자료에서 찾지 못했습니다.
- 회사 추천: 승인 메일을 보낼 때 마지막에 "본사에 제안하고 싶은데 담당 부서가 있나요?"를 한 줄 붙이면 한 번에 끝납니다.

## 회장님이 본사(윤리강령부 메일 또는 고객센터)에 물어볼 질문 — 3개, 한 번에
> 답은 꼭 **메일이나 문자로** 받아 캡처를 노션 "🔒 암웨이 사업실"에 보관.

1. 제가 직접 만든 **가상 라운지(웹)** 를 누구나 체험하게 공개하려고 합니다(기록 없이 체험만, 사업 소개·가입 권유 없음). 웹사이트 콘셉트 승인이 필요하면 이 메일로 신청한 것으로 봐 주실 수 있나요? 그리고 이것을 **다른 사업자 팀에 무료로 나눠 주거나, 만들어 주고 비용을 받는 것**도 되나요?
2. 라운지 화면에 **암웨이 간판, 공식 포스터(삿포로 비전 트립, 것모닝 레시피), 쉐이커 모양**을 원본 그대로 넣는 것과 **'샤넬백'이라는 이름**을 쓰는 것 — 앞서 괜찮다고 하신 답을 **서면으로** 한 번 받을 수 있을까요?
3. 이 라운지를 **본사에 제안**하고 싶은데, 아이디어·도구를 제안하는 담당 부서나 방법이 있나요?

## 추천 순서
1. 지금: 오픈판은 위 "피하는 법" 표대로 만들어 둠 (공개는 아직 안 함, 이미 멈춤 상태)
2. 회장님이 질문 1~3을 **메일 한 통**으로 (메일 글은 회사가 써 드릴 수 있음, 보내기는 회장님 — 회원번호가 필요해서)
3. 답이 오면 암웨이사업팀이 이 메모를 고치고 → 공개 결재
4. "만들어 드려요" 판매는 질문 1의 답을 보고 결정. 그 전에는 암웨이 흔적 없는 일반판만 검토
