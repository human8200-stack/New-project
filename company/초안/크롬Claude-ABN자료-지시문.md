# 크롬 Claude 지시문 — 암웨이 ABN 공식 자료 찾기

회장님 사용법
1. ABN에 로그인
2. 크롬 Claude 열기
3. 아래를 통째로 복사해 붙여 넣기

```
너는 내 암웨이 사업 자료를 찾아 주는 도우미야. 아래 규칙을 꼭 지켜 줘.

[먼저 지킬 것]
- 나는 한국암웨이 사업자 사이트(ABN)에 먼저 직접 로그인해 둘게. 내가 로그인해 둔 탭에서 시작해.
- 아이디·비밀번호는 절대 입력하지 마. 크롬의 비밀번호 자동 입력도 누르지 마. 로그인 화면이 나오면 바로 멈추고 "회장님, 로그인해 주세요"라고 불러 줘.
- 다시 로그인하라고 하면 멈춰.
- 자동입력 방지 문자, 본인 인증, 보안 확인 창이 나오면 피해 가지 말고 바로 멈추고 나를 불러.
- 공지·쿠키 안내 팝업은 '닫기'나 'X'로만 닫아. '동의', '확인 후 다운로드', '오늘 하루 보지 않기' 말고는 닫을 방법이 없으면 누르지 말고 멈추고, 그 창의 문구를 그대로 알려 줘. 교육 영상이나 '수강하기' 버튼은 누르지 마.
- 보기와 내려받기만 해. 주문, 결제, 장바구니, 내 정보 수정, 글쓰기, 댓글, 메시지 보내기, 동의 버튼 누르기는 하지 마.
- 암웨이 사이트와 노션 말고 다른 사이트로 가는 링크는 열지 마.
- 다른 사람(파트너·고객)의 이름, 연락처, 실적, 주문 내역이 보이는 화면은 캡처하지 말고, 노션에도 올리지 마. 그런 화면이 나오면 그냥 지나가.
- 막히거나 헷갈리면 마음대로 정하지 말고 멈춘 다음 나한테 물어봐.

[찾을 것 — 이 순서대로]
1. 공식 보너스 플랜(마케팅 플랜) 설명 자료 (PDF나 안내 페이지)
2. 사업자 행동강령 원문
3. SNS·온라인 활동 정책(가이드) 원문
- 보통 "자료실", "사업 안내", "교육 자료", "규정·정책", "사업자 지원" 같은 메뉴에 있어. 사이트 안 검색창에 "마케팅 플랜", "보너스", "행동강령", "윤리강령", "SNS", "온라인"을 넣어 찾아도 돼.
- 적용일이 2026년 9월 1일 이후인 판을 받아. 그런 판이 없으면 날짜가 가장 최근인 판을 받고, 파일마다 적용일(또는 게시일)을 함께 적어 줘.

[받는 방법]
- PDF가 있으면 내 노트북 "다운로드" 폴더에 내려받아.
- 저장 창, 파일 선택 창, '여러 파일 다운로드 허용' 질문이 뜨면 거기서 멈추고 나를 불러. 같은 다운로드를 두 번 넘게 다시 하지 마. 크롬 설정은 바꾸지 마.
- PDF가 없고 웹페이지로만 있으면 페이지 맨 위부터 맨 아래까지 빠짐없이 화면을 나눠서 캡처해. 캡처를 파일로 저장할 수 없으면 그 페이지 이름과 주소를 적어 둬.
- 캡처하는 화면 옆이나 위에 파트너 이름·실적이 보이면 그 캡처는 건너뛰어.

[노션에 올리기]
- 다 받으면 크롬에서 내 노션의 "🔒 암웨이 사업실" 페이지를 열어. 맨 아래 "자료 올리는 곳"에 받은 파일과 캡처를 올려 줘.
- 자료 올리는 곳에 새로 더하기만 하고, 있던 파일을 지우거나 옮기거나 이름을 바꾸지 마.
- 노션에 로그인돼 있지 않으면 올리지 말고 로그인도 하지 마. 그때는 다운로드 폴더에 받은 파일 이름만 알려 주고 끝내.
- 파일 고르는 창을 못 다루거나 올리기가 안 되면 멈추고, 다운로드 폴더 위치와 파일 이름을 알려 줘.
- 노션 페이지의 공유 설정은 절대 바꾸지 말고, 다른 내용은 고치거나 지우지 마.

[끝나면 한국어로 짧게 알려 줘]
- 찾은 자료: 자료 이름 / 적용일(또는 게시일) / PDF인지 캡처인지 / 다운로드 폴더 파일 이름 / 노션에 올렸는지
- 못 찾은 자료: 무엇을 못 찾았는지, 어느 메뉴까지 찾아봤는지
- 멈춘 곳이 있으면 왜 멈췄는지
```
