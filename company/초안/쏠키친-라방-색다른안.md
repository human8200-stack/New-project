## 추천 ① 냉장고 SOS — "남은 재료 3개로 15분 한 접시"
**한 줄:** 시청자가 댓글로 자기 냉장고에 남은 재료를 말하면, 회장님이 그중 3개를 골라 그 자리에서 한 접시를 만듭니다.

**색다른 점**
- 레시피를 미리 정하지 않습니다. 시청자 재료가 메뉴가 됩니다.
- 회장님의 진짜 실력(즉석 응용)이 보이고, 매 회 결과가 달라 "다음에 또 보고 싶은" 이유가 생깁니다.
- 연말 냉장고 정리 시기(12월 중순)와 맞습니다.

**30분 흐름**
| 시간 | 할 일 |
|---|---|
| 0~3분 | 인사, 이름 불러 드리기. "오늘은 메뉴가 없어요. 여러분 냉장고가 메뉴예요." |
| 3~8분 | 댓글로 "우리 집 냉장고에 남은 것" 받기 → 회장님 냉장고에 있는 것과 겹치는 재료 3개 고르기 |
| 8~10분 | 메뉴 2개 중 고르기: 댓글 "1" 또는 "2" (예: 볶음 vs 전) |
| 10~25분 | 15분 타이머 켜고 만들기. 기다리는 동안 "이 재료 남으면 저는 이렇게 해요" 한 마디씩 |
| 25~28분 | 담고 맛보기. 재료 낸 분 이름 불러 드리기 |
| 28~30분 | "다음 쏠키친에도 냉장고 털어 드릴게요. 12월 27일 일요일 밤 8시." · "저랑 따뜻한 밥 한 끼 해요." |

**회장님 준비물 (적음)**
- 평소 냉장고 그대로 + 흔한 재료만 조금 더 채워 두기: 달걀, 양파, 대파, 두부, 버섯, 밥, 기본 양념
- 팬 1개, 냄비 1개, 그릇, 타이머(휴대폰 말고 주방 타이머)
- 미리 만들어 둘 것 없음

**시청자 참여 장치**
- 댓글 "남은 재료" 받기 → 이름 불러 주며 채택
- 숫자 댓글 투표 "1 / 2"로 메뉴 고르기
- 재료가 뽑힌 분 = "오늘의 냉장고 주인" 으로 이름 불러 드리기 (선물 없음 → 돈·규정 부담 없음)

**위험**
- 준비 부담: 낮음. 다만 재료가 안 맞으면 당황할 수 있음 → 회사가 "흔한 재료 조합 5가지" 쪽지 한 장을 미리 드림.
- 15분 안에 못 끝날 수 있음 → 볶음·전·덮밥처럼 빨리 되는 것만 고름.
- 규정: 효능 말("이거 먹으면 ○○에 좋아요")이 나오기 쉬움 → 쪽지에 "맛·편함 이야기만" 한 줄.

## ② 연말 홈파티 한 상 — "시청자 투표로 차리는 4인 연말 상"
**한 줄:** 12월 모임 상을 차린다면? 메인·곁들이·마무리를 시청자 투표로 하나씩 골라, 이미 만들어 둔 음식을 담고 테이블을 꾸밉니다.

**색다른 점**
- 요리를 만드는 방송이 아니라 "상 차리기·담기" 방송입니다. 접시 고르기, 놓는 자리, 작은 장식이 주인공.
- 시청자가 고른 대로 상이 완성돼 끝에 사진 한 장이 남습니다(라이브 뒤 게시물 재료).
- 연말에 집으로 사람을 부르는 분(모임 여는 분)에게 바로 쓸모가 있습니다.

**30분 흐름**
| 시간 | 할 일 |
|---|---|
| 0~3분 | 인사. "오늘은 연말 상을 같이 차려요." |
| 3~8분 | 투표 1: 메인 2개 중 고르기(댓글 1/2) → 고른 것 담기 |
| 8~15분 | 투표 2: 곁들이 2개 중 고르기 → 담기. 접시 고르는 이유 이야기 |
| 15~22분 | 테이블 꾸미기: 냅킨 접기 하나, 초·솔방울 같은 작은 장식 |
| 22~27분 | 투표 3: 마무리(디저트·차) → 상 완성, 위에서 한 장면 보여 주기 |
| 27~30분 | "여러분이 차린 상이에요." 다음 회 날짜 안내, "저랑 따뜻한 밥 한 끼 해요." |

**회장님 준비물 (중간)**
- 미리 만들어 둔 음식 6가지(투표 후보 3쌍) — 부담이 커서, **후보는 3쌍 중 하나는 "그릇만 바꿔 보여 주기"로 줄일 수 있음**
- 접시·컵·냅킨, 초 1~2개, 식탁보

**시청자 참여 장치**
- 댓글 숫자 투표 3번 (메인·곁들이·마무리)
- "우리 집 연말 상 단골 메뉴" 댓글 받아 읽기

**위험**
- 준비 부담: 셋 중 가장 큼(음식 미리 만들기). 줄이려면 후보를 2쌍으로.
- 그릇 이름·브랜드를 말하면 공구 홍보처럼 들림 → 그릇 이름·구입처는 말하지 않음. 그릇장·그릇 공구는 메종 에델 몫이라 본계정 라이브에서는 꺼내지 않습니다.
- "모임"이라는 말이 사업 모임으로 들리지 않게 → "가족·친구 연말 상"으로만 말함.

## ③ 이웃 친구와 둘이서 — "한 부엌, 두 사람, 두 접시"
**한 줄:** 친한 이웃·친구 한 명을 부엌에 초대해, 같은 재료로 각자 한 접시씩 만들고 서로 맛을 봅니다.

**색다른 점**
- 처음으로 두 사람이 나옵니다. 잘나가는 계정 분석(11/10)에서 "함께 있는 장면이 가장 퍼진다"고 나왔습니다.
- 대화가 생겨 회장님 혼자 말을 이어 갈 부담이 줄어듭니다.
- 시청자가 "누구 접시가 더 끌려요?"로 응원 댓글을 답니다(승패보다 놀이).

**30분 흐름**
| 시간 | 할 일 |
|---|---|
| 0~4분 | 인사, 게스트 소개(이름 또는 별명만, 게스트가 원하는 만큼만) |
| 4~7분 | 같은 재료 공개(예: 두부·달걀·대파). 각자 무엇을 만들지 한 줄씩 |
| 7~22분 | 나란히 요리. 서로 질문·수다, 댓글 읽어 주기 |
| 22~27분 | 서로 맛보기 → 시청자 댓글 "1(회장님) / 2(게스트)" 끌리는 접시 |
| 27~30분 | 게스트 한마디, 마무리 인사 |

**회장님 준비물 (중간)**
- 게스트 한 분 섭외(회장님만 할 수 있는 일 — 가장 큰 부담)
- 같은 재료 2인분, 팬 2개 또는 화구 2개, 앞치마 2장
- 게스트 동의: 얼굴·이름이 라이브와 다시보기·클립에 나와도 되는지 **미리 말로 확인**

**시청자 참여 장치**
- 끌리는 접시 숫자 투표
- "같이 요리하고 싶은 사람 태그" 대신 → "친구랑 해 보고 싶은 메뉴" 댓글 (태그 권유는 하지 않음)

**위험**
- 게스트가 사업 이야기(수입·직급·제품)를 꺼낼 수 있음 → **게스트에게 미리 "오늘은 요리 이야기만" 부탁**. 사업을 같이 하는 분보다 요리 친구를 추천.
- 게스트 개인정보·얼굴 → 동의 받은 범위만, 클립은 게스트 확인 후.
- 일정이 안 맞으면 못 함 → 12/13 일주일 전(12/6)까지 게스트가 안 정해지면 ① 냉장고 SOS로 바꿈.
