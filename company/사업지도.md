## 순서 (추천, 결재 5번 갱신)
1. **지금**: ⓪ 『슬기로운요리생활』 판매 늘리기 (이미 2,000권 검증된 책) + 메종에델에 쿠팡 파트너스 붙이기 (돈 안 들고 바로 가능)
2. **다음**: ② **건강 책** 기획 시작 — 회장님 판단: 승산이 더 큼. 건강강의 앱 내용이 재료. 감수(전문가 확인) 일정 때문에 일찍 시작
3. 메인 계정 열기/정비 — 회장님 소개(출판사 대표, 2,000권, AI로 만든 앱들), 제휴 문의 받는 창구
4. 메종에델 첫 공구 (구독자 반응·신뢰 확인 후)
5. ① 레시피함 전자책, ③ 메종에델 요리책 (시간 걸림)
5-2. 인테리어: 블로그 반자동 프로그램을 업체에 판매 (기획 완료 → 시제품)
6. 앱 → 진짜 앱 (앱스토어·플레이스토어 판매): **⭐ 소비자 관리 앱(ABLE CRM) 1순위**, 공부 루틴(학습 앱), 레시피함, 건강강의

### ⭐ 소비자 관리 앱 (ABLE CRM) — 판매 1순위 앱 (회장님 지시 2026-11-01)
회장님이 직접 쓰며 만든 앱 → "현장에서 검증된 도구"라는 이야기가 있음.

**팔기 전에 꼭 정할 것**
1. **누구에게 파나**
   - A. 암웨이 사업자 전용 — 팀·다른 사업자가 바로 이해함. 단, **암웨이가 사업자에게 도구·자료를 파는 것을 규정으로 제한할 수 있음 → 규정 확인 전에는 팔지 않음** (결재 13번 규정 원문과 함께 확인)
   - B. **1인 판매자 일반용** (방문판매·보험·뷰티·공방 등) — 시장이 넓고 암웨이 규정과 무관. 암웨이 사업자도 쓸 수 있음
   - 회사 추천: **B로 만들고, 암웨이 사업자에게는 규정 확인 후 소개**
2. **고객 개인정보를 맡아 보관하는 서비스가 됨** → 판매하려면 필수:
   - 쓰는 사람마다 데이터가 완전히 분리 (남의 고객이 보이면 안 됨), 로그인·암호화·백업
   - 개인정보 처리방침, 이용약관, 탈퇴 시 삭제
   - 지금 앱이 이걸 어떻게 하고 있는지 개발팀이 먼저 점검 (회장님 고객 정보는 보지 않고 구조만)
3. **값 받는 방법**: 월 구독 (예: 무료 체험 → 월 ○원) — 앱출시팀이 비슷한 앱 가격 조사 후 제안

**순서**: ① 앱 코드 위치 확인 → ② 개발팀 구조 점검(보안·데이터 분리) → ③ 앱출시팀 제품 기획안(누구에게, 핵심 기능 5개, 가격) → 결재 → ④ 정리·보완 → ⑤ 아는 사람 5~10명 무료 체험 → ⑥ 유료

### 공부 루틴 (학습 앱) — 팔기 전에 고칠 것
- 지금은 **한 학생(군포고 1학년) 맞춤**: 학교 이름, 교재(쎈·마플시너지 등), 시험 범위 예상이 그 학생 기준 → 누구나 학교·학년·교재를 고르게 바꿔야 함
- 사진 읽기(AI)는 집마다 각자 API 키를 넣는 방식 → 팔 때는 회사가 AI 비용을 내고 구독료에 포함하는 방식이 쉬움 (비용 계산 필요)
- 학생 정보를 다루므로 개인정보 처리방침 필요, 만 14세 미만이 쓰면 부모 동의 필요
- 장점: 이미 v54까지 실제로 쓰며 다듬은 앱 = "학부모가 직접 만든 앱"이라는 이야기 → 메인 계정·학부모 대상 홍보 재료
- 순서 추천: 아는 학부모 몇 집에 무료로 써 보게 → 반응 확인 → 유료
