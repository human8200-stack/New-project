## 비고
- **EP.01** — 10/27 ChatGPT가 승인 없이 크레딧을 거의 다 써서 25만 남았다는 노션 기록만 있음. 사용량 숫자 없음. ChatGPT 사진은 따로 돈 안 냄(회장님 말씀).
- **EP.02** — ChatGPT 사진 8장+추가 컷(노션). 영상 크레딧 숫자 없음.
- 확인하려면: 회장님 런웨이 화면 **Settings → Billing / Usage**의 10월 날짜별 사용 내역 사진 1장 (회사 쪽 기록은 10/31부터만 보임).
- **EP.03 첫 제작** — 사진 22장(440) + 영상 12개(Gen-4 Turbo 7개 175 / 시댄스 2 Fast 4개 384 / 시댄스 2 1개 120). 아침 잔액 831 + 충전 1,000 − 지금 572 = 1,259와 정확히 맞음.
- **EP.03 다시 만들기** — 장면 1 시험 사진 20(712→692) + 장면 1 영상 120(692→572, 잔액으로 확인, 만드는 중). 영상이 실패하면 크레딧이 돌아오는지는 끝난 뒤 다시 확인.
- 10/31 유리컵 영상 25크레딧은 레시피 장면이 아니라 어느 편에도 넣지 않음.

## 남은 크레딧으로 되나 (11/1 기준)
- 남은 **572** (요금제 몫 0 + 충전 몫 572, 런웨이 화면 확인)
- 한 편 650 − 572 = **78 모자람** → 새 편 하나를 처음부터 끝까지 만들 수 없음.
- EP.03 다시 만들기를 650 안에서 끝내면 510 더 씀 → **62 남음**. 이번 달 두 번째 편은 충전 없이는 못 만듦.
- 충전은 최소 1,000크레딧(10달러, 약 17,000원)부터. **충전은 결재 필요.**

## 돈 기준
- 충전 크레딧: 1,000크레딧 = 10달러 = 약 17,000원 → **1개 약 17원**
- 요금제 크레딧: Standard 월 15달러(약 25,500원) ÷ 625크레딧 → **1개 약 41원** (충전보다 비쌈). 연 결제면 월 12달러 → 1개 약 33원. 월/연 결제인지 모름.
- 환율 1달러 = 1,700원 (회장님 기준)
- 11/1 아침 831크레딧 중 요금제 몫이 얼마였는지 모름 → 41원으로 치면 EP.03 금액이 더 커짐. 이 표는 모두 17원으로 계산.
