# 회장님에 대해 회사가 아는 것

> 저장소 기록과 연결된 서비스를 보고 회사가 **추정**한 내용입니다. 틀린 게 있으면 "회장님 메모 고쳐 줘: …"라고 말씀하세요.

## 어떤 분인가
- 개발자가 아니지만, Claude와 함께 실제로 쓰는 웹앱을 여러 개 만들어 운영하는 분.
- 고등학교 1학년 자녀(군포고)의 공부를 챙기는 학부모. 자녀용 **공부 루틴** 앱을 만들어 계속 다듬고 있음 (v54까지).
- 행사를 여는 일이 있음 → 큐알 등록·룰렛 **행운 추첨** 앱을 만듦 (누구나 쓰도록 공개).
- 주로 **휴대폰**으로 지시하고 확인함. 아이에게는 아이패드.

- **1인 출판사 대표.** 첫 책 『슬기로운요리생활』을 회장님 출판사에서 출간함 (출판사 **육공이**, 2024-07-12 출간, 감수 강설화). 약 **2,000권** 판매. 스마트스토어 `yookgongee`, 인포마당(납품처), 소형 서점 2곳에서 판매.
- **책을 내는 것이 목표.** 건강강의 앱 → 건강 책, 레시피함 앱 → 전자책, 요리 유튜브 **메종에델** → 요리책.

## 일하는 방식 (지켜야 할 것)
- 설명은 **쉬운 한국어**로. 개발 용어 없이. (저장소 커밋 메시지도 전부 쉬운 한국어)
- 숫자를 직접 입력하는 것보다 **버튼으로 고르는 것**을 좋아함.
- **무료**로 되는 방법 먼저 (Firebase·Cloudflare·Netlify 무료 요금제를 씀). 돈은 각자 쓴 만큼만.
- 비밀번호·가입 절차는 최소로.
- 직접 아이디어를 내기보다 회사가 좋은 안을 정해 오기를 원함. 회장님은 **확인·로그인·결제**만.
