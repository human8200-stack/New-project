# GPT 그림 연결 안내서 (메종 에델 장면 그림)

> 회장님용. 한 번에 한 단계만 하시면 됩니다. 단계가 끝나면 사장실 대화에 적힌 말만 보내 주세요.
> 만든 날: 2026-11-01 · 담당: 운영팀 · 근거: OpenAI 공식 문서 (아래 "확인한 사실")

---

## 1분 설명

- **왜 하나요?** 노션 메종 에델 작업실에 "ChatGPT = 에델 캐릭터·이미지 생성"으로 정해져 있습니다. 지금은 Runway 안에서 같은 그림 기능(gpt-image-2)을 빌려 쓰고 있습니다. OpenAI(ChatGPT 회사)에 **직접** 연결하면 같은 그림을 **더 싸게**, 회사가 혼자 그릴 수 있습니다. 회장님이 ChatGPT에 주문서를 붙여 넣는 일도 줄어듭니다.
- **어떻게 돌아가나요?** 회장님이 OpenAI 개발자 사이트에서 **열쇠(API 키)** 를 하나 만들어, 클라우드 환경 설정에 넣어 두십니다. 회사는 그 열쇠로 그림을 주문합니다. 에델 얼굴·주방 사진 같은 **참고 그림 여러 장**을 같이 넣어서 얼굴이 매번 같게 그립니다.
- **비용:** 그린 만큼만 냅니다. 세로 그림 1장에 **약 70원(보통 품질)~약 280원(최고 품질)**. 먼저 **10달러(약 1만 7천 원)** 를 충전해 두고, 다 쓰면 멈추게 합니다. 회사는 그리기 전에 몇 장·얼마인지 먼저 여쭙니다.
- **ChatGPT Plus 구독과는 별개입니다.** Plus 요금에 이 사용료는 들어 있지 않아 따로 충전합니다. (Plus를 끊을 필요는 없습니다.)
- **주의 — ChatGPT 앱의 대화·기억과는 연결되지 않습니다.** 회장님이 ChatGPT 앱에서 에델과 나눈 대화, 앱이 기억하는 설정은 회사가 볼 수 없습니다. 그래서 에델 모습은 **참고 그림**으로 맞춥니다. 마음에 드는 에델 그림이 있으면 그 사진만 회사에 주시면 됩니다.
- **회장님이 하실 일:** 로그인 → 10달러 충전 → 월 한도 걸기 → 열쇠 만들어 환경 설정에 넣기. 이것뿐입니다.
- **걸리는 시간:** 모두 **약 20분, 5단계** (조직 인증이 필요하다고 나오면 +10분, 1단계 더).
- **어디서:** 휴대폰(사파리)도 되지만 OpenAI 개발자 화면이 작게 보입니다. **노트북 크롬이 편합니다.**

## 오늘 부탁할 첫 단계 하나

> **휴대폰이나 노트북에서 platform.openai.com 에 들어가, ChatGPT를 쓰는 그 계정으로 로그인만 해 주세요. 다 되면 사장실에 "GPT 1단계 끝"이라고 보내 주세요.**

## 전체 단계 (5단계 + 필요할 때 1단계, 약 20분)

표시: 💻 = 노트북이 편함 · 📱 = 휴대폰도 됨

### 1단계 · 개발자 사이트 로그인 📱💻 (약 3분)
- **어느 화면:** 주소창에 `platform.openai.com`
- **무엇을 누름:**
  1. 오른쪽 위 **Log in** (로그인)
  2. ChatGPT에 쓰는 방법 그대로 (구글로 계속 / 이메일) 로그인
  3. 처음이면 "조직 이름" 같은 질문이 나옵니다 → `Second Wave` 입력 (이미 `Second Wind`로 만드셨으면 그대로 두셔도 됩니다 — 이름을 바꾸려면 회장님 로그인 필요) → **Create** (만들기). 무엇을 만들지 묻는 질문은 **Skip** (건너뛰기)
- **다 되면:** "GPT 1단계 끝"

### 2단계 · 10달러 충전 💻 (약 5분) — 돈이 드는 단계
- **어느 화면:** 오른쪽 위 **톱니바퀴(Settings, 설정)** → 왼쪽 **Billing** (결제)
- **무엇을 누름:**
  1. **Add payment details** (결제 수단 추가) → **Individual** (개인) → 카드 입력 → 저장
  2. 충전 금액 칸에 **10** (달러) 입력. 최소 5달러, 기본 10달러입니다.
  3. **Automatic recharge** (자동 충전)은 **꺼 두세요.** 꺼 두면 10달러를 다 쓰면 그냥 멈춥니다.
  4. **Continue** → **Confirm payment** (결제 확인)
- 참고: 충전한 돈은 1년이 지나면 없어지고, 보통 돌려받을 수 없습니다. 그래서 10달러만 넣습니다.
- **다 되면:** "GPT 2단계 끝, 10달러 충전"

### 3단계 · 월 사용 한도 걸기 💻 (약 2분)
- **어느 화면:** Settings → 왼쪽 **Limits** (한도) (프로젝트 쪽에 있으면 **Project → Limits**)
- **무엇을 누름:**
  1. **Monthly budget** (월 예산) 칸에 **10** 입력
  2. 알림 받을 금액(**Notification threshold**)이 있으면 **8** 입력
  3. **Save** (저장)
- 왜: 실수로 많이 그려도 회장님께 알림이 가고, 2단계에서 자동 충전을 꺼 두었기 때문에 10달러를 넘게 빠져나가지 않습니다.
- **다 되면:** "GPT 3단계 끝"

### 4단계 · 열쇠 만들기 💻 (약 3분)
- **어느 화면:** Settings → 왼쪽 **API keys** (또는 주소창에 `platform.openai.com/api-keys`)
- **무엇을 누름:**
  1. **Create new secret key** (새 비밀 열쇠 만들기)
  2. 이름 칸: `maison-edel-image` → 권한(Permissions)은 그대로 → **Create secret key**
  3. `sk-` 로 시작하는 긴 글자가 **한 번만** 보입니다 → **Copy** (복사)
  4. **채팅(사장실 대화·카톡·노션)에 붙여 넣지 마세요.** 바로 5단계로 가서 넣습니다.
- 혹시 채팅에 붙여 넣으셨다면: 같은 화면에서 그 열쇠 옆 **휴지통(Revoke)** 을 누르고 새로 만들어 주세요.
- **다 되면:** 아직 말씀 안 하셔도 됩니다. 바로 5단계.

### 5단계 · 열쇠를 클라우드 환경 설정에 넣기 📱💻 (약 3분)
- **어느 화면:** 이 사장실 대화 화면 **맨 위 제목 줄의 환경 이름** (예: "기본")
- **무엇을 누름:**
  1. 환경 이름 누르기 → **편집** (Edit)
  2. **환경 변수** 칸에 한 줄 추가: `OPENAI_API_KEY=` 뒤에 4단계에서 복사한 열쇠 붙여 넣기
     (예: `OPENAI_API_KEY=sk-...` — 앞뒤에 빈칸 없이)
  3. **저장**
- 열쇠는 **새 대화부터** 쓰입니다. 저장 후 사장실 대화를 새로 열어 주세요.
- **다 되면:** 새 대화에서 "GPT 5단계 끝, 열쇠 넣음"

### (필요할 때만) 조직 인증 💻 (약 10분)
- 회사가 시험 그림을 그릴 때 "조직 인증이 필요합니다"라는 답이 오면 그때만 합니다. 회사가 먼저 말씀드립니다.
- **어느 화면:** Settings → **General** (일반) → **Verify Organization** (조직 인증)
- **무엇을 누름:** 안내대로 신분증 사진·얼굴 확인. 끝나고 사용 가능해질 때까지 조금 걸릴 수 있습니다.
- **다 되면:** "GPT 인증 끝"

### 그다음 — 회사가 할 일 (회장님은 승인만)
1. 회사가 **가장 싼 품질로 시험 1장**(약 9원)을 그려 연결을 확인합니다 → 결과 보고.
2. 에델 참고 그림을 넣고 **보통 품질 1장**(약 70원) 시험 → 회장님께 보여 드리고 승인받기.
3. 승인 후에는 영상마다 "몇 장 · 약 얼마"를 먼저 여쭙고 그립니다.

## 비용 비교 (세로 1024x1536 한 장, 1달러 = 1,700원)

| 어디서 | 1장 값 |
|---|---|
| Runway 안 gpt-image-2 (지금) | 20크레딧 ≈ **340원** |
| OpenAI 직접 · gpt-image-2 최고 품질 | 0.165달러 ≈ **281원** |
| OpenAI 직접 · gpt-image-2 보통 품질 | 0.041달러 ≈ **70원** |
| OpenAI 직접 · gpt-image-2 낮은 품질(시험용) | 0.005달러 ≈ **9원** |

- 한 줄 요약: **최고 품질로 그려도 Runway보다 1장에 약 60원 싸고, 보통 품질이면 약 5분의 1 값입니다.**
- 참고 그림을 넣으면 넣은 그림 값이 조금 더 붙습니다 (참고 그림 1장당 정확한 값은 확인 못 함 — 시험 1장 후 실제 금액으로 다시 알려 드립니다).
- 월 10달러면 보통 품질로 약 240장, 최고 품질로 약 60장입니다 (참고 그림 값 빼고 계산).

## 확인한 사실 (2026-11-01, 공식 문서)

- **쓸 수 있는 그림 모델:** `gpt-image-2.5-sunburst`(고치기 정확도 중시), `gpt-image-2.5-flare`(빠른 일상용), `gpt-image-2`, `gpt-image-1.5`, `gpt-image-1-mini`. `gpt-image-1`은 2026-10-23 종료. — [가격](https://developers.openai.com/api/docs/pricing), [그림 안내](https://developers.openai.com/api/docs/guides/image-generation)
- **세로 크기:** 추천 크기에 `1024x1536` 있음. 원하는 크기도 됨(가로·세로 16의 배수, 비율 3:1 안, 한 변 3840 이하) → 정확한 9:16(예: `1152x2048`)도 가능. — [그림 안내](https://developers.openai.com/api/docs/guides/image-generation)
- **참고 그림 여러 장으로 고치기(edits):** 됨. 공식 예시가 4장을 넣음. 최대 장수는 문서에 없음. 한 장 50MB 미만. `gpt-image-2`는 참고 그림을 항상 고화질로 읽어서 입력 값이 더 들 수 있음. — [그림 안내](https://developers.openai.com/api/docs/guides/image-generation), [gpt-image-2 모델](https://developers.openai.com/api/docs/models/gpt-image-2)
- **장당 가격(gpt-image-2):** 1024x1536 기준 낮음 0.005달러 · 보통 0.041달러 · 높음 0.165달러 (1024x1024는 0.006 · 0.053 · 0.211). — [그림 안내 가격표](https://developers.openai.com/api/docs/guides/image-generation)
- **gpt-image-2.5 장당 가격:** 공식 문서에 장당 값 없음(사용량 단가만: 그림 입력 100만 단위당 8달러, 출력 30달러 — gpt-image-2와 같음). **확인 못 함.**
- **결제 방식:** 선불 충전. 최소 5달러, 기본 10달러, 1년 지나면 소멸, 보통 환불 안 됨. 잔액이 다 되면 멈춤(조금 넘게 쓰일 수 있음 — 다음 충전에서 빠짐). — 출처: OpenAI 도움말 [선불 결제](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing), [8264778](https://help.openai.com/en/articles/8264778) (검색 결과로 확인. 이 클라우드에서 도움말 원문은 접속이 막혀 직접 열어 보지는 못함)
- **ChatGPT Plus와 별도:** ChatGPT와 개발자(API) 결제는 따로. Plus에 API 사용료 포함 안 됨. — 출처: OpenAI 도움말 [8156019](https://help.openai.com/en/articles/8156019-is-api-usage-included-in-chatgpt-plus) (위와 같이 검색 결과로 확인)
- **조직 인증:** 공식 안내에 "GPT Image 모델을 쓰려면 조직 인증이 **필요할 수 있다**"고만 있음. 우리 계정에 필요한지는 시험 1장을 그려 봐야 앎. — [그림 안내](https://developers.openai.com/api/docs/guides/image-generation)
- **회장님 그림이 학습에 쓰이나:** 아니요. API로 보낸 자료는 회장님이 따로 동의하지 않으면 학습에 쓰지 않음. — [데이터 안내](https://developers.openai.com/api/docs/guides/your-data)
- **월 한도(3단계)의 정확한 버튼 이름**은 화면이 자주 바뀌어 확인 못 함. 다른 이름이면 "Limits" 화면 사진을 보내 주세요.
- **이 클라우드에서 접속:** `api.openai.com` 접속 됨 (열쇠 없이 시험 → "열쇠 없음" 답(401)이 옴 = 길은 열려 있음). 2026-11-01 운영팀 확인.
