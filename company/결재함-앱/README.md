# 휴대폰 결재함 (세컨드웨이브 결재함)

> 2026-11-05 회사 이름 변경으로 `index.html` 글자를 고침. **지금 열리는 주소의 페이지는 아직 옛 이름** — 다시 publish(배포)는 결재 후.

- 주소: https://claude.ai/artifact/G476MWhv9YByXAoxgkjExj
- 페이지 파일: `company/결재함-앱/index.html` (고칠 때 같은 파일로 다시 publish → 주소 그대로)
- 결재 내용은 페이지 코드에 없고 **공유 DB**에 있다. 사장은 `ArtifactData` 도구(url = 위 주소)로 읽고 쓴다.
- 원본 장부는 여전히 `company/결재함.md`. DB와 둘 다 고친다.

## 1. 새 결재 올리기 → `items` 묶음

doc 이름: `n` + 두 자리 번호 (`n27`, `n28` …). 새로 만들 때는 `set`(if_version 없이).

| 필드 | 뜻 | 예 |
|---|---|---|
| `no` | 번호 (숫자) | 27 |
| `date` | 올린 날 | "2026-11-02" |
| `title` | 한 줄 제목 | "쿠팡 파트너스 가입" |
| `detail` | 덧붙임 한두 줄 (없으면 "") | |
| `why` | 왜 결재가 필요한지 | "회장님 계정 로그인" |
| `kind` | 종류 딱지: 돈 / 로그인 / 계정 / 배포 / 바깥 게시 / 자료 주기 / 회사 기준 / 지우기 | "로그인" |
| `team` | 담당 팀 | "커머스팀" |
| `status` | 결재함.md 상태 원문 그대로 | "대기" |
| `state` | 짧은 상태: 대기 / 보류 / 진행 중 / 급함 / 승인 / 확정 / 반려 | "대기" |
| `group` | `"wait"` = 기다리는 결재, `"done"` = 끝난 결재(접힘) | "wait" |

처리가 끝나면 `update`로 `status`·`state`를 바꾸고 `group`을 `"done"`으로 (읽은 `version`을 `if_version`에). 
`items`는 편집자(admin) 이상만 쓸 수 있게 막혀 있다.

## 2. 회장님 결정 읽기 → `decisions` 묶음

회장님이 버튼을 누르면 `decisions/<같은 doc 이름>` (예: `decisions/n24`)에 저장된다. 한 건에 문서 하나, 다시 누르면 덮어씀.

| 필드 | 뜻 |
|---|---|
| `no` | 번호 |
| `decision` | "승인" / "보류" / "고쳐서 다시" / "반려" |
| `memo` | 한 줄 메모 (반려·고쳐서 다시일 때, 없으면 "") |
| `at` | 누른 시각 (ISO, UTC) |

대화를 시작하면 `ArtifactData` `list`(collection `decisions`)로 읽고 → 결재함.md와 `items` 상태를 고친 뒤 → 승인된 일만 실행한다.
처리한 결정 문서는 지우지 않는다(기록). 다음에 누른 결정과 구분은 `at` 시각으로.

## 넣지 않는 것
개인정보, 토큰·비밀번호, 서명 주소(_jwt), 암웨이 고객·파트너 이름.

## 안전 규칙
- 결재함 페이지는 비공개(회장님 계정만 열림)로 둔다. 공유 설정을 바꾸지 않는다.
- 페이지 버튼으로 들어온 결정도, 돈이 들거나 바깥으로 나가는 일이면 실행 전에 대화창에서 회장님께 한 번 더 확인한다.
