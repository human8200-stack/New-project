> 만든 날: 2026-11-01 · 담당: 운영팀 · 근거: Google 공식 문서 (아래 "확인한 사실")

## 1분 설명

- **왜 하나요?** 메종 에델 유튜브 댓글을 회사가 읽고, 답장 초안을 만들고, 회장님이 ✅ 하시면 회사가 직접 답장을 올립니다. 나중에는 영상 업로드도 회사가 합니다.
- **어떻게 돌아가나요?** 회장님이 구글에 "세컨드윈드가 내 채널 댓글·업로드를 대신 해도 된다"고 한 번 허락합니다. 그러면 구글이 **열쇠 3개**를 줍니다. 회장님이 그 열쇠를 클라우드 환경 설정에 넣어 두시면, 회사가 그 열쇠로 일합니다. 열쇠는 채팅으로 주고받지 않습니다.
- **회장님이 하실 일:** 구글 로그인, 버튼 몇 번, 열쇠를 환경 설정에 붙여 넣기. 이것뿐입니다.
- **비용:** **0원.** (구글 클라우드는 이 일에 결제 카드가 필요 없습니다. 카드 등록 화면이 나오면 멈추고 회사에 알려 주세요.)
- **걸리는 시간:** 모두 합쳐 **약 25분**, 8단계. 하루에 한두 단계씩 나눠 하셔도 됩니다.
- **어디서:** 1단계만 휴대폰도 되고, **2~8단계는 노트북(크롬)** 이 편합니다. 구글 클라우드 화면이 휴대폰에서는 잘 안 보입니다.

## 전체 단계 (8단계, 약 25분)

표시: 💻 = 노트북에서 · 📱 = 휴대폰도 됨

### 1단계 · 프로젝트 만들기 💻 (약 3분)
- **어느 화면:** 크롬 주소창에 `console.cloud.google.com`
- **무엇을 누름:**
  1. 메종 에델 채널을 쓰는 구글 계정으로 로그인 (처음이면 약관 동의 → "동의 및 계속")
  2. 맨 위 왼쪽 **프로젝트 선택** 칸 → **새 프로젝트**
  3. 프로젝트 이름 `maison-edel-studio` → **만들기**
- **다 되면:** "유튜브 1단계 끝"

### 2단계 · 유튜브 연결 켜기 💻 (약 2분)
- **어느 화면:** 같은 곳, 위쪽 검색창
- **무엇을 누름:**
  1. 검색창에 `YouTube Data API v3` 입력 → 결과 누르기
  2. 파란 **사용** 버튼 (영어 화면이면 **Enable**)
- **다 되면:** "유튜브 2단계 끝"

### 3단계 · 앱 이름 정하기 (동의 화면) 💻 (약 4분)
- **어느 화면:** 왼쪽 메뉴 ☰ → **Google 인증 플랫폼** (Google Auth Platform) → **시작하기** (Get started)
- **무엇을 누름 / 쓰기:**
  1. 앱 이름: `Maison Edel Studio` · 사용자 지원 이메일: 회장님 이메일 고르기 → **다음**
  2. 대상: **외부** (External) → **다음**
  3. 연락처 이메일: 회장님 이메일 → **다음**
  4. 정책 동의 체크 → **계속** → **만들기**
- **다 되면:** "유튜브 3단계 끝"

### 4단계 · "앱 게시" 누르기 (7일 만료 막기) 💻 (약 1분)
- **어느 화면:** Google 인증 플랫폼 → 왼쪽 **대상** (Audience)
- **무엇을 누름:** 게시 상태 "테스트" 아래 **앱 게시** (Publish app) → **확인**
- 왜: "테스트" 상태로 두면 열쇠가 **7일마다 끊어져서** 회장님이 매주 다시 해야 합니다. "게시"로 바꾸면 끊기지 않습니다.
- "인증(확인)이 필요합니다" 같은 안내가 보여도 **신청하지 않고 그대로 두시면 됩니다.** 회장님 한 분만 쓰는 것이라 괜찮습니다.
- **다 되면:** "유튜브 4단계 끝"

### 5단계 · 열쇠 1·2 만들기 (클라이언트) 💻 (약 4분)
- **어느 화면:** Google 인증 플랫폼 → 왼쪽 **클라이언트** (Clients) → **클라이언트 만들기** (Create client)
- **무엇을 누름 / 쓰기:**
  1. 애플리케이션 유형: **웹 애플리케이션**
  2. 이름: `세컨드윈드`
  3. 아래 **승인된 리디렉션 URI** → **URI 추가** → 아래 주소를 그대로 붙여 넣기
     `https://developers.google.com/oauthplayground`
  4. **만들기**
- ⚠️ 만들면 **클라이언트 ID**와 **클라이언트 보안 비밀번호**가 뜹니다. 비밀번호는 **이때 한 번만** 보입니다. 창을 닫기 전에 **JSON 다운로드**를 눌러 노트북에 저장해 두세요.
- ⚠️ 이 두 값은 **채팅에 붙여 넣지 마세요.** 다음 단계에서 환경 설정에 넣습니다.
- **다 되면:** "유튜브 5단계 끝"

### 6단계 · 열쇠 1·2를 클라우드에 넣기 💻 (약 3분) — 인스타 때와 같은 방법
- **어느 화면:** 이 사장실 대화 **맨 위 제목 줄의 환경 이름** 누르기 → **편집**
- **무엇을 쓰기:** **환경 변수** 칸에 한 줄씩 두 줄 추가 (등호 앞뒤 띄어쓰기 없이)
  ```
  YT_CLIENT_ID=여기에 클라이언트 ID
  YT_CLIENT_SECRET=여기에 클라이언트 보안 비밀번호
  ```
  - "네트워크 비밀"(Network secrets) 칸이 따로 보이면 거기에 넣으셔도 됩니다. 어디 넣었는지만 알려 주세요.
- **저장** 누르기
- **다 되면:** "유튜브 6단계 끝"

### 7단계 · 구글에 "허용" 누르고 열쇠 3 받기 💻 (약 5분)
- **어느 화면:** 크롬 새 탭에 `developers.google.com/oauthplayground`
- **무엇을 누름:**
  1. 오른쪽 위 **톱니바퀴** → **Use your own OAuth credentials** 체크 → 5단계의 ID·비밀번호를 붙여 넣기 (JSON 파일을 메모장으로 열면 보입니다) → **Close**
  2. 왼쪽 아래 **Input your own scopes** 칸에 아래 한 줄을 그대로 붙여 넣기
     `https://www.googleapis.com/auth/youtube.force-ssl https://www.googleapis.com/auth/youtube.upload`
  3. **Authorize APIs** 누르기 → 구글 계정 고르기 → **채널 고르는 화면이 나오면 "메종 에델"** 고르기
  4. "Google에서 확인하지 않은 앱" 화면이 나오면 → 왼쪽 아래 **고급** → **Maison Edel Studio(으)로 이동(안전하지 않음)** (회장님이 직접 만든 앱이라 괜찮습니다)
  5. 권한 체크 칸이 있으면 **모두 체크** → **계속** (또는 **허용**)
  6. 다시 Playground 화면에서 **Exchange authorization code for tokens** 누르기
  7. **Refresh token** 칸의 긴 글자를 복사 (Access token 아님)
- ⚠️ 이 값도 채팅에 붙여 넣지 마세요.
- **다 되면:** 바로 8단계로

### 8단계 · 열쇠 3을 클라우드에 넣기 💻 (약 2분)
- **어느 화면:** 6단계와 같은 곳 (제목 줄 환경 이름 → **편집** → **환경 변수**)
- **무엇을 쓰기:** 한 줄 추가
  ```
  YT_REFRESH_TOKEN=여기에 Refresh token
  ```
- **저장** → **새 대화를 하나 열기** (열쇠는 새 대화부터 보입니다)
- **다 되면:** 새 대화에서 "유튜브 연결 끝, 확인해 줘"

그 뒤는 회사가 합니다: 채널이 메종 에델이 맞는지 확인 → 댓글 읽기 시험 → 첫 업로드는 **비공개로 1개만** 시험해서 공개 설정이 되는지 확인 → 회장님께 보고.

## 회사가 쓸 환경 변수 이름 (정해 둠)

| 이름 | 무엇 | 비밀인가 |
|---|---|---|
| `YT_CLIENT_ID` | 클라이언트 ID (5단계) | 덜 비밀이지만 환경 변수로만 |
| `YT_CLIENT_SECRET` | 클라이언트 보안 비밀번호 (5단계) | **비밀** |
| `YT_REFRESH_TOKEN` | 새로 고침 토큰 = 오래 쓰는 열쇠 (7단계) | **비밀** |

- 실수로 채팅에 붙여 넣으셨으면: 5단계 화면에서 그 클라이언트를 지우고 새로 만들거나(비밀번호), 7단계를 다시 하면(토큰) 예전 값은 쓸모없어집니다. 회사가 순서를 안내합니다.
- 회사는 이 값들을 어떤 파일·노션·커밋에도 적지 않습니다.

## 회사 쪽 메모 (운영팀·개발팀용)

### 확인한 사실 (2026-11-01, 공식 문서)
- **권한 범위:** 댓글 답장(`comments.insert`)은 `youtube.force-ssl` 필요. 업로드(`videos.insert`)는 `youtube.upload` 등 중 하나. → 두 개만 요청. (출처: developers.google.com/youtube/v3/docs/comments/insert, …/videos/insert)
- **할당량(하루 기본 10,000):** 댓글 답장 1번 = 약 50+2 단위. 업로드는 별도 "업로드" 칸에서 하루 100번까지. 메종 에델 규모로는 충분.
- **"테스트" 상태 7일 만료:** "게시 상태가 '테스트'인 앱은 7일 후 만료되는 새로 고침 토큰을 받는다" (이름·이메일·프로필만 쓰면 예외 — 우리는 해당 안 됨). (출처: developers.google.com/identity/protocols/oauth2)
- **"앱 게시"로 7일 만료 피하기:** "프로덕션" 상태가 되려면 "앱 게시" 버튼을 누르면 됨. 민감한 범위(유튜브 범위 포함)를 인증 없이 쓰면 "확인되지 않은 앱" 경고 화면이 뜨고, 경고 후 **새 사용자 100명까지** 제한(프로젝트 평생). 회장님 1명만 쓰므로 문제없음. (출처: support.google.com/cloud/answer/15549945, /7454865)
- **토큰 개수 한도:** 구글 계정 1개·클라이언트 1개당 새로 고침 토큰 100개. 새로 만들면 가장 오래된 것이 말없이 끊김 → 7단계를 여러 번 반복하지 않게 안내.
- **클라이언트 비밀번호는 만들 때 한 번만 보임** → 5단계에서 JSON 다운로드 안내. (출처: …/guides/auth/server-side-web-apps)
- **업로드 비공개 제한 — 문서가 서로 다름:**
  - 2020-07-28 공지(변경 기록): "2020년 7월 28일 이후 만든, 검수 안 된 프로젝트에서 올린 영상은 비공개로 제한. 풀려면 감사(심사) 필요."
  - 지금 `videos.insert` 설명(status.privacyStatus 항목): "검수 안 된 API 프로젝트에서 올린 영상은 비공개로 제한되지 않는다(not restricted to private viewing mode)."
  - 이 제한을 없앴다는 변경 기록 글은 찾지 못함. → **첫 업로드는 비공개로 1개 시험**하고, 공개로 바꿀 수 있는지 실제로 확인한 뒤 회장님께 보고. 제한이 남아 있으면 그때 감사 신청서(회사가 작성)를 결재로 올린다.
- `SNS운영.md` 4번의 "감사 통과 전까지 비공개로만" 문장은 위 확인 후 고친다.

### 이 클라우드에서 접속 확인 (2026-11-01, curl)
| 주소 | 결과 | 뜻 |
|---|---|---|
| `www.googleapis.com` (유튜브 API 설명 파일) | 200 | 접속됨 |
| `oauth2.googleapis.com/token` | POST 시 400 `invalid_request` "refresh_token 없음" | 접속됨 (열쇠만 있으면 됨) |
| `youtube.googleapis.com/youtube/v3/videos` | 403 "등록되지 않은 호출자" | 접속됨 (열쇠 없이 불러서 정상 거절) |

| `developers.google.com/oauthplayground` | 200 | 열림 |

→ 막힌 곳 없음. 열쇠 3개만 들어오면 클라우드에서 바로 연결 가능.

- 한국어 화면의 정확한 버튼 글자(예: "앱 게시", "클라이언트 만들기")는 공식 영어 이름을 바탕으로 적음. 실제 화면 글자가 다르면 회장님이 말씀해 주시는 대로 고친다.

- 프로덕션 + 미인증 상태에서 새로 고침 토큰이 다른 이유로 끊기는 경우(비밀번호 변경, 6개월 미사용 등)는 일반 규칙대로 — 끊기면 7·8단계만 다시.
