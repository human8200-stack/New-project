# Able Team 강의북

에이블팀 레시피북과 같은 구조로 만든 건강 강의 도구입니다. claude.ai 아티팩트로 배포되어 있고, 이 폴더의 `lecture-book.html`은 그 원본입니다.

- 말로 기록: 강의하면서 말한 내용이나 노션 녹음 요약을 붙여 넣으면 A4 강의 카드로 정리
- 강의 만들기: 대상·시간을 고르면 강의함의 우리 팀 강의를 참고해 강의안 생성
- 강의함: 분류·제품으로 찾기, 시간 −/+, 강의 화면(슬라이드 + 대본), PDF·카톡 이미지, 표현 점검
- 한 장 요약지: 강의 여러 개를 한 장에, 제품 QR, 실천 체크리스트 복사
