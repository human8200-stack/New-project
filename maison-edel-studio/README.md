# Atelier Edel

Maison Edel(메종 에델)의 요리 영상 시리즈 **La Table d'Edel** 제작 도구입니다.
레시피를 넣으면 아래를 한 번에 만듭니다.

- 장면별(5초) 화면 글자: 재료·계량·온도만, 한국어·영어
- 자막 파일 (SRT, CapCut에서 불러오기)
- 인스타 릴스 캡션, 유튜브 쇼츠 제목·설명, 해시태그
- 전자책 원고 (Maison Edel — Seasonal Recipes)
- ChatGPT에 붙여넣을 콘티 요청문

레시피 공개 범위(전체 공개 / 맛보기 / 책 전용)에 따라 화면 글자와 캡션에 계량을 넣을지 정합니다.

## 쓰는 곳

claude.ai 아티팩트: https://claude.ai/artifact/2XCsQkLvHGH7goULaDH1sE
AI 작성은 claude.ai에서 열 때만 켜지고, 여는 사람의 Claude 계정 사용량을 씁니다.
`index.html`은 그 페이지의 원본입니다.

## 역할

| 담당 | 하는 일 |
|---|---|
| ChatGPT | 에델 캐릭터·이미지, 영상 콘티, AI 영상 생성·검수 |
| Claude | 화면 글자·자막, 캡션, 전자책 원고, 업로드 자동화 |
| 설화 | 스타일 승인, 레시피 확인, 결과물을 노션 작업실에 올리기 |

브랜드 기준(이름, 에델 캐릭터, 비주얼·영상 규칙)은 노션 'Maison Edel 작업실'에 있습니다.
